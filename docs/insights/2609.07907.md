## 四视角独立批评

### 微架构

9 IUs × 6 PEs; 32 positions × 4 colors; 160b/spin coeff record; sign-select adder tree + tanh LUT + LFSR; source-sync C2C FIFO. Silicon numbers on p.3.

### 负载

planted-MaxCut, spin-glass, frustrated-loop, semiprime factor, 3SAT.

### 仿真方法学

Measured ASIC @ 48 MHz core / 0.9 V; 41.5G updates/s aggregate attempts; TTS99 metrics. Real silicon, not only sim.

### 工业可行性

28nm HPC+ ~1.5 mm²/chip; embedding efficiency is the product story; still sparse-graph embedding tax for arbitrary COPs.

## Master Class

1. **The Real Abstract** — Scale sparse Ising with degree-15 Pegasus + scheduled multichip boundary exchange so connectivity/precision beat degree-8/5b annealers without O(N²) storage.

2. **The Rashomon Synthesis** — Theory wants denser native graphs; circuit wants O(N) SRAM; packaging wants short C2C. Shared: embedding blowup kills logical capacity.

3. **The Magic Trick** — Color-scheduled Pegasus updates create a free transfer window before remote neighbors are needed.

4. **The Skeleton in the Closet** — 41.5G is attempt rate not solution rate; hard α=8 success is sparse (2/16). Embedding quality dominates usable problem size.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 全连接数字 Ising 要 O(N²) 系数存储与每自旋 O(N) 加权和；稀疏图把邻居数封顶为 O(N) 存储，但问题嵌入会引入额外物理自旋，限制单芯片逻辑规模。(p.1)
2. 先前两片/九片 CMOS 退火器多用度数 8 的 King's 图，后者系数 5b，并靠退火中压缩自旋数据迁就片间延迟。(p.1)
3. 同一 32 自旋全连接嵌入示例：Pegasus 需 133 物理自旋，King's 图要 1,885。(p.1)
4. 片间必须交换相关更新的自旋态；若传输不能与计算重叠，多片扩展会被通信卡住。(p.1–2)
5. 四片 planted-MaxCut（27,069 逻辑节点）追踪在 3.3 µs 计算时间到达解；α=8 的另一实验 16 次运行仅 2 次到精确基态，耗时 2.9 s 与 8.9 s。(p.3)
