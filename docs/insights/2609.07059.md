## 四视角独立批评

### 微架构

Per-row SNG→Bernoulli WL; column TIA+1-bit SA+popcount; shared or per-column Vref. Array MAC physics unchanged. Missing: N vs accuracy curves, ADC baseline bit-widths compared.

### 负载

MAC-level + ViT-Base end-to-end. Not LLM decode.

### 仿真方法学

Unbiased estimator variance O(1/N); noise averaging claims; SCC/ZCE characterization. Analytical + empirical on p.1–2.

### 工业可行性

Stochastic latency (N cycles) vs ADC one-shot; RNG area; calibration of Imax/Rj. Good fit where ADC dominated power.

## Master Class

1. **The Real Abstract** — Replace multi-bit ADC digitization of noisy column current with probabilistic 1-bit comparisons averaged over N cycles.

2. **The Rashomon Synthesis** — Mixed-signal wants fewer ADC bits; theory wants unbiased MAC; layout wants shared LFSR. Shared: converter, not cell, is the scaling wall.

3. **The Magic Trick** — Encode MAC as a comparison probability so zero-mean noise averages out.

4. **The Skeleton in the Closet** — ViT gap 0.03 pp is under stated noise; LLM-scale arrays and ADC energy break-even vs N not in first pages.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 模拟 CIM 的面积/功耗/延迟常被每列读出与每行编码外设限制，而不是阵列内计算本身。(p.1)
2. 多比特 ADC 把瞬时噪声与信号一起量化进固定数字字；精度绑在 ADC 分辨率、读噪声、参考波动和随并行行数增长的电流量程上。(p.1)
3. 提高 ADC 分辨率改善保真但进一步抬高外围成本；阵列扩展往往卡在转换器而不是交叉开关。(p.1–2)
4. 逻辑随机计算里比特流相关会偏置 AND 乘；若误用同一假设会限制共享 SNG 省面积的做法。(p.2)
5. ViT-Base 上：读噪声下 Top-1 84.48% 相对 BF16 基线 84.51%；精度由比特流长度 N 而非多比特转换器分辨率决定，读出延迟随 N 线性增长。(p.1, p.3)
