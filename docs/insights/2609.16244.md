## 四视角独立批评

### 微架构

Claimed substrate on p.1–3: one 256-bit VLIW word with four 56-bit engine slots (ARRAY / VPU / DMA_LD / DMA_ST) plus a loop-control tail; dependences are an explicit wait mask—no scoreboard, rename, or runtime interlock. Instruction memory is a hard 256-word budget. ARRAY ops named: G_FWD, A_QKT, A_PV, A_DRAIN. VPU lists ten ops spanning Layer/RMS norm, adaptive modulation, residual, SiLU/GELU, RoPE, CFG combine, scaled-add sampler update, and casts. The 16×16 dual-dot cell does four FP8 or two BF16 products as an exact dot into FP32; a physical-design config halves the array to 8×8. On-chip memory is four banked regions (activations / stationary weights / accum-out / descriptors) reached by a crossbar of aligned 512-bit read pairs with a fixed per-region port budget (typically 2R1W). Softmax and epilogue sit on the array output path. Descriptor capture-at-issue and hardware walkers (base/stride/window) are the stated software-pipeline hook. Exact cycle schedules, port conflict tables, and full-chip P&R beyond the five routed engines live after p.3.

### 负载

Diffusion-transformer inference, not autoregressive decode. Image-class shape cited: N=128, d=256, h=4, d_h=64; video-class extends N and head count. Same block is also claimed for diffusion robot policies, the AlphaFold 3 diffusion head, and vector-set 3D assets—hence the eleven published-shape benchmarks. Serial dimension is denoising step count T; product metric is per-step latency (time-to-image), not batch throughput. Each weight byte is reused T×B times more than a single forward; no growing KV cache, so on-chip capacity is sized by the layer working set. Operator extras vs a training accel: SiLU/GELU PWL, adaptive LayerNorm modulation, CFG combination, sampler update z ← az+b; host supplies noise tiles (no on-chip RNG). Arithmetic: FP8 E4M3 and BF16 with FP32 accumulation. Two author-reported falsifications of their own workload analysis: batching a guidance pair does not amortize the weight stream on this program, and the original diffusion-transformer head dimension does not fit the fused attention pipeline at this on-chip capacity.

### 仿真方法学

p.1–3 give the verification contract and a few measured-control claims, not a full eval chapter. Acceptance is semantic and frozen before RTL: run a real denoising trajectory and cut MSE against a clean latent by ≥10×; reported 23× at both synthesized configurations, zero element failures across 237 million checked values, UVM vs a double-precision reference. Software-pipelining result (schedule-only, no RTL change): multi-engine concurrency 1.83% → 44.66% of cycles, measured 1.484× with unchanged arithmetic. Five engines taken to routed sky130 layout with parasitic-annotated timing and measured-activity power; full chip synthesized; the host limit that stopped P&R is named as quantified but not given a number on p.1–3. Treat 99.4% occupancy / 23× / 1.484× as author-reported.

### 工业可行性

Story is a compile-time-static, latency-first inference engine for diffusion world models—closer to a frozen VLIW ASIC/IP than a general GPU. Lean-out of optimizer, backward, and on-chip RNG is explicit. Adoption hinges on accepting sky130 open-source physicals plus a 256-word IRAM wall: the authors already report that the original diffusion-transformer head dimension misses the fused attention fit, and that host P&R—not the RTL argument—stopped the full chip. The semantic (trajectory-MSE) gate is the verification sales pitch versus element-wise tolerance. Independent, self-funded; no foundry product node on p.1–3 beyond sky130.

## Master Class

1. **The Real Abstract** — Diffusion inference is a compile-time-static full forward over a fixed-shape latent; the only serial dimension is T. Build a latency-first VLIW multi-engine that keeps one denoising step short, not a dynamic-issue core or a growing-KV decoder.

2. **The Rashomon Synthesis** — Autoregressive people drag token recurrence and KV history; diffusion people have static shapes and T-step reuse; compiler people can place every move at a fixed offset; classical VLIW skeptics object to data-dependent control that this workload does not have.

3. **The Magic Trick** — One instruction word issues four engines with explicit wait masks; keep weights stationary on a dual-dot array and stream attention as single-pass online-softmax so it matches the feed-forward contraction.

4. **The Skeleton in the Closet** — Occupancy / MSE / software-pipeline speedups are unread beyond the opening claims; 256-word IRAM is a hard architectural budget; the original head dimension does not fit fused attention; full-chip P&R already failed on the host; the rescale chain is numerically delicate exactly where low-precision scores saturate toward one-hot.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 自回归解码在每层每步拖着 token 级串行依赖；扩散模型对固定形状隐变量做完整前向，唯一步间串行维是去噪步数 T，步内形状在编译前已知。(p.1)
2. 产品指标是单步时延而非批吞吐：单步时延减半则出图时间减半，批吞吐加倍并不等价缩短 time-to-image。(p.2)
3. 同一套权重在 T 步、批大小 B 下相对单次前向多复用约 T×B 倍，把权重装载开销摊到整条轨迹上成为一阶压力。(p.2)
4. 相对自回归，扩散轨迹没有不断增长的 KV cache；片上容量主要按层工作集而非序列历史定标。(p.2)
5. 流式 soft-max 在运行最大值抬升时要对已累积输出与分母做再缩放；在低精度分数饱和、分布趋近 one-hot 的区间，这条再缩放链在数值上脆弱。(p.2)
6. 原始扩散 Transformer 的头维在给定片上容量下装不进融合注意力流水线；把引导对批在一起也不能在该程序上摊掉权重流。(p.2)
