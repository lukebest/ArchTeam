## 四视角独立批评

### 微架构

Endpoint validation; protected NACK + full-flit replay for Class-H; per-region interval table; ordered per-VC staging. Decouples whether-to-replay from where-to-restart.

### 负载

BF16-like tensors; synthetic Garnet traffic; DeiT-S communication traces; DenseNet-121/ESC-50 fault-injection anecdote (exp-MSB → 2.0% acc).

### 仿真方法学

gem5 Garnet protocol; ASAP7 pipelined checker II=1; ten-seed campaigns; CRC32 silent-delivery bound 3.18e-7 (95%).

### 工业可行性

Needs link BER regime + ECC/CRC integration; semantic classes are format-calibrated (BF16-like); policy that also replays Class-M hurts quality in their wrapper study.

## Master Class

1. **The Real Abstract** — Don’t uniformly protect/replay AI flits—gate replay by numerical consequence and shrink recovery distance only where geography is noisy.

2. **The Rashomon Synthesis** — Reliability wants zero silent catastrophe; latency wants fewer replays/checkpoints; geography of faults is nonuniform.

3. **The Magic Trick** — Split semantic eligibility from geographic restart distance; Class-H may NACK/replay, Class-M/L do not default-replay.

4. **The Skeleton in the Closet** — Operating point is synthetic BER; DenseNet collapse is motivational not the main NoC campaign; quality metric definition drives Ψdel ranking.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. AI 张量穿越 NoC/片间/晶圆级织物/HBM 等链路时，低位尾数翻转可像量化噪声，高位指数翻转可造成离群或非有限值并主导归约/污染状态。(p.1)
2. DenseNet-121/ESC-50 故障注入中，指数 MSB 故障使训练精度跌到约 2.0%（随机水平）并在后续检查点保持，干净对照约 83.3%。(p.1)
3. 固定 34-hop 恢复基线在基础 BER 约 3×10⁻⁵ 的十点种子实验中，是主要对照；语义感知地理恢复相对其报告 Ψdel 约降 30.1%，平均延迟约降 28.0%。(p.1–2)
4. 更高 BER、相同注入负载下，固定基线会堆积 backlog，而地理自适应间隔策略仍保持有界队列（作者叙述）。(p.1–2)
5. 若让有界的 Class-M 故障也触发重放：在相同有限重试预算下，每原始包重试 DATA flit-hop 约×2.30，丢包率约 7.42%→21.64%，交付语义质量约降 8.3%。(p.2)
