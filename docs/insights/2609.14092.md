- One-line hardware fact (from p.1–2 only): heterogeneous sparse accelerator with dual ANN and SNN core types that co-execute at output-element granularity (shared bitmap FiberCache/memory hierarchy; mode switch on PE control path, INT8 storage); abstract claims 97–99% PE utilization vs 40–45% layer-wise hybrids, 57–67% EDP cut vs strong ANN-only, up to 2.5× vs dual-sparse SNN-only, scheduler +16–19% throughput vs random assignment.

## 四视角独立批评

### 微架构

Claimed substrate: dual sparse vector engines (ANN MAC vs SNN accumulate-over-T), element-level assignment, shared bitmap-encoded FiberCache / memory hierarchy, on-the-fly spike generation keeping spikes 1-bit with threshold scaling absorbed into weights at compile time (INT8 throughout; mode switch changes control, not storage format). Offline cost-guided scheduler (simulated annealing, element-flip moves) is software-side packing—ask whether it stays offline-only. Exact PE counts, FiberCache ports, and timestep pipeline are after p.2.

### 负载

Edge inference across CNNs / transformers / LLMs. Fig. 1: VGG-16 conv3_3 (256→256, 3×3 → 3136×256 GEMM); 63.0% activation sparsity + 80% globally pruned weights; surviving non-zero matches vary several-fold across output elements; 16×16 tiles mix high- and low-work cells. Dual-sparsity multiplicative skip is the shared premise with prior ANN-only sparse accelerators; SNN path trades energy for T-step latency.

### 仿真方法学

Abstract reports EDP/speedup/utilization vs SparTen and LoAS and vs layer/tile hybrids. p.1–2 give Fig. 1 workload map and qualitative hybrid failure modes; full RTL microbenchmark coefficients for the scheduler and end-to-end tables are unread. Treat 57–67% / 2.5× / 97–99% as author-reported.

### 工业可行性

Story is finer-grained hybrid than layer/tile switching without accuracy loss—depends on accepting an integer-exact ANN↔SNN equivalence (prior work named on p.2) as a training/conversion contract. Offline annealing assignment may not fit dynamic serving; shared memory hierarchy helps, but dual core types still burn area when one side is cold. Edge NPU vendors already ship sparse MAC paths; buying a second SNN datapath needs a clear utilization story beyond paper hybrids at 40–45%.

## Master Class

1. **The Real Abstract** — Dual-sparsity work is uneven across output elements; layer/tile hybrids idle half the silicon; push mode choice to the finest inner-product grain without conversion error.

2. **The Rashomon Synthesis** — Sparse-ANN people want single-pass MAC; neuromorphic people want accumulate-only spikes; hybrid people keep switching too coarsely and watching PE utilization collapse.

3. **The Magic Trick** — Prove local integer equivalence per output element, then schedule each element onto the cheaper core while sharing one sparse memory fabric.

4. **The Skeleton in the Closet** — Headline EDP/speedup numbers are unread beyond p.2; scheduler is offline annealing; “first element-level” is positioning; related-work section on p.3 will name the conversion lineage the accuracy claim rests on.

5. **可提取的问题线索**（仅 p.1–2，有数字，无机制名）

1. 边缘推理把功耗与时延预算当成一阶约束；同一模型层内不同输出元素存活的非零匹配数可相差数倍，工作量在输出矩阵上极不均匀。(p.1, Fig.1)
2. 在 VGG-16 中层卷积（256→256、3×3，im2col 成 3136×256 GEMM；图示 128×128 裁剪）上，约 63.0% 激活稀疏、约 80% 全局剪枝权重后，仍需算术的有效非零匹配在输出元素间分布极不均匀，16×16 tile 内可同时含高/低工作量元素。(p.1, Fig.1)
3. 仅 ANN（MAC）执行快但功耗高；仅 SNN（多时间步累加）更省操作能量但时延随时间步 T 放大——能量–时延权衡在层内元素间并不均匀。(p.1)
4. 按整层在 ANN/SNN 间切换时，一种核在工作另一种核就闲置，层级混合在评测中 PE 利用率可落到约 40–45%。(abstract / p.1–2)
5. 按固定 tile 独立路由仍迫使 tile 内高低匹配元素共用一种模式，tile 内变异吃不到；更细粒度若依赖有损 ANN→SNN 转换，则每个被路由到脉冲路径的单元都会用精度换能量，误差在单元素上难以靠平均抹平。(p.2)
6. 历史近似转换靠层/模型级校准把误差摊薄；落到单个输出元素时没有这种摊薄，细粒度混合长期被视为不安全——需要在不读后续解法的前提下，把「层内元素级能量–时延失配 + 粗粒度混合闲置」当作开放硬件问题。(p.2)
