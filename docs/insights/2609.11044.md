## 四视角独立批评

### 微架构

Start from a systolic AI chiplet; add flexible PE datapath and register-access so the same array maps CNN/MLP and irregular pathology ops. Operator set on p.1: feature aggregation, load-balanced execution, Euclidean distance, binning, counter aggregation. Spatial locality of cell-graphs is an explicit design goal. Area increment is the 1.1× chiplet tax.

### 负载

Whole-slide pipeline: nuclei segmentation (CNN) → features → kNN edge config → iterative GCN (vertex-centric Aggregation / edge-centric Combination). CGC-Net: 139 slides, \(4548\times7520\) @20×, ~12 h on 4× TITAN V. Clinical WSI up to \(\sim150000\times100000\). Cell-graphs can be millions of nodes/edges. Fig. 2 (CRC, 8 images) starts on p.3 without readable bar numbers in this scope.

### 仿真方法学

Motivation is baseline inefficiency on CPU / GPU / AI / GCN platforms; software re-structuring is paired with PE mods. Headline 56×/14× live in the p.3 contribution list; mapping, cycle model, and EnGN setup begin after p.3 and are unread.

### 工业可行性

AI+X is a volume argument: pathology alone cannot amortize a custom die; a 1.1× AI chiplet can if it still ships as an AI part. Small-market X (genomics / graph mining / FHE cited as cautionary) is the commercial failure mode if the extra operators tax the AI common case.

## Master Class

1. **The Real Abstract** — Don’t build a pathology ASIC. Put a thin operator set on a systolic AI chiplet so one on-chip resource pool eats both regular CNN/MLP stages and irregular kNN/aggregation.

2. **The Rashomon Synthesis** — Clinics need repeated retrain on huge WSIs; GPUs diverge on irregular stages; dedicated GCN chips assume power-law edges; AI chips assume regular GEMM.

3. **The Magic Trick** — Flexible PE datapath + register access so aggregation, Euclidean kNN, binning, and counters share the AI array (AI+X, 1.1× area).

4. **The Skeleton in the Closet** — 56×/14× are unread end-to-end claims; Fig. 2 has no extractable phase % on p.1–3; “software re-structuring” is named on p.1 but not specified in this scope.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 过去十年病理医师数量下降超过 17%，诊断一致性不足；院内本地数据往往不够训可靠分类器，扫描仪/软件升级还会使旧模型失效，需要在大数据上反复重训/再校准。(p.1)
2. 在 4× TITAN V 上，仅 139 张全切片（4548×7520、20×）训 CGC-Net 就要约 12 小时；实际全切片可达约 150000×100000 像素，训练时长进一步恶化。(p.1)
3. 计算病理流水线含核分割/特征、kNN 构图、以及交替 Aggregation/Combination 的迭代 GCN；kNN 常用顺序索引或暴力法，顶点中心聚合被高数据搬运主导，不规则阶段在 GPU 上易线程发散。(p.2)
4. 为各阶段做独立模块会复制片上缓冲并在设计期固定资源配比，运行时易负载失衡；专用 GCN 加速器常依赖幂律边分布，而病理 kNN 图顶点边数相近，既有策略失效；基线 CPU/GPU/AI/GCN 平台上该流水线整体低效。(p.2)
5. 非 AI 小市场加速器难复制 AI 芯片的商业规模；需要能同时吃 CNN/MLP 规则阶段与 kNN/聚合不规则阶段的同一套片上资源，否则小市场 X 难以摊销制造成本。(p.1–2)
