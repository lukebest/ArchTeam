## 四视角独立批评

### 微架构

Mechanism candidates on p.1–3: (1) periodic tile partition of the planar-mesh qubit graph (Fig. 2 example tilesize=5); (2) substrate phonon barriers on tile boundaries with permeability bp; (3) interleaving multiple independent QEC codes so virtually-neighbor qubits sit farther apart physically (p.1–2). Barrier physics is treated abstractly — not a specific trench/metal stack (p.3). Width–permeability toy model w(bp)=10√((1−x)/x) with bp∈[0,0.01] and experimental attenuation cited at **2–100×** for Al strips **10–100 µm** (p.3). Missing: decode graph changes under interleaving, coupler routing congestion, and how barriers interact with microwave control lines.

### 负载

“Workload” is fault-tolerant QEC under radiation: rotated surface code, degree ≤4 planar connectivity, MWPM-style decoding (p.2–3). Radiation transients last **µs–tens of seconds** while a QEC round is **a few µs or less**, so one event spans many rounds (p.2). Event rate cited **once/hour → multiple/minute** (p.2). Abstract’s **>51M** circuit sims / **>99.8%** peak logical-error cut / **80%** transient-duration cut / **87%** barrier-tracing cost cut are unpaid in the first three pages beyond the claim list.

### 仿真方法学

Opening promises modeled radiation transients over many barrier + interleaving configs (abstract). Permeability and tile size are first-class sweep axes (RQ1–RQ5, p.2). First three pages do not specify soft-error vs quasiparticle burst model, decoder version, or distance-d scaling plots. Treat 99.8% / 51M as author headlines pending unread §V.

### 工业可行性

Per-qubit barriers/traps are called not cost-effective at scale (p.3); underground shielding does not scale (p.1, p.3); suspended qubits / gap engineering add manufacturing variance (p.1, p.3). Selective tiling is the cost lever — but real bp floors, cryogenic process modules for barriers, and yield of long barrier perimeters are unpaid. Abstract’s **87%** barrier-tracing saving via sparser tiles is exactly the industrial question: how sparse before correlated faults re-enter the code distance.

## Master Class

1. **The Real Abstract** — Radiation dumps correlated, locally dense defects that sit outside sparse QEC assumptions; qubit radiosensitivity ≫ CMOS. Tile the mesh, put permeable phonon barriers on tile edges, and interleave independent surface-code patches to raise physical distance between code-neighbors — no extra round/decode time claimed (p.1–3).

2. **The Rashomon Synthesis** — Microarch cares about tile size vs coupler routing; “workload” is the radiation + QEC envelope (µs rounds vs seconds-long transients); tools want the 51M-sim protocol; industry asks whether sparse tiling still works at bp floors of real processes. Agreement: correlated bursts are the threat model.

3. **The Magic Trick** — Don’t barrier every qubit; barrier tile boundaries and move code-neighbors apart in space so one radiation puddle cannot cover a logical neighborhood.

4. **The Skeleton in the Closet** — Effectiveness hinges on bp∈[0,0.01] and a simple w(bp) cost model (p.3); first three pages do not validate that model against a named foundry barrier module. Interleaving’s decode/layout tax is asserted zero — unpaid.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 外部辐射在超导量子器件上会触发同一衬底上多比特同时、空间相关的缺陷，足以让面向稀疏非相关错误的 QEC 失效。(abstract / p.1)
2. 量子比特对辐射的敏感度比 CMOS 晶体管高约数千倍，可能成为规模化量子计算机的绑定约束。(p.1)
3. 辐射诱发事件频率约从每小时一次到每分钟多次；瞬态可持续微秒至数十秒，而一轮 QEC 纠错约数微秒或更短，故单次事件常跨越多轮纠错。(p.2)
4. 地下屏蔽降低外部通量但难以规模化；能隙工程、悬空比特、逐比特准粒子势垒/陷阱等方案会抬高制造成本并在逐比特尺度引入可扩展性约束。(p.1 / p.3)
5. 衬底声子势垒/沟槽等硬件加固若按逐比特铺满，制造成本随比特数线性上升，性价比差。(p.3)
6. 铝条势垒实验衰减约在 **2–100×**，宽度约 **10–100 µm**；工程上可实现的渗透率质量因子大致落在 bp∈[0, 0.01]（越接近 0 越不透）。(p.3)
7. 单芯片上会嵌入越来越多彼此独立的逻辑比特/QEC 码块；若码内“逻辑相邻”的物理比特在芯片上仍挤在一起，一次局部辐射团更容易同时打中同一码的多个相关位置。(p.1–2)
