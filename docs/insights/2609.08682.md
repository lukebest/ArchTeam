## 四视角独立批评

### 微架构

Not a new NMP chip; mapping/scheduling over distributed banks. Continuous Pic allows partial expert split (TP-like). NoC sim Mesh/Torus/Fat-tree.

### 负载

MoE LLM inference (Qwen2-57B-A14B etc.). Metrics TBT/speedup.

### 仿真方法学

Unified cost model + discrete-event NoC sim (Ns3/BookSim-inspired). Claims 1.1–3.4× vs TP, 1.1–1.5× vs EP, etc. Ranges are wide.

### 工业可行性

Deployable as compiler/runtime on existing 3D NMP; hardware-aware gating perturbs model—needs accuracy SLA. TCAD acceptance helps credibility.

## Master Class

1. **The Real Abstract** — On 3D NMP, mix TP for hot experts and EP for cold/co-activated ones, then adapt online when routing skew and NoC cost disagree with gate scores.

2. **The Rashomon Synthesis** — Parallelism people pick TP vs EP; NoC people see hotspot links; model people see gate scores. Shared: sparse routing × distributed banks = imbalance or all-reduce.

3. **The Magic Trick** — Treat near-boundary expert choices as fungible so hardware cost can break ties.

4. **The Skeleton in the Closet** — Speedup ranges start at 1.1×; gains depend on skew. Gating perturbation bounds only sketched via cosine similarity on p.3.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. MoE 稀疏激活降低算量却抬高内存容量/带宽需求，在带宽小、batch 小的边缘侧更明显。(p.1)
2. 3D NMP 内存/计算分布在多 bank+NoC：纯 TP 每专家跨 bank 切分，负载均衡但 all-reduce 通信重；纯 EP 整专家落不同 bank，通信轻但动态路由造成计算不均衡。(p.1–2)
3. 大 GPU 集群可用专家复制缓解不均衡，但内存受限的 3D NMP 上复制不现实；静态部署难跟动态专家激活。(p.1)
4. Qwen2-57B-A14B-Instruct 上少数专家吃掉大量 token、多数很少被激活，且存在强共激活亲和；近边界专家分数接近但 batch 负载可差很多。(p.2–3)
5. 只有少数被选专家拿走主导门控分数，替换低排名已选专家为近边界未选候选时输出余弦相似度仍高——模型偏好与硬件代价错配。(p.3)
