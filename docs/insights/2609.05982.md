# 2609.05982: CMD: An Integrated CGRA Framework with Cluster-Based Distributed Memory Design (first-3-pages note)

- arXiv: [2609.05982](https://arxiv.org/abs/2609.05982) · PDF: [arxiv.org/pdf/2609.05982](https://arxiv.org/pdf/2609.05982)
- Venue: ICCD 2026 (cs.AR)
- Domain tag: CGRA memory fabric / NoC-adjacent
- One-line hardware fact (from p.1–3 only): CGRA partitioned into clusters; each cluster shares a multi-bank data memory (banks = cluster size) plus arbiter/coherence; MESI-like coherence controller with varInfoTable; DMA loads at config.
- Reading scope: **PDF pages 1–3 only**. Methods/eval unread by design where they begin after p.3.

## 四视角独立批评

### 微架构

Cluster-local multi-bank DM; mesh tiles; coherence packet to controller; explored cluster sizes {1,2,4,6} on 6×6. Missing on p.1–3: bank conflict model, NoC hop cost of coherence, clock/tech.

### 负载

Kernel DFGs (vector add/mul, gemm); II-centric mapping. Domain/app DSE mentioned, not LLM.

### 仿真方法学

Post-DSE average 1.39× speedup, area 0.912× vs conventional (abstract). Metrics: CompEff, MUR, COR. Mapper is heuristic; no RTL area breakdown on p.1–3.

### 工业可行性

Distributed CGRA memory + compiler DSE is productizable for DSP/ML kernels; coherence traffic and per-kernel retuning of cluster/mem size are the integration tax.

## Master Class

1. **The Real Abstract** — Replace centralized CGRA memory ports with cluster-local multi-bank memories plus a mapper/DSE that picks cluster and bank size per kernel set.

2. **The Rashomon Synthesis** — Architects see port count; compilers see II/routing; SoC sees coherence. Shared: centralized memory ports inflate II.

3. **The Magic Trick** — Give each small tile group its own banks so mapping stops wasting tiles as routers.

4. **The Skeleton in the Closet** — Headline 1.39×/0.912× is after DSE; bad cluster size (1) only 1.15×. Coherence cost under write-heavy kernels not quantified in opening.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 常规 CGRA 用阵列旁全局数据存储器，每周期只有有限位置/数量的 tile 能访存（如仅最左列，或每行/列仲裁一个），访存密集核易卡住。(p.1)
2. 2×2 示例向量核理论 MII=4，受访存路由约束后映射 II 升到 5；若干 tile 只做搬运，计算效率被拉低。(p.2)
3. 6×6 上 gemm：cluster size=1 时归一化加速仅约 1.15×，MUR 仅 8.33%；cluster=6 时加速约 1.56×、MUR 50%——同一设计参数扫出大幅波动。(p.2–3)
4. 变量可能被多 cluster 需要而多份存放，写后必须同步；示例一致性包可达 68×4 bit。(p.3)
