## 四视角独立批评

### 微架构

Systolic-array DNN accelerator; no new PE topology drawn. Quantization: each layer is tried at candidate bit-widths, accuracy drop vs full precision is recorded, then a greedy search reduces precision from the least-sensitive layers until accuracy-drop budget τ, producing profile b = [b₁…b_K] (later also written as [b₁…b_L] layers). Symmetric constraint bits(Wᵢ) = bits(Aᵢ) = bᵢ so packing is deterministic. Slot cost φᵢ = 2bᵢ. Safe-FFD: sort slots non-increasing φ, first-fit into words of width R subject to Σ 2bᵢ ≤ R and overflow Σ (2^{bᵢ}−1)² < 2^R; no operand crosses a register boundary. Slack sⱼ = R − Σ 2bᵢ. Density dⱼ = pairs per word; K_eff = |J| words. Compile-time only—authors say no hardware reconfiguration. Critical layers: MSB of each quantized weight is replicated twice into slack (TMR); a majority voter reconstructs the MSB, replicas are logically cleared, then multiply. Sim PE: one packed word/cycle; subword MAC via compile-time posₖ / maskₖ; C_{t+1} = C_t + Pⱼ. Protected-layer vote claimed in parallel with data movement, “negligible latency.” R examples 16 or 32. Array size, PE area, process node not on p.1–3.

### 负载

Edge DNN inference on fault-prone hardware (voltage scaling, radiation, manufacturing variability); safety-critical examples named: autonomous driving, medical diagnostics. Models named for the unread eval: AlexNet, VGG-11, ResNet-18. Homogeneous precision vs mixed-precision is the accuracy/efficiency tension; MAC-count and memory footprint are the efficiency axes. This is compile-time packing of a static bit-width schedule, not runtime bit-fusion.

### 仿真方法学

Abstract: “up to 62% memory reduction and up to 56% reduction in MAC operations,” plus “significantly improving accuracy resilience under fault injection” vs baseline and fully protected models; RAP vs P_drop across bit-error rates. No BER table, no RAP/P_drop numbers, no array dimension on p.1–3. Method sketch: parameterized systolic-array sim (FPGA-style), offline Safe-FFD traces, register-level SIMD, fault injection. Treat 62%/56% and “significantly improving” as unpaid until unread §III plots.

### 工业可行性

Story is software/compile-time packing on an otherwise unmodified systolic array plus a lightweight MSB voter. Symmetric W/A bit-widths and no runtime reconfiguration are the product constraints. Slack-funded TMR only covers MSBs of “critical” layers—not full ECC. Adoption needs a trustworthy sensitivity profile and a τ that still packs; overflow constraint (4) may reject dense packs. No process node, area, or energy on p.1–3. BEC2026 accepted paper; six pages total.

## Master Class

1. **The Real Abstract** — Edge DNNs must compress hard and still survive faults; spend mixed-precision slack inside fixed registers so leftover bits become both SIMD width and cheap MSB replicas.

2. **The Rashomon Synthesis** — Quantization people assign bits per layer; SWAR people pack homogeneous subwords; reliability people bolt on ECC/TMR after the fact. The unused bits in a mixed-precision word are the same resource all three are fighting over.

3. **The Magic Trick** — Greedy sensitivity bit-widths with W=A; Safe-FFD-pack heterogeneous pairs into R-bit words; copy the MSB of critical weights twice into leftover slack and majority-vote before the MAC.

4. **The Skeleton in the Closet** — Opening pages give 62%/56% with no setup; τ, candidate set B, and which layers are “critical” are knobs without a closed sensitivity on p.1–3; overflow-safe packing can leave more slack than TMR needs or not enough; voter “negligible latency” is unpaid; array size unstated.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 边缘加速器上的 DNN 要同时做激进压缩并在故障易发硬件上保持可靠；现有 ECC、冗余或比特级保护虽能提升韧性，却常带来显著的内存、面积与能耗开销。(p.1)
2. 各层对量化误差敏感度不同，同质位宽难以兼顾；现有混合精度路径又多依赖再训练或计算昂贵的神经架构搜索，且故障保护常与量化决策彼此独立。(p.1)
3. 定宽寄存器上的 SWAR 思路能把多个低比特操作数打进同一字，但现有做法多假设同质操作数位宽或依赖运行时硬件重配置，也未把敏感度驱动的量化与故障保护嵌进打包过程。(p.1)
4. 在定宽寄存器（文中仿真例为 16 bit 或 32 bit）里，混合精度的权重–激活对会留下未用空隙；若不做联合设计，这些空隙既难变成有效并行度，也难低开销地承载冗余。(p.2–3)
