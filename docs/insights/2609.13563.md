## 四视角独立批评

### 微架构

Intro problem is dual-class traffic on one fabric: events need low deterministic latency and may drop; non-events need reliability. Abstract/Fig.1 sketch routing chiplets in a 2D mesh, each attachable to a BSS-2 ASIC or FPGA. p.2 schematic (solution territory) already shows phit decode, weighted arbiter, flit gearbox/CRC, ARQ, credit, and separate event vs wormhole non-event paths—readers doing first-3-pages criticism will see the widgets but must not treat them as vetted. Physical link context named: C2C links ≤1×10⁻¹⁰ BER at 2 Gbit/s; ~11 data links/direction → ~22 Gbit/s/port; DDR 22-bit phit / 1 ns.

### 负载

BrainScaleS-2 mixed-signal SNN: continuous-time analog neurons/synapses + ADCs + embedded processor; up to 512 neurons / 131072 synapses; ~1000× biological real-time; plasticity on the embedded CPU. Spikes carry timing, not payload; small spike loss OK; config and processor messages are not. Surrogate-gradient training is the abstract’s bandwidth-stress use case (spike-to-secured ratio sweeps).

### 仿真方法学

Abstract validates in simulation (95% utilization, BER 1×10⁻¹⁰). p.3 mentions CXXRTL cycle-accurate C++ model + high-level link/traffic models—methodology detail is solution/eval adjacent. No silicon measurement on p.1–3. Treat utilization/jitter claims as unpaid.

### 工业可行性

Story is chiplet scaling of an existing mixed-signal neuromorphic SoC (65 nm analog core that will not ride process the way digital does). Yield/binning/modularity arguments are standard chiplet sales; the hard product question is whether one physical D2D class can honestly multiplex lossy timed spikes and ARQ’d control without wrecking either. HBP/EBRAINS funding lines on p.1—research platform first.

## Master Class

1. **The Real Abstract** — Scale fixed-size analog SNN tiles with chiplets only if the interconnect can carry loss-tolerant timed spikes and loss-intolerant control on the same wide parallel link without freezing continuous-time biology.

2. **The Rashomon Synthesis** — Analog designers cannot pause the core; network people hate static bandwidth partitions under bursty spike/control mixes; reliability people refuse to run config over best-effort fabric.

3. **The Magic Trick** — Unify two traffic classes on one D2D phit stream with class-aware reliability (best-effort timed spikes vs secured flits).

4. **The Skeleton in the Closet** — Event router itself is explicitly out of scope (broadcast stand-in for eval); 95% utilization is sim-only; §II on p.2 already dumps the full microarch—first-three-page “problem only” discipline is easy to violate here.

5. **可提取的问题线索**（仅 p.1，有数字，无机制名）

1. 模拟脉冲神经元/突触是固定硬件资源、不能复用时分复用；可仿真网络规模被物理拷贝数直接封顶（文中现网片：最多 512 神经元、131072 突触）。(p.1)
2. 模拟核面积受限，不像嵌入式数字处理器那样随先进工艺节点显著受益；要把混合信号神经形态系统做大，片上单片放大代价高，芯粒扩展成为现实压力。(p.1)
3. 模拟神经元/突触是连续时间仿真、不能停表；放大后的系统必须全局异步运行。拥塞会改变脉冲到达时间，因此拥塞脉冲往往只能丢弃，不能靠停顿排队来保时序。(p.1)
4. 脉冲本身几乎无载荷、信息在到达时刻；系统可容忍少量丢脉冲，但配置数据与片上处理器交换的消息必须可靠正确——同一扩展互连要同时承载这两类截然不同的流量。(p.1)
5. 现网片相对生物实时约 1000× 加速，嵌入式处理器还要跑复杂可塑性规则；扩展后若互连把配置/处理器流量与脉冲流量硬性割裂或静态切分带宽，负载不均时会同时伤实时性与可用性。(p.1)
