## 四视角独立批评

### 微架构

Event-driven control plane beside hierarchy; session register file; unified eviction+migration state; claims undecomposable into independent IPs/SW without failure modes. Kendall τ>0.998 vs FP ranking.

### 负载

Agent loops (tool waits); SWE-bench + GAIA; 1415 sessions / 33596 turns; three model families; six capacity envelopes edge→cloud.

### 仿真方法学

Trace-driven hit/AMAT/TTFT vs Belady/recency/timeout/ETA; HW area/power for 64 sessions. Learned RL policies rejected as too slow (100s µs–ms vs µs budget).

### 工业可行性

Tiny scheduler core is cheap; needs tight coupling to serving runtime events; structural-necessity claim is the adoption gate vs software proxies.

## Master Class

1. **The Real Abstract** — Rank who leaves and who sits in fast tier from each session’s own gap history and turn progress, not recency/timeout that mistake a live tool wait for coldness.

2. **The Rashomon Synthesis** — Serving wants TTFT↓; pool wants hit rate; agent runtime already emits gap/turn signals that eviction proxies ignore.

3. **The Magic Trick** — One live ranking drives both eviction and idle-window DMA tiering beside the memory hierarchy.

4. **The Skeleton in the Closet** — Necessity-of-hardware argument is structural analysis; end-to-end depends on event fidelity and capacity envelopes chosen in traces.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. Agent 循环在工具等待期间仍驻留增长的 KV 前缀，并把许多会话压进同一 SRAM/HBM 池；驱逐与层次放置变成会话级效率问题，与算力模式优化正交。(p.1)
2. 同一十二轮会话：agent-resident 合同在每次工具等待保留前缀，request-scoped 则每次 decode 后丢弃缓存；工具等待是计划内返回，不等于多轮聊天的人类停顿。(p.1)
3. 1 415 会话、三模型族的编码/网页代理轨迹上，前缀 token 单调涨入边缘与云侧 SRAM/HBM 包络，预算装不下 live set 时会话级调度不可避免。(p.1–2)
4. 基于近因、超时或 ETA 的代理在六条轨迹与六种容量包络上，AMAT、额外 prefill 与 TTFT 都高于 Bélády next-reference 上界。(p.2)
5. 近内存调度器的单次决策预算约在个位数微秒；学习式替换若每决策要数百微秒到毫秒，会超出该流水线约两个数量级。(p.2–3)
