# 2609.04266: Time-Domain Analog Softmax for CIM Attention (first-3-pages note)

- arXiv: [2609.04266](https://arxiv.org/abs/2609.04266) · PDF: [arxiv.org/pdf/2609.04266](https://arxiv.org/pdf/2609.04266)
- Venue: IEEE-style preprint (v1 2 Sep 2026; cs.AR primary, cs.LG). GlobalFoundries 22-nm FDSOI circuit study.
- Domain tag: compute-in-memory / analog attention peripheral / time-domain computing
- One-line hardware fact (from p.1–3 only): 128-element analog softmax peripheral that turns CIM score voltages into normalized attention weights via a shared falling ramp, comparator score-to-time events, RC-decay sampling for exponential weights, and in-circuit normalization — temperature set by ramp slope and RC τ, not weak-inversion MOS.
- Reading scope: **PDF pages 1–3 only** (through early §II.B exponential-weight generation). Full §III–IV eval unread by design.

## 四视角独立批评

### 微架构

Boxes visible by p.3: shared ramp generator + comparator array (score→time) → pulse/RC sampling onto exponent caps → approximate normalizer (Fig. 1). Explicit rejection of weak-inversion source-coupled softmax: that path needs all inputs inside weak inversion, so usable VIN range collapses toward moderate/strong inversion (p.1–2). Programmability knobs named: ramp slope SR via VBIAS / CR, and τE = RHRS·CE with memristor held in HRS (p.2–3). Element area 70.2 µm²; full 128-way array 9453.42 µm² including shared ramp (abstract). Missing on p.1–3: how approximate normalization is wired, ADC-free handoff into the next CIM stage, and whether one shared ramp skews across 128 comparators.

### 负载

Workload is Transformer attention softmax over CIM-generated score vectors; sequence length / head count appear only as “as sequence length and model size increase, softmax becomes non-negligible” (p.1). MemTorch decoder-only Transformer is named for later HW-aware eval (abstract) — not exercised in the first three pages. No LLM serving batch, no KV-cache story. Score-range drift across heads/layers/array gain is the stated reason temperature must be programmable (p.2).

### 仿真方法学

Headline numbers are transistor / post-layout: 242.97 ns eval latency, 13.44 mW, 25.5 pJ/element, simultaneous-128 RMSE 24.46 mV vs ideal softmax; MemTorch validation loss 1.7868 vs ideal 1.7435 (~2.5%) (abstract/p.2). Corners promised: capacitance variation, mismatch, PVT, Monte Carlo, shared-interconnect parasitics (abstract). First three pages do not report Monte Carlo N or which Softmax digital/mixed-signal baselines. Treat endpoint Transformer loss as unpaid until §IV.

### 工业可行性

22-nm FDSOI + programmed HRS memristor for τE is a two-technology stack; programming is “only when operating condition is configured,” not per vector (p.3) — still a fab/integration tax. Shared interconnect parasitics are already flagged as an accuracy threat (abstract). Product path needs: VIN dynamic-range vs ramp linearity, retention of HRS τ under temperature, and whether 24.46 mV RMSE survives end-to-end attention at realistic sequence lengths. Not answered in first three pages.

## Master Class

1. **The Real Abstract** — CIM can emit analog attention scores, but softmax needs exp + normalize; weak-inversion analog softmax is range-starved. Convert scores to time with one falling ramp, sample an RC exponential, normalize in circuit; set effective T via SR and τ. Claimed 128-way @ 242.97 ns / 25.5 pJ/el, RMSE 24.46 mV (p.1–3).

2. **The Rashomon Synthesis** — Microarch cares about shared-ramp skew and the approximate normalizer; workload asks whether programmable T matches real head/layer score distributions; tools want Monte Carlo N and baseline Softmax HW; industry asks memristor-HRS + 22 nm co-integration. Agreement: ADC-free CIM→softmax is a real seam. Disagreement: whether time-domain RC is a product circuit or a simulation artifact.

3. **The Magic Trick** — Make exp(·) a timing/RC event instead of a subthreshold I–V law, so temperature becomes two electrical knobs.

4. **The Skeleton in the Closet** — HardSigmoid prior art avoided true softmax because sequence-dimension interconnect is hard in analog (p.1); this design still needs a vector-wide normalizer — first three pages do not prove that interconnect tax is gone. Memristor τ programming and 2.5% loss claim sit ahead of unread evaluation sections.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. Transformer 在每个 attention head/层反复做 softmax；与分类器末端一次性 softmax 不同，序列长度与模型规模上升后，指数与归一化成为不可忽略的开销。(p.1)
2. 存内计算阵列可自然产出模拟分数电压/电流，但 softmax 需要非线性指数再加向量级归一化；常规路径常插入数字或混合信号外设，并在模拟 CIM 输出与数字 softmax 之间付出转换代价。(p.1)
3. 用源耦合晶体管弱反型实现模拟 softmax 时，指数关系只在弱反型成立；输入逼近中/强反型后 I–V 偏离指数，可用输入电压动态范围被压缩。(p.1–2)
4. 弱反型路径还受温度依赖、漏电、尾电流精度、失配、以及“全部输入器件必须留在目标工作区”等约束，实际可用区间更窄。(p.2)
5. 既有模拟存内 attention 为避开序列维互连，会用 HardSigmoid 等近似替代真正的 softmax 归一化，牺牲归一化语义。(p.1)
6. CIM 分数范围随 head、层、阵列增益与模拟非理想性漂移，需要可调的 score→weight 映射，而不是固定斜率的指数律。(p.2)
7. 128 路并行评估的后仿量级：评估时延约 242.97 ns、总功率约 13.44 mW（约 25.5 pJ/输出元）、相对理想 softmax 的 RMSE 约 24.46 mV；单元约 70.2 µm²、含共享斜坡的 128 路约 9453.42 µm²（abstract / p.2）。
