## Master Class

1. **The Real Abstract** — Rewrite inner product as norms + squared differences so PEs use squarers instead of general multipliers without approx error.

2. **The Rashomon Synthesis** — Circuit wants fewer partial products; architecture wants dataflow agnosticism; algo wants exactness. Shared: multiplier is still the PE tax.

3. **The Magic Trick** — Law of cosines moves work onto reusable norms + cheaper squarers.

4. **The Skeleton in the Closet** — Percentage ranges span wide (5–48%); without bitwidth/array context easy to over-read. Online norm overhead claimed negligible—verify.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 深度学习加速器里 GEMM/内积是主流负载，传统 PE 的乘法器仍是面积、能耗与关键路径的主要贡献者。(p.1)
2. 稀疏/近似方法有的依赖足够稀疏并常要微调，有的牺牲算术精确性，跨模型家族通用性受限。(p.1–2)
3. Winograd/FIP 类精确代数法可减少乘法，但常仍基于乘法器数据通路且绑死特定脉动阵组织，时钟还可能被拖慢；FFIP 仍受乘法器延迟束缚。(p.2)
4. n 比特乘法器要处理约 n² 个部分积，平方器对称性大约只需一半部分积，关键路径更短。(p.3)
5. 报告相对基线 PE 阵列：面积降 11–36%、能量降 5–48%、时钟周期降 11–19%，且保持精确计算。(abstract/p.1)
