## 四视角独立批评

### 微架构

PoT-coded K + integer SAC score path; mantissa-extended PoT-Mk; shift-exact online softmax; KV stores codes only (e.g. 101 B/key PoT-4 vs 256 FP16). Gap: no packed shift-dot ISA on sm89; PTX vshl.add emulated (~4.1×).

### 负载

Decoder attention; TinyLlama-1.1B-Chat; WikiText perplexity; long T up to 32k; batch decode.

### 仿真方法学

Fused CUDA kernels + bit-exact PyTorch ref; first-order cost model from disassembly (R/Θmem vs N/Θalu). No ASIC area for DS4A on p.1–3.

### 工业可行性

GPU SW/ISA co-design today; real win needs DS4A-class ISA or ASIC/FPGA; PoT density argument stronger than raw GPU throughput vs INT8 MAC.

## Master Class

1. **The Real Abstract** — Make the bigger QK product multiplier-free by coding keys as signed powers-of-two so scores are shift-accumulate, and expose how GPUs lack a packed shift-dot.

2. **The Rashomon Synthesis** — Decode wants denser KV + less MAC energy; GPU ISA wants dp4a-class packed ops; accuracy wants mantissa bits not extra exponents.

3. **The Magic Trick** — Represent dynamic K as multi-level signed PoT so QK and AV both become shifts (not just post-softmax AV).

4. **The Skeleton in the Closet** — Measured win is issue-bound on current GPUs; projected 6.51× needs nonexistent DS4A; εS scale-free so exponent bits alone do not buy accuracy.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. Decode 阶段每个生成 token 要整份读出 key cache；注意力里更大的矩阵积是 QK⊤，而先前乘方量化多只改写 softmax 之后的 AV。(p.1)
2. 1.1B Llama 解码器、RTX 4090：相对 FP16 scaled-dot-product，报告在 T=32k 时注意力吞吐约 4.60×，KV 缓存约小 2.5×；8 存储位时 WikiText 困惑度约 7.881→7.896。(p.1)
3. 当前 GPU 暴露 4-way 整数乘加却没有等价的打包移位点积；移位数据通路约发 1011 条整数 ALU 指令，对照同结构 MAC 内核约 409 条。(p.1)
4. sm_89 上 PTX 标量移位累加（vshl.add）被仿真实现，代价约是普通 C 移位加的 4.1×；缺的是打包移位点积原语。(p.1)
5. 最近对数量化的相对误差与指数位数近似无关（三/四/五指数位 εS 同为约 0.1302）；精度要靠划分 binade（尾数），多加指数位几乎买不到误差下降。(p.2–3)
