## 四视角独立批评

### 微架构

Base graph G_M is an n×n bidirectional mesh; express set E_X adds long edges whose wire cost is Manhattan distance. A legal placement must satisfy Σ w(e) ≤ B, deg_X(v) ≤ d_X, and w(e) ≥ w_min. Express traversal latency τ(e) is a function of w(e); every link is one flit/cycle. Three placers: budget-matched random; traffic-aware ASPL greedy (largest drop in demand-weighted average shortest-path latency per unit wire); simulation-guided simulated annealing that swaps edges and scores accepted throughput / latency over a set of injection rates with the same committed router used at runtime. Routing: adaptivity once, at the source. Offline enumeration keeps loop-free routes with 0/1/2 directed express hops and XY mesh segments between waypoints; main K=8; extra metadata ~2 log₂ K bits/packet (ignored in their simplified accounting). Injection cost C(P) = L(P) + α Σ q_e + β Σ r_e on express edges only. q is occupied non-escape VCs at the express output; r is registered in-flight demand. q/r are 4-bit quantized, periodically advertised, and observed after a register delay plus Manhattan distance from the express entry; a setup/ACK sideband updates r. Escape: one VC on a deterministic mesh-XY path (Duato-style). Authors already list sideband area, energy, and worst-case queuing as open limitations. Router microarch (VC counts, crossbar, credit) is not drawn on p.1–3.

### 负载

On-chip 2-D mesh traffic in which a few rows, columns, or cuts carry disproportionate demand and set saturation throughput while other capacity sits idle. Evaluation named on these pages (no numeric speedups): four synthetic workloads; persistence checks under delayed quantized congestion, longer express latency, multi-flit packets, and a 16×16 heterogeneous workload. Placement takes a known or estimated demand matrix D_st. This is topology+routing co-design for different traffic matrices, not a single hand-drawn express topology.

### 仿真方法学

Abstract: optimized placements “consistently improve high-load throughput” over Mesh and random; annealing further improves Greedy; gains “persist” under the delayed/quantized/multi-flit/16×16 conditions. No throughput or latency deltas are printed on p.1–3. Method sketch: lightweight C++ simulator for SA proposals; finalists re-ranked with longer runs and independent/validation seeds; topology quality vs routing quality separated by holding the runtime mechanism fixed across Mesh / random / Greedy / SA, then ablating route selection, congestion information, escape, and scale. Treat “consistently improve” as unpaid until the unread plots.

### 工业可行性

Incremental on the mesh NoCs already in SoCs: a few long wires plus source-route metadata and a sparse express sideband, with an XY escape VC that existing meshes already understand. Physical honesty is the wire budget + degree + min-length triple. Adoption needs a trustworthy traffic matrix (or a good estimate) and a sideband whose area/energy/queuing the authors have not closed. Static graph metrics are admitted to be poor predictors of simulated throughput/latency—that is why SA exists, and why a product team cannot place express links from hop-count alone. No process node or router area on p.1–3.

## Master Class

1. **The Real Abstract** — A 2-D mesh wastes capacity beside a few saturated cuts. If only a small extra wire budget exists, spend it on a few traffic-aware long links and make routing use those links without turning them into the next hotspot.

2. **The Rashomon Synthesis** — Layout people like regular meshes; traffic people see cut bottlenecks; shortest-path routing funnels everyone onto the new shortcut; local adaptive routing cannot see congestion several hops away. Topology and routing are one problem.

3. **The Magic Trick** — Place a legal express set with traffic-weighted greedy then simulation-guided annealing; at injection, commit to one of K complete routes scored by delayed express occupancy and reservations; keep an irreversible XY escape VC.

4. **The Skeleton in the Closet** — Opening pages give no numeric speedup; SA score and K=8 are design knobs without a closed sensitivity on p.1–3; congestion state is sparse, delayed, and 4-bit; the control sideband is explicitly un-costed; greedy can spend endpoints that a later pair would have used better.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 二维 mesh 规则易布线，但在许多流量模式下通信量会挤过少数行/列或割边，这些链路决定整网饱和吞吐，同时别处容量闲置。(p.1)
2. 若只能再花一小笔布线预算，乱放长距捷径可能吸来流量却不缓解真瓶颈；最短路或纯局部路由会把过多包漏斗进同一条 express，或看不到数跳外的拥塞。(p.1)
3. 拓扑与路由耦合：有用的长距边必须把容量放到流量真正需要处，路由又必须用上这些容量且不把新边变成新热点。(p.1)
4. 合法放置还需同时满足总曼哈顿线长预算、每路由器 express 度数上限与最小有用长度；静态图指标难以预判仿真里的吞吐/时延。(p.1–2)
