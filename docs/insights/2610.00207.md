## 四视角独立批评

### 微架构

主张不是「再做一层 tensor-wise 混合精度」，而是把**张量内分块 bit-width**接到 systolic PE 的可配置几何上：精度选择直接决定有效块高与计算并行度，从而让片上数据流与量化粒度同构。结构线索（p.1–3）：(i) 权重投影按 block 独立赋 **1/2/4/8-bit**，激活固定 **8-bit**；(ii) PE 配置与量化块尺寸耦合——precision → effective block height / compute parallelism；(iii) 加速器集成 block rescaling、attention softmax、piecewise-linear 非线性，目标线性投影 + 注意力 + FFN；(iv) TSMC 16nm、1 GHz 实现口径。作者对比现有平台：GPU 等因非均匀访存与固定功能 datapath，难高效吃 intra-tensor 混合精度块。反向工程未读：systolic 阵列规模与 tiling、PE 内多精度算术单元（bit-serial vs parallel multiplex）、rescaling 通路时序、片上缓冲层次、softmax/非线性是否与 MAC 流水重叠、控制/配置面面积。

### 负载

动机负载是 **Vision Transformer / Diffusion Transformer** 推理：ViT（DeiT）图像分类与 PixelDiT 像素域扩散生成；扩散进一步把同一 transformer backbone 在多步去噪上放大计算与访存。前三页强调参数对量化的**非均匀敏感度**（层/通道/参数组），tensor-wise 激进低比特易伤准确率或生成质量；block-wise 缩放比 tensor-wise 更灵活。摘要数字：DeiT/ImageNet-1K 上相对 SOTA 混合精度准确率差 **3.3%** 内、有效位宽低 **2 bit**；PixelDiT 生成质量可比；硬件 **1.5 TOPS / 760 GOPS/mm² / 2.8 TOPS/W**——问题侧更应抓住：软件侧已有细粒度混合精度（含 channel-wise intra-tensor），但常规推理平台仍卡在 per-tensor 赋值。明确范围：聚焦传统 ViT 核心（线性投影、attention softmax、非线性），初始 embedding / 末层线性 / LayerNorm / RoPE / reshape / scaling 标为 offload 出加速器（p.3），即加速器覆盖面有边界。

### 仿真方法学

前三页给出工艺（TSMC **16nm** PDK）与频率（**1 GHz**）及摘要级吞吐/面积效率/能效，但 **未**给出仿真器名、iso 条件（电压、SRAM 配置、片外带宽模型）、面积拆分、或与 GPU/既有低比特加速器的对照协议。方法学风险：若 block 配置切换与 rescaling 开销未计入稳态 TOPS，细粒度混合精度的「可实现」叙事会被高估；若评测只报有效位宽与准确率差、不报端到端延迟/能效在真实 batch/序列下的分布，则硬件–模型权衡表不完整。Abstract 数字在未读完整评测前勿当作已付清系统级结论。

### 工业可行性

命题是「用 PE–块粒度共设计，让片上 systolic 真正吃到软件侧已有的细粒度混合精度，而不是停在 tensor-wise」。工业墙：多精度 PE 与配置切换的验证/DFT 成本；与现有 NPU ISA / 编译器量化契约对齐（GPTQ 等 PTQ 工具链 vs 自定义 block 赋值）；Invited Paper 定位与 16nm 学术 PDK 流是否映射到商用先进节点；ViT/DiT 之外（LLM decode、长上下文）是否同构；softmax/非线性硬化与模型演进的耦合风险。前三页产品叙事清楚（intra-tensor 硬件缺口），软件生态与可配置比特宽的标准接口未给。

## Master Class

1. **The Real Abstract** — Block-wise and even channel-wise mixed-precision already help transformers keep accuracy at aggressive bit-widths, but conventional accelerators and GPUs still mostly expose per-tensor (or coarse) precision, so the software’s fine-grained bit assignment cannot map onto efficient on-chip dataflow.

2. **The Rashomon Synthesis** — Quantization researchers see nonuniform parameter sensitivity that wants per-block bits; GPU/NPU vendors see fixed-function MAC datapaths that hate heterogeneous intra-tensor layouts; ViT/DiT deployers see memory and matmul cost exploding under multi-step diffusion. Leftover: couple quantization block geometry to systolic PE configuration so precision itself sets block height and parallelism, with on-accelerator softmax/nonlinearities for the ViT core.

3. **The Magic Trick** — ShatterQuant Transformer Accelerator: intra-tensor block bit-widths in {1,2,4,8} for weights (8-bit activations) whose block size is tied to PE configuration; hardware-aware PTQ using block std / sensitivity; block rescaling + integrated softmax and piecewise-linear nonlinearities; TSMC 16nm @ 1 GHz implementation claim.

4. **The Skeleton in the Closet** — 1.5 TOPS / 760 GOPS/mm² / 2.8 TOPS/W / ±3.3% / “2 bit lower” unpaid as full iso accounting on p.1–3; PE micro-datapath, rescaling cost, and buffer hierarchy unread; scope deliberately offloads embedding/LayerNorm/RoPE/etc.; invited-paper framing may limit generality claims vs LLM-class transformers.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 常规加速器对**张量内异构精度**支持有限，神经网络量化部署仍大量停留在 **per-tensor** 精度赋值，细粒度混合精度难以落到高效硬件路径。(p.1 Abstract)
2. Transformer（含视觉与扩散）推理反复执行大规模矩阵与注意力；扩散还把同一 backbone 在**多步去噪**上放大计算与访存成本。(p.1–2)
3. 激进低比特（尤其 **sub-8-bit**）常因参数对量化的**非均匀敏感度**（不同层/通道/参数组）导致分类或生成质量不可接受下降。(p.2)
4. **分块量化**可比 tensor-wise 提供更细缩放与更激进整体压缩，但现有 GPU 等推理平台因非均匀访存与固定功能计算通路，难高效执行混合精度块。(p.2)
5. 软件侧已有按层敏感度或 **channel-wise 张量内**混合精度的技术路线，硬件侧仍多为粗粒度精度配置或以稀疏跳过代替变精度权重。(p.2–3 Related)
6. 若要把块粒度 bit-width 真正变成吞吐/能效，需要量化块几何与处理单元配置**同构**——否则精度选择无法直接决定有效块维与计算并行度。(p.1–2 贡献陈述)
7. 视觉 Transformer 核心虽可收敛到线性投影、注意力 softmax 与非线性，但仍有 embedding、LayerNorm、位置编码等操作常被留在加速器外，端到端收益取决于边界如何划。(p.3)
8. 在约 **16nm**、GHz 级实现口径下，需同时报告吞吐、面积效率与能效，并对照「更低有效位宽换可接受准确率/生成质量」的权衡；完整 iso 与对照协议 unread。(p.1 Abstract)
