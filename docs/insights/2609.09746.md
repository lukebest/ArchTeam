## Master Class

1. **The Real Abstract** — Give triangular mesh/torus minimal deadlock-free routes with only two forbidden turns (1 VC mesh / 2 VC torus) and a narrow one-link fault extension.

2. **The Rashomon Synthesis** — Topology wants path diversity; wormhole needs acyclic resource order; torus wraparounds reintroduce cycles one VC cannot kill.

3. **The Magic Trick** — Two-turn mesh rule + Hamiltonian dateline VC cut for the residual torus cycle.

4. **The Skeleton in the Closet** — They also claim a counterexample against a prior 3-VC hexagonal-torus construction’s complete-CDG claim—correctness fight is proof-heavy; fault model is one static known link only.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 虫洞流控下正确性不仅要求每对源宿有路径，还要求全部允许路径的并集不形成环状资源依赖。(p.1)
2. 六度三角格子的基本环与最短路径扇区不同于正交 mesh；其周期商还含不可收缩的信道环，路由规则不能直接照搬正交理论。(p.1)
3. 对相应 torus 物理路由关系：在 n≥3 时，仅用 1 个虚通道仍会留下有向 Hamiltonian 资源环。(p.1–2)
4. 先前某六角 torus 族构造用 3 类虚通道并声称完全 CDG 无环；作者按原文规则复现后给出同类型同 VC 的有向资源环反例（不等于已证明可达死锁）。(p.2)
5. 单条静态、路由纪元前已知的双向链路故障：希望在保持原 VC 计数与全连接的前提下，相对健康最短路至多多 1 跳。(p.1)
