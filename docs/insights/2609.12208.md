## 四视角独立批评

### 微架构

Targets existing systolic-array LLM accelerators with “minimal overhead” extensions: specialized vector/lookup path to reorganize codebook accesses and cut PE-level memory conflicts; dual execution flows tuned separately for compute-reuse prefill vs memory-bound GEMV decode; dedicated on-the-fly VQ units for dynamically generated KV. Motivation §2.3 also flags LUT-style VQ (precomputed partial sums + index gather) shifting the bottleneck from matmul to accumulation and leaving utilization low — so the claimed dual-flow + DSE is partly a PE/accumulator balance story, not only a dequant story. Exact port counts, buffer depths, and cycle schedules live after p.3.

### 负载

Autoregressive LLM: prefill (GEMM-like, high reuse) vs decode (token-at-a-time GEMV, memory-bound). Extreme weight compression (VQ / residual VQ into ~sub-2-bit / ~1.4-bit average regimes) plus input-dependent activation sparsity (principle ~30–50% compute cut). Fig. 2(a): Llama2-7B 2-bit AQLM is ~1.88× slower than FP16 end-to-end. Fig. 2(b): exploitable sparsity collapses with batch — ~30.4% @BS1 → 16.5 / 9.1 / 6.2 / 5.1% @BS 2/4/8/16 — so sparsity wins are concentrated in small-batch / BS=1 decode. Growing KV often exceeds weights; must be quantized/consumed on the fly.

### 仿真方法学

p.1–3 are motivation + challenge framing (Fig. 1 quant schemes; Fig. 2 VQ slowdown & sparsity-vs-batch). End-to-end speedup/energy numbers and FIGLUT baseline appear as claims; measurement setup, process node, and full DSE tables are after p.3 and unread. Treat headline 8.03×–23.7× / 5.68×–12.5× as author-reported until the eval section is opened.

### 工业可行性

Story is incremental retrofit of systolic arrays (lookup unit + light PE extensions + optional KV VQ path) rather than a greenfield chip. Adoption hinges on whether codebook conflict + accumulator imbalance + on-the-fly KV VQ can be absorbed without blowing SRAM/ports, and whether training-free codebook-wise sparsity stays accurate at ~1.4-bit average vs 4-bit analytical baselines. No foundry/node or area overhead on p.1–3.

## Master Class

1. **The Real Abstract** — Make extreme VQ (and matching contextual sparsity) actually run on systolic hardware by fixing irregular codebook lookups, balancing dual prefill/decode flows, and extending VQ to on-the-fly KV.

2. **The Rashomon Synthesis** — Algorithms can hit sub-2-bit weights and 30–50% activation skip; systolic PEs thrash on concurrent codebook reads; batched decode erases the sparsity intersection; long-context KV becomes the new DRAM wall.

3. **The Magic Trick** — Reorganize lookups / buffering and run two complementary execution flows; add high-throughput on-the-fly VQ for KV; align sparsity to codebook granularity so fine-grained skips stay structurally regular.

4. **The Skeleton in the Closet** — Headline speedups vs FIGLUT are unread beyond p.3; Fig. 2 already shows sparsity dying by BS≈16; LUT-style flows may just move the stall from matmul to accumulate; “minimal hardware overhead” is not quantified on p.1–3.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 极致压缩（向量量化 / 输入依赖稀疏）能显著减小 LLM 显存足迹，但在常规脉动阵列加速器上，向量量化带来高昂的片上反量化开销，且输入依赖稀疏的不规则模式难以被硬件吃掉。(p.1)
2. LLM 天然存在细粒度、随 token 变化的输入依赖稀疏，理论上可砍掉约 30–50% 计算，但落到现有硬件上仍难变成稳定加速。(p.1)
3. 多个 PE 并发查码本会产生严重片上访存冲突，限制并行与吞吐；结果是压缩比很高，却经常换不成真实推理加速。(p.2)
4. 细粒度激活稀疏需要按 token 动态决策，并引入现有硬件不擅长的不规则计算与访存；批处理时只能取各 token 稀疏模式的交集，随 batch 增大可剥削稀疏迅速塌缩，实践上收益往往锁死在 batch≈1。(p.2)
5. 端到端测得：Llama2-7B 在 2-bit AQLM 量化下相对全精度约慢 1.88×（图中亦标约 1.9×），说明压缩并未自动变成加速。(p.3, Fig. 2a)
6. 可测稀疏率随 batch 下降：batch=1 约 30.4%，2/4/8/16 分别约 16.5% / 9.1% / 6.2% / 5.1%。(p.3, Fig. 2b)
7. 解码逐步自回归，计算退化为 GEMV、复用差，整体受内存带宽束缚；仅压静态权重不够——随上下文增长，动态生成的 KV 往往超过权重大小，成为新的内存主因，且必须在线量化并立即消费，需要高吞吐的在线量化能力。(p.2–3)
8. 把「边反量化边乘」改成「按码本项预计算部分和再按索引查表累加」后，瓶颈从矩阵乘单元挪到累加单元，两端负载失衡，利用率仍然偏低。(p.3)
9. 解析型低比特量化在 LLM 权重高度非均匀时，超低比特区效果受限；向量量化可达 sub-2-bit / 平均约 1.4-bit 量级，但在现有硬件上仍难兑现吞吐。(p.1–2)
