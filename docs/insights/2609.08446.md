## Master Class

1. **The Real Abstract** — One digital CIM macro that reshapes/rebits weight vs membrane storage and picks WS or OS per layer so SNN layers stop fighting fixed CIM geometry.

2. **The Rashomon Synthesis** — Circuit wants fixed dual-WL; system wants per-layer shapes; camera wants µs latency. Shared: membrane state + sparsity break CNN-CIM assumptions.

3. **The Magic Trick** — Treat membrane potentials as first-class CIM citizens with reconfigurable shape, not leftover SRAM.

4. **The Skeleton in the Closet** — 45%/52% are large-scale system projections vs fixed stationarity—not necessarily the 40nm macro alone.

5. **可提取的问题线索**（仅 p.1–3，有数字，无机制名）

1. 移动端紧凑模型已要数亿 MAC 与百万参数；参数搬运可占总功耗约 60%。(p.1)
2. DVS 主动像素比常约 <1%–10%；端到端事件产生延迟可低于 100 µs——要求后端跟上稀疏低延迟。(p.2)
3. SCNN 要长期保存膜电位：若权 8b、膜电位 16b，膜电位存储器可占等价非脉冲 CNN 总内存约 25–67%。(p.2)
4. 既有 SNN-CIM 固定分辨率/纵横比/单一数据流，难以匹配层形状多样；固定站定在大规模系统上浪费片上/片外搬运。(p.1–2)
5. 事件视觉稀疏常 >90%，使依赖 ADC 的 in-array CIM 利用率不足；timestep-first 执行会丢掉 DVS 低延迟优势。(p.3)
6. IBM DVS gesture 上 95.8% 精度；相对固定站定，大规模系统可降约 45% 能量、52% 延迟（报告值）。(abstract)
