# M-12 跳数松弛错峰发射（Hop-Slack Staggered Launch, HSSL）

- problem: P-0198
- id: P-0198/M-12
- author: Jim Keller
- round: 2

## 1. 根因分析

一波推理 decode 的 KV shard / 推理期 collective 在 `t=0` 同时变 ready。Bufferless 环上近 dest 的源先抢到空槽，远源被过路挡在注入口。last-completion 变成：

```
T_last ≈ t_inject(far, late) + hops(far)
```

而不是：

```
T_last ≈ t0 + hops(far)
```

差的那一项是 **近源把早期空槽吃掉造成的远源开工迟到**。这不是「空槽不够」（CBC 死在再分配 raw↔steal、`p_inj` 不动、尾不动），也不是「没有 GRANT」（CSR 把门控做成公民税，`r≈1`），也不是「对向造洞」（AODI `hole_asym>0`、`T_mix=1`）。

源端流控减 outstanding，只会让远源更晚。CRRF 加 Dat 时隙，不改变「谁先占用早期空槽」。M-3 DPH / 最短 CW-CCW 已经 T0 死/冻，本卡 **不** 改方向选择。

根因：**同波 ready 集合的注入次序与剩余跳数反相关**。推理尾由最远贡献者的到达决定；训练大块集合不作本卡主论证。

## 2. 机制

### 2.1 结构

每个 NIC 一张静态跳数 ROM + 一扇 **只挡本波第一拍注入** 的门。没有周期性时隙表——这不是 TDM / slotted-ring（保守批 M-6 那条路 T0 已 FUNCTIONAL_EQUIVALENT，禁止再走）。

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Hop ROM | 14×14×4b（src,dst → hops）或按方向两张 14×4b | 拓扑静态，非消息到达预测 |
| Wave leader | dest（P2P/KV）或 collective root | 只发 **一条** LAUNCH 控制 flit |
| LAUNCH flit | 走 **Rsp**（或 Req）；载荷：`t0` 8–12b + `H_max` 4b + `wave_id` 4b | 环公民，低频 |
| Launch gate | 每 NIC、每 wave 1b + 比较器 | `now >= t0 + γ·(H_max − hops_i)` 才允许该波 **首拍** 注入 |
| γ CSR | 2–3b，默认 1 | 每跳松弛的拍数假设 |
| 无窗口计数器 | — | **不** 限 outstanding；门只推迟首拍，不关后续拍 |

LAUNCH 是屏障对齐，**不是** 流量神谕：它不携带未来到达时刻，只广播「本波 `t0`」。`t0` 取 leader 本地周期，源端用 Rsp 到达拍作本地零点（skew ≤ 环周，必须建模）。

### 2.2 数据路径 / cycle-level

1. 软件/运行时在 decode 步门铃上标 `wave_id`（已有 doorbell 语义即可；**禁止** harness 按未来消息到达时刻改 `t0`）。
2. Leader 在本波首个 ready 后注入 1 条 LAUNCH 到 Rsp。LAUNCH 按基线路由绕到各源；源锁存 `t0_local = now_at_recv`，计算

   ```
   release_i = t0_local + γ * (H_max - hops(i, dest_or_root))
   ```

   远源 `hops` 大 ⇒ `release` 早；近源晚。
3. 源 i 对本 `wave_id` 的 **第一拍 Dat** 在 `now < release_i` 时 fail-wait（与基线注入失败相同，不占槽）。到点后按基线抢空槽，**不再** 限速。
4. 同一源后续拍（512 B 多拍）不受门控——门只校正「谁先开工」，不把突发切成 TDM。
5. 无 LAUNCH（丢、超时 `T_launch_to`）⇒ 门打开，回退 no-CC。超时必须计数，禁止静默当「已错峰」。

### 2.3 时序

| 事件 | 周期 |
|------|------|
| Hop ROM | 组合 / 1 拍 |
| LAUNCH 一圈 | ≤ `C_ring` 链路延迟 |
| `release` 比较 | 同拍 |
| 首拍推迟 | `γ·(H_max−hops)`，假设 γ=1 时 ≤ `H_max` |

插入：Rsp 上偶发 1 槽。Dat 路径无额外管线。

### 2.4 仿真器改动

- **默认只加模型**：`tests/soc_sim` NIC 注入器加 launch gate + hop 查表；Rsp 增加 LAUNCH opcode。
- **结构变更（仅当现有 NIC 没有「按波首拍门」）**：platform 仓 **新分支**，禁止改 `main`。改动点：`tests/soc_sim` 端点注入 FSM 增加 `wave_id/release` 状态；Rsp 解码 LAUNCH。不改 highway 槽数、不改 RBRG、不加队列。
- 若验证发现必须让 harness 写 `t0`：那是神谕，**禁止**。卡失败，而不是改成预测器。

## 3. 为什么有效（尾）

同波 N 个 ready 源争早期空槽。无序注入下近源的 `t_inject≈t0`、远源 `t_inject≈t0+Δ_contend`，尾 = `t0+Δ_contend+hops_far`。HSSL 把远源放进早期空槽，近源的迟到被短 hop 吃掉：

```
T_last ≈ max_i ( release_i + hops_i ) ≈ t0_local + γ·H_max + hops_far
```

**机制级理由**：改的是 max 而不是和，也不抬 `p_inj`。若 cycle 里尾其实由 dest 单口串行弹出 N 个已到达 flit 决定，错峰帮不上——消融会给出 `T_mix≈1`，本卡淘汰。不要假装。

相对基线（假设）：

- **no-CC**：近源霸凌早期槽。HSSL 反转开工序。
- **source-FC**：减窗口 ⇒ 远源更饿。HSSL 不减窗口。
- **CRRF**：多给 Dat 时隙，谁先用仍是近源。CRRF 还交 drain / Snp 税。HSSL 不碰 Snp 绑定。

## 4. 失败模式

- **Dest-eject 串行主导**：所有源 hop 差被 dest 单口淹没。必须用 dest-eject 占用探针证伪；成立则淘汰，不许改卖「更公平」。
- **LAUNCH 神谕化**：harness 按未来到达填 `t0`。`oracle_used` 必须 False。
- **γ 过大**：近源被拖过远源到达之后，尾变差。扫描 γ∈{0,1,2,4}；γ=0 即消融。
- **被写成 TDM**：周期性预留槽、按节点轮转时隙 = 另一张卡，且 T0 会死。本卡只有 **每波一次** release。
- **只跑单 dest、单跳距**：减箱，证明不了错峰。

## 6. 评估计划

- **信封 / 主指标**：同 M-11；主看推理 KV P2P 与推理期 collective 的 last-completion / p99。多跳距源必须在。
- **cycle 基线**：no-CC；source-FC；M-5 CRRF（duty 分列，不贴 T2）。
- **必须建模**：LAUNCH 在 Rsp 上的真实占槽与偏斜；`release_i`；γ 扫描；`oracle_used=False`；超时回退计数；Snp 15:1 分列。
- **消融**：γ=0 / launch-off。HARD：推理主类尾 **严格** 差于 γ=1（或扫出的最佳 γ，但最佳必须预先登记，禁止事后挑臂）。
- **预期（假设，未测）**：
  - 多跳距 decode KV / 推理 AllGather：相对 no-CC **0.75–0.95×** 尾（中）
  - 相对 source-FC：**0.70–0.95×**（中；窗口与错峰正交且窗口常伤尾）
  - 相对 CRRF：**0.85–1.10×**（低–中；CRRF 在 Dat 饱和 bbox 仍可能更快，但 Snp 活体上 HSSL 应不输）
  - 单跳距 / dest-eject 主导：**≈1.0×**，该行应淘汰本卡而不是平均掉
  - Snp 15:1：假设 **≤1.05×** no-CC

## 7. 可证伪声明

1. **H-FAR-FIRST**：LAUNCH 后远源首拍注入时间的分布中位数 **早于** 近源；否则门没工作。
2. **H-TAIL**：推理主类 last-completion on < off。`T_mix≈1` ⇒ 淘汰。
3. **H-NOT-TDM**：不存在周期时隙表；每波恰好 1 次 LAUNCH（超时另计）。
4. **H-NO-ORACLE**：`t0` 不得由未来到达生成。
5. **H-SNP**：未过线 Snp 数不卖。

## 8. 自检（淘汰约束）

1. 消融必须 cycle 级让尾变差；禁止把 Amdahl「更齐到达」解析式贴成 T3。
2. 不把更高 `p_inj` / 更早平均注入当收益。远源开工早而尾不动 = 死。不重提 bubble/GRANT/AODI。
3. 不是 slotted-ring / TDM / 最短方向。γ=0 对照就是「无错峰」，不是换方向。
4. Snp 15:1 分列。
5. 数字皆假设。
6. 六硬：launch-off 仍满占用不得记分；不冻地址高位（hop ROM 是拓扑不是 addr map）；单一尾定义；killer 单跳距/双忙必须单列；对照 no-CC/source-FC/CRRF/最短方向冻基线；0.85 是 bar；减箱 ≠ 全信封。
