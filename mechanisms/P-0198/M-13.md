# M-13: Dat 环选择组播（目的位图）

- problem: P-0198
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

推理 decode 的集合通信（TP allreduce / broadcast / allgather 的残差，通常小）若被拆成 **N 路单播**，每路按已冻最短弧走，槽·拍占用约 `Σ hops_i ≈ N·(N/4)` 量级（双向环均值）。这些占用是 highway 上的过路，直接拿走当前步 KV P2P 的残差注入，并把集合自身的完成钉在最慢那路单播上。`T_step = max(KV 尾, 集合尾)`，两条尾巴被同一组多余过路同时拉长。

基线公开扫描里 broadcast 有时不崩、其它集合崩，已经说明扇出形态敏感。根因不是「注入率不够」，而是 **同一份小 payload 被复制成多份在途 flit**。无缓冲环上多一份在途就多一拍有人不能注。

本卡只动 **Dat 环** 的复制-转发。不把 payload 改挂到 Req/Rsp/Snp（CHI 通道字面合法）。Snp 环保持近空，不用 Snp 做数据广播（Snp 路径不作卖点）。不是源端流控；`--cc-scheme srcfc` 与 M-5 CRRF 黑盒是对照。

## 2. 机制

### 结构

1. **目的位图 `DMASK[13:0]`**：14 die（12 top + 2 bottom）。写入 Dat header 侧带（CHI user 位或 Dat 环 14b 伴随线，不加 512 B 数据通路宽度）。单播时恰 1 bit，行为退化为基线。
2. **环成员掩码 `RINGMEM[13:0]`**：每条物理 Dat 环一份硬线/CSR，标记「哪些 die 挂在本环」。源 NI 组合计算 `local_mask = DMASK AND RINGMEM`、`remote_mask = DMASK AND ~RINGMEM`。
3. **每环至多 1 个组播 flit**：`local_mask≠0` 则在本环注入 **一个** 带 `local_mask` 的 Dat 包（多拍 payload 则每拍复制同一掩码）。`remote_mask≠0` 则另注入 **一个** 单播种子到最近 RBRG（目的 = 对端环上一个成员），对端环 NI 再以该环的子掩码做组播。RBRG **不复制**、不加桥上第三份存储；跨环仍是 1 个 flit 过桥（可与 M-11 正交，本卡不依赖）。
4. **复制-转发**（每个 Dat NI，每方向）：
   - 过路 Dat 的 `DMASK[me]=1`：向 **既有 CHI RX 口** 复制一份（endpoint 弹出，不是织物队列），`DMASK[me]` 清 0 后 **继续** 在 highway 上前送。
   - `DMASK` 清完（或 `last=1`：本节点是剩余掩码里沿本方向的最后一位）：**只弹出、不前送**，本拍该方向输出空槽。
   - `DMASK[me]=0` 且掩码非空：纯前送，与基线过路相同。
5. **方向**：本环组播沿已冻最短弧走向「掩码质心」或固定 CW（CSR `MDIR`：0=CW，1=按最低置位 die 的最短弧）。不引入新的自适应路由。`MDIR=0` 是默认，消融用。

allreduce 的「每源一份」仍是多源；本卡吃掉的是 **每源对多 dest 的扇出**，不是把 allreduce 变成一条魔法 flit。broadcast / allgather 扇出收益最大。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| `DMASK` | 14 bit / Dat 包头侧带 | 随 flit | 14b |
| `RINGMEM` | 14 bit / 物理 Dat 环 | 1R 硬线/CSR | 14b |
| 子掩码 AND | 0 | 组合 | 14b AND |
| 复制 mux | 0 | 1 出到既有 RX | 与 Dat 切片同宽 |
| `me` 译码 | 4 bit die_id | 组合 | 14:1 bit 选择 |
| last 检测 | 0 | 组合 | `DMASK & ~((1<<(me+1))-1)` 一类前缀（CW）或对称 CCW |
| `MDIR` | 1 bit / 环 | 1R1W | 复位 0=CW |
| `MC_EN` | 1 bit | 1R1W | 0=全部当单播（off） |

无 SRAM，无 CAM。复制目标是 endpoint RX，深度不增加（RX 本来就要收这份数据）。节点内不额外堆 flit：highway 仍 0 或 1。

### 数据路径与状态机

无多状态 FSM。每拍 Dat NI：

1. 若 `MC_EN=0` 或 `popcount(DMASK)≤1`：基线单播。
2. 否则：`hit = DMASK[me]`；`last = (DMASK & downstream_mask)==0`（downstream_mask 由 `MDIR` 与 `me` 组合）。
3. `hit`：RX 端口写使能 = 1（与单播弹出同一口）；`DMASK'[me]=0`。
4. 输出：`last ? 空槽 : 带 DMASK' 的过路`。
5. 源侧：按 `RINGMEM` 拆成 ≤2 个包（本环组播 + 可选跨环种子）。

时序：14b 掩码与 1 bit 选择，目标同拍；last 检测是 14b OR 树，约 4 级。过路在 `hit=0` 时 +0。Snp/Req/Rsp 数据通路不实例化本逻辑。

## 3. 为什么有效

第一性原理：一份 broadcast 的槽·拍从 `≈N·N/4` 降到 **一条环弧上的一次巡游**（最坏 `N` 拍，通常到最后 dest 为止 `<N`）。集合尾 `C_coll` 的下界从「最慢单播」变成「一趟弧」。同时，少掉的那些过路拍还给同环 KV 做残差注入，KV 尾 `C_kv` 的注入段缩短。`T_step = max(C_kv, C_coll)` 的两边都被同一件结构移动——这是占用 **条数** 下降，不是 `p_inj` 上升。

不得把「组播注入成功率高」当主收益。主收益是 `T_step`。若组播把一趟长弧打满、而 KV 本来走另一方向、`T_step` 不动，记失效。

推理（主）：decode 残差小（数拍 Dat 以内），组播巡游成本低，扇出 N=8–14 时占用比单播差一个 N 因子。失效：集合 dest 只有 1；或 payload 大到巡游时间被数据拍数主导且与单播总拍数同阶（见训练）。

训练大块集合（次要，一句话）：字节数主导，组播少的是副本控制不是数据体积，大块 makespan 预期近似中性，不作过线。

## 4. 评估计划

### 基线

1. 流控 OFF；集合 = 平台默认多单播。
2. `srcfc` 等对照。本卡开/关 × 对照。
3. M-5 CRRF 黑盒（`sims/P-0198/M-5/sweep.py --mode smoke --seed 20260903`；无 soc_sim 开关则评估方提供）。不实现 CRRF。
4. 消融：
   - U0：`MC_EN=0`（off，单播）。
   - U1：只组播 broadcast / allgather 扇出，allreduce 仍单播。
   - U2：全集推理集合扇出都组播（全卡）。
   - U3：错误地把 payload 挂到 Snp（非法臂）：若有人实现，Snp 路径超阈则 KILL 该臂；本卡规范禁止此臂当正结果。
   HARD：U2（或 U1）须在诚实 cycle 下推理 `T_step` 优于 U0。只改善集合 goodput、`T_step` 不动则失败。

### 必须 cycle 级建模的结构

- 14b `DMASK`、`RINGMEM` 拆分、复制-转发、last 停送。
- 跨环种子单播、RBRG 不复制。
- Dat 专用；Req/Rsp/Snp 无此逻辑。
- **不要** 在桥上建组播扇出缓冲。

### 仿真器改动（独立分支，不动仿真仓 main；RTL 不改）

1. `tests/soc_sim` 加 `--cc-scheme dat-mcast`。
2. Dat flit 头模型加 14b `DMASK`（`chi_flit` / header 模块按仓内文件名落地）。
3. Dat NI 弹出路径加 copy-forward 与 last 空槽。
4. 集合流量发生器：`MC_EN=1` 时 broadcast/allgather/allreduce 扇出改发 1 个带掩码的包（每环），而不是 N 个单播。
5. 为什么改结构：基线 header 只有单 dest，不扩展 Dat 头与弹出路径就无法在无额外在途副本的前提下做选择组播。

### 指标与负载

主指标：推理 decode `T_step`（KV P2P + 该步集合）、集合自身完成时间、KV p99、完成数、collapse。写死：每 decode 步 1 次 TP broadcast 或 1 次小 allreduce（bytes 用推理残差档，例如 ≤8 KiB），加上该步 KV。训练大块只附一列。0.85 是推理 pass bar。占用条数、单环注入成功是 proxy。禁止 gather T/off、Snp duty 当 card-claim。

### 预期收益区间与证伪

相对 U0，带扇出的推理步：`T_step` 预期 **10%–30%**（broadcast/allgather 靠前，allreduce 靠后）。无集合的纯 KV 步：预期 **0%**，不得写入主表当收益。Snp 路径预期 = U0。

证伪：U2 的 `T_step` 不低于 U0，或只见占用条数下降而 `max` 不动 → 失败。不贴 T2。不宣称 T0 通过。

## 5. 硬件开销估算

假设同前。面积：每 Dat NI 14b 掩码线 + OR 树 + RX 写使能，14×2 方向，估计 **<4 kGE** + 14b 伴随线。无 SRAM。功耗：仅 `popcount>1` 的 Dat 过路打开 last 检测。延迟：0 拍弹出；last 停送制造的空槽是收益不是附加延迟。Snp/Req/Rsp +0。

## 6. 与已知工作的区别（为何不是功能等价）

- **不是** SCI / token-ring 全员广播：掩码选择、last 停送，不是人人见人人。
- **不是** CHI Snoop 广播：明确不走 Snp，避免 15:1 类 Snp 路径被拿来当卖点。
- **不是** Panda 等多目的 worm（有缓冲 mesh）：无织物队列，复制只进 endpoint RX。
- **不是** TDM / 最短路径 / Age+Class / 偷气泡。
- **不是** 把四条 CHI 环当可互换公路（上轮亲和卡的洞）：payload 仍只在 Dat。

## 7. 自检

1. HARD = U2 vs U0，诚实 cycle `T_step` 须优于单播基线；不贴 T2。结论：写入。
2. 主收益是集合尾 + 并发 KV 尾合成的 `T_step`，不是注入率。结论：写入。
3. §6 非功能等价。结论：写入。
4. Snp 不承载数据，路径预期不变，不作卖点。结论：写入。
5. 占用条数 / gather T/off 不是 card-claim。结论：写入。
6. 纯 KV 臂不得写集合收益；0.85 是 bar；配比写死。结论：写入。
7. 不加深缓冲、不加槽；`DMASK` 是头侧带不是队列。结论：写入。
