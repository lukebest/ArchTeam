# M-13 波次日落占用回收（Wave-Sunset Occupancy Reclaim, WSOR）

- problem: P-0198
- id: P-0198/M-13
- author: Jim Keller
- round: 2

## 1. 根因分析

推理 decode 不是一条集合曲线，是 **一串短波**：token t 的 KV P2P / 推理期 AllGather，紧接着 token t+1。Bufferless 环没有队列吸收「上一波还在绕的公民」。上一波已经在 dest **完成** 的 flit（晚到的重复拍、未杀干净的多播残段、RBRG 换路残留、NACK 重注入）仍占 highway 时，下一波的尾 flit 在注入口和 dest 门口同时被挡。

单波 makespan 上这东西几乎看不见——所以 CBC/AODI/CSR 的单波 T3 出现 `T_mix=1`：你在波内造洞、发 GRANT，**波间占用耦合** 纹丝不动。CRRF 的 drain 甚至 **主动** 加死时间，对逐步 decode 是惩罚。

根因：**语义已死的占用还在当一等公民**。WSOR 不制造空槽日历，不限当前波 outstanding（那是源端流控），只在 dest 确认本波完成后把 stale wave 从环上回收。主指标必须是 **多步 decode 的端到端 makespan / 尾**；单波 `r≈1` 是预期，不是过关。训练大块集合不作主论证。

## 2. 机制

### 2.1 结构

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| `wave_id` | flit 头 4b（16 波模） | 每 decode 步 +1，软件门铃写 |
| Expected-count CSR | 每 dest 16b | 本波应收拍数；**软件posted，非到达预测** |
| Recv scoreboard | 每 dest 16b 计数 + 1b `complete` | 只计本 `wave_id` |
| SUNSET marker | 走 **Req**；载荷 `wave_id` + `epoch_src` | dest 在 `complete` 后注入，绕一圈 |
| Sunset latch | 每节点 4b `sunset_w` | 看见 marker 后更新 |
| Reclaim 规则 | 组合 | `flit.wave_id` 在 `sunset_w` 的模 16 **过期窗**（默认落后 1–2）⇒ 槽变 empty |
| NACK 路径 | 走 Rsp，仅当 dest **未** complete 却被误回收 | 必须计数；稳态目标 ≈0 |

过期窗用模算术：`stale ≡ (sunset_w − wave_id) mod 16 ∈ {1,2}`。当前波与超前波（乱序门铃）不回收。

**不是 CBC**：不按日历 duty 把 raw-empty 打成 bubble，不 steal。只回收 **已经 complete 的旧波**。
**不是 source-FC**：当前波 outstanding 不设上限。
**不是 CSR GRANT**：不挡注入、不在 RBRG 会合。

### 2.2 数据路径 / cycle-level

1. 源注入时把头 `wave_id` 写成当前门铃。无门铃 ⇒ `wave_id=0`，WSOR 对该流不使能（回退 no-CC）。
2. Dest 每成功 eject 一拍且 `wave_id` 匹配：`recv++`。`recv>=expected` ⇒ `complete=1`，注入 1 条 SUNSET 到 Req（若 Req 本拍忙，下一次空槽；SUNSET 不得抢 Dat 槽）。
3. SUNSET 每到一节点：更新 `sunset_w`。节点对本拍 highway **四个 CHI 环分别** 看槽：若 payload 的 `wave_id` 落入 stale 窗：
   - dest 已对那波 `complete`（默认成立，因为 marker 由 dest 发出）：槽改 empty，`reclaim++`，**不** NACK。
   - 若实现竞态导致 dest 尚未 complete（偏斜）：走 Rsp NACK，源按基线重注入，`false_reclaim++`。稳态 `false_reclaim` 必须解释；假设目标 0。
4. 节点 **不** 因 sunset 推迟当前波注入。当前波与 no-CC 相同抢槽。
5. Marker 丢了：`T_sunset_to` 后 dest 重发一次。禁止 harness 广播全局 `complete`。

### 2.3 时序

| 事件 | 周期 |
|------|------|
| recv++ / complete | eject 同拍 |
| SUNSET 等待 Req 空槽 | ≥0，有界重试 |
| SUNSET 一圈 | ≤ `C_ring` |
| reclaim 改 empty | 同拍组合 |

税：Req 上每波 1 个 marker。相对 CRRF 整波 drain（1–2 圈停注入）是两个数量级的轻税——这是假设，cycle 必须把 marker 占槽算进下一波尾。

### 2.4 仿真器改动

- **只加模型即可** 若 `tests/soc_sim` 允许「本拍把 payload 改 empty」：加 `wave_id`、SUNSET、scoreboard。
- **结构变更**（slot 模型若把 kind 当成不可变）：platform **新分支**，禁止改 `main`。改动点：`tests/soc_sim` highway slot 增加 `wave_id` 与 `convert_to_empty` 臂；Req 增加 SUNSET；dest 增加 expected-count CSR。不加队列，不改槽数。
- 评估 harness **必须** 跑 K∈{8,16,32} 步 decode 序列。单波 run 的 r≈1 **不得** 当作通过。

## 3. 为什么有效（尾）

令第 t 步单波服务为 `S_t`，波间残留占用造成的附加等待为 `C_t`。无回收时多步 makespan

```
T_seq ≈ Σ (S_t + C_t)
```

`C_t` 来自 t−1 还在绕的公民挡 t 的尾 flit（注入或 dest-eject）。Sunset 后 stale 不再是公民，`C_t→0`（减 marker 税）。**单步 `S_t` 可以完全不变**——这就是为什么单波 T3 会给出 `T_mix=1`，以及为什么本卡把主 endpoint 钉在 `T_seq` / 逐步 p99。

相对基线（假设）：

- **no-CC**：`C_t` 全留着，逐步 decode 尾叠加。
- **source-FC**：用窗口压 `C_t`，同时压 `S_t` 的并发，decode 小消息上常常 `T_seq` 更差。
- **CRRF**：flip/drain 把 `C_t` 变成显式死时间，逐步 decode 上税更重；Snp 15:1 再杀一刀。WSOR 不重绑、不 stall Snp。

## 4. 失败模式

- **只评单波**：`r≈1`，诚实淘汰。禁止事后改成「单波也该快」。
- **expected_count 神谕**：harness 按实际到达填数而不是门铃。必须用 posted 值；错填导致 `false_reclaim` 或永不 sunset。
- **模 16 绕回**：K>16 且 dest 慢时误回收当前波。必须测 K=32；若 `false_reclaim>0` 要加宽窗或 5b id，不得瞒。
- **把 reclaim 做成日历气泡**：又是 CBC。禁止对非 stale 的 empty 打 tag。
- **SUNSET 走 Dat**：与 KV 抢尾槽，自残。只许 Req。

## 6. 评估计划

- **主指标**：K 步推理 decode（KV P2P + 推理期 collective 按公开混合）的 **序列 makespan** 与逐步 p99。单波只作对照行，标明「预期无收益」。
- **cycle 基线**：no-CC；source-FC；M-5 CRRF。CRRF 在逐步场景必须把 drain 税算进 `T_seq`，禁止只用 STEADY 甜区。
- **必须建模**：posted expected-count；SUNSET 占 Req；reclaim 同拍改 empty；`false_reclaim`；K∈{8,16,32}；Snp 15:1。
- **消融**：sunset-off（`wave_id` 仍打但不回收）。HARD：`T_seq` off **>** on；单波 HARD 允许等号，不得用单波等号冒充失败，也不得用单波等号冒充成功。
- **预期（假设，未测）**：
  - K=16 decode KV 序列相对 no-CC：**0.70–0.92×** `T_seq`（中）
  - 相对 source-FC：**0.75–0.95×**（中）
  - 相对 CRRF：**0.65–0.90×** `T_seq`（中；CRRF drain×K 步）
  - 单波：**0.98–1.05×**（高置信近 1，**不是**卖点）
  - Snp 15:1：假设 **≤1.05×**

## 7. 可证伪声明

1. **H-SEQ**：K≥8 的 `T_seq` on < off。单波不作为本声明的正例。
2. **H-STALE-GONE**：sunset 后环上 `wave_id` 过期公民计数 → 0（允许 marker 飞行期残留 ≤1 圈）。
3. **H-FALSE0**：稳态 `false_reclaim==0`；非零必须解释且不得伴随静默丢当前波。
4. **H-NOT-CBC**：reclaim 只作用于 stale payload，不 tag raw-empty，不 steal。
5. **H-SNP**：未过线不卖。

## 8. 自检（淘汰约束）

1. 多步消融必须 cycle 级赢；禁止把「残留占用解析」贴成 T3 `T_seq`。单波 r≈1 预期。
2. 不把 `p_inj` / 空槽率当收益。不重提 bubble、GRANT、AODI。本卡甚至 **不试图** 抬单波注入。
3. 不是 TDM / 最短方向。Sunset 不是时隙表。
4. Snp 15:1 分列。
5. 数字皆假设。
6. 六硬：sunset-off 仍满占用（当前波）不得给单波记分；不冻高位地址；`T_seq` 与单波 makespan 两套数必须分列，禁止用单波定义偷换序列定义；killer（K=1、错 expected）必须单列；对照三条基线；0.85 是 bar；K=2 减箱 ≠ K=32 全信封。
