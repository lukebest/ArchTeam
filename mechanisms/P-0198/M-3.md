# M-3 方向分区高速槽（Direction-Partitioned Highway, DPH）

- problem: P-0198
- id: P-0198/M-3
- author: Jim Keller

## 1. 根因分析

双向环每方向每周期 1 槽。LLM 两类形态——(1) P2P/近均匀数据移动（权重重读、KV 扫描、激活分片 R/W）；(2) 集合（broadcast/gather/reduce/allgather/allreduce/alltoall）——叠在 **同一方向** 上产生跨形态队头阻塞式注入失败：过路的长距 P2P Dat 流占满 CW（或 CCW），集合扇入无法注入，反之亦然。

基线 R/W 不对称：均匀读峰值后坍至 ~2.8–3.4 TB/s，写平台 ~5.5 TB/s 未见同等坍塌报告——说明方向角色与流量形态耦合 asymmetric。根因是 **零和槽上的形态混复用**，不是缺更大 buffer；QoS 加权仍共享同一方向几何，无法消除跨形态 HOL。

## 2. 机制

### 结构

将双向环改为 **不对称角色**（路由规则变更，非仅 QoS）：

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Traffic Class Latch | 1b / 注入事务 | NIC：0=P2P_STREAM，1=COLL_CTRL_DATA |
| Direction Lock 表 | 16×2（class/子类 → 首选方向编码） | 例：P2P_DAT→CW；COLL_FAN→CCW；短控制→CCW |
| Classifier | opcode + 形态位 → class（可与 CSR 分类器共享 ROM 口） | 32× 条目级 |
| RBRG U-turn 口 | 组合 CW↔CCW 交叉，1 拍偏转，**无队列** | 唯一合法例外跳 |
| Livelock age | 8b 头字段 | U-turn 循环时 age++；超限强制沿 Lock 首选方向等待空槽 |

角色默认（可配表，非运行时预测）：

- **CW**：主成长距 P2P Dat 流
- **CCW**：主成集合扇入/扇出与短控制
- 目的方向由 class 位选定；仅当目的几何要求反向时，经 **RBRG U-turn** 一跳换向，然后锁回目标方向角色

### 数据路径

1. 注入前：Classifier 写 Traffic Class Latch；查 Direction Lock → preferred_dir。
2. 路由：flit 仅沿 preferred_dir 前进（相对基线“最短/双向任选”的规则收紧）。
3. 若目的在反向半环且无同向合法路径：到最近 RBRG 做 1-cycle U-turn deflect（CW→CCW 或反之），仍 bufferless；U-turn 后按新方向 Lock 继续。
4. age：每次 U-turn +1；age≥AGE_LIM(例如 8) 禁止再 U-turn，改为在锁定方向上等空槽注入/前进，破活锁。
5. **不**永久增加槽数；**不**加 flit 队列。

### 时序

| 路径 | 延迟 |
|------|------|
| Class latch + Lock 查表 | 1 组合或 1 拍 |
| 环上前进 | 基线链路延迟 |
| U-turn deflect | **1 拍**组合交叉 |
| age 比较 | 同拍 |

机制插入 0–1 拍于 NIC；U-turn +1 拍于 RBRG 例外路径。

## 3. 为什么有效

**零和槽 + 去跨形态 HOL**：两形态争同一方向 ⇒ 过路 A 阻塞注入 B。分区后 CW≈P2P、CCW≈集合，注入失败主要来自 **同形态** 内部争用，跨形态 HOL 几何消除。Little：同形态空槽可见率上升 ⇒ λ 上升 ⇒ makespan 下降。

**基线 R/W 不对称吸收**：读坍/写稳暗示方向角色可承载不对称；把“易坍形态”与“稳形态”分到不同方向，避免读态流量拖垮写向（或反之）。

**Amdahl**：设跨形态冲突占注入失败份额 f_x，分区理想下去掉 f_x；残余同形态争用仍在（尤其 alltoall）。

**Killer（HARD-4 / alltoall）**：alltoall 同时使用两类形态，**两方向皆忙**。本卡 **不声称** 两方向保持空闲；预期残差争用：alltoall makespan 改善弱于纯 gather/broadcast，区间见评估。必须在仿真中填满声称容量并报告完成数，禁止静默丢包。

**对比**：异于 CBC（无日历气泡）；异于 AODI（非临时偏转制造注入洞，而是永久角色分区）。

## 4. 评估计划

- **基线**：DV200 `tests/soc_sim`，额外 FC 关；12+2；512B；outst. 512/256。
- **指标**：分流量类 makespan；完成事务数；collapsed；均匀读峰值后 goodput。
- **负载**：P2P 均匀读/写 + 全集集合；**强制包含 alltoall** 作为 killer。
- **必须 cycle 级建模**：Classifier；Direction Lock 16×2；RBRG U-turn deflect（1 拍）；livelock age 8b；与 CHI 四环（每通道对 CW/CCW）交互。
- **消融**：Lock 关闭（恢复双向任选/最短）→ 跨形态 HOL 应回归，集合/读坍指标变差才可归因 DPH。
- **包络**：满 12+2 多环全集；减箱不足。
- **预期收益区间与置信度**：
  - 均匀读（抗坍）：makespan **0.70–0.95×**，峰值后 goodput 坍塌幅度缩小（中置信）
  - 均匀写：**0.90–1.05×**（高置信近中性）
  - gather/reduce/broadcast：**0.60–0.88×**（中）
  - alltoall：**0.75–1.05×**（低–中；残差双形态争用，**不宣称双方向空闲**）
  - allgather/allreduce：**0.65–0.92×**（中）
  - 禁止用单类均值或“通过 0.85”表述。

## 5. 硬件开销估算

| 项 | 面积 | 功耗 | 延迟 |
|----|------|------|------|
| Class latch 1b + Lock 16×2 / NIC | ~0.0002–0.0005 mm² | <0.2 mW | 组合–1 拍 |
| RBRG U-turn 交叉（每通道对） | ~0.001–0.003 mm² | ~0.5–2 mW | 1 拍 |
| age 8b 比较 | 可忽略 | <0.1 mW | 同拍 |
| **每节点级合计** | **~0.001–0.004 mm²** | **~1–3 mW** | **0–1 拍 + U-turn 1 拍** |

纯路由规则与组合交叉，保持 bufferless；无增带宽调参。
