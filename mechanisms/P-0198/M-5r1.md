## 0. 相对 M-5 改了什么

### 诊断根因（Snp 15:1 KILL）

T3 night（审计 PR #76 / 仿真 tip `b0b4cf9`）在诚实周期里把 15:1 H-SNP-LAT **加严到** `snp_path=17.0533`、`mixed=32.5873`，对照 T2 代数 `1.5625`（|rel| 9.91 / 19.86）。T2 用 `q=1` 细槽 TDM：`E[wait]=(r/(r+1))·(r·q/2)`，`L_snp=C_ring/2` → 15:1 才踩 1.4×。**周期级不合法**：每次 DAT↔SNP 绑定切换必须走 Epoch Drain（marker 双回 + `epoch_committed` 绕环），量子是粗的 `≈T_steady`，不是 `q=1`。Snp **无环上队列**，DAT_EPOCH 期间整条 Snp 物理环被 **排他译成 ghost Dat 身份**，本征 Snp 只能 stall 到下一 SNP_EPOCH。

非绑定假说「bulk Dat 偷了小包容量 / drain 卡住小包」**对了一半**：

1. **主因（已由 `snp_path` 单独证实）**：15:1 臂在 **没有 Dat 混合** 时仍到 17.05×。这不是 Dat 占槽，是 **排他 epoch 身份 + 粗 drain 量子** 把 Snp 锁在 SNP_EPOCH 窗外。夜测 7:1 `snp_path` 已双峰 KILL（258/253/23），混合窗 3:1/7:1 也 KILL（27.51 / 30.84）。completions 不丢——duty floor 最终会注入；**失败端点是 makespan / 尾，不是完成数**。
2. **加重项（mixed 32.59 vs snp_path 17.05）**：Dat 重 gather 把 FSM 钉在长 DAT_EPOCH；翻到短 SNP_EPOCH 再付一次 `T_drain≈75`。小包即使挤进 1/16 窗，也先吃完 drain 死时间。Rsp 不是本杀线（绑定表未动 Rsp 环）。
3. **T2 1.5625 不得贴成 T3 pass**。T3 报告已写：fine-slot H-SNP-LAT 不是合法周期日程。

只把 duty 从 15:1 改回 7:1 / 3:1 **不算修订**（参数扫描，机制仍是排他身份）。3:1 混合夜测已经 27.51× KILL。

### 结构改动（机制，不是旋钮）

M-5：**绑定表 = 物理环的排他逻辑身份**。DAT_EPOCH 里 Snp 导线 = ghost Dat；本征 Snp 禁止上该环。

M-5r1：**绑定表降级为 ghost Dat 宾客资格**。Snp 物理环的 **本征通道残留权（native residual）** 永不被 epoch 剥夺：

- header `channel-id=Snp` 的 flit **永远是 Snp 环合法公民**，不看 DAT/SNP_EPOCH，**不为注入 Snp 走 Epoch Drain / FLIP**。
- ghost Dat 仍可占用 **本拍空出的** Snp 环槽（保留 M-5 的第二 Dat 高速），但本地 `Snp pending>0` 时 **新** ghost 注入被门控：空槽归本征 Snp（steal-back）。
- 在途 ghost Dat **继续前进**（highway 仍赢；不抢在途、不加 flit 队列、不发明第三槽）。
- Epoch Drain / `epoch_committed` **只服务 ghost 世代切换**，不再是 Snp 注入的准入闸。

### 为何能在 15:1 混合下界住小包延迟

Snp 等待从 `O(T_drain + r·q)`（排他窗 + 粗量子）变成 `O(等本地 Snp 环空槽)`（无缓冲注入的普通几何等待）。15:1 只还规定 **无 Snp pending 时** ghost 可借走多少空槽，不再规定 Snp 必须消失 15/16 的时间。稀疏 Snp（推理 decode / 目录嗅探）下，空槽到达率仍接近 M-5 的 ghost 供给。

### M-5 哪些收益留下

- Dat 饱和时，Snp 环空槽仍可作 ghost Dat → Dat 有效槽仍 `≤1+duty_dat`，再扣 drain/SYNC/pipe **与 steal-back 税**。
- 屏障、接受集 `{local, local−1}`、失配 NACK、禁止把 Dat 当 Snp 译码，全部保留（只约束 **宾客** Dat）。
- 相位仍只看本地 Dat EMA / Snp pending；hint 至多 advisory；SYNC ≠ 预测。
- HARD-1 仍要：rebind-off 的 Dat 侧重集合 / 推理搬运 makespan **严格差于** 开 SB 的最佳 on-arm。

## 1. 根因分析（信封内）

DV200：Req/Rsp/Snp/Dat 四条独立双向环，每向每拍 1 槽，无片上 flit 队列。LLM **推理** 主路径是 decode KV-cache / 权值 P2P 搬运 + 推理期集合（broadcast / 小规模 allgather 等）。这些作业 Dat 重、Snp 稀疏但 **延迟敏感**（目录/一致性栅栏进推理尾）。

M-5 看见 Dat 饱和、Snp 导线闲，把闲置导线时间借给 Dat——对 Dat 槽争用是对的。但它用 **整环身份翻转** 实现借用：小包被写成「等下一个 SNP_EPOCH」。T2 把这次等待当成 `q=1` 轮转；诚实周期必须为每次翻转付 `T_drain=(k_circ+1)·C_ring+n_pipe`。结果：Snp 路径被机制本身拉成十几倍，混合窗再翻倍。这不是流量倒霉，是 **排他复用把本征通道写成宾客**。

源端流控能削 Dat 突发，**不**还给 Snp 一条被身份锁死的物理环。无拥塞控制则 Dat 继续崩。要同时留住 ghost Dat **和** 小包尾，必须改所有权，而不是改 7:1 / 15:1。

## 2. 机制

### 2.1 结构

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Rebind FSM / die | IDLE / ARM_DRAIN / DRAIN / FLIP / STEADY | **只** 切换 ghost 资格，不切换本征 Snp 公民权 |
| 绑定表 | NIC + RBRG 各一份 4×4 one-hot + 1–2 拍 pipe | `bind_snp∈{Snp, Dat}` = **ghost Dat 是否被允许**，不是「此环现在是谁」 |
| 本征残留仲裁 | 每节点、每向、组合 + 可选 1 拍 | 同拍：`Snp pending ∧ 本地 Snp 环槽空` → Snp 赢；ghost 新注入门控 |
| Epoch / SYNC / DRAIN | 与 M-5 同：2b tag、Req 环 marker、`epoch_committed` | **仅** 约束 ghost Dat 新世代 |
| 失配路径 | 深度 1 holding（非 highway 队列） | 只针对 **宾客 Dat** 的 tag/绑定失配 |
| 本地压力 | Dat util EMA + Snp pending | 调 duty **偏置**（借多少空槽），不调 Snp 准入 |

STEADY 绑定例（duty 15:1 仍可配，因为它不再锁死 Snp）：

| 默认资格 | Req | Rsp | Snp 物理环 | Dat 环 |
|----------|-----|-----|------------|--------|
| ghost-eligible（DAT 偏置） | Req | Rsp | **本征 Snp 优先**；空槽可 ghost Dat | Dat |
| ghost-ineligible（SNP 偏置 / rebind-off） | Req | Rsp | 仅 Snp | Dat |

**明确**：时间复用仍 ≠ 第二永久 Dat 端口。有效 Dat ≤1+duty_dat − drain − SYNC − pipe − steal-back。声称「近乎双 Dat 无税」仍是撒谎。

**明确不是**：slotted-ring / TDM 日历（无固定第 k 槽留给 Snp）；textbook 最短 CW/CCW；M-10 年龄优先（优先级是 **本征通道权**，不是包年龄）；只加 buffer。

### 2.2 Snp Steal-Back（同拍规则）

每节点、每方向，对 Snp 物理环本地槽：

1. 过路 flit 仍赢（零和不变）。
2. 槽空且 `Snp pending` → 注入本征 Snp；`channel-id=Snp`；**不**检查 DAT_EPOCH，**不**要求 `epoch_committed` 为 Snp 服务。
3. 槽空且无 Snp pending 且 `bind_snp=Dat` 且 FSM=STEADY 且 ghost 世代已 committed → 允许新 ghost Dat（M-5 宾客路径）。
4. 槽空且两者都想上 → **Snp 赢**；Dat 回退主 Dat 环或下一拍。
5. 禁止：为了给 Snp 让路而丢/缓冲在途 ghost（那是第三槽或队列）。

RBRG：**header channel-id 是本征权威**。`channel-id=Snp` 按 Snp 桥接，**禁止**要求「当前 bind 必须是 Snp」。`channel-id=Dat` 走 Snp 物理环时仍按绑定表 + `epoch_tag` 译码；接受集外 → NACK / 原 Dat 环重注入。永不把 Dat 载荷按 Snp 语义重解释。

### 2.3 Epoch Drain（收窄后的职责）

Flip 序列仍是 ARM_DRAIN → DRAIN → FLIP + `epoch_committed`，但：

- ARM_DRAIN **只停新 ghost Dat**（即将被取消资格的宾客），**不停本征 Snp**，也不停主 Dat 环。
- DRAIN / sniff 仍清 `epoch_tag==old` 的 **ghost** 在途。
- 晚节点不得提前按新 **ghost** 绑定注入；本征 Snp 不受该门控。
- 稳态 `bind_mismatch_redirect==0` 仍针对宾客路径。

这切断 T3 的因果链：Snp 不再为「整环换身份证」付 1–2 环周税。

### 2.4 相位臂

与 M-5 相同：本地 `ρ_dat_ema` 高且 `n_snp_pend` 低 → 请求更高 Dat duty（更多空槽借给 ghost）；反向则拉回。Runtime hint 至多 advisory。无 hint 必须仍能安全 drain/flip/steady。SYNC 只对齐 epoch / 传播屏障。

### 2.5 时序

| 路径 | 延迟 |
|------|------|
| 本征残留仲裁 | 组合或 +1 拍（与 highway 同拍采样） |
| ghost 新注入门控 | 同拍读 `Snp pending` |
| ARM_DRAIN → DRAIN（仅 ghost） | ≥1–2 环周 |
| FLIP + bind pipe | 1–2 拍 |
| `epoch_committed`（仅 ghost 新世代） | +1 环周 |
| Snp 等空槽 | 无缓冲几何等待；**不是** duty 周期 |

## 3. 为什么有效（推理主指标）

主指标：**推理 makespan / 尾**（decode KV-cache 与 P2P 搬运，加上推理期集合与其一致性 Snp）。训练集合不单独论证。

**相对无拥塞控制**：KV / P2P / 推理集合仍是 Dat 槽争用。SB 保留 ghost 空槽 → Dat 段仍可短于单 Dat 轨；Snp 不再被机制锁窗，一致性栅栏不把 decode 尾打飞。

**相对源端流控**：源端 FC 削 Dat outstanding，Snp 环身份仍是 1:1，**没有**第二 Dat 物理路径。崩塌区 Dat makespan 的上界仍是一条环。SB 给的是「空槽借给 Dat、本征小包随时可抢回」，不是源端节流。

**相对原 M-5**：Dat 甜区（T3 gather on-arm 打平、HARD-1 成立）留下；杀掉的是排他身份。15:1 混合下 Snp 等待不再乘粗量子。steal-back 税是「有 Snp pending 的那些空槽不借给 ghost」——推理 Snp 稀疏，税小；Snp 风暴时 Dat 宾客理应让路（H-SNP-CAP 仍可杀 Dat 侧甜区，必须分列）。

**零和**：不增加物理槽。谁用 Snp 完成数不掉、只报 Dat 0.55× 过关，谁在重演 M-5 的藏法。

## 4. 评估计划

- **信封**：DV200 `tests/soc_sim`；12+2；512 B；公开 outstanding；禁完美预测 / 无限带宽。
- **主负载（推理）**：decode KV 扫描与权值 P2P；推理期 broadcast / 小 allgather；**强制** 15:1 与 3:1/7:1 的 Snp-on-Dat 混合。训练 AllReduce 等可作对照列，**不是**过关主列。
- **基线（cycle，分列，不平均）**：无拥塞控制（rebind-off / 额外 FC 关）；源端流控（只节流 Dat outstanding，不重绑）；原 M-5（排他 epoch，15:1 必须保留一列）。
- **强制 endpoints**：推理 makespan 与尾（p99 完成）；Snp makespan **与** completions；Dat 分流量类 makespan / collapsed；`bind_mismatch_redirect` 稳态目标 0；steal-back 次数 vs ghost 新注入次数（归因）。
- **消融**：`sb-off`（回到 M-5 排他）→ Snp 15:1 应回到 KILL 量级；`ghost-off`（只留本征残留、不借空槽）→ Dat 侧应回到无 CC 量级。只涨 `p_inj` / 结构零 / 注入优势而 makespan/尾不缩 = 不得分。
- **杀假设（假设，不是测得）**：Snp makespan ≤ **1.4×** 无 CC / rebind-off。相对 T2 代数阈值 **1.5625**：预测（**假设 H-SNP-LAT-SB**）稀疏 Snp 的 `T_snp/off` 落在 **≤1.4**，并 **低于** 1.5625；**禁止**把 1.5625 或 T3 的 17.05/32.59 改写成 r1 的测得 pass。混合 15:1 若仍 >1.4 = 该臂失败。
- **Dat 侧**：card-claim 区间仍写 0.55–0.85×（扣税 + steal-back 后）——**不签字、不把 T3 的 0.551/0.583 贴过来**。
- **包络**：满 12+2 + 四环 + 推理 P2P/集合 + Snp 列。单环、只开 Dat、只报 Dat 均值 = reduced-bbox。
