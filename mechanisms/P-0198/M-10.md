# M-10: 环上年龄/集合进度优先仲裁（注入侧）

- problem: P-0198
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

无缓冲环：过路占用 highway 时本地不能注入。过路走空后出现一个气泡，**该节点上** 可能有多个本地候选同时想注入（同一 NI 的多个 CHI staging 头、或同一节点上多个 TC 的待发 flit）。默认随机或 round-robin 把气泡分给「碰巧轮到」的候选，不区分该候选是否位于集合临界路径上。

集合 makespan 由最慢加入者决定：`T_allreduce ≥ max_i T_join(i)`（gather/reduce 同构）。根节点附近或晚到扇入的 late joiner 若在本地仲裁里反复输给连续的 P2P 短事务，屏障被拉长，而平均注入成功率仍可看起来「还行」。公开扫描下多数集合 `collapsed=true`，broadcast（8192 B、OQ 4096）却能维持约 117.76 B/ns——形态之间的临界路径不同，RR 对它们一视同仁。

基线均匀读/写 makespan ≈ 4403.2 / 4834.6 ns（各 46080 txn）说明 P2P 本身也重；仲裁必须给集合进度加权，同时把 P2P 饥饿用年龄饱和封顶，避免 P2P 无界推迟。

本卡是 **节点内注入仲裁**，不是源端速率环、不是 token bucket、不是 ECN、不是端到端 tag/窗口。过路仍然绝对优先。平台 `--cc-scheme srcfc|ecn|tagwin|…` 是对照基线。Age 计数的是 **本节点注入失败拍**，不在网络里循环调整发行率。

## 2. 机制

### 结构

每个 NI、每个环方向一份本地仲裁。候选数钉死为 **4**（与「4-input 比较树」一致），对应本节点该方向上最多 4 个已就绪的 header staging 槽：

- 槽 0..3 可以是 4 个 TrafficClass 桶，或 4 个 CHI 未完成请求头；`tests/soc_sim` 建 4 深 **header-only** staging（每槽 1 个 header）。这不是织物 flit 队列，不出 NI。

1. **年龄 `Age[3:0]`**：每槽 4 bit，饱和到 15。该槽 `ready=1` 且本拍未赢仲裁（含因过路未能注入）则 `Age <= Age+1`（饱和）。该槽赢仲裁并成功注入则 `Age <= 0`。空槽 `Age=0`。
2. **集合进度类 `Class[1:0]`**：每槽 2 bit，来自流量发生器标签或 CHI opcode 映射 CSR（16 项 × 2b = 32 bit / die，与 M-8 的 `TC` 可共用译码，但本卡不依赖 M-8）。编码钉死：
   - `0`：P2P / 均匀读 / 均匀写 / 权值 / KV / 激活
   - `1`：broadcast
   - `2`：reduce / gather
   - `3`：allgather / allreduce / alltoall（`all*`）
3. **分数**：`Score = Age + K·Class`，无符号。`K` 为 4 bit CSR，合法 0..15，复位 `K=4`。则 `Score ∈ [0, 15+15×3] = [0,60]`，6 bit。复位下 `all*` 相对 P2P 的静态偏置 +12，约等于 12 次失败年龄。
4. **仲裁**：仅当该方向 `slot_occupied=0` 且存在 `ready` 槽时启动。比较树在 4 个 `Score` 里取最大；打平选槽号最小（确定性）。胜者获得本拍注入权。`slot_occupied=1` 时无人注入，4 个 ready 槽都年龄 +1。
5. **过路绝对优先**：highway 输入有效则比较树输出作废，不驱动注入 mux。

本卡不向邻居要占用、不调节源 outstanding、不丢 flit。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| staging 槽 | 4 × 1 header / NI / 方向 | 每槽 1 装填 1 弹出 | header 与平台 CHI 头同宽；`ready` 1b×4 |
| `Age` | 4 × 4 bit | 每拍条件 +1 / 清零 | 4b，饱和 15 |
| `Class` | 4 × 2 bit（装填时写入） | 1W 随 header | 2b |
| opcode→Class 表 | 16×2b = 32 bit / die | 1R 组合 | in 4b `TC` 或 opcode 低 4b |
| `K` CSR | 4 bit / die（可全局） | 1R1W | 0..15，复位 4 |
| `Score` | 组合 4×6 bit | 无存储 | `Age` 4b + `K*Class` 6b（`Class`≤3，`K`≤15 → 乘 2b×4b） |
| 比较树 | 3 个 6b 比较器（4→2→1） | 1 次/拍 | 胜者索引 2b |
| 注入 mux | 4:1 | 1 出到 highway | 2b 选择 |

14 die × 4 通道 × 2 方向 × 4 槽 × 4b Age = 1792 bit 年龄寄存器。无 CAM，无跨节点分数总线。占用指标仍是 `O_d(t)∈{0,1}`，与其它卡同一套，不另定义「加权占用」来过线。

### 数据路径与状态机

每拍每方向：

1. 若 `in_valid`（过路）：输出 = 过路；对所有 `ready` 槽 `Age = sat15(Age+1)`；结束。
2. 否则对每个槽算 `Score_i = Age_i + K * Class_i`（`ready=0` 的槽不参与，比较输入塞 0 且 mask 掉）。
3. `winner = argmax Score_i`（mask 后）；`inject = ready[winner]`。
4. 注入成功：弹出该 header，`Age[winner]=0`。
5. 其余 ready 槽 `Age = sat15(Age+1)`。
6. 无 ready：输出空槽，年龄不变。

无多状态 FSM。乘 `K*Class`：`Class` 2b 可用 `(Class==1)?K:(Class==2)?(K<<1):(Class==3)?(K<<1)+K:0`，3:1 mux + 4b 加，同拍。比较树 2 级 6b，目标 1 周期。禁止把分数送到其他节点。

## 3. 为什么有效

气泡是零和残差：每拍每方向最多 1 个本地赢家。RR 把残差均匀给各槽，集合 straggler 的有效 `λ` 被 P2P 稀释为约 `1/4`（4 槽满时）。`Class=3` 在复位 `K=4` 下静态 +12，使 `all*` 在年龄尚未饱和时优先拿到气泡；`Age` 饱和到 15 后，长期饥饿的 P2P（`Score=15`）可以超过刚到达的 `all*`（`Score=12`），避免 P2P 活锁。

Little 用在屏障：`T_barrier ≥ L_straggler / λ_straggler`。本地优先提高的是 straggler 的 `λ`，不改变环的 `μ=1 slot/cycle`，也不先验降低 offered rate。Amdahl：仅当「本地仲裁选错赢家」占该类 makespan 的 `f_a` 时，加速上界 `1/(1−f_a)`。单候选节点 `f_a=0`（比较树退化成直通），不得用「只有一个 ready 槽」的用例写收益。

约束 1：年龄-only（`K=0`）或类别-only（`Age` 恒 0）若与全卡不可分，不得把关掉的那一项写成原因。off 臂应是 RR 或固定槽优先；若 off 仍「满占用」且 makespan 重合，禁止写因果。

## 4. 评估计划

### 基线

1. 公开基线：12+2、512 B、AIC RO 512 / WO 256、流控 OFF；本地仲裁 = RR 或平台默认。
2. 对照：`--cc-scheme srcfc`、`ecn`（及 `tagwin` 若已实现）。仲裁开/关 × 各对照。srcfc/ecn 降 offered rate，本卡不降；两者收益不得混记。
3. 消融：
   - D0：RR（off）。
   - D1：仅 Age（`K=0`）。
   - D2：仅 Class（`Age` 不递增，只比 `K·Class`）。
   - D3：Age + Class，`K=4`。
   - D4：`K=8` 敏感性。
   只对与 D0 可区分的臂写因果。D3≈D0 则本卡无贡献。D3≈D1 则 Class 无贡献，依此类推。

### 必须 cycle 级建模的结构

- 每方向 4 个 header staging + 4b Age + 2b Class。
- 6b Score 与 4-input 比较树，1 周期。
- 过路优先旁路。
- opcode/`TC` → Class 表 32b。
- **不要** 建全局准入、token bucket、跨 NI 年龄交换、织物数据队列。

### 指标与负载

Full envelope：12+2、CHI 四环、有限链路延迟、有限 outstanding。必测：allreduce、gather、alltoall 的 makespan（相对 RR）；全集其余集合；P2P 权值/KV/激活与均匀读/写。并发信封至少一组（P2P + 一个 `all*`），以暴露本地多候选。扇入/扇出与读写不对称必须打到，禁止未声明 `p_mix`。

Endpoints：每类 makespan、完成 txn 数、collapse 标志。P2P 回归硬界：均匀读/写 makespan 相对 D0 **不得变差超过 8%**（超过则判本卡在该设定失败，而不是「集合赢了所以通过」）。0.85 是每类 pass bar，不是跨类均值。

Proxy：各 Class 赢得气泡的次数、Age 饱和次数、inject-fail。平均 hop / 单环注入成功 / 均匀读峰值 goodput ≠ endpoint。

Reduced-bbox（单环单测、top 子集、只均匀读、完美预测、无限 BW）≠ full envelope。

### 预期收益区间与置信度

allreduce / gather / alltoall：相对 D0，makespan 预期 **8%–25%**，且须 D3 相对 D0 可分；collapse 可能对部分设定翻转。broadcast：预期 **0%–12%**（`Class=1` 偏置弱）。P2P：预期 **-8%～+5%**（允许小幅变差，超出 8% 失败）。D1/D2 单独预期小于 D3；若 D3 不优于较好的单臂，报告「第二项无因果」，不要写满卡故事。

置信度中：比较树语义可 cycle 验证；临界路径占比未知。不宣称 T0 通过。

## 5. 硬件开销估算

面积：每方向 4×4b 饱和计数 + 3 个 6b 比较 + 4:1 header mux。14×4×2 方向复制，年龄寄存器约 1.8 kbit，逻辑估计 **<8 kGE** 合计。无 SRAM 阵列。延迟：1 拍仲裁，过路路径不进比较树。功耗：仅在 `~slot_occupied && any_ready` 时打开比较树时钟。不增加 highway 槽，不增加织物缓冲。
