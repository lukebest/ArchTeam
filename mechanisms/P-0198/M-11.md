# M-11 未命中弹出本地回弹（Missed-Eject Local Bounce, MELB）

- problem: P-0198
- id: P-0198/M-11
- author: Jim Keller
- round: 2

## 1. 根因分析

Bufferless 双向环：每方向每拍 1 个 highway 槽，过路优先，无 flit 队列。目的节点若本拍不能 eject（NIC 口忙、RBRG 对侧忙、同拍已接另一方向），到达 flit **必须再绕整圈** 才能重试。环周 `C_ring` 在文档底环量级约数十 CS；一次 miss 把该 flit 的剩余服务时间加上一整圈，而不是 1–2 拍。

推理 decode 的 KV-cache / P2P 搬运把多源 shard 砸向少数 decode die：尾 flit 不是「还没注入」，而是 **已经在环上、在 dest 门口被弹回整圈**。上一轮死掉的 CBC / AODI 把故事写成「制造注入洞 / 抬 `p_inj`」——T3 上 `p_inj` 动了、`T_mix=1`、尾不动。CSR 的 GRANT 公民税同样没砍 last-completion。CRRF（M-5）靠时间复用 Snp 导线抬 Dat 槽，gather 尾能动，但 15:1 把 Snp 小包延迟打到杀线。

本卡根因钉死：**missed-eject × 整圈 orbit 税**，不是空槽稀缺，不是源端窗口，不是通道–环绑定。推理尾 = 最后一拍 KV / 推理期 collective 的最后到达；那一拍如果 miss 一次，makespan 直接 `+C_ring`。训练 AllReduce 大块是次要场景，本卡不另作收益论证。

## 2. 机制

### 2.1 结构

仅在 **目的节点、同一 CHI 通道的方向对** 上加回弹口。禁止跨 Req/Rsp/Snp/Dat。禁止把回弹写成注入洞。

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Dest-miss 检测 | 1b：`at_dst ∧ ¬eject_ok` | 只在 dest 采样，过路节点不动作 |
| 2×2 bounce XB | 同通道 CW↔CCW；深度 0 | 仅 dest-miss 使能，**不是** AODI 的 inject-hole 仲裁 |
| Bounce hop 计数 | 头 2b，目标 = 2 | 回弹路径恰好 2 跳后对准 dest 再试 |
| `BOUNCE_MAX` | 可配，默认 2 次 | 超限改走整圈 orbit（与基线相同） |
| `inject_from_bounce_hole` 计数 | CSR 32b | **硬不变式 ≡ 0**：回弹让出的槽禁止被本地注入偷走 |
| Opposite-busy 门 | 1b | 对向本拍占用 ⇒ 禁止回弹，走整圈 |

**与 AODI 的结构切断（禁止再提交等价物）**：AODI 偏转的是 **挡路过路 flit**，目的是给 **本地注入** 造 1 拍洞。MELB 偏转的是 **自己这条已在途、已到 dest 的 flit**，目的是把重试路径从 `C_ring` 砍到 2。本地 NIC 看到回弹让出的槽必须当普通过路空/下一公民，**不得** `inject_ok`。T3 若观测 `inject_from_bounce_hole>0`，本卡作废，不是「意外收益」。

### 2.2 数据路径 / cycle-level

每拍、每个节点、每个 CHI 通道方向：

1. Highway 槽到达。若 `dst≠me`：基线前进，MELB 不插脚。
2. 若 `dst==me` 且 `eject_ok`：弹出，回弹计数清零。结束。
3. 若 `dst==me` 且 `¬eject_ok`：
   - 对向出口本拍 **空** 且 `bounce_count < BOUNCE_MAX`：U-turn 进入对向，`bounce_count++`，头标记 `in_bounce=1`。本方向槽变 empty。**本地注入仲裁对本拍该 empty 视为禁注入**（记入探针，违例=机制失败）。
   - 否则：整圈前进（基线 orbit），`bounce_count` 保持。
4. `in_bounce=1` 的 flit 在对向走满 2 跳后，在下一节点再 U-turn 回原方向，对准 dest；此时若 dest 仍忙，重复步骤 3。
5. 不跨通道；不进 RBRG 侧缓；无 flit 队列。对向双忙时回弹几何为零——与 AODI 双忙 `hole≡0` 同类诚实，本卡 **不** 在双忙区宣称尾收益。

### 2.3 时序

| 事件 | 周期 |
|------|------|
| dest-miss 检测 + opposite-busy | 同拍组合 |
| 2×2 U-turn | 同拍或 +1 拍打拍 |
| 回弹路径 | **恰好 2 跳** + 可选 1 拍打拍 |
| 超限回退整圈 | 与基线 `C_ring` 相同 |

机制关键路径 0–1 拍。最坏仍有界：`BOUNCE_MAX` 次短回弹后回基线 orbit。

### 2.4 仿真器改动（必须写明）

- **允许只加模型**：`tests/soc_sim` 里 dest eject 失败分支增加 bounce FSM 与 `inject_from_bounce_hole` 探针，**不必**改 RTL。
- **若现有 highway mux 没有 dest-only U-turn**：这是 **simulator structure** 变更——只允许开在 platform 仓 `bufferless-ring-noc` 的 **新分支**（禁止改该仓 `main`，合入须审计后）。改动点：

## 3. 为什么有效（尾，不是 `p_inj`）

推理 decode 一波 KV / 推理期 gather 的 last-completion：

```
T_last = t_arrive_last + n_miss · C_retry
```

基线 `C_retry = C_ring`。MELB 在「dest 忙且对向空」时 `C_retry = 2 (+pipe)`。`n_miss` 不需要变小——**单次 miss 的税**变小，尾就动。这与「多偷几个空槽让更多人开工」是不同的关键路径。Little 在这里用在 **已在途尾包的驻留**，不是注入成功率。

相对三条必须打败的基线（假设，待 cycle 证伪）：

- **无拥塞控制**：尾包 miss 一次就 `+C_ring`。MELB 把该项换成 2。
- **源端流控**：窗口只能少注入，**不缩短已经到 dest 门口的 miss 税**；decode 小消息上窗口还容易把有效并发打没。MELB 不碰 outstanding。
- **M-5 CRRF**：CRRF 赢的是 Dat 槽时间复用；T3 已证明 15:1 Snp 杀线，且 gather 三档 duty 尾打平（dest 弹出主导，不是 duty 在买 span）。MELB 不借 Snp、不 flip epoch、不交 drain 税，直接砍 dest-miss 的 `C_retry`。若 dest 从未 miss，本卡必须自己死——见 §7。

## 4. 失败模式

- **对向也满**（推理期 MoE all-to-all / 双向 KV）：回弹门关闭，行为=基线 orbit。必须单列，禁止折进 P2P 单向甜区。
- **回弹让出的槽被注入器偷走**：退化成 AODI。`inject_from_bounce_hole≡0` 违例 = 机制失败。
- **BOUNCE_MAX 过大 + 对向抖动**：短环抖振。`BOUNCE_MAX=2` 是默认；扫描 {1,2,4}，4 若拉长 Snp/对向尾必须暴露。
- **把 2×2 做成 1 深侧缓**：发明队列，信封禁止。XB 深度必须 0。
- **只报 `p_inj` / hole 计数**：上一轮就是这么死的。

## 6. 评估计划

- **信封**：DV200 `tests/soc_sim`，12+2，CHI 四环，512 B，公开 outstanding，禁完美预测 / 无限带宽。
- **主指标**：推理 **decode KV-cache / P2P** 与 **推理期 collective**（decode 步 AllGather KV、小 AllReduce、token broadcast）的 **makespan / p99 尾 / last-completion**。训练大块集合只作附注，不参与过关叙事。
- **必须同表打败的 cycle 基线**：`no-CC`；`source-FC`（源端窗口/令牌，参数扫公开档）；`M-5 CRRF`（rebind-off + 3:1/7:1/15:1 分列，**禁止**把 CRRF 的 T2 1.5625 / 0.55–0.85× 贴进本卡 T3）。
- **必须 cycle 建模**：dest-miss U-turn；2 跳回弹；`BOUNCE_MAX`；`inject_from_bounce_hole≡0`；对向忙回退整圈；Snp 15:1 混合小包延迟（本卡不借 Snp，但仍必须报，不得贩卖未过线的 Snp 数）。
- **消融**：`bounce-off`。HARD：推理主类 last-completion **严格差于** bounce-on；若 `T_mix≈1` 则淘汰，即使 `p_inj` 上升。
- **包络**：满 12+2 + 多环 + 多步 decode；单环 / 单波 / 只报注入率 = reduced-bbox。
- **预期区间（假设 / 预测，未测，不签字）**：
  - 单向 decode KV / 热 dest P2P 尾：相对 no-CC **0.70–0.95×**（中；依赖 miss 率）
  - 相对 source-FC：**0.75–0.98×**（中；源端窗口不砍 miss 税）
  - 相对 CRRF Dat 尾：在 dest-miss 主导且 Snp 必须活着时 **0.80–1.05×**（低–中；CRRF 若本 bbox 无 miss 则本卡无事可做）
  - 双忙 / 推理 all-to-all：**0.95–1.15×**（低；应接近 1，变差必须单列）
  - Snp 15:1 混合：假设 **≤1.05×** no-CC（高；不借 Snp）。超过 1.4× = 杀，不得改叙事。

0.85 是约束条，不是测得均值。禁止用各类平均过关。

## 7. 可证伪声明

1. **H-MISS-TAX**：存在 dest-miss 且对向空的周期；这些周期上 `C_retry_on < C_retry_off`（2+pipe vs `C_ring`）。若 miss 计数为 0，本卡主收益不成立。
2. **H-TAIL-NOT-PINJ**：`inject_from_bounce_hole≡0` 且 `p_inj` 相对 bounce-off 变化不得当作收益；只有 last-completion / p99 下降才算。
3. **H-HARD-BOUNCE**：bounce-off 的推理主类 makespan **>** bounce-on。等号 ⇒ 淘汰。
4. **H-NO-AODI**：任意周期不得把 bounce 空槽写成 inject-hole。
5. **H-SNP**：Snp 15:1 混合小包 makespan 不得以未过线数字当卖点。

## 8. 自检（淘汰约束）

1. **禁止 T2 贴 T3**。消融 bounce-off 必须在诚实 cycle 上让尾变差；否则淘汰。不把解析 `C_ring/2` 当测得。
2. **注入优势 / 空槽 / 更高 `p_inj` 不算收益**。本卡显式禁止偷 bubble / 造洞；`T_mix≈1` 即使 hole 很多也淘汰。不重提 CBC「empty=机会」、CSR「reserve/grant 抬吞吐」、AODI「对向偏转造注入洞」。
3. **不是** slotted-ring / TDM / 最短 CW-CCW / DPH 方向分区。回弹不是选路，是 dest-miss 后的短重试。
4. **Snp 15:1** 必须分列；未过线不卖。
5. **本节所有数字都是假设/预测**，不是 card-claim 签字。
6. **2026-09-04 六硬**：bounce-off 仍满占用不得记因果分；不冻结地址高位（bounce 不改路由键）；只用一套 last-completion 定义（禁止再报一套「有效注入 makespan」）；killer 双忙 stride 必须单列不得瞒死；对照经典基线（no-CC / source-FC / CRRF / 最短方向基线 M-7 冻作对照不重发明）；min/mean≥0.85 是约束不是均值；单 dest / 单环减箱 ≠ 12+2 全信封。
