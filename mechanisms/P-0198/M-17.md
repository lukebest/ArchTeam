# M-17: Decode-epoch 单拍 highway 对换

- problem: P-0198
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

冻结信封同 P-0198：每方向每拍 1 highway 槽，过路绝对优先，无织物 flit 队列。推理 decode 一步的完成时间是该步所有 KV / P2P 小包与该步推理集合的 `max`。环上经常同时存在 **当前步** 的尾包和 **下一步预取 / 已完成步的迟到非关键 flit**。过路优先把 highway 给「碰巧已经在环上」的那一个，不管它是不是当前 `T_step` 的临界路径。当前 epoch 的 KV 头停在 NI 既有 staging 里看着过路走过去，注入等待进入该步的尾。

这不是多候选本地打分问题（那个结构已是已知 Age+Class）。即使本 NI **只有 1 个** 当前 epoch 头，只要 highway 被非当前 epoch 占着，尾包仍然起不来。根因是 **在途非临界 flit 与临界注入之间不能交换位置**，而节点上本来就有两个 1-flit 位置：highway 输入寄存器，和 CHI 口 1-flit staging。

本卡不是源端速率环、不是 token/ECN/窗口。平台 `--flow-control` / `--cc-scheme srcfc` 与 M-5 CRRF 黑盒是对照。

## 2. 机制

### 结构

每个 NI、每个 CHI 通道、每个方向一份对换器。Snp 环硬线关闭对换（`SWAP_EN_SNP=0`），Snp 路径 +0。

1. **epoch 字段 `EP[2:0]`**：在注入时写入 header 侧带（CHI user/qos 空位，或 3b 伴随线）。值来自本 die AIC 的 `CUR[2:0]` CSR，**不是** 测试台相位表，也不是对完成时刻的预测。
2. **`CUR` 的硬件递进**（因果，无预言）：AIC 为每个已发行请求保留 `EP`（落在既有 outstanding 表，读 512 / 写 256 的标签列 +3b）。当 `inflight(CUR)==0` 且 AIC 接受了新的 decode 步请求，`CUR <= CUR+1 (mod 8)`。不同 die 允许相差 1（流水）。禁止用全局屏障预言或 harness 标签冒充 `CUR`。
3. **紧急序**：`rank(ep, CUR) = (CUR - ep) mod 8`，值 0 表示当前步，1–3 视为「更老的 straggler」（尚未被本 die 退休的晚到步），4–7 视为「更新的预取」。比较器用 3b 减法。对换条件钉死为：
   - highway 有过路 flit，其 `rank_hw ≥ 4`（预取 / 未来步）或 `rank_hw > rank_st`（过路比 staging 更新）；
   - staging 有就绪 flit，其 `rank_st ≤ 3`（当前或更老）；
   - 过路 **不是** Snp（Snp 环本就关对换）。
4. **单拍对换**：满足则 highway 寄存器 ⇄ staging 寄存器。下一拍，原 staging 的临界 flit 成为过路（已在环上），原过路停在 staging，按普通注入规则等下一个空槽或再对换。节点内 flit 数不变：仍是 1 个 highway + 1 个 staging。
5. **不对换的情况**：staging 空；或过路同样临界 / 更老；或 Snp 环。此时过路优先保持基线。

禁止用对换「吸收」对端忙：被换下的 flit 不是因为下一跳不存在，而是因为临界序更差。它的下一跳仍是「再注入本方向」，与基线注入失败后的保持相同。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| `EP` 侧带 | 3 bit / 在途 flit | 随 flit | 3b |
| `CUR` CSR | 3 bit / die / 通道（可 4 通道共享） | 1W 硬件递进 / 1R | 3b |
| outstanding 标签 | 既有表加 3b/条 | 随发行写 | 读 512 + 写 256 上界；不新建表 |
| `rank` | 组合 | 0 存储 | 3b 减法 |
| 对换使能 | 1 bit CSR `SWAP_EN` / 通道 | 1R1W | Snp 复位 0，其余 1 |
| 对换 mux | 0 | 2× 2:1（highway ↔ staging） | 1b `do_swap` |
| staging | **既有** 1-flit CHI header/beat | 不新增深度 | 与平台 flit 切片同宽 |

14 die × 4 通道 × 3b `CUR` ≈ 168 bit CSR。无 CAM，无第三份 flit 寄存器。不变量（仿真器断言）：任一 NI 任一方向 `highway_valid + staging_valid ≤ 2`，且 `≤` 基线同一时刻上界。

### 数据路径与状态机

无多状态 FSM。每拍每方向：

1. 采样 highway `EP_hw`、staging `EP_st`、`CUR`。
2. `do_swap = SWAP_EN AND hw_valid AND st_valid AND (rank_st≤3) AND (rank_hw>rank_st)`。
3. 若 `do_swap`：组合 mux 交换两个寄存器，本拍 **不再** 走「过路直通」；临界 flit 从本节点进入环输出。
4. 否则：基线过路优先；staging 仅在 `~slot_occupied` 时注入。
5. `CUR` 递进与数据路径并行，只看 AIC `inflight` 计数器。

时序：3b 减 + 比较 + 2:1 mux，目标同拍；1 GHz 裕量不够则 `rank` 用上一拍 `EP`（epoch 在途不变）。过路在不对换时 +0 门（mux 选直通）。

## 3. 为什么有效

第一性原理：`T_step = max_i C_i`。把 highway 从「未来步预取」换成「当前/更老步」的 flit，是把临界 `C_i` 的剩余环上时间提前，把非临界 `C_j` 推迟。`max` 对推迟非临界不敏感，对提前临界敏感。这是屏障 makespan 的重排，不是提高 `μ` 或 `p_inj`。

节点数量不变：对换是两个已有寄存器的置换。被换下的预取 flit 多等的是它自己的松弛；它不进新队列，只是回到它注入前本来就在的 staging。

Amdahl：仅当「highway 被非临界占着、staging 里有临界头」这一事件占 `T_step` 的 `f_s` 时，加速上界 `1/(1−f_s)`。单 epoch、无预取的痕迹上 `f_s≈0`，必须报失效，不得用这种痕迹写收益。

推理（主）：decode KV 与同一步小集合带同一 `EP`，互相不对换；预取下一 token 的 KV / 提前发出的集合被换下。预期 `T_step` 与该步 p99 下降。失效：无预取、无跨步重叠；或 staging 经常空（临界头还没就绪——那是计算/内存，不是环）。

训练大块集合（次要，一句话）：大块通常同一 epoch 占满环，对换很少触发，预期近似中性。

## 4. 评估计划

### 基线

1. 流控 OFF 公开基线；过路优先、无对换。
2. `--cc-scheme srcfc` 等平台对照。本卡开/关 × 对照。
3. M-5 CRRF 黑盒：`sims/P-0198/M-5/sweep.py --mode smoke --seed 20260903`（`rebind-off` vs duty 臂）；`tests/soc_sim` 无开关则由评估方提供。不实现 CRRF。
4. 消融：
   - W0：`SWAP_EN=0`（off）。
   - W1：只允许 `rank_hw≥4` vs `rank_st=0`（只打预取，不动更老 straggler）。
   - W2：全卡比较。
   - W3：harness 写死 `CUR`（非法臂）：若只有 W3 优于 W0，判「测试台排程」，本卡失败。
   HARD：W2（或 W1）必须在诚实 cycle 下推理 `T_step` 优于 W0。W2 与 W0 不可分则禁写因果。

### 必须 cycle 级建模的结构

- 3b `EP` / `CUR`，`inflight(CUR)` 递进。
- 对换 mux 与 `highway_valid+staging_valid≤2` 断言。
- Snp `SWAP_EN=0`。
- **必须** 有跨步重叠（当前步 KV + 下一步预取），否则是 reduced-bbox。
- **不要** 建第 3 个 flit 槽、Age 计数、Class 权重。

### 仿真器改动（独立分支，不动仿真仓 main；RTL 不改）

1. `tests/soc_sim` 加 `--cc-scheme epoch-swap`。
2. NI 注入/过路模块：增加 `do_swap` 与 highway↔staging mux；flit 控制加 3b `EP`。
3. AIC/outstanding 模型加 3b 标签与 `CUR` 递进（按 `inflight==0`，禁止从 trace 预知完成时刻）。
4. 为什么改结构：基线过路路径没有「与本地 staging 置换」的端口，不改 NI 数据通路就无法在无第三槽的前提下重排临界 flit。

### 指标与负载

主指标：推理 decode `T_step`、步内 p99、完成数、collapse。负载写死：每步每 die 一组 KV P2P + 可选 1 次小集合，并与下一步预取重叠（预取 outstanding 上限写死，例如不超过当前步的 25%）。训练大块只附一列。0.85 是推理类 pass bar。禁止洞/`p_inj`/gather T/off 当 card-claim。

### 预期收益区间与证伪

相对 W0，有预取重叠的推理信封：`T_step` 预期 **8%–22%**。无预取：预期 **0%–5%**，不得当主结果。W3 优于 W2 视为失败。Snp 路径预期 = W0（对换关闭）。

证伪：W2 的 `T_step` 不低于 W0，或只见预取吞吐下降、当前步 `max` 不动 → 失败。不把 T2 数字贴 T3。不宣称 T0 通过。

## 5. 硬件开销估算

假设同 M-16。面积：每 NI 每通道每方向 3b 减 + 比较 + 2 个 2:1 mux，14×4×2 份，估计 **<6 kGE**；outstanding +3b 是标签列不是 SRAM 阵列。功耗：仅 `hw_valid && st_valid` 时打开比较。延迟：0–1 拍。对换不增加槽、不加深度。Snp +0。

## 6. 与已知工作的区别（为何不是功能等价）

- **不是** Age+Class / QNoC / Abts SC'07 / Das MICRO'09 LocalAge：那些在 **空槽出现后** 于本地多候选里打分；本卡在 **槽已被非临界占用时** 置换在途 flit，单候选也生效；键是发行时写死的 epoch，不是失败拍年龄。
- **不是** TDM 注入窗：不卖空波，不对换时 work-conserving。
- **不是** 最短 CW/CCW。
- **不是** 偷气泡：不把空槽当注入机会重定义；空槽仍按基线注入。
- **不是** 预取取消/完美预测：不预测哪一笔会是 straggler，只比较已写在 header 上的步号。
- **不是** 加队列：不变量是基线已有的 2 个位置做置换。
