# M-2 RBRG 集合通信脊骨（Collective Spine via RBRG, CSR）

- problem: P-0198
- id: P-0198/M-2
- author: Jim Keller

## 1. 根因分析

CHI 四通道 Req/Rsp/Snp/Dat 各为独立双向环，环间经 RBRG 桥接。基线下集合流量（gather/reduce/allreduce/allgather/alltoall）在公开扫描中常 collapsed=true；broadcast 可维持峰值 goodput ~117.76 B/ns。均匀读/写 makespan 分别约 4403.2 / 4834.6 ns（46080 txn），但集合扇入把 N 个源压到 **同一方向单槽环** 上。

根因是 **Amdahl 扇入瓶颈 + balls-and-bins**：12 个 top die 源若全部在 Dat 环上逐跳洪泛，单槽环上注入争用为 Ω(N)；RBRG 今日仅作桥，不承载 reduce/multicast 状态，无法把争用从环面挪到脊骨。P2P 近均匀移动与集合叠用同一环路径 ⇒ 不同槽占用形态互相污染。HBM/一致性/底 die D2D 超出范围；问题要求无完美预测、无无限带宽。

## 2. 机制

### 结构

将 allreduce / allgather / broadcast / gather / reduce **重映射到经 RBRG 的生成树脊骨**；P2P 仍走基线环路径。

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| RBRG Reduce/Mcast 引擎 | 每 RBRG 1 套 | 跨环脊骨核心 |
| Tag CAM | 8 项 ×（txn_id 宽假设 16b + child bitmap ≤12b + 态 2b）≈ 8×30b | txn_id→子节点位图 |
| Partial-reduce latch | 512b（一 flit 宽） | 就地归约暂存；**有界 1 flit，非队列** |
| FSM | 4 态：IDLE / COLLECT / REDUCE / DISPATCH | 每活跃 txn 槽 |
| Endpoint Collective Classifier | 32×2 ROM：opcode→{RING_P2P, SPINE_TREE} | 端点 NIC |
| Tree 边表 | 静态每集合类；bitmap 宽 ≤12（top dies）；底 die ≤2 作根/汇 | 非消息级预测 |

树形态假设（可证伪）：广播/扇出以 bottom 或选定 RBRG 为根；gather/reduce 以对应汇为根；allreduce = reduce-spine + broadcast-spine；allgather/alltoall 拆为多棵有界深度树或分段脊骨，深度 O(log N) 或 O(bottom 数)。

**最小结构例外声明**：512b latch 是单 flit 宽归约寄存器，容量上界 = 1 flit/活跃 CAM 项（≤8），**不是** highway flit 队列，不把环改造成 buffered NoC；满 CAM 时新集合 txn 回退 RING_P2P（显式降级，禁止静默丢弃——HARD-4）。

### 数据路径

1. 端点 Classifier：CHI 集合 opcode → SPINE_TREE；普通读写 → RING_P2P。
2. SPINE_TREE flit：尽早经环短跳进入本地 RBRG；在 RBRG 入 CAM，更新 child bitmap；COLLECT 齐后 REDUCE（若需）写 latch，再 DISPATCH 沿树边出站到子/父环口。
3. RING_P2P：基线环路径，不进 Reduce/Mcast 引擎。
4. 四 CHI 环独立：集合载荷主要压 Dat；控制/完成可走 Req/Rsp；Snp 轻量时不强制进脊骨。
5. 树为 **每集合类静态**；不假设未来消息到达时刻。

### 时序

| 阶段 | 周期 |
|------|------|
| Classifier ROM | 1 组合 / 1 拍 |
| 入 RBRG → CAM 匹配 | 1 拍 |
| COLLECT 等待 | 取决于子到达（有限 outstanding，非无限带宽） |
| REDUCE 组合/1 拍（512b 宽运算按类型） | 1–2 拍 |
| DISPATCH 出站 | 1 拍 + 环链路延迟 |

端到端树深度：目标 O(log 12)≈3–4 级或经 ≤2 bottom，对比环上 Ω(N) 扇入跳数。

## 3. 为什么有效

**Amdahl（扇入）**：N 源单槽环 ⇒ 注入争用 Ω(N)。树深 d=O(log N) 或 O(#bottom) 把争用从环面挪到 RBRG 脊骨边；环上只承担到最近 RBRG 的短途，f_inject 段加速直接砍 makespan。

**Balls-and-bins**：12 源映射到 ≤2 bottom 经 RBRG，bin 数从“每环槽”变为“脊骨边”，碰撞从环零和变为有界 CAM 项争用（8 项，溢出回退环——可测，非静默死亡）。

**零和**：不增加每方向 highway 槽数；通过 **路径集合变更** 减少同时争同一槽的源数。P2P 与集合形态解耦：集合走脊骨，P2P 留环，降低交叉占用。

**因果（HARD-1）**：消融 spine-off（强制集合回环）必须 **恢复坍塌**；否则不得归因 CSR。CAM 满回退必须在指标中显式计数，禁止未申报静默丢失（HARD-4）。

**非预测**：静态树按 opcode/类，SYNC/到达时刻不进入调度；与“完美预测”减箱不同。

## 4. 评估计划

- **基线**：DV200 `tests/soc_sim`，额外流控关；12+2；512B；outstanding 512/256。
- **指标**：分流量类 makespan；完成事务数；collapsed；均匀读峰值后 goodput。须覆盖 P2P 与全集集合。
- **负载**：均匀读/写 + broadcast/gather/reduce/allgather/allreduce/alltoall。
- **必须 cycle 级建模**：RBRG FSM + 8-entry CAM + 512b latch；Classifier 32×2；与 CHI 四环交互；CAM 溢出回退路径。
- **消融**：spine-off → 集合应重现 collapse；P2P-only 路径应近似基线。
- **包络**：满 DV200 12+2 + 多环 + 全集；单环/子集/仅均匀读/完美预测减箱不足。
- **预期收益区间与置信度**：
  - gather/reduce/allreduce/allgather：**0.40–0.75×** makespan（中置信；树对齐好则靠下）
  - alltoall：**0.55–0.90×**（低–中；多树残差争用）
  - broadcast：**0.70–0.95×**（中；基线已未坍，脊骨仍减环占用）
  - 均匀读/写：**0.95–1.05×**（高置信近中性）
  - 不作 0.85 过关宣称；约束若用须全类满足，非均值。
