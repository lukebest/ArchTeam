# M-2 RBRG 集合通信脊骨（Collective Spine via RBRG, CSR）— 会合–授权脊骨（Rendezvous–Grant）

- problem: P-0198
- id: P-0198/M-2
- author: Jim Keller
- revision: T1-return-1

## 0. T1 退回回应

1. **Cycle-level 不变式（替代「≤1 Dat 拍」）**：本修订 **彻底取消** RBRG 上任何 Dat 载荷 latch / fold 存储。活跃 CAM 项在任意周期持有的 Dat 拍数恒为 **0**（强于「≤1」）。512 B 多拍 reduce/allreduce、outstanding 256/512、12 top 下，子节点只经短 divert 送入 **1-flit RENDZ 头**（header/credit，无 payload）；payload Dat 拍永不进入 RBRG 存储，始终在 Dat 环上直到 GRANT。RBRG 拒收 RENDZ 头时 **立即 RING_P2P 重分类**（`cam_overflow_fallback++`），头继续在环上前进——**永不**对 Dat 载荷做 reject-and-orbit，环上不累积 depth>0 的 RBRG 拒收滞留。不变式可断言：`∀i occupancy(CAM_i, Dat_beats) == 0`；`RBRG_reject_retention_depth == 0`。

2. **取消「1–2 物理 latch 时分复用 8 CAM」**：物理状态与并发诚实对齐。`N_cam = 4`，每项 **专用** 状态位（非时分假 8）。每项：`txn_id 16b + child_bitmap 12b + state 3b + timeout 8b` = 39 b；4 项 × 39 b ≈ 156 b CAM 阵列 + 每项独立 timeout 计数器与 FSM 切片。面积按 **4 路真正并发** 计，不再用 1–2 latch 伪装 8 槽。

3. **COLLECT 超时/逃逸 + CAM 溢出回退计入 endpoints**：每 CAM 项独立 `timeout[7:0]`；到期 → `FORCE_FALLBACK RING_P2P`，释放 CAM，`collect_timeout_fallback++`。CAM 满或 busy 拒收 RENDZ → 立即重分类 RING_P2P，`cam_overflow_fallback++`。禁止静默等死、禁止静默丢弃；两计数进入评估 endpoints，与 makespan / completions / collapsed 并列。

## 1. 根因分析

CHI 四通道 Req/Rsp/Snp/Dat 各为独立双向环，环间经 RBRG 桥接。无缓冲：每方向每拍一 highway 槽，无片上 flit 队列。基线均匀读 ~4403.2 ns / 写 ~4834.6 ns；集合类（gather/reduce/allreduce/allgather/alltoall）在公开扫描下大量 collapsed=true。

根因不是「缺一个归约寄存器」，而是 **集合成员会合与环上扇入零和叠在同一 Dat 公路上**：12 top 源把 N 路 fan-in 压到单槽环，注入争用 Ω(N)。旧 CSR 草案把 512b Dat latch 塞进 RBRG，在 512 B 多拍 + 高 outstanding 下立刻撞上「CAM 项持拍」与「拒收滞留」爆炸——那是把 highway FIFO 偷运进桥，违反 bufferless 契约。

真正可硬化的脊骨是 **Rendezvous + Grant**：RBRG 只做 **成员会合状态机**（谁齐了、何时授权），**不碰 payload**。折叠加在端点寄存器堆/缓存路径（端点已有），环上只跑 GRANT 调度后的有序注入/orbit。与 M-1 CBC 切割清楚：**CBC = 空槽日历**（制造注入气泡）；**CSR = 集合成员会合 + GRANT flit**（授权集合序列何时占用环）。两者正交，不是同一招换皮。

## 2. 机制

### 2.1 结构（Rendezvous–Grant Spine）

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Tag CAM | **N_cam = 4** 项；每项独立：txn_id 16b + child_bitmap 12b + state 3b + timeout 8b ≈ 39 b | **无** 512b Dat latch；**无** 多拍 fold 存储 |
| CAM 端口 | 1 读匹配 + 1 写分配 / 拍（短 divert 口） | 满则拒收头 → 立即 RING_P2P |
| GRANT 发射器 | 1 flit/拍 可注 Dat 环（circulating 1-slot citizen） | 位图齐后发射 |
| Endpoint Classifier | opcode→{RING_P2P, SPINE_RENDZ}；含 overflow/timeout 强制 RING_P2P | NIC 侧 |
| 静态 order 表 | 每集合类一张：reduce/allgather 序列的注入/orbit 窗序 | 非消息级预测 |
| 回退计数器 | `cam_overflow_fallback`, `collect_timeout_fallback`（端点可见） | HARD-4 完整性 |

**禁止项（硅片不得实现）**：RBRG 内任何 Dat payload 寄存器堆、多拍归约缓冲、reject-and-orbit 载荷滞留队列。

状态编码（每 CAM 项 `state[2:0]`）：`IDLE=0 / COLLECT=1 / GRANT_PENDING=2 / GRANT_SENT=3 / FORCE_FALLBACK=4`。

### 2.2 数据路径

1. **分类**：集合 opcode → `SPINE_RENDZ`；普通读写 → `RING_P2P`。
2. **RENDZ 头**：子节点发 **1-flit HEADER/credit**（或 CHI Dat beat 0 header-only，tag=`RENDZ`）经短 divert 进 RBRG。匹配/分配 CAM：置 `child_bitmap[src]=1`，装载/刷新 `timeout`。
3. **Payload 永不进桥**：该 txn 的后续 Dat 拍 **留在 Dat 环**，直到看见本 txn 的 **GRANT flit** 打开的调度窗；折叠在 **目的端或指定 root NIC 的端点寄存器堆**完成（复用已有 cache/RF 端口，**不**发明 highway FIFO）。
4. **GRANT**：`child_bitmap` 对应该类静态成员掩码全 1 → FSM → `GRANT_PENDING` → 向 Dat 环注入 1 拍 GRANT flit（含 txn_id + 序列相位）。GRANT 作为环上 1-slot 公民循环；各参与端按 order 表在授权窗内注入/交出拍。
5. **CAM 满 / busy**：RBRG **不能** 收 RENDZ 头 → 该 txn **立即** `RING_P2P` 重分类，头继续在环前进，`cam_overflow_fallback++`。**绝不** 对 Dat 载荷做 RBRG reject-and-orbit。
6. **COLLECT 超时**：每拍 `timeout--`；到 0 → `FORCE_FALLBACK`，释放 CAM，通知相关端改走 RING_P2P，`collect_timeout_fallback++`。无静默永等。
7. **多拍 512 B**：脊骨零持拍；拍序由 GRANT 在环上排序。不变式：`occupancy(CAM_i, Dat_beats)=0` 恒真。
8. **alltoall**：拆多棵小树 / 分段 GRANT；残差环争用 **单独报告**，不得埋进均值。

### 2.3 时序（cycle 模型要点）

| 阶段 | 周期上界（建模） |
|------|------------------|
| Classifier | 1 组合 / 1 拍 |
| RENDZ 头 divert → CAM 匹配/分配 | 1 拍 |
| COLLECT | 子头到达决定；受 `timeout` 硬上界（默认可配，如 255 拍量级） |
| GRANT 发射 | 1 拍（环槽可用时） |
| 端点 fold（每拍到达） | 端点 RF 1 拍/运算宽度；**不在 RBRG** |
| FORCE_FALLBACK / overflow 重分类 | 同拍决策，次拍头已在 RING_P2P |

**Cycle-level 证明义务（仿真断言）**：

- 任意时刻、任意活跃 CAM：`Dat_beats_held == 0`。
- 无 RBRG→环 的 payload reject 滞留：`retention_depth == 0`。
- 512 B / outstanding 256|512 / 12 top 扫描下上述断言全绿；违例 = 机制失败。

### 2.4 与 M-1 CBC 的区分

| | M-1 CBC | M-2 CSR（本卡） |
|--|---------|-----------------|
| 对象 | 空槽 / 注入日历 | 集合成员会合 + GRANT |
| 状态在哪 | 日历/槽时间表 | RBRG Tag CAM（无载荷） |
| 环上多出来的公民 | 日历气泡 | GRANT flit |
| 失败形态 | 日历错位 | CAM 溢出 / COLLECT 超时 → 显式 RING_P2P |

## 3. 为什么有效

**Amdahl（扇入）**：把「谁齐了」从环上 payload 洪泛里抽出来，环上只在 GRANT 窗内跑有序集合序列，扇入争用从 Ω(N) 盲目注入降为 **授权窗口内的有界并发**。

**零和诚实**：不增加每方向 highway 槽数；不在 RBRG 造 FIFO。代价是 CAM 只有 4 路真并发——溢出就回环，**可数、可证伪**，不是静默加速。

**Balls-and-bins**：会合状态 bin 数 = 4；碰撞结果是计数回退，不是深度堆积。

**因果**：spine-off（强制全 RING_P2P）必须让集合 makespan/collapse **回到基线量级**；否则不得把收益记在 CSR 上。`cam_overflow_fallback` / `collect_timeout_fallback` 必须进报表——完整性是 endpoint，不是脚注。

**非预测**：order 表按集合类静态；不假设到达时刻；timeout 是逃逸，不是预言。

## 4. 评估计划

- **平台信封**：DV200 ≤12 top + 2 bottom；`tests/soc_sim`；CHI 四环；无额外「完美预测 / 无限带宽」。
- **基线对照**：均匀读 ~4403.2 ns / 写 ~4834.6 ns；集合 collapsed 扫描同公开设定。
- **Endpoints（强制）**：
  - 分流量类 makespan、完成事务数、collapsed；
  - **`cam_overflow_fallback` 计数**；
  - **`collect_timeout_fallback` 计数**；
  - 断言 `occupancy(CAM_i, Dat_beats)==0` 全程；
  - alltoall **残差环争用**（分桶或分位数，禁止只报均值）。
- **消融**：spine-off → 集合应重现崩塌/基线 makespan 量级。
- **负载**：均匀读/写 + broadcast/gather/reduce/allgather/allreduce/alltoall；512 B；outstanding 256/512。
- **包络**：满 12+2 + 多环 + 全集；单环/子集/仅均匀读 = reduced-bbox ≠ full envelope。
- **预期区间（非过关宣称，0.85 是 bar 不是 mean）**：
  - gather/reduce/allreduce/allgather：**0.45–0.80×** makespan（中；视 GRANT 窗与回退率）
  - alltoall：**0.60–0.95×** + 显式残差（低–中）
  - broadcast：**0.75–0.98×**（中；基线已未坍）
  - 均匀读/写：**0.95–1.05×**（高；近中性）
  - 若 `cam_overflow_fallback` 或 `collect_timeout_fallback` 主导完成路径 → 区间失效，机制需改 N_cam/timeout，不得自评通过。

## 5. 硬件开销估算

| 项 | 规模 | 备注 |
|----|------|------|
| Tag CAM | 4 × 39 b ≈ 156 b 存储 + 比较器 | **诚实 4 并发**；非 8 伪装 |
| 每项 timeout/FSM | 4 ×（8b 计数 + 3b 态 + 控制） | 专用，非时分 |
| GRANT 发射器 | ~1 flit 装配 + 1 注入仲裁口 / Dat 方向 | 无载荷缓冲 |
| Classifier ROM | 小（opcode→2b 类） | 端点 |
| 回退计数 CSR | 2×32b 可见计数 | 评估必需 |
| **明确为零** | 512b Dat latch、多拍 fold RAM、highway FIFO | T1 已杀 |

面积叙事：CSR 买的是 **4 路会合状态**，不是「小 latch 假装大 CAM」。并发上限写在硅上；溢出走计数回退。这是脊骨，不是偷运的 datapath reduce 栈。
