# M-7: CW/CCW 最短争用弧方向选择

- problem: P-0198
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

冻结信封同 P-0198：无缓冲 **双向** 环，每方向每拍 1 highway 槽；过路占用则本地不能注入。一条 flit 一旦注入，将在所选方向上连续占据沿途每一拍的槽，直到到达出口（或 RBRG 下环）。争用暴露量近似正比于所选弧的 hop 数：`exposure ≈ hops_dir`（单位：槽·拍）。

集合通信把这个几何放大。gather / reduce / allreduce 的扇入指向一个根；若多数源选了较长弧，根前方的弧段被过路打满，根附近 NI 的残差注入接近 0，扇入尾部拉长该类 makespan。alltoall / allgather 则是多对多，错方向同样把两倍弧长的槽变成过路占用。点对点（权值重读、KV 扫描、激活分片）在近邻为主时，错方向等于主动绕远，把本可留给其他源的空槽吃掉。

基线不对称已经提示方向/形态敏感：均匀读峰值后崩到 2.8–3.4 TB/s，写平台约 5.5 TB/s 且基线未报崩塌；broadcast（8192 B、OQ 4096）可维持约 117.76 B/ns，其它集合在公开扫描下大量 `collapsed=true`。用单一均匀流或「平均 hop」代理会抹掉扇入弧。

禁止项：全局占用预言、无限带宽、完美预测下一空槽。本卡只在 **注入点** 用确定性跳数 + 至多 1 拍邻域空槽传感做方向二选一。这不是源端速率控制，也不是 ECN/窗口。

## 2. 机制

### 结构

每个 CHI 通道环独立决策（Req/Rsp/Snp/Dat 拓扑相同则硬件可复制 4 份）。节点编号 `id ∈ {0..N−1}`，`N` 为该环节点数。DV200 单环按「每 die 每通道 1 个 NI + 每 bottom 附着最多 2 个 RBRG 口」封顶，取 **`N ≤ 16`**（12 top + 4 附着余量）。`N` 由 CSR `N_RING[4:0]` 给出（合法 2..16，复位按平台实例）。

1. **跳数**：对目的 `D`（普通 P2P 为目的 NI；集合扇入/扇出为 **collective root** 的环上节点号，由流量发生器或 CHI opcode 旁路给出 4b `dst_id`）。
   - `hop_cw  = (D − S) mod N`
   - `hop_ccw = (S − D) mod N`（即 `N − hop_cw`，若 `hop_cw=0` 则本地，不进环）
   实现：5b 减法 + `N` 校正；或 16×4b LUT（`dst` 索引，存 `hop_cw`，`hop_ccw` 由补算出）。
2. **主规则**：`hop_cw < hop_ccw` → 选 CW；`>` → 选 CCW。等长（`N` 偶数且对角）进入打平。
3. **打平**：用 **2 bit** 本地/邻域空槽传感，**不是** 全局 oracle。
   - `free_cw`：本拍本节点 CW 向 `~slot_occupied_cw`（即将注入的那个槽）。
   - `free_ccw`：同上 CCW。
   - 可选 1 拍线：立即 CW 邻居的 `~slot_occupied_cw`、立即 CCW 邻居的 `~slot_occupied_ccw`（各 1b，线延迟按文档链路区间的 **1 cycle** 采样，禁止更长窥探）。
   - 打平优先级：`(free_local_pref) > (neighbor_free) > 硬线默认 CW`。即：本地该方向空则选空的；两边都空或都忙则看邻居 1b；仍平则 CW。
4. **方向 mux**：选中方向的 highway 才看到这次注入请求。另一方向不占用。决策在 flit header 旁寄存 1 拍：`DIR` 1b 写入 header 侧带字段（若 CHI header 无空位，用 NI 内部 1b 伴随寄存器，不进织物位宽）。

过路仍绝对优先：所选方向若该拍 `slot_occupied=1`，注入失败，**不** 在同拍改选另一方向（避免双口投机占用）。下一拍重新计算（目的不变则组合结果不变，只有打平传感可能变）。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| `N_RING` CSR | 5 bit | 1R1W | 值域 2..16 |
| `dst_id` | 4 bit（来自路由字段或集合根 CSR） | 1R/拍 | 4b |
| 跳数单元 | 0 或 16×4b = 64 bit ROM/LUT | 1R 组合 | in 4b `D`+4b `S`；out `hop_cw` 4b、`hop_ccw` 4b |
| 比较器 | 0 | 组合 | 4b 比较 → `lt/eq/gt` 2b |
| 邻域空槽输入 | 2 bit 输入触发器 | 每方向 1 入 | `nbr_free_cw/ccw` 各 1b，1-cycle 线 |
| 本地空槽 | 2 bit（本节点两向 `~occupied`） | 已有 highway 采样 | 1b×2 |
| `DIR` 寄存 | 1 bit | 与 header 对齐 1 拍 | 1b |
| 方向 mux | 0 | 2:1 到注入口 | 1b 选择 |

每 NI 每通道一份。无全局占用总线。无按目的的多拍历史（那会滑向预测器，本卡不要）。

### 数据路径与状态机

无多状态 FSM。每拍待注入时：

1. `hop_cw/ccw = DIST(S, D, N)`。
2. 若 `hop_cw=0` 且 `hop_ccw=0`：本节点交付，不进环。
3. 若 `hop_cw != hop_ccw`：`DIR = (hop_cw < hop_ccw) ? CW : CCW`。
4. 若相等：`DIR = TIEBREAK(free_cw, free_ccw, nbr_free_cw, nbr_free_ccw)`，组合 ROM 16 行 × 1b（4 输入），复位表如上节优先级。
5. `DIR` 进 1b 寄存器，与 flit 对齐；该方向 `inject_req = staging_valid AND ~slot_occupied_DIR`。
6. 失败则 staging 保持，下一拍重评（仅打平可能变）。

组合深度：5b 加减 + 4b 比较 + 4:1 打平，目标同拍；不够则跳数组合、打平用上一拍邻域采样（传感本就规定 1-cycle）。禁止为等结果去等更远节点。

## 3. 为什么有效

争用暴露 `exposure = hops_chosen`。最短弧把单 flit 的槽·拍占用从最多 `N−1` 降到 `⌊N/2⌋`。对 `N=16`，对角最坏从 15 降到 8（约一半）；近邻从 `N−1` 错向降到 1。零和含义：少占的那些槽·拍还给沿途节点做残差注入。

Amdahl：设该类 inject-fail 中由「长弧过路」造成的比例为 `f_long`。最短弧只削减这块，加速上界 `1/(1−f_long·β)`，`β` 为弧长比（对角约 0.5，近邻可接近 1）。gather/reduce 扇入对根前弧尤其敏感：多数源选短弧时，根对面的长弧腾空，根本地残差回升，扇入尾部（makespan 的 straggler）缩短。这是 Little 用在 **集合屏障的最慢加入者** 上：`T_barrier ≥ T_straggler`，降低 straggler 的环上排队比提高平均 hop 更接近 endpoint。

打平传感只解决 `N` 偶数对角，覆盖面小；**主收益必须来自 hop 比较**。若消融掉邻域传感后 makespan 与「hop+传感」不可分，不得把传感写成因果（约束 1）。若 hop-only 与固定方向（总是 CW）也不可分，不得写本卡收益。

## 4. 评估计划

### 基线

1. 公开基线：12+2、512 B、AIC RO 512 / WO 256、流控 OFF；方向策略 = 平台默认（若默认固定 CW 或哈希，如实记录）。
2. 对照：`--cc-scheme srcfc`、`ecn` 等已有方案。本卡开/关 × 各对照。方向选择不是速率环。
3. 消融（必须）：
   - A0：固定 CW（off）。
   - A1：仅 hop 比较，打平恒 CW。
   - A2：hop + 本地 2b 空槽，无邻居线。
   - A3：hop + 本地 + 1-cycle 邻居（全卡）。
   只有与 A0 **可区分** 的臂允许写因果。A3 相对 A1 无差异则结论写「传感无贡献」，不是「全卡有效」。

### 必须 cycle 级建模的结构

- `N_RING`（≤16）与 `DIST` 组合或 64b LUT。
- 1b `DIR` 寄存与方向 mux。
- 本地两向 `slot_occupied`。
- 可选 2×1b 邻居空槽，延迟锁 1 cycle。
- 集合根 `dst_id` 来源（流量类 → 根节点号）。
- **不要** 建全局占用向量、多跳窥探、或「选当前最空的整段弧」。

### 指标与负载

Full envelope：12+2、CHI 四环、点对点 + **全集** 集合、有限链路延迟、有限 outstanding。重点类：gather、reduce、allreduce（扇入向根）；alltoall / allgather（多对多错向代价）；broadcast（扇出，应对称地选短弧）；均匀读/写与权值/KV/激活 P2P。

Endpoints：每类 makespan、完成 txn 数、collapse 标志。Proxy：平均 hop、所选弧长分布、inject-fail、方向选择 CW/CCW 计数。不得用平均 hop 代替 makespan。读写不对称必须都报，不得只报读。扇入/扇出覆盖必须实际打到，禁止用未声明的 `p_mix` 死亡填充。

0.85 若使用：是 **每类** endpoint 的 pass bar，不是跨类均值。Reduced-bbox（单环单测、top 子集、只均匀读）≠ full envelope。

### 预期收益区间与置信度

扇入集合（gather/reduce/allreduce）：相对固定 CW，makespan 预期 **10%–35%**，且仅当 A1 相对 A0 已拉开；collapse 标志对公开扫描中部分设定可能从 true→false，不保证全部集合。alltoall：预期 **5%–20%**。近均匀 P2P / 均匀读：预期 **0%–12%**（目的已较近时默认方向若碰巧对，收益接近 0）。对角打平传感：预期额外 **<5%**，高概率与 A1 不可分。

轻载：最短弧不卖空波，单笔延迟不应系统性变差；若变差，先查是否同拍禁止改向造成多 1 拍，属实现瑕疵不是机制收益。

置信度中：弧长代数可证；makespan 取决于扇入是否真是瓶颈。不宣称 T0 通过。

## 5. 硬件开销估算

面积：每 NI 每通道一次 5b 加减或 64b LUT + 4b 比较 + 1b 寄存器 + 2:1 mux，4 通道 × 14 die 量级，估计 **<4 kGE**，SRAM 0（或每 NI 64b ROM）。邻居 2b 线按 die 间已有邻接，不新增宽总线。延迟：决策 0–1 拍，过路路径不加门。不增加缓冲、不增加槽数。
