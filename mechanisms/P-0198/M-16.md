# M-16: RBRG 空槽拼接与本环续行

- problem: P-0198
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

冻结信封：DV200，≤12 top + 2 bottom；CHI 四通道 `Req/Rsp/Snp/Dat` 各自成环；环间经 RBRG。无缓冲双向环，每方向每拍 1 个 highway 槽；过路占槽则本地注入失败。织物内无 flit 队列。

跨环正反馈是推理 decode 步 makespan 尾的一条具体路径。KV 分片与推理期集合（decode 阶段的 TP allreduce / broadcast 残差）经常 top↔bottom 换路。RBRG 若在对端环 `slot_occupied=1` 时仍把 flit **切进去**，该 flit 成为对端环上的外源过路，把对端残差注入压到 0，对端当前 decode-epoch 的 KV 注入等待被拉长；被切进去的 flit 自己也往往要再绕一圈才能找到出口。局部槽争用变成全局 decode 步的 `max` 完成时间。这不是平均 hop 能看见的。

本卡 **不** 关窗、不拉 `bp`、不加 skid、不把已上环的 flit 收回 NI。合法拒绝动作只有一种：flit **沿当前环走下一跳**（highway 已有的路径），下一圈再在同一 RBRG 看对端是否空。这不是源端流控；平台 `--flow-control` / `--cc-scheme srcfc` 是对照。M-5 CRRF 只作黑盒对照，本卡不实现它。

## 2. 机制

### 结构

每个 RBRG 口、每个 CHI 通道、每个方向一份拼接器。四通道复制，语义相同；Snp 口硬件在，但本问题 Snp 负载应接近空，Snp 路径不作卖点。

1. **当拍对端空槽采样 `dst_free`**：读对端环该方向 highway **输入寄存器** 的 `~in_valid`（已有采样，与本地注入看过路的是同一类 1 bit）。禁止多跳窥探，禁止用对端未来占用预言。
2. **拼接判定**（同拍组合）：
   - `cross_req=1` 且 `dst_free=1`：`splice=1`，flit 离开本环、写入对端 highway 输出（对端该拍无过路，不破坏过路优先）。
   - `cross_req=1` 且 `dst_free=0`：`splice=0`，flit **本环续行** `next = 本环下一节点`。不进任何新存储。
   - `cross_req=0`：旁路，本环过路不动。
3. **绕回计数 `REV[2:0]`**：flit header 侧带 3 bit（占用 CHI user/txn 旁路位；若无空位则 Dat/Req/Rsp 各加 3b 伴随线，不加数据位宽）。每次经过「曾请求过桥但未拼接」的同一 RBRG，`REV += 1`（饱和 7）。`REV` 不做关窗。
4. **可选 1 拍空位请求 `VAC_REQ`**（消融可关）：当 `REV≥R`（CSR `R[2:0]`，复位 `R=2`，约两圈）且本拍仍 `dst_free=0`，RBRG 向 **对端环紧邻上游 NI** 送 1 bit `vac_req`（1-cycle 线）。该 NI 若本拍本要注入且槽空，则 **跳过这一次注入**，把空槽放给 RBRG 口。该 NI 自身若也 `REV` 紧急（见下）则不跳过。`VAC_REQ` 每 `S` 拍至多成功 1 次（`S` CSR，复位 4），防止上游饿死。
5. **永不关窗**：不存在 Hold/窗外状态。不存在 skid。对端忙时唯一下一跳是本环续行。

方向选择沿用已冻基线（最短 CW/CCW），本卡不改。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| `dst_free` | 0（复用对端 `~in_valid`） | 1R/拍 | 1b |
| `splice` 与门 | 0 | 组合 | `cross_req AND dst_free` |
| `REV` | 3 bit / 在途 flit 侧带 | 随 flit 走 | 3b，饱和 7 |
| `R`, `S` CSR | 3b + 3b / 桥 | 1R1W | 复位 2、4 |
| `vac_req` | 1 bit 线 / 桥 / 方向 | 对端上游 NI 1 入 | 1b，1-cycle |
| 冷却计数 | 3 bit / 桥 / 方向 | 每拍条件 +1 / 清零 | 3b |
| 本环续行 mux | 0 | 2:1（splice vs next_hop） | 1b 选择 |

无 SRAM，无按 flit 的 CAM，无桥上 flit 寄存器。占用仍只用 `O_ch,d(t)∈{0,1}`。

规模：2 bottom × 4 通道 × 2 方向 ×（每 bottom 至多 2 个 top 附着）封顶，拼接器 ≤32 份。`REV` 侧带是在途状态，不是节点存储。

### 数据路径与状态机

无多状态 FSM。每拍每桥口：

1. 采样 `dst_free = ~dst_in_valid`（与数据路径并行）。
2. 若 highway 输入不是过桥请求：输出 = 本环下一跳，结束。
3. 若 `dst_free`：`splice`，`REV` 清 0，flit 进对端输出寄存器。
4. 否则：`REV = sat7(REV+1)`，输出 = 本环下一跳；若 `REV≥R` 且冷却到期，断言 `vac_req` 一拍。
5. 对端上游 NI：`inject_ok = ~slot_occupied AND NOT (vac_req AND local_ready AND ~local_urgent)`。跳过时本地 header 留在 **既有 CHI staging**（本来就要等空槽）。

时序：`dst_free` 与 splice mux 目标同拍；`vac_req` 规定 1-cycle，用上一拍 `REV` 预译码。禁止为等结果去读更远节点。过路路径：非过桥 flit 不进 splice 逻辑，+0 门。

## 3. 为什么有效

第一性原理（makespan 尾，不是吞吐）。decode 步完成时间 `T_step = max_i C_i`，`C_i` 为该步第 `i` 笔 KV 或推理集合事务的完成时刻。对端环被外源过路打满时，对端当前 epoch 的 KV 注入成功率 `λ_local → 0`，那些 `C_i` 的注入段无界拉长，`T_step` 被 straggler 钉住。拼接把「进入对端」限制为对端本来就空的那一拍：外源占用不对对端 `λ_local` 做额外减法。被拒 flit 的等待是 **绕本环一周再试**（`N` 拍量级，`N≤16`），有上界；不是在对端环上再制造一圈外源过路。

Little 用在 straggler：`C_straggler ≥ W_inj / λ_local`。本卡提高的是 **被灌环节点上当前 epoch 的 `λ_local`**，不提高环的 `μ=1`，也不抬源 outstanding。因此主收益直接落在 `T_step` / 尾完成时间，而不是 `p_inj` 均值。若只看到跨环 flit 自己的平均延迟下降、而 decode `max` 不动，不得写收益。

与「抬注入率 / 预约授予」的区别：本卡有时让跨环 flit **更晚** 进入对端（等空槽），平均跨环吞吐可能下降；换来的是对端 KV 尾缩短。T3 已表明抬吞吐但 `T_mix≈1` 不算赢。本卡的可证伪点是 `T_step` 本身。

推理（主）：decode 阶段 KV / P2P 小包大量 top↔bottom；推理期集合（小 allreduce/broadcast）同样过桥。预期 `T_step` 相对「忙则仍切入」基线缩短，因为对端残差回到当前 epoch。失效：几乎不经 RBRG 的单环 KV；或对端环长期 `O=1` 且无自然空槽——此时 `vac_req` 也造不出洞（上游无空可让），卡应报「无空可拼」，不得假装加了带宽。

训练大块集合（次要，一句话）：大 payload 过桥次数更多，续行会拉长单笔跨环时间，大块集合 makespan 允许持平或小幅变差，不作为本卡过线项。

## 4. 评估计划

### 基线

1. 公开基线：12+2、512 B、AIC RO 512 / WO 256、**额外流控 OFF**，RBRG = 平台默认「对端忙仍尝试切入 / 无本卡续行语义」。
2. 对照（不是本卡）：`--flow-control` / `--cc-scheme srcfc`（及平台已有 `ecn` 等）。本卡开/关 × 各对照。
3. M-5 CRRF 黑盒：若评估树已有 `sims/P-0198/M-5`，按该目录 README 调用 `python3 sims/P-0198/M-5/sweep.py --mode smoke --seed 20260903`，以 `rebind-off` 为 CRRF 关、其 duty 臂为 CRRF 开；**不读、不改 CRRF 机制正文**。若 `tests/soc_sim` 无同名开关，由评估方提供等价黑盒，本卡不实现 CRRF。
4. 消融（HARD 臂必须在诚实 cycle 下写）：
   - S0：splice-off（对端忙仍切入，`vac_req` 关）= 本结构 off。
   - S1：splice-on，`vac_req` 关（只有续行）。
   - S2：splice-on + `vac_req`（全卡）。
   - S3：`R=1` / `R=4` 敏感性。
   主因果必须落在 S1 相对 S0 的 **推理 decode `T_step` / 尾**。S2 相对 S1 不可分则结论写「空位请求无贡献」，不是「全卡有效」。S0 若已满占用且与 S1 的 `T_step` 不可分，禁止写因果。

### 必须 cycle 级建模的结构

- 当拍 `dst_free`、splice mux、本环 `next_hop`。
- 3b `REV` 侧带。
- 可选 1b `vac_req` + 3b 冷却。
- **不要** 建桥 skid / 多 flit FIFO / 窗外 Hold / 源端 token 机。

### 仿真器改动（独立分支，不动 bufferless-ring-noc main；RTL 不改）

本 ArchTeam PR **只交卡**。验证时在仿真仓独立分支改结构：

1. `tests/soc_sim` 入口增加 `--cc-scheme vacant-splice`（或等价开关）。
2. RBRG 过桥模块（仓内实际文件名按 `rbrg` / `bridge` / `cross_ring` 落地）：grant 条件改为 `dst_free`；失败走本环下一跳，删除「忙则 stall / 进 skid」的路径。
3. flit 控制字段加 3b `REV`；可选 1b `vac_req` 端口接到对端上游 NI 注入与门。
4. 为什么改结构：现有默认切入/stall 没有「本环续行」这一合法下一跳，不改模块边界就无法在无队列约束下拒绝过桥。

### 指标与负载

主信封：12+2 DV200、CHI 四环、有限链路延迟、有限 outstanding。**主指标是推理**：decode 阶段 KV / P2P 搬运 + 同一步内的推理集合（小 allreduce / broadcast / allgather）。报 `T_step`（该步全部相关 txn 的 max 完成）、该步内 p99 完成时间、完成 txn 数、collapse 标志。训练大块集合只附一列，不作过线。

0.85 是每类推理 endpoint 的 pass bar，不是 measured mean，不是与训练的平均。Proxy（inject-fail、跨环次数、`REV` 分布、平均 hop）可报，不可替代 `T_step`。禁止把 gather T/off、`C_dat_eff`、洞数、`p_inj` 写成 card-claim。Reduced-bbox（单环、top 子集、只均匀读、完美预测、无限 BW）≠ full envelope。并发配比必须写死（例：每 decode 步 12 路 KV P2P + 1 次 TP allreduce 残差），禁止事后未声明 `p_mix`。

### 预期收益区间与证伪

诚实 cycle，相对 S0：推理 `T_step` 预期改善 **6%–20%**，且必须同时看到「对端环外源过路拍数」下降，以及当前 epoch KV 的注入等待尾下降。S1 必须已经优于 S0；否则全卡失败。轻载（对端经常空）：S1≈S0，允许 `T_step` 差在 **±3%**，不得用轻载冒充收益。对端长期满占用：`T_step` 允许不降，记失效，不得改成加队列。

置信度中：续行合法性可 cycle 断言；`T_step` 取决于跨环是否钉尾。不宣称 T0 通过。不把任何 T2 解析式数字贴到 T3。

证伪：同一 seed、同一推理信封，S1 的 `T_step` 不低于 S0，或只改善 `p_inj` / goodput 而 p99/`T_step` 不动 → 本卡失败。Snp 路径相对 S0 变差超过评估方 Snp 阈值 → 只记 Snp 回归，不得用未过线 Snp 数当卖点（本卡对 Snp 的预期是 ≈基线，因为 Snp 环近空，`dst_free` 几乎总真）。

## 5. 硬件开销估算

假设：1 GHz 级环时钟，CHI header ~128b，Dat 数据拍按平台切片，控制逻辑 7nm 量级标准单元。面积：每桥口 1 AND + 2:1 mux + 3b 饱和计数 + 6b CSR，32 份合计估计 **<2 kGE**，0 SRAM。`REV` 侧带 3b 若走伴随线：4 通道 × 2 方向 × 3b，不是数据通路加宽。功耗：每拍每桥一次 1b 采样，`<0.01 pJ/bit`。延迟：splice 0 拍；`vac_req` +1 拍到上游；过路 +0。不增加 highway 槽，不加缓冲。

## 6. 与已知工作的区别（为何不是功能等价）

- **不是** slotted-ring / Æthereal slot table / Nostrum TDM：无周期许可位图，空槽该拼就拼（work-conserving 于空槽）。
- **不是** 最短 CW/CCW（已冻基线）：不改方向。
- **不是** Age+Class QoS：无分数、无类权重。
- **不是**「空槽≡注入机会 / 偷气泡」：本卡在对端 **非空** 时拒绝进入，把 flit 留在本环；空位请求是让上游 **少注一次**，极性相反。
- **不是** HiRD（Ausavarungnirun 等 SBAC-PAD 2014）：HiRD 桥上有 transfer FIFO，满则绕回，并靠 injection/transfer guarantee。本卡 **零 FIFO / 零 skid**，只有当拍空槽拼接或本环续行；进度靠绕回再看空，而不是排队吸收对端忙。
- **不是** 上轮门控窗：不存在窗外第三态，已上环 flit 始终有下一跳。

## 7. 自检

1. **不把 T2 贴 T3**：预期区间只作 cycle 假说；HARD 臂是 S1 vs S0，要求诚实 cycle 下推理 `T_step` 优于基线，判据见 §4 证伪。结论：写入。
2. **主收益是 makespan/尾**：写的是对端 KV straggler 的 `C_i` 与 `T_step`，不是 `p_inj`、洞、CAM 零。结论：写入。
3. **非功能等价**：§6 逐条。结论：写入。
4. **Snp**：不作卖点；预期 ≈S0；超阈只记回归。结论：写入。
5. **中间量**：gather T/off、`C_dat_eff` 等不是 card-claim。结论：写入。
6. **消融 / 0.85 / 信封 / 配比**：S0 满占用不可分则禁写因果；0.85 是 pass bar；reduced-bbox 不得冒充；配比写死。结论：写入。
7. **不加缓冲/带宽、无完美预测、存储不是队列**：无新 flit 存储；`REV` 是 header 侧带；staging 是既有注入等待。结论：写入。
