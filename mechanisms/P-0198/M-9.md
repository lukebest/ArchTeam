# M-9: RBRG 跨环门控窗（无大缓冲）

- problem: P-0198
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

无缓冲环上一旦某方向进入高占用，本地注入残差下降，`inject-fail` 上升。RBRG 若对跨环请求做 **任意拍 cut-through**，崩塌环上的重试与迟到 flit 会立刻占用对端环的 highway 槽，把局部零和变成全局 makespan 拉伸。集合通信的扇入/扇出天然跨 die、跨环（top↔bottom、Req↔Dat），公开扫描下 gather/reduce/allreduce/allgather/alltoall 大量 `collapsed=true`，与这条传播路径一致。

基线均匀读 makespan ≈ 4403.2 ns、写 ≈ 4834.6 ns（各 46080 txn）；读侧峰值后崩到 2.8–3.4 TB/s。跨环污染使「单环看起来还能注」的节点也要等对端槽，平均 hop 与单环注入成功率都测不到这个耦合。

约束：问题禁止靠加织物 flit 队列吸收突发，也禁止完美预测/无限带宽。本卡只在 RBRG 上加 **短周期 grant 窗**：窗内至多 1 flit 过桥，窗外 CTRL stall。这不是源端 token/ECN/窗口限速环——限的是 **桥的 grant 相位**，源仍按自己的 outstanding 发行。平台 `--flow-control` / `--cc-scheme` 是对照。

## 2. 机制

### 结构

每个 RBRG 端口、每个 CHI 通道、每个方向一份门控（Req/Rsp/Snp/Dat × CW/CCW 可复制；Snp 在本问题负载下应接近空，硬件仍在）。

1. **Epoch 计数器 `EΦ[3:0]`**：每拍 `+1`，模 `E`。`E` 由 CSR 选 `8` 或 `16`（复位 `E=16`）。同一物理桥的四通道可共享一个 `EΦ`（复位共享），避免通道间窗漂移；CSR `E_SHARE` 1b，1=共享。
2. **窗 CSR**：`W[3:0]` 窗长（合法 1..8，复位 `W=4`），`W0[3:0]` 窗起点（复位 0）。拍 `t` 落在窗内当且仅当 `((EΦ − W0) mod E) < W`。例：`E=16, W=4, W0=0` → 拍 0–3 grant，4–15 hold。
3. **Grant FSM**（每桥每通道每方向 2 bit）：
   - `Idle (00)`：窗外，或不满足过桥条件。
   - `Grant (01)`：窗内且接受 1 个 flit 进入桥。
   - `Hold (10)`：窗外，或窗内但桥上已有 1 flit 未完成 cut-through。
   - `11` 保留，视为 `Hold`。
4. **1-flit skid**：桥上最多 **1** 个 flit 在途（已有桥 skid 若存在，本卡把它钉死为 ≤1 flit / 通道 / 方向）。**禁止** 扩成多 flit 织物队列。skid 满时即使在窗内也进 `Hold`。
5. **反压线 `bp`**：1 bit 回到本侧 NI/桥控制。`bp = (state==Hold) OR (skid_valid AND NOT grant_fire)`。NI 侧停在既有 CHI staging / credit，不在环上堆 flit。过路在本环上的 flit **不** 进 RBRG、不受 `bp` 影响（它们继续沿本环走）。

Cut-through 规则：仅当 `in_window AND ~skid_valid AND req_valid` 时 `grant_fire=1`，该 flit 进入 skid 或直接打到对端环注入口；对端环仍遵守过路优先——对端 `slot_occupied=1` 则本拍不能离开 skid，FSM 留在 `Grant` 直到送出或窗结束转 `Hold`（skid 仍最多 1）。窗外到达的跨环请求不进入 skid，只拉 `bp`。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| `EΦ` | 4 bit / 桥（可 4 通道共享） | 1W 自增 / 1R | 4b；模 `E∈{8,16}` |
| `E_SEL` | 1 bit | 1R1W | 0→`E=8`，1→`E=16` |
| `W`, `W0` | 4b + 4b / 桥 | 1R1W | 窗长、起点 |
| `E_SHARE` | 1 bit / 桥 | 1R1W | 通道是否共享 epoch |
| Grant FSM | 2 bit / 通道 / 方向 | 每拍 1 次转移 | 状态 2b |
| skid | ≤1 flit / 通道 / 方向 | 1 入 1 出 | 与 CHI flit 同宽；`skid_valid` 1b |
| `bp` | 1 bit 线 / 通道 / 方向 | NI 1 入 | 1b |
| 窗比较 | 0 | 组合 | 4b 减法 + 4b 比较 → `in_window` 1b |

规模：2 bottom die，每 die 按 4 通道 × 2 方向 ×（至多 2 个 top 附着簇）封顶，skid 个数 ≤ `2×4×2×2=32`，每个 1 flit。`tests/soc_sim` 必须按 ≤1 建模，多了即违反本卡。占用仍只用 `O_ch,d(t)∈{0,1}`，与 M-6/M-8 同一套定义。

### 数据路径与状态机

每拍每桥口：

1. `EΦ <= (EΦ + 1) mod E`。
2. `in_window = ((EΦ − W0) mod E) < W`。
3. FSM：
   - `Idle`：若 `in_window AND req_valid AND ~skid_valid` → `Grant` 并 `grant_fire`；若 `~in_window AND req_valid` → `Hold`（`bp=1`，不装 skid）；否则留 `Idle`。
   - `Grant`：送出 skid/当拍 flit 到对端且对端接受 → 若仍 `in_window AND req_valid` 再 grant 下 1 个，否则 `Idle`。对端不接受则留 `Grant`（skid 保持）。窗结束 → `Hold`（skid 仍在则继续等对端，`bp=1`）。
   - `Hold`：`in_window AND ~skid_valid AND req_valid` → `Grant`；skid 送空且无请求 → `Idle`；否则留 `Hold`。
4. 过路（不请求过桥）的 highway 路径旁路 FSM，0 额外门（除已有 RBRG 出口比较）。

时序：窗比较 4b，FSM 2b，目标同拍产出 `grant_fire`/`bp`；对端注入仍受对端过路优先约束。禁止用对端未来占用预言提前 grant。

## 3. 为什么有效

污染半径：无门控时，崩塌环在任意拍把 flit 推进邻环，邻环 `O=1` 的时间被「外源过路」抬高，残差注入下降，重试再回流，形成跨环正反馈。门控把外源注入邻环的时刻限制在每 `E` 拍中的 `W` 拍，且在途 ≤1 flit。邻环每个 epoch 至多被该桥占用 `W` 个槽（再受对端过路截断），污染从无界变成 `O(W/E)` 的占空比。`W=4, E=16` 时该桥贡献的额外占用上界 25%。

这把无界 retry storm 转成 **延迟但相位对齐** 的过桥：makespan 的方差下降，集合扇入不再被随机跨环毛刺拉长尾部。Little 用在桥：`L_bridge ≤ 1`，`λ_bridge ≤ W/E`（每通道每方向）。Amdahl：仅当跨环传播占该类 makespan 的 `f_b` 时，加速上界 `1/(1−f_b·γ)`，`γ<1`。单环不经过 RBRG 的流量 `f_b≈0`，不得用单环单测冒充收益。

诚实性：Hold 在轻载下增加单笔跨环延迟，上界约 `E−W` 拍（`E=16,W=4` → 最多 12 拍等窗）+ skid 等待对端空槽。相对 ~4.4 μs 基线通常很小，但 **必须单报轻载回归**。本卡不加带宽、不加队列深度。

## 4. 评估计划

### 基线

1. 公开基线：12+2、512 B、AIC RO 512 / WO 256、流控 OFF；RBRG 任意拍 cut-through（平台默认）。
2. 对照：`--cc-scheme srcfc`、`ecn` 等。门控开/关 × 各对照。不得把源端限速记作本卡。
3. 消融：
   - C0：`W=E`（窗永远开，off，skid 仍 ≤1）。
   - C1：`E=16, W=4, W0=0`。
   - C2：`E=8, W=2`（占空比同 25%，周期更短）。
   - C3：`E=16, W=8`（占空比 50%）。
   若 C1–C3 与 C0 的 endpoint 不可分，禁止写因果。C0 仍带 ≤1 skid——若有人把「多 flit 桥队列」当 off，那是改问题，不是消融。

### 必须 cycle 级建模的结构

- 4b `EΦ`、`W`/`W0`、2b FSM、`skid_valid`、1b `bp`。
- 桥上在途 flit **硬上限 1** / 通道 / 方向。
- 对端环过路优先 + 有限链路延迟。
- 跨环 retry / bridge-fail 计数（proxy）。
- **不要** 建多 flit 桥队列、全局占用 oracle、源端 token 机。

### 指标与负载

Full envelope：12+2 DV200、CHI 四环、点对点 + 全集集合、有限 outstanding、有限链路延迟。多 die 集合（allreduce/allgather/alltoall/gather）为必测；P2P 权值/KV/激活与均匀读/写必须同信封出现（可并发或分列，但过线看每类，且至少一组并发）。

Endpoints：每类 makespan、完成 txn 数、collapse 标志。Proxy：cross-ring retry、bridge-fail、`bp` 断言拍数、skid 占用时间。不得用瞬时利用率或单环注入成功代替。

0.85 是每类 pass bar，不是 mean。Reduced-bbox（单环单元、top 子集、只均匀读）测不到本卡，不能当 full envelope。

### 预期收益区间与置信度

跨环集合（allreduce/alltoall/allgather/多 die gather）：相对 C0，makespan 预期 **8%–28%**，且须同时看到 bridge-fail/跨环 retry 下降；collapse 对部分公开扫描设定可能翻转，不保证全部。单环为主的均匀读：预期 **0%–8%**（几乎不经桥则接近 0）。轻载：单笔跨环延迟允许增加，makespan 允许变差 **0%–10%**；超过则把 `W` 加大或 `E` 减小，而不是加队列。

置信度中：污染占空比可证，makespan 取决于跨环是否为主导。不宣称 T0 通过。

## 5. 硬件开销估算

面积：每桥口 4b 计数 + 2b FSM + 8b 窗 CSR + 1 flit skid flop。skid 是主要存储：32 × 一拍 CHI flit。若 Dat 数据拍按 512 B 计，必须明确 **skid 只存当前拍的 flit 切片**（平台若已把 512 B 切成多拍，则每拍仍 ≤1 切片，不是 512 B 整包 SRAM）。控制逻辑估计 **<2 kGE** / 桥 + 已有或新增 1-flit flop。禁止为「方便」写成 4–8 深 FIFO。延迟：grant 0–1 拍；窗外增加等待，不是组合关键路径。功耗：FSM 每拍翻转，skid 仅在 grant 时时钟门控。
