# M-5 CHI 通道–环重绑织物（Channel–Ring Rebind Fabric, CRRF）

- problem: P-0198
- id: P-0198/M-5
- author: Jim Keller
- revision: T1-return-1

## 0. T1 退回回应

1. **Epoch Drain / Barrier + SYNC 采样偏斜**：新增完整 **Epoch Drain Protocol**（ARM_DRAIN → DRAIN → FLIP + `epoch_committed`）。Flip 前必须本地 drain 完成；SYNC 只对齐 epoch 计数，**不**预言流量。Skew 窗口内接收方接受 `flit.epoch_tag ∈ {local_epoch, local_epoch−1}`；cycle 模型必须显式打 skew 采样。

2. **Ghost Dat channel-id @ RBRG**：Dat 形态走 Snp 物理环时，flit 仍携带原 channel-id / `epoch_tag`；RBRG 按 **绑定表 + epoch** 译码，**禁止** 把 Dat 误读成 Snp。接受集外失配 → **NACK / 原 Dat 环重注入** 路径，计数 `bind_mismatch_redirect`；**禁止** 静默丢弃，**禁止** 永久 inject stall。

3. **强制 Snp makespan / completions + duty 扫描；干掉相位预言**：Rebind FSM 相位 **仅** 用本地注入压力计数（Dat util EMA / Snp pending）。删除「软件/运行时类提示」作为主使能；runtime hint **至多 advisory**，正确性不得依赖。SYNC ≠ 预测。评估强制：Snp makespan≤1.4× rebind-off 为杀假设；duty∈{3:1,7:1,15:1}；`COLL_EP` 不得靠软件暗示躲过 Snp 退化。

## 1. 根因分析

Req/Rsp/Snp/Dat 静态 1:1 绑四条独立双向环。LLM 集合重相位下 Dat 饱和、Snp 往往空闲——容量钉死在 Dat 槽，闲置 Snp 导线帮不上忙。基线均匀读 ~4403.2 ns / 写 ~4834.6 ns；集合常 collapsed。

根因是 **通道–环静态绑定**，不是缺第二套 Dat 缓冲。CRRF 做 **时间复用已有 Snp 环导线** 承载 ghost Dat：每物理环每方向每拍仍 1 槽（零和不变），Dat 逻辑在 DAT_EPOCH  temporarily 获得第二物理环。这 **不是** 发明并行第二 Dat 槽的永久双端口；理想有效 ≤1+duty_dat，再扣 drain 死时间、SYNC 槽、+1–2 拍 bind 管线。

旧稿用「软件/运行时 COLL_EP 提示」当主臂，等于把相位预言藏进 runtime——T1 杀掉。本修订：**本地压力计数驱动**；SYNC 只做 epoch 对齐；flip 前 **强制 drain**，否则 skew 下 channel-id 鬼影会污染 Snp 语义。

## 2. 机制

### 2.1 结构

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Rebind FSM / die | 态：IDLE / ARM_DRAIN / DRAIN / FLIP / STEADY | **无** COLL_EP 软件主臂 |
| 本地压力计数 | Dat util EMA（如 8–16b）+ Snp pending（计数饱和有界） | 唯一主触发 |
| Epoch 计数 | `epoch` 2b；flit `epoch_tag` 2b | 绑定世代 |
| SYNC / DRAIN marker | 走 **Req** 环 | 对齐 + drain；**不**预测 |
| 4×4 绑定 one-hot | NIC 与 RBRG 各一份；+1–2 拍 pipe | 仅 DRAIN 完成后更新 |
| `epoch_committed` | SYNC 载荷 1b/代 | 全环提交后才允许新世代注入 |
| 失配路径 | NACK / 原 Dat 环 re-inject | 计数 `bind_mismatch_redirect` |
| SNP duty floor | 可配；例 min 1/8 | 硬地板，防 Snp 饿死 |

绑定例（STEADY，duty Dat:Snp = 7:1）：

| Epoch 类型 | Req 环 | Rsp 环 | Snp 环硬件 | Dat 环 |
|------------|--------|--------|------------|--------|
| DAT_EPOCH（7/8） | Req | Rsp | **ghost Dat** | Dat |
| SNP_EPOCH（1/8） | Req | Rsp | Snp | Dat |

**明确**：时间复用 ≠ 第二并行 Dat 槽；有效容量理想 ≤1+duty_dat，减去 drain 死时间与 SYNC 占用。

### 2.2 Epoch Drain Protocol（强制）

Flit 携带 `epoch_tag[1:0]` = 绑定世代。

**Flip 序列（每节点 FSM）**：

1. **ARM_DRAIN**：在 Req SYNC 路径注入 DRAIN marker；**停止** 将使用「即将被重绑环」的 **新** 注入（已在途 flit 继续）。
2. **DRAIN**：本地倒数环周（或见 DRAIN marker **返回两次**），并 **嗅探 highway**：确认本物理环上无 `epoch_tag==old` 的在途 flit。
3. **FLIP**：仅当本地 DRAIN 完成 → 更新 4×4 one-hot；SYNC 携带 `epoch_committed` 绕全环，使晚节点 **不得** 提前按新绑定注入。
4. **Skew 窗口**：drain/提交期间，接收方接受 `flit.epoch_tag ∈ {local_epoch, local_epoch−1}`；**永不** 把 Dat 载荷按 Snp 语义重解释。接受集外失配 → **NACK / 在原 Dat 环重注入**（`bind_mismatch_redirect++`），禁止静默丢，禁止永久卡死 inject。

### 2.3 Ghost Dat @ RBRG（channel-id 正确性）

- Ghost Dat flit 在 Snp 物理环上前进，但 **header channel-id 仍标 Dat** + 匹配的 `epoch_tag`。
- RBRG 查 **当前（或 skew 允许的）绑定表**：仅当该物理环在本 epoch 被绑为 Dat 形态时，按 Dat 桥接规则处理。
- 若看到 Dat id 但本地绑定为 Snp 且 tag 不在接受集 → 走失配重定向，**不当 Snp 嗅探处理**，不丢。
- Snp 消息仅在 SNP_EPOCH（或 duty floor 保留窗）注入 Snp 物理环。

### 2.4 相位臂（杀预言）

- **主臂**：本地 Dat util EMA 高且 Snp pending 低 → 请求提高 Dat duty / 进入更积极 DAT_EPOCH 比；反向则拉回。
- **Runtime hint**：可选 advisory，**正确性不依赖**；硅片在无 hint 时必须仍能安全 drain/flip/steady。
- **SYNC**：只对齐 `epoch` / 传播 DRAIN 与 `epoch_committed`；**SYNC ≠ 流量预测**。

### 2.5 Snp 活体与 stall 界

DAT_EPOCH 期间 Snp 源可 stall，但：

- 保留 **SNP_EPOCH duty floor**（例 min 1/8）；
- **杀假设**：Snp makespan ≤ **1.4×** rebind-off；若超过 → duty 重调或机制失败；
- Stall **有界**（duty floor 保证注入机会），不是永久 inject stall。

### 2.6 时序

| 阶段 | 建模 |
|------|------|
| SYNC 采样偏斜 | ≤ 环周链路延迟；cycle 模型必打 |
| ARM_DRAIN → DRAIN | ≥ 1–2 × 环周（marker 双回或 sniff 清） |
| FLIP + bind pipe | 1–2 拍 |
| `epoch_committed` 全环 | +1 环周 |
| 失配 NACK/re-inject | 显式路径，计入 redirects |

## 3. 为什么有效

**Amdahl**：把闲置 Snp 导线时间借给 Dat 形态，砍 Dat 槽争用主导的集合/搬运 makespan；扣掉 drain/SYNC 税后仍可能净赢——**税必须进模型**。

**零和**：不增加物理槽；有效 ≤1+duty_dat − drain − SYNC。谁宣称「近乎双 Dat 无税」谁在撒谎。

**正确性**：drain + skew 接受集 + 失配重定向，堵住「epoch 翻转瞬间把 Dat 当 Snp」的鬼影；RBRG 按绑定+tag 译码，不靠运气。

**非预测**：压力计数是反馈，不是先知；SYNC 是屏障对齐。软件 hint 靠边站。

## 4. 评估计划

- **信封**：DV200 ≤12 top + 2 bottom；CHI 四环；512 B；公开 outstanding；禁完美预测/无限带宽。
- **强制 endpoints**：
  - 分流量类 makespan、completions、collapsed；
  - **Snp makespan 与 Snp completions**（杀假设 ≤1.4× rebind-off）；
  - duty 扫描 **{3:1, 7:1, 15:1}**；
  - `bind_mismatch_redirect`：稳态目标 **==0**；非零必须解释；
  - skew-window 注入/弹出 **cycle 级建模**；
  - HARD-2：512 B 下 destination spread。
- **消融**：rebind-off（经典 1:1）→ Dat 侧应变差、Snp 侧作对照基线。
- **禁止**：用 runtime `COLL_EP` 暗示代替压力计数；用 SYNC「预测」流量；只报 Dat 均值藏 Snp 退化。
- **包络**：满 12+2 + 多环 + 点对点与全集集合；减箱 ≠ 全信封。
- **预期区间（非过关宣称；0.85=bar≠mean）**：
  - Dat 重集合 / 均匀读饱和区：**0.55–0.85×** makespan（中；扣 drain 税后）
  - Snp 路径：**≤1.4×** rebind-off（硬杀假设；超出 = fail）
  - duty 过敏（15:1）可能伤 Snp：必须在扫描中暴露，不得只报 7:1 甜区
  - 均匀写 / 已对称负载：**0.85–1.05×**（中低；受益窄）
