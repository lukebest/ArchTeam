# M-15 仅尾拍 Snp 快道（Tail-Only Snp Express, TOSE）

- problem: P-0198
- id: P-0198/M-15
- author: Jim Keller
- round: 2

## 1. 根因分析

CRRF（M-5）是上一轮唯一活过 T3 的 Keller 卡：把 Snp **整段 epoch** 借给 ghost Dat，gather 尾能动。Night T3 同时钉死两件事：（1）15:1 上 Snp 小包延迟 **KILL**（snp_path ≈17×、混合 ≈33×，不是 T2 的 1.56）；（2）3:1/7:1/15:1 的 Dat gather 尾 **打平**——duty 没在买 span，dest 弹出在主导。还交 Epoch Drain 税。

推理 decode 真正要的是 **这一波最后一拍 KV / 最后一跳 collective 贡献** 早点到，不是把整段 Dat 相位变成双环。Snp 在 decode 路径上往往是小包、稀疏，但 **不能被 stall 到 epoch 窗**——一致性 / 目录延迟进尾。

根因：**尾拍仍挤在已经饱和的 Dat 环上，而 Snp 环大量空拍被浪费；CRRF 用停 Snp 的方式借整环，借错了粒度。** TOSE 只允许带 `tail_critical` 的 **至多一拍** Dat 在 Snp 环 **空拍** 上走，Snp 永远赢。不是 15:1 TDM，不是通道静态亲和，不是源端窗口。训练大块不另论证。

## 2. 机制

### 2.1 结构

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Tail scoreboard | 每 dest 每波：`expected` 16b + `recv` 16b + `armed` 1b | dest 或源在「最后 outstanding 拍」置位 |
| `tail_critical` | Dat 头 1b | **每 dest 每波至多 1 个** 在途（HARD-2 / issued-window 唯一性） |
| Snp-empty 采样 | 1b / 方向 | 本拍 Snp highway 为 empty **且** 本节点无 Snp 待注入 |
| Express mux | Dat NIC → Snp 物理环的 **旁路口** | 仅当 `tail_critical ∧ snp_empty ∧ ¬snp_pending` |
| Snp 绝对优先 | 组合 | 任何 Snp flit / Snp 注入 vs express Dat：Snp 赢 |
| Channel-id | 2b 保持 Dat | 在 Snp 导线上仍标 Dat；RBRG / dest **按 id 不按物理环** 译码 |
| 1 深 mismatch hold | 仅 express 失配，深度 1 | 与 CRRF 同样声明：不是 highway 队列；满则回 Dat 环重试 |
| **没有** epoch / SYNC / 4×4 重绑 / Snp stall | — | 与 CRRF 切断 |

`tail_critical` 武装规则（非预测）：

- P2P / KV：源在本波最后一拍（门铃 `nbytes` 剩余 ≤ 一拍）置位；或 dest 在 `expected−recv==1` 时于 Rsp 回一条 ARM_TAIL，源给 **下一拍** 置位。
- 推理 collective：root/dest 对 last contributor 发 ARM_TAIL；其他拍不得置位。
- 同时武装 >1：后到的清先到的（只留 1），`tail_dup++`。必须报。

### 2.2 数据路径 / cycle-level

1. 普通 Dat 拍：只走 Dat 环，与 no-CC 相同。**禁止** 非尾拍上 Snp 导线。
2. 尾拍在源 NIC：若本拍 Snp 方向槽 empty 且无 Snp pending ⇒ 注入 Snp 物理环，头 `chi=Dat`、`tail_critical=1`、`via=express`。否则走 Dat 环（不 stall Snp，也不等 Snp 空——不等就是为了不引入源端窗口）。
3. Express flit 在 Snp 环上前进。节点若本拍要注入 Snp：Snp 注入 **不得** 被 express 挡住——过路 express 是 Dat，Snp 注入只在 empty 时发生；若槽是 express Dat，Snp 注入 fail-wait（**这是唯一可能伤 Snp 的点**）。因此 express 在途密度必须有界：每 dest 每波 1 拍，12 dest ⇒ 环上 express ≤12，通常 ≪1。
4. Dest：看到 `chi=Dat` 无论物理环是 Dat 还是 Snp，按 Dat eject。Snp 语义不得解释该槽。
5. RBRG：按 channel-id 桥接 Dat；若本地把该物理环当纯 Snp 且看到 Dat id ⇒ 1 深 hold，下一拍送回 Dat 环，`express_redirect++`。稳态假设 ≈0（四环独立、不重绑时不应失配）。
6. **禁止** DAT_EPOCH / SNP_EPOCH。没有 drain。Snp 消息任何周期都可在 Snp 环注入（受 express 占槽的零和限制，见上）。

### 2.3 时序

| 事件 | 周期 |
|------|------|
| tail 武装 | 门铃剩余判定：组合；ARM_TAIL：Rsp 1 圈（可选路径） |
| express 注入判定 | 同拍 |
| Snp vs express 仲裁 | 同拍，Snp 赢 |
| dest 跨环 eject | 基线 + 1 拍 id 核对（假设） |
| mismatch hold | 1 深，≤1 拍再加等 Dat 空槽 |

### 2.4 仿真器改动

- **结构变更**：NIC 增加 Dat→Snp 物理环旁路；dest/RBRG 必须按 channel-id 而不是「物理环==通道」译码。这与 CRRF 的 4×4 epoch 重绑 **不是** 同一改动。
- platform **新分支**，禁止改 `main`。改动点：
  - `tests/soc_sim` NIC bind：增加 `express` 臂（条件如上）；
  - dest eject / RBRG decode：channel-id 优先于 phys ring；
  - 1 深 mismatch hold 显式化（深度、压在哪个口、计入零和）；
  - **不要** 复用 CRRF 的 Rebind FSM / SYNC / duty。
- RTL 仍禁止改。

## 3. 为什么有效（尾）

一波的 last-completion 就是那一拍 `tail_critical` 的到达。它在饱和 Dat 环上的等待是 `n_wait_dat`；Snp 环在 decode 期空拍率高（CRRF 自己的前提，只是它借整 epoch）。TOSE 让这一拍看见另一条物理空槽，`n_wait` 换成 Snp 空拍等待——通常是 0 或 1，且 **不关 Snp 注入器的 stall 门**。

相对 CRRF 的机制级差：

| | CRRF | TOSE |
|---|---|---|
| 谁上 Snp 导线 | 整段 ghost Dat | 每 dest 每波 ≤1 尾拍 |
| Snp 能否随时注入 | 仅 SNP_EPOCH | 除 express 占槽外随时 |
| Drain 税 | 1–2 圈 + committed | 无 |
| 15:1 | T3 KILL | 不存在 duty |

相对 no-CC：尾拍少挤 Dat。相对 source-FC：不减窗口，尾拍甚至被允许换环。

若 cycle 显示尾拍其实不在 Dat 环上等待（dest-eject 或计算在主导），express 是空操作，`T_mix≈1`，淘汰。CRRF T3 gather 打平已经警告过「dest 弹出主导」——本卡必须在 **尾拍仍在 Dat 争用** 的 bbox 上赢；只复现 dest-0 打平不得签字。

## 4. 失败模式

- **退化成 mini-CRRF**：让非尾拍也上 Snp，或给 Snp 加 stall epoch。T3 会再杀 Snp。硬断言：非尾 Dat 上 Snp 环的拍数 ≡0；Snp stall-for-epoch ≡0。
- **express 密度爆**：`tail_dup` 失控或所有拍都标尾。scoreboard 必须强制每 dest 每波 1。违例=失败。
- **Snp 注入被 express 挡出尾**：15:1 混合必须报 Snp makespan。假设 ≤1.05×；>1.4× = 杀假设，与 CRRF 同一把刀，不得藏进 Dat 均值。
- **channel-id 当 Snp 嗅探**：正确性洞。RBRG/dest 禁重解释。
- **1 深 hold 变成队列**：深度>1 或吸收突发 = 违规。

## 5. 硬件开销估算

| 项 | 面积（假设） | 功耗 | 延迟 |
|----|-------------|------|------|
| tail scoreboard / dest | ~0.0005 mm² | <0.3 mW | 同拍 |
| express mux / NIC | ~0.001–0.003 mm² | ~0.5–2 mW | 0–1 拍 |
| id 核对 + 1 深 hold / RBRG | ~0.001–0.002 mm² | ~0.5 mW | 1 拍 |
| **每 top** | **~0.003–0.006 mm²** | **~1–3 mW** | **0–1 拍** |

无 4×4 重绑，无 SYNC 公民风暴。比 CRRF 更小，税更短——这是面积叙事，不是测得加速。

## 6. 评估计划

- **主指标**：推理 KV P2P / 推理期 collective 的 last-completion 与 p99；**强制** Snp 15:1 混合小包 makespan + completions。
- **cycle 基线**：no-CC；source-FC；**M-5 CRRF** 全臂（rebind-off/3:1/7:1/15:1）。TOSE 必须在 **Snp 不过杀线** 的前提下比 CRRF 的 Dat 尾不差，或在 CRRF Snp-KILL 臂上展示「Dat 不输且 Snp 活」。禁止把 CRRF T2 1.5625 贴到任何表。
- **必须建模**：`tail_critical` 唯一性；Snp 优先；非尾 Dat 上 Snp≡0；express 占槽对 Snp 注入的零和；mismatch hold 深度 1；无 epoch。
- **消融**：`express-off`（尾拍只走 Dat）。HARD：推理主类尾 off **>** on。另加 `mark-all-as-tail` 杀手：Snp 应爆，用来证明「只标尾」是必要的，不是可以偷成 CRRF。
- **预期（假设，未测）**：
  - 推理 KV 尾相对 no-CC：**0.75–0.95×**（中）
  - 相对 source-FC：**0.75–0.95×**（中）
  - 相对 CRRF Dat 尾：**0.90–1.15×**（低–中；不宣称全面更快）
  - 相对 CRRF **Snp 15:1**：假设 TOSE **≤1.05×** no-CC vs CRRF KILL（中高；这是本卡对 CRRF 的主胜场）
  - `mark-all-as-tail`：Snp 应 >1.4×（杀手，必须暴露）
  - card-claim 不签字；0.85 是 bar

## 7. 可证伪声明

1. **H-UNIQUE-TAIL**：任意时刻、任意 dest、任意 wave，在途 `tail_critical==1` 的 Dat flit ≤1。
2. **H-NO-EPOCH**：不存在 SNP_EPOCH stall；Snp 注入门不含 duty。
3. **H-NONTAIL0**：非尾 Dat 出现在 Snp 物理环的拍数 ≡0。
4. **H-TAIL**：express-off 推理尾 **>** on。`T_mix≈1` ⇒ 淘汰。
5. **H-SNP-LIVE**：默认 TOSE 的 Snp 15:1 混合 ≤1.4× no-CC；超过则与 CRRF 同罪，不得只报 Dat。
6. **H-NOT-CRRF**：duty 扫描对本卡无定义；谁写出 7:1 TOSE 谁在伪造。

## 8. 自检（淘汰约束）

1. 消融与 CRRF 对照必须 cycle 级；禁止把「Snp 空拍率 × 1 尾拍」解析式贴成 T3 尾。CRRF 的 T2/T3 数字不进本卡结果表。
2. express 成功次数 / 更高 `p_inj` 不算收益。尾不动则死。不是 bubble、GRANT、AODI 造洞。
3. 不是 TDM/slotted/最短方向。空拍借用 ≠ epoch 表。
4. Snp 15:1 必须跑、必须报；未过线不卖。`mark-all-as-tail` 杀手不得瞒死。
5. 数字皆假设 / 预测。
6. 六硬：express-off 仍填满 Dat 占用不得给「借了 Snp」空头分；`tail_critical` 必须证明 issued-window 唯一、不塌成「所有拍都是尾」；禁止 Dat 尾与「有效 Dat+Snp 槽」两套不等价指标；killer stride / 全标记必须单列；对照 no-CC、source-FC、CRRF、最短方向冻基线；0.85 是约束；只跑 Snp 空闲减箱 ≠ 15:1 混合全信封。
