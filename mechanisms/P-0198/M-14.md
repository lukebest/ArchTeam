# M-14 路过订阅者拷贝 + 末订户斩槽（Pass-by Subscriber Copy + Last-Sub Kill, PSCK）

- problem: P-0198
- id: P-0198/M-14
- author: Jim Keller
- round: 2

## 1. 根因分析

推理期 fan-out——token / 前缀 KV 分享、TP broadcast、decode 步的小 AllGather 展开——在基线上被拆成 **N 条 unicast**。Last subscriber 的到达时间含 `(N−1)` 次注入串行，外加 N 条公民在环上继续占槽直到各自 eject。Bufferless 单槽把这件事变成 makespan 的主项：不是 dest miss，不是远源迟到，是 **同一载荷被注入 N 次**。

教科书环 multicast / multidrop 会让一份拷贝绕满圈。那把注入串行砍了，却把 **斩槽时刻** 留在绕回源——下一 decode 步仍吃残余占用。T0 已杀 slotted-ring/TDM 与最短方向；本卡不走时隙表，也不改 CW/CCW 选择。

CSR 用 RBRG CAM + GRANT 做扇入，T3 `r≈1` 且 GRANT 税 ≥ 收益。PSCK 是 **扇出、payload 永不进桥、无 GRANT、路过拷贝、末订户立刻变 empty**。训练 All-to-All 大块不是主论证。

## 2. 机制

### 2.1 结构

| 结构 | 容量 / 端口 / 位宽 | 说明 |
|------|-------------------|------|
| Subscriber bitmap | 头 12b（≤12 top）+ 2b bottom 可选 | 1=仍需拷贝 |
| `mcast` 1b | 头 | 置位才走本路径 |
| Copy-without-remove | dest eject 旁路 | 拷贝进 NIC，**不** 从 highway 拿走，除非本拍是末订户 |
| Popcount / last-sub | 组合：`popcount(bitmap)==1` 且本节点 bit=1 | 末订户斩槽 |
| Classifier | opcode / doorbell 类 → mcast 或 unicast | 32×1 ROM；普通 P2P 不置位 |
| 无 RBRG CAM | — | payload 过桥按基线；桥 **不** 持拍、不 fold |
| Busy-dest | 1b | dest 本拍不能收：bit **保持**，flit 继续走，不斩 |

满 bitmap 且无人能收：flit 最多再绕 `LAP_MAX`（默认 2）圈，然后 Rsp NACK 回源、回退 unicast。禁止静默丢。

### 2.2 数据路径 / cycle-level

1. 源对 fan-out 波只注入 **一条** Dat flit：`mcast=1`，bitmap=订阅者。方向按基线路由（不强制最短、不分区）。
2. flit 到达节点 i：
   - `bitmap[i]==0`：过路，PSCK 不动作。
   - `bitmap[i]==1` 且 `eject_ok`：NIC 拷贝 1 拍；清 `bitmap[i]`。若清后 bitmap=0：**本拍斩槽**（kind←empty），`last_sub_kill++`。若仍有 bit：flit 带着新 bitmap 前进。
   - `bitmap[i]==1` 且 `¬eject_ok`：不清 bit，前进（允许再绕）。`defer_copy++`。
3. 源看到绕回且 bitmap≠0：`laps++`；`laps≥LAP_MAX` ⇒ 剩余 bit 拆 unicast 回退，`fallback_unicast++`。回退完成数必须进分母。
4. Snp/Req/Rsp 默认不走 PSCK。推理期 consistency 小 Snp 保持基线路径。
5. **禁止** 在 RBRG 做 reduce/latch。AllGather 的扇入半边不在本卡范围（那是 CSR 的坟）。

### 2.3 时序

| 事件 | 周期 |
|------|------|
| Classifier | 组合 / 1 拍 |
| Copy-without-remove | dest 同拍；highway 不停 |
| Last-sub kill | 同拍改 empty |
| 再绕 | ≤ `LAP_MAX·C_ring` |
| Unicast 回退 | 基线 N 注入（失败路径） |

Dat 管线 0–1 拍。无队列。

### 2.4 仿真器改动

- **结构变更几乎必然**：现有 `tests/soc_sim` dest eject 多半是「弹出=拿走」。Copy-without-remove + 头上改 bitmap + 同拍斩槽 是 highway 语义改动。
- **必须** 开在 `bufferless-ring-noc` **新分支**，禁止改 `main`，合入仅审计后。改动点：
  - dest eject：增加 `copy_keep` 臂（拷贝但不清槽）；
  - flit 头：12b bitmap + 1b mcast；
  - slot：允许 payload→empty（last-sub）；
  - 源 NIC：fan-out 只发 1 条 + `LAP_MAX` 回退。
- 不加 flit 队列，不加第三槽，RBRG 不新增 CAM/latch。

## 3. 为什么有效（尾）

Unicast 扇出：

```
T_last_uni ≈ t0 + (N−1)·T_inj_serial + hops(last)
```

PSCK：

```
T_last_mcast ≈ t0 + hops(last_sub_along_path) + n_defer·C_ring
```

末订户斩槽让 **下一 decode 步** 不再吃「多播残段绕回源」的占用（与 WSOR 互补：WSOR 回收已完成波，PSCK 在波内提前结束公民生命）。

相对基线（假设）：

- **no-CC**：N 次注入串行。N=12 时这就是尾。
- **source-FC**：窗口让 N 次注入更慢。
- **CRRF**：多 Dat 时隙能缩短串行，但仍是 N 条公民；且 Snp 15:1 死。PSCK 用 1 条公民，不借 Snp。

若负载根本不是 fan-out（纯 pairwise KV），classifier 不置位，本卡必须报中性，不得拿 P2P 行冒充成功。

## 4. 失败模式

- **写成教科书绕满圈 multicast**：不斩槽 ⇒ 波间占用不降，T0 还可能 FUNCTIONAL_EQUIVALENT。斩槽是本卡身份，消融 `kill-off` 必须让 `T_seq` 或下一波尾变差。
- **busy dest 活锁**：bit 永不清。`LAP_MAX` + unicast 回退是逃逸；回退主导则 fan-out 区间作废。
- **bitmap 当地址折叠**：HARD-2。bitmap 是 dest 集合，不是冻结 addr 高位。512 B issued-window 内每 txn 一张 bitmap，不得把多 txn 压进同一 bit 槽。
- **RBRG 偷持拍**：回到 CSR 死因。断言 `RBRG_dat_beats_held==0`。
- **all-to-all 当 fan-out**：N² 条 mcast 会自焚。All-to-all 必须走 unicast 或拒绝置位，单独报「不适用」。

## 6. 评估计划

- **主指标**：推理期 broadcast / 前缀 KV 分享 / TP broadcast / decode AllGather **扇出半边** 的 last-sub 到达与多步 `T_seq`。P2P 中性行必须在。All-to-all 标不适用或回退，不得均值。
- **cycle 基线**：no-CC（N unicast）；source-FC；M-5 CRRF。
- **必须建模**：单注入；copy-keep；last-sub kill；busy-dest 保持 bit；`LAP_MAX` 回退计数；`RBRG_dat_beats_held==0`；Snp 15:1。
- **消融**：`mcast-off`（回 N unicast）；`kill-off`（拷贝但不斩槽）。HARD：fan-out 类 last-sub 到达，off **>** on；`kill-off` 的下一波尾应 ≥ on（残留占用）。任一消融 `T_mix≈1` 且声称主收益 ⇒ 淘汰。
- **预期（假设，未测）**：
  - 推理 broadcast / TP fan-out 相对 no-CC：**0.40–0.80×** last-sub（中；N 大靠下）
  - 相对 source-FC：**0.40–0.75×**（中）
  - 相对 CRRF：**0.70–1.00×** 且 Snp 不爆（中；CRRF 在 Dat 很空时可能接近）
  - 纯 P2P KV：**0.98–1.05×**（高；中性）
  - 回退主导的 all-to-all：**不宣称 <1**
  - Snp 15:1：假设 **≤1.05×**

## 7. 可证伪声明

1. **H-ONE-INJECT**：每条 fan-out txn 源端 Dat 注入次数 == 1（回退前）。>1 且非回退 = 失败。
2. **H-LAST-SUB**：last subscriber 到达时间 on < N-unicast off。
3. **H-KILL**：last-sub 后该 flit 不再以 payload 身份前进（同拍 empty）。
4. **H-NO-BRIDGE-BUF**：全程 `RBRG_dat_beats_held==0`。
5. **H-SNP**：未过线不卖。

## 8. 自检（淘汰约束）

1. 消融必须 cycle 级动 last-sub / 下一波尾；禁止把「环 multicast O(C_ring) vs O(N)」解析式贴 T3。
2. 不把「少注入所以 `p_inj` 看起来更高」当收益。尾不动则死。不是 bubble / GRANT / AODI。
3. 斩槽 ≠ TDM 时隙；方向仍是基线，不是最短方向新发明。
4. Snp 15:1 分列。
5. 数字皆假设。
6. 六硬：mcast-off 仍满占用（N 条公民）不得给 on 记「占用下降」空头分；bitmap 须证明 issued-window 内 txn 不塌成 1 个 bit 槽；禁止再定义一套「拷贝完成时间」与 last-sub 不等价还拿来过关；killer all-to-all / busy-dest 必须单列；对照三条基线 + 教科书绕满圈（`kill-off`）；0.85 是 bar；只跑 N=2 减箱 ≠ 12 top。
