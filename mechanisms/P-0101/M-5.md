# M-5: stride-class 可配 XOR 矩阵

- problem: P-0101
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

一组静态抽取只对一个 `v2(S)` 最优。`S=2^m` 的区分位是 `[m,33)`：`m=9`（粒度 512B）要吃低 G 位才能铺满 N；`m=21`（2MiB）必须吃 `addr[32:21]`。把矩阵钉在低窗，大步长占用掉到 9；钉在高窗，顺序流的低位熵被丢掉（或完全依赖冻结陪集）。

固件知道或可被告知主导 stride class。本卡用 **4～8 项配置表**，按编程的 `m` 换一张 14×24 XOR 矩阵。v1 **不**做硬件步长探测器，只接受 CSR 编程。快照占用仍 ≤K；目标是在编程 class 上坐到 ~K。禁止 `core_id` 进 map。

## 2. 机制

### 结构

1. **class 索引**：`m_raw` 为软件写入的步长 2-adic 阶（或作业描述）。`m = clamp(m_raw, 9, 21)`。`class = quantize(m)` 3 bit，v1 用 8 档：`{9,11,13,15,17,19,20,21}`，未命中档位向下并入最近已编程档。
2. **8 张矩阵**：每张是 `14×24` 的 bit-select/XOR，吃 `G[23:0]=addr[32:9]`，吐 14b `idx[13:0]`。`⌈log2 N⌉=15`，14b 值域 16384，9-way 残差由 `idx` 折叠得到。不用 `idx + 9·fold(idx) mod 18432` 的含糊式，拼装固定为：
   - `u = idx[10:0]`（2048）
   - `c = idx[13:11] % 9`（3b→0..7，再用 `idx[0]⊕idx[12]` 扩到 0..8 的满射）
   - `flat = c·2048 + u`
3. **矩阵语义（评估指定四档）**：
   - `m=9`：行主对角吃 `G[13:0]`（`addr[22:9]`），高 G 位作 XOR 扰。
   - `m=19`（S=512KiB）：行吃 `G[23:10]` 即 `addr[32:19]`，区分位宽 14，目标占用 K=16384。
   - `m=20`（S=1MiB）：行吃 `addr[32:20]` 的 13b + 1 个冻结扰码。
   - `m=21`（S=2MiB）：行吃 `addr[32:21]` 的 12b，余 2 行从冻结位只选陪集（占用目标 K=4096 不是 16384）。
4. 软件/BIOS 在作业启动写表。硬件 stride 探测 **不是 v1 范围**。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| 矩阵文件 | 8×(14×24)=2688 bit | boot/作业 2W（双口仅启动）；译码 **1R** | 读口一次吐 336 bit（一张矩阵）或按行 14×24 预展开 |
| `m` CSR | 5b | 1W 软件 / 1R 译码 | 5b，clamp 到 9..21 |
| class 选择 | 3b 译码 | 组合 mux 8:1 | 选中一张 14×24 |
| XOR 阵列 | 14 个 24 输入 XOR（掩蔽后） | 组合 | in 24b G / out 14b |
| flat 拼装 | 0 | 组合 | 15b |

实现建议：不在每请求读 2688b。把 8 张矩阵映成 8 组熔丝/flop，3b class 做 8:1 **行选择**，每行 24b mask。1R 指「每请求只启用一组 mask」，不是双口 SRAM 银行。双口仅 boot 加载。

### 数据路径与状态机

无运行时 FSM。每请求：

1. `class = Q(clamp(m,9,21))`（3b）。
2. 取出 14 个 24b mask：`mask_i = T[class][i]`。
3. `idx_i = ⊕_j (mask_i[j] & G[j])`，14 路并行，XOR 树深 5（24 输入）。
4. `u=idx[10:0]`，`c = (idx[13:11] + (idx[0]⊕idx[12])) % 9`（3b+1b，常数 `%9` 用 4b 比较减法）。
5. `flat=c·2048+u` → `/48` → 拓扑。

换 `m` 或换表：必须在空闲或复用 M-4 栅栏之后；v1 规定只在作业开始时写，飞行中只读。

## 3. 为什么有效

对编程 class `m`，矩阵行空间对准区分位 `[m,33)`，GF(2) 秩拉到 `min(14, 33-m)`。占用：

- `m=21`：秩 ≤12，占用 ≤4096=K。
- `m=20`：秩 ≤13，占用 ≤8192=K。
- `m=19`：秩 ≤14，占用 ≤16384=K（`N=18432`，14b+9-way 可接近 K 而非 N）。
- `m=9`：区分位几乎是全部 G，占用可接近 N（此时 K>N，上界改成 N）。

偏离 class：例如编程 `m=21` 却跑 `S=512B`，高行吃的是顺序流里仍变的高地址，加上低位扰码行，占用通常仍高，但 DMC 均匀性可能差——「优雅降级」而不是塌到 9。编程 `m=9` 却跑 `S=2MiB`，则退回低窗饥饿（占用 ≪K），这是负对照。

Little/roofline 与 M-1 相同：编程正确时 bank 占用坐在 K，再被 384 DMC 截。

## 4. 评估计划

### 基线

单张静态低窗矩阵（`m=9` 冻结）；`G mod N`；M-1 硬线高 12b。

### 必须 cycle 级建模的结构

- 8×14×24 配置文件及 3b class mux。
- 5b `m` CSR 与 clamp/quantize。
- 14 路 24 输入屏蔽 XOR。
- 3b+1 → 9-way 与 `flat`。
- 写表/写 `m` 的时机（仿真器应在非空闲写时报违例）。

### 指标与负载

为 `m∈{9,19,20,21}` 各装一张矩阵；扫 `S∈{512B,4K,512KiB,1MiB,2MiB}`。编程匹配的 class 上占用应坐在 ~K（或 `S=512B` 时 ~N）。偏离 class 应优雅下降，不得差于 `G mod N` 的 9。min/mean BW 同上。不要报占用 >K。

### 预期收益区间与置信度

匹配 class：占用 `0.9K～K`，相对 `mod-N` 的 BW `×8～×40`。错 class（高步长 + 低窗矩阵）：占用回到 `9～256`，BW 接近基线——这是必须暴露的负例。置信度中（矩阵满秩可检查）。不宣称 T0 通过。v1 无探测器，作业描述写错 `m` 即失去收益。

## 5. 硬件开销估算

面积：2688b flop ≈ `2688×6GE≈16kGE`（或 336B 小 SRAM + 8:1）；XOR 阵列 `14×24` AND + XOR 树 ≈ `2kGE`。合计译码侧 `~20kGE` 或 `0.002mm²` 量级。功耗：每请求 14 路 24b XOR，动态 `0.2～0.5mW` @1GHz。延迟：1 cycle 寄存 XOR（树深 5 门，1GHz 建议寄存）。
