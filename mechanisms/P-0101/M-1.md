# M-1: 区分位饱和抽取

- problem: P-0101
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

冻结信封：`W=8GiB=2^33`，`N=18432=2^11×9`，粒度 `512B` 故 `G=addr>>9`。任意可逆映射在步长 `S` 的一次快照里，占用不超过该算术级数的点数 `K=⌊(W−base)/S⌋+1`。`S=512KiB/1MiB/2MiB` 时 `K=16384/8192/4096`，故 `S=2MiB` 占用上界是 `K/N≈22.2%`，打满 18432 bank 不是合格项。

更糟的是仿射 `(G mod N)`：`S=2^m` 时 `S_g=2^{m-9}`，`gcd(S_g,N)` 吃掉全部 2 幂。具体：

| S | S_g | gcd(S_g,N) | 仿射占用 ≤ N/gcd |
|---|-----|------------|------------------|
| 512KiB | 2^10 | 2^10 | 18 |
| 1MiB | 2^11 | 2^11 | 9 |
| 2MiB | 2^12 | 2^11 | 9 |

根因：大步长 AP 上 `addr[0,m)` 为常数；若 bank 索引从这些冻结位搭建，值域塌缩。区分位是 `[m,33)`，宽 `33-m`；`S=2MiB` 时恰为 12 bit = 4096 = K。要把快照占用从 9 拉到 K，必须让这 12 个区分位注入式进入 bank 索引，冻结位只选陪集、不再充当主索引。

本卡不把 `core_id` 混进 DRAM bank map（破坏一致性）。partial-good 不在本卡改拓扑：bank 索引仍落在本 DMC 的 48 槽，退役交给后续 per-DMC live mask（不跨 DMC 借 bank）。

## 2. 机制

### 结构

纯组合「区分位抽取 + 9 路陪集编码」，无 SRAM、无运行时状态。

1. **12-bit 区分向量** `d[11:0]`：硬线接到 `addr[32:21]`（`S=2MiB` 的区分位；更小 2 幂步长上这些位仍变）。可选每 bit 再 XOR 一个中位（见位宽）做顺序流扰动，但不减少 `d` 的 12 维满秩。
2. **12-bit XOR fold**（默认可为恒等接线）：`v[11:0] = d[11:0] ⊕ P·addr[20:9]`，`P` 为硬线 12×12 0/1 矩阵，复位为 0（不折叠）。
3. **9-way 编码器**：输入为冻结切片 `f[3:0]=addr[16:13]`（`S≥128KiB` 时相对 2MiB 为冻结），`16→9` 组合编码 `c∈{0..8}`。`c` 只选择该 base 落在哪个 4096 点陪集，不参与区分。
4. **拼装**（`N=9×2048`，但用 4096 点块）：`flat = (c·4096 + v[11:0]) mod 18432`，再常规译码 `dmc = flat / 48`，`bank = flat % 48`，`die/HA/pipe` 由 `dmc` 按冻结拓扑切开（2 die × 96 HA × 2 pipe）。

`4096` 与 `18432` 的商是 `4.5`，故陪集不是 N 的整齐剖分；取模后任一固定 `c` 仍给出 **4096 个互异** `flat`（连续 4096 点模 18432 互异）。快照占用 → K，不是 9。禁止宣称占用 >K。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| `d` 接线 | 0 bit 存储 | 组合，无时钟口 | `addr[32:21]` → 12b |
| XOR fold 矩阵 P | 144 bit 硬线（12×12，可熔丝；复位 0） | 0R 存储 / 组合 1 次 | 每输出至多 12 输入 XOR |
| 9-way 编码 | 16×4 ROM = 64 bit 或等价组合 | 1R 组合 | in 4b / out 4b（值域 0..8） |
| `flat` 拼装 | 0 | 组合 | `c` 4b、`v` 12b、`flat` 15b（0..18431） |
| 拓扑切开 | 0 | 组合 | `dmc` 9b（0..383）、`bank` 6b（0..47） |

无 SRAM。无 CSR。无写口。地址译码路径每请求 1 次组合读。

### 数据路径与状态机

无状态机。每拍路径：

1. `G = addr[32:9]`（24b）。
2. `d = addr[32:21]`；`v = d ⊕ (P·addr[20:9])`（12b XOR 树，深度 4 级 2 输入 XOR）。
3. `c = ENC9(addr[16:13])`（并行于步骤 2）。
4. `flat = (c<<12) + v`；因 `c≤8`，`c<<12 ≤ 32768`，再 `flat = flat0 - 18432` if `flat0≥18432`（单次减法，不用通用除法）。
5. `bank = flat - 48·q`，`q = flat / 48` 用 `×(1/48)` 定点倒数：`q = (flat × 5461) >> 18`（`5461/2^18 ≈ 1/48.00007`），再校正 0 或 1；`dmc=q`（`flat<18432` 故 `q<384`）。
6. 冻结拓扑：`die = dmc[8]` 的函数（`dmc / 192`）、`ha_in_die = (dmc/2) % 96`、`pipe = dmc % 2`。

时序：XOR 树 + 常数取模，目标 1 周期寄存输出；组合深度不够则在 `flat` 后插一级流水，映射对单请求无反馈。

## 3. 为什么有效

占用代数：步长 `S=2^m` 的 AP 是 `addr = base + k·2^m`，`k=0..K-1`，`K=2^{33-m}`。区分位 `[m,33)` 对 `k` 是恒等（或满秩仿射）。`m=21` 时 `d` 跑遍 `{0,1}^12`，`v` 满秩则 `v` 亦跑遍 4096 值；`c` 冻结，故 `{flat}` 基数 = 4096 = K。不能更大：`|{f(base+kS)}| ≤ K`。

对比仿射：`(G mod 18432)` 在 `S_g=2^12` 上 `gcd=2^11`，基数 ≤ 9。本图把 12 个区分位全部留下，不再与 `N` 的 2 幂因子做一次全局 `mod`。

Little：机内 outstanding `≤ 120×128=15360`。若有效 bank=9，且单 bank 饱和发行率 `μ_b`，则吞吐 `≤ 9μ_b`；有效 bank=K=4096 时上界 `4096μ_b`（再被 384 DMC / pipe roofline 截断）。Amdahl：若 collapse 是唯一瓶颈，相对 `(G mod N)` 的加速上界约 `4096/9≈455`；实际还受 DMC/HA 与 `t_RC` 限制，见 §4 区间。本卡不追求 bank 占用 >K/N。

## 4. 评估计划

### 基线

1. 恒等切开：`flat = G mod 18432`。
2. 仿射 `(G mod N)` 的结构化译码（与 1 同类，记录 gcd 表）。
3. 低位抽取：只用 `addr[20:9]` 做索引（区分位丢弃，应塌到 1 或数个 bank）。

### 必须 cycle 级建模的结构

- 12b XOR fold（含可选矩阵 P，复位 0）。
- 4b→9-way 编码器。
- `c·4096+v` 的 18432 校正减法。
- `/48` 定点译码到 `(dmc,bank)`。
- 冻结拓扑切开到 `(die,HA,pipe)`。
- 每核 128 独立 outstanding 的发行/完成；每 DMC 1 pipe 发行口。
- **不要** 建 18432 项 SRAM remap；本卡无此物。

### 指标与负载

负载：8GiB 整机共享作业；stride `S∈{512B,512KiB,1MiB,2MiB}`；随机 `base` ≥ 32 个；每核 128 outstanding。指标：bank/DMC/HA/die 占用（一次快照）；相对满映射 roofline 的 min/mean BW。`S∈{512KiB,1MiB,2MiB}` 上占用必须 ≈K（16384/8192/4096）而不是 ≈18/9/9。禁止报占用 >K。partial-good 冒烟：随机退役 12.5% 时本卡本身不管 live-set，只确认索引仍在 48 槽内，不跨 DMC。

### 预期收益区间与置信度

`S=2MiB`：bank 占用从 9 拉到约 `0.95K～K`（XOR 不满秩或 `/48` 校正误差会掉几个点）。DMC 占用预期远好于 9/384，但不保证 384/384（那是 M-3 的目标）。min/mean BW 相对仿射基线预期 `×8～×40`（DMC 界，不是 `×455`）。置信度中：组合满秩可证，BW 取决于 bank/DMC 谁先饱和。不宣称 T0 通过。

## 5. 硬件开销估算

面积：约 12 个 12 输入 XOR 树 + 64b ROM + 15b 加法/减法，估计 `<0.5kGE`，0 SRAM。功耗：译码每请求 `<0.05pJ/bit×36b` 量级，静态可忽略。延迟：XOR 树 ~4 门 + 一次比较减法，组合 `≤1` 周期（1GHz 级需寄一层则 +1 cycle，无倒带）。
