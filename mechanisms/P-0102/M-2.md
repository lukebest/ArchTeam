# M-2: 高低位折叠 XOR

- problem: P-0102
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

顺序流（`S=512B`）的熵在低地址位；大步长（`S=2MiB`）的熵在 `[21,33)`。静态低窗服务不了后者，静态高窗伤害前者。P-0102 的窗口饥饿是「只接一侧」。

经典折叠：每个 bank/DMC 索引位至少 XOR **一位** `[9,21)` **和一位** `[21,33)`。顺序时低位变、高位慢变；大步长时高位变、低位冻结。两侧都有熵。同一张硬线图服务两种交通，这是本卡要点。禁止 `core_id`。0 SRAM。

## 2. 机制

### 结构

14 个 XOR 门（对应 ~14.17 bit 的 N 索引），每个 2 或 3 个源，全部来自 `addr[32:9]`。

硬线配对（v1 默认，可熔丝改源）：

| 输出位 | 源（至少一低一高） |
|--------|-------------------|
| `idx[0]` | `addr[9] ⊕ addr[21]` |
| `idx[1]` | `addr[10] ⊕ addr[22]` |
| `idx[2]` | `addr[11] ⊕ addr[23]` |
| `idx[3]` | `addr[12] ⊕ addr[24]` |
| `idx[4]` | `addr[13] ⊕ addr[25]` |
| `idx[5]` | `addr[14] ⊕ addr[26]` |
| `idx[6]` | `addr[15] ⊕ addr[27]` |
| `idx[7]` | `addr[16] ⊕ addr[28]` |
| `idx[8]` | `addr[17] ⊕ addr[29]` |
| `idx[9]` | `addr[18] ⊕ addr[30]` |
| `idx[10]` | `addr[19] ⊕ addr[31]` |
| `idx[11]` | `addr[20] ⊕ addr[32]` |
| `idx[12]` | `addr[9] ⊕ addr[15] ⊕ addr[27]` |
| `idx[13]` | `addr[12] ⊕ addr[21] ⊕ addr[32]` |

`[9,21)` 12b 与 `[21,33)` 12b 正好一对到底；`idx[12:13]` 做 3 输入扰码，避免 `flat` 只覆盖 4096。

拼装：`u=idx[10:0]`，`c=(idx[13:11]+idx[0])%9`，`flat=c·2048+u`，再 `/48` 得 `(dmc,bank)`。

可配变体：每源用 5b 选择（14×(5+5)=140b 配置，2 源可编程）；v1 评估先用上表硬线。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| XOR 门 | 12×XOR2 + 2×XOR3 = 0 存储 | 组合 | in 来自 `addr[32:9]` 24 线 / out 14b |
| 可选源配置 | 14×10b = 140b | boot 1W | 每输出两个 5b 选择（24 合法） |
| 拼装 | 0 | 组合 | 15b flat |

0 SRAM。无运行时写口。

### 数据路径与状态机

无 FSM。每请求：14 路 XOR → 9-way 拼装 → 拓扑切开。组合深度 2 级 XOR + `%9` 减法。可选寄 1 拍。同一张图跑 `S=512B` 与 `S=2MiB`，中间不重配。

## 3. 为什么有效

记 `idx_i = ℓ_i ⊕ h_i`（忽略第三源）。

- `S=512B`：`ℓ` 随 G 全变，`h` 缓变 ⇒ `idx` 满秩接近 14，占用接近 N（此时 K>N，上界 N）。
- `S=2MiB`：`ℓ` 冻结，`h` 跑遍 12b ⇒ `idx[11:0]` 满变，占用 4096=K，不是 1 桶。I≠0。
- `S=1MiB`：自由位 `[20,33)` 含 `addr[20]`（低窗最上）+ 全部高窗，占用 ≤8192=K。

对比只吃 `[9,24]`：`S=2MiB` 只剩 `addr[23:21]` 3b → ≤8 桶，HA/DMC 集中，min/mean BW≪0.85。

Little：两端交通共享同一 `μ` 上界——大步长按 K 个 bank / 最多 384 DMC；顺序按满 N。Amdahl 可加速段是「大步长信息量为 0」那一项，折叠把它从 0 拉到 12 bit。

## 4. 评估计划

### 基线

只接低窗 `[9,21)` 的 12 XOR（无高位）；只接高窗；I-Poly `[9,29)`；OriginalMapper `[9,24]`。

### 必须 cycle 级建模的结构

- 14 个 XOR（2–3 源），硬线表按上表。
- 9-way 拼装与 `/48`。
- **同一 map** 上先后打 `S=512B` 与 `S=2MiB`（本卡论点）。
- HA/DMC/bank 占用。

### 指标与负载

顺序 `S=512B` 与 `S=2MiB` 必须走同一配置。两者占用都应靠近各自上界（N 或 K）。min/mean BW vs 0.85。禁止为了 2MiB 而重配后再测顺序。

### 预期收益区间与置信度

`S=512B`：占用 `0.9N～N`，BW ≈ 满映射。`S=2MiB`：占用 `0.9K～K`，DMC 占用 `0.5～1.0`，min/mean 回到 0.85 讨论区（仍受 K/N）。置信度中高（接线可证满秩）。不宣称 T0 通过。

## 5. 硬件开销估算

面积：16 个 XOR2 当量 `<50GE`；可配 140b 则 `~1kGE`。0 SRAM。功耗：可忽略。延迟：2 级 XOR，组合纳入 1 cycle。
