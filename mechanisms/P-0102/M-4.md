# M-4: 启动可配 bit-mux 抽取

- problem: P-0102
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

拓扑与 partial-good 在 boot/测试时已知；硬接线窗才是缺陷。OriginalMapper 把 die/HA/bank 钉在 `[9,24]`，BIOS 无法把 `[29,33)` 纳进索引。这不是新算法族，就是保守的「BIOS DRAM map」：若干独立 mux，固件在发现拓扑后编程。

禁止 `core_id` 进 map。固件按 stride 类别与活 bank 几何选源，但不在 mux 里编 core。占用 ≤K。

## 2. 机制

### 结构

14 个独立 5-bit mux，每个从 `addr[32:9]` 的 24 个候选里选 1 根（5b 选择子覆盖 32，合法 0..23，24..31 映射到 0 以免 X）。

- `SEL[i] ∈ {0..23}`，`idx[i] = addr[9+SEL[i]]`，`i=0..13`。
- 固件在拓扑发现后写 14×5b。推荐两套对照程序：
  - **高位程序**（本卡主张）：`SEL = {12,13,...,23, 0,1}` 即优先 `addr[21:32]` 再补 `addr[9:10]`——覆盖 `[21,33)`。
  - **OriginalMapper-like**：`SEL` 落在 `[9,24]` 对应偏移 `{0..15}` 重复，不含 `[25,33)`。
- 拼装同前：`flat` from 14b idx → `(dmc,bank)`。
- partial-good：固件若已知某 DMC 退役 bank，不把 mux 改成跨 DMC 借 bank；只保证选出的位仍译到本机拓扑。活集压缩是 P-0106 的事。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| SEL CSR | 14×5 = 70 bit | boot 1W / 译码 1R（或 flop 常开） | 5b ×14 |
| mux 阵列 | 14×24:1（或 14×32:1） | 组合 | in 24b 广播 / out 14b |
| 拼装 | 0 | 组合 | 15b flat |

1R CSR 指译码每拍读 SEL（实际是固定 flop 输出进 mux）。无 SRAM 表。

### 数据路径与状态机

无 FSM。`idx[i]=MUX32(addr[32:9], SEL[i])` ×14 并行，深度 ~5 级 2:1。可选输出寄存 1 cycle。SEL 仅 boot/作业开始写；飞行中视为常数。

## 3. 为什么有效

可编程抽取把「支撑 ⊂ [0,L)」从硬件常数变成固件选择。当 SEL 包含 `[21,33)` 的全部 12 线，`S=2MiB` 上 I=12 bit，占用可达 K。当 SEL 模仿 OriginalMapper 停在 `[9,24]`，`S=2MiB` 只剩 3 自由位，占用 ≤8，HA/DMC 集中——这正是本题症状的可复现对照。

相对 M-1 滑动窗：本卡不必滑 20b 连续窗，可以稀疏抽取（例如只要 `[21,33)` + 2 个低位），对 sequential 与 large-stride 的折中由 BIOS 表决定。

Little/roofline：高位程序下大步长按 K；低位程序下按 8 或更少，BW≪0.85。公式：`I=|{i: SEL[i]+9 ≥ m}|`，占用 ≤ `2^I`，再 ≤K。

## 4. 评估计划

### 基线

同一 mux 硬件，两套 SEL：含 `[21,33)` vs `[9,24]` OriginalMapper-like；另加硬线 I-Poly `[9,29)`。

### 必须 cycle 级建模的结构

- 14×32:1 mux 与 70b SEL。
- 非法 SEL≥24 的折回。
- 拼装与占用。
- boot 写 SEL 的一次性加载。

### 指标与负载

S 扫描 `{512B,4K,512KiB,1MiB,2MiB}`。min/mean BW；HA/DMC 占用。高位程序在 `S≥1MiB` 应远离「1 个 HA」塌缩；低位程序应复现 ≪0.85。不要报占用 >K。

### 预期收益区间与置信度

高位程序、`S=2MiB`：占用 ≈K，BW 回 0.85 讨论区。低位程序：占用 ≤8，BW ≪0.85。置信度高（就是选哪些线）。不宣称 T0 通过。

## 5. 硬件开销估算

面积：14×32:1 mux ≈ 14×31×2.5GE ≈ `1.1kGE`；70b CSR `<0.5kGE`。0 SRAM。功耗：`<0.1mW`。延迟：组合 ~5 mux 级 + 可选 1 cycle 寄存。
