# M-2: 同 DMC 奇数步长 / 第 k 活位压缩

- problem: P-0106
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

压缩需要「第 k 个活 bit」。朴素「死了就 +odd 再探」在译码路径上最多 48 次迭代，**不合法**。`α` 只奇数也不够：`48=16×3`，奇数与 16 互素、仍可能与 3 不互素，3-adic 碰撞集不消。

本卡的数学：仿射哈希后对 **`n_live` 取余**（`α` 与 `n_live` 互素，`n_live` 变则重编程），再用 **1 cycle 并行前缀「找第 k 个活 bit」** 译成物理 bank。这是无 SRAM 列表的组合译码。可逆性来自「`Z_{n_live}` → 活集合」的双射，而不是「从 hash(G) 沿 +α 走到第一个活槽」（后者多对一，不可逆）。禁止跨 DMC。禁止 48-iter 探针上译码路径。

## 2. 机制

### 结构

每 DMC：

- 48b live mask `M`（与 M-1 同形，但是本卡的「列表」是组合 kth-one，不是 48×6b SRAM）。
- `n_live` 6b CSR（repair 时 `popcount(M)` 写回）。
- `α` 6b CSR：`gcd(α, n_live)=1`。推荐：`n_live` 变后固件选最小正 `α∈{1,5,7,11,13,17,19,23,25,31,35,37,41,43,47}` 中与 `n_live` 互素者（既奇且非 3 的倍数，尽量避开 3-adic）。
- `β` 6b 可选偏置，默认 0。
- 组合：`g = XOR_fold6(G)`（6b），`slot = (α·g + β) mod n_live`，`bank = kth_one(M, slot)`。

`kth_one`：48b 并行前缀 popcount 比较，1 cycle，无 SRAM list。这与 M-3 的差别：M-3 用显式 LUT 存「slot→物理 bank」；本卡即时从 mask 算。

关于「probe-until-live」：仅当把活 bank 看成某置换的前 `n_live` 个槽时，它才是 `mod n_live` 再译码的实现。本卡 **不** 在硬件上做迭代探针；迭代只允许出现在离线验证脚本里对照 kth-one。

### 容量 / 端口 / 位宽

| 结构 | 容量 | 端口 | 位宽 |
|------|------|------|------|
| mask | 384×48b = 2.25KB | 1R 译码 / 1W repair | 48b |
| n_live, α, β | 384×(6+6+6)=6912b≈864B CSR | repair 1W / 译码 1R | 各 6b |
| 6b×6b 乘 | 组合 | 每请求 1 次 | 积 12b |
| `mod n_live` | 12b ÷ 6b 余数，1 cycle | — | 商不用 |
| kth-one 前缀树 | 共享 1 份组合 | 1 次 / 请求 | 48b→6b |

无 48×6b 列表 SRAM。无 48-iter。

### 数据路径与状态机

无运行时 FSM。每请求：

1. 上游固定 DMC（不得因 dead 改 DMC）。
2. 1R：`(M, n, α, β)`。
3. `g = ⊕` 折 `G[23:0]` 到 6b（6 个 4 输入 XOR）。
4. `prod = α·g + β`（12b）。
5. `slot = prod mod n`（比较减法或小数倒数，1 cycle；`n≤48`）。
6. `bank = kth_one(M, slot)`（1 cycle，可与上一级流水叠成 2 cycle 译码）。

**逆（活集）**：`slot = popcount(M[bank-1:0])`；`g = α^{-1}·(slot − β) mod n_live`。仿真必须实现 encode：给活 bank 找回规范 `g`（再嵌入 G 的折）。`gcd(α,n)=1` 保证 `α^{-1}` 存在。

`n_live`/`α` 只在 repair+fence 后写。

## 3. 为什么有效

`ψ(slot)=kth_one(M,slot)` 是 `Z_n → L` 双射。`slot=(αg+β) mod n` 在 `gcd(α,n)=1` 时是 `Z_n` 上双射，故复合双射。死命中 0。

3-adic：若仍对 48 取余，`gcd(S_g, 48)=16`（`S_g=2^{≥4}`），每 DMC 占用 ≤3。改成 `mod n_live` 后，`gcd(α S_g, n)=gcd(S_g, n)`（α 与 n 互素）。例如 `n=40=8×5`（丢掉因子 3），`gcd(2^k,40)=8`（k≥3），占用 ≤5，好于卡在 48 的 3 槽。`n=36=4×9`，`gcd(2^k,36)=4`，占用 ≤9。这是约束里「丢掉奇数因子会改 gcd」的正面用法：参数跟着 `n_live` 走，而不是沿用满好 48。

Little：`λ_d ≤ n·μ_b`。stacking 无此界的均匀性。Amdahl：退役 25% 且均匀，DMC 界应用几乎不掉；3-adic 步长上，重绑 `α`+`mod n` 避免每 DMC 只剩 3 个活碰撞类。

## 4. 评估计划

### 基线

M-1 的 `r0 % n` 但 `α=1` 固定；48-iter 探针（只作功能对照，不得当合格硬件）；无 live-set mapper。

### 必须 cycle 级建模的结构

- mask + (α,β,n) CSR。
- 6b×6b 乘与 `mod n`（1 cycle）。
- 并行 kth-one（禁止建模成 48 拍循环）。
- 逆映射检查器（decode 再 encode）。
- 3-adic / 奇数因子 stride（`S` 使 `S_g` 与 3 有关的图案，以及纯 2 幂）。

### 指标与负载

可逆性；死命中=0；三档退役 BW；3-adic 交互：对比 `mod 48`+跳死槽 vs 本卡 `mod n`。占用按活集算。min/mean vs 0.85。

### 预期收益区间与置信度

死命中 0、可逆：高置信。2 幂大步长 + `n` 丢掉 3：每 DMC 占用类从 3 升到 `n/gcd(2^k,n)`（常见 5～9），BW 相对「仍 mod 48」预期 `×1.5～×3`。均匀 25%：与 M-1 接近。置信度中。不宣称 T0 通过。

## 5. 硬件开销估算

面积：2.25KB mask + 864B CSR；乘加与 `mod n` ≈ `0.3kGE`；共享 kth-one 树 `~0.5kGE`。相对 M-3 的 13.5KB LUT，省去列表 SRAM。功耗：1R 48b+18b + 6b 乘，`0.3mW` 量级。延迟：2 cycle 译码（乘余 1 + kth 1）。
