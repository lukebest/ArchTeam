# M-8: Dat 拍级子环着色

- problem: P-0221
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

每个物理环上 Dat 已有 **2** 个独立 `TNetwork`，Snp **1** 个（`TRing.cpp:48-54`）。两套槽互不占用。默认环间路由钉 `defaultSubChannel=0`（`TMultiRing.h:77`），8-beat txn（512 B / 64 B，`TrafficGen.h:51-54`）常在 **同一** Dat 子环上打出连续列车，把该子环下游环段填满；另一子环同位置可能空着。逐节点 outstanding 跨子环合计。`dualRingRR` 是 1×2 等长路径 RR（`TBridge.cpp:253-258`），L1 swap 改方向/水位（`TNetworkInterfaceBase.cpp:664-718`），都不是「同一 txn 的拍在两个已有 Dat 子环上交错」。

三项先例也不做这件事：srcfc 限源速率；i-tag / leaf-tag 在 **一个** highway 上预留槽。本卡作用点是 **已有 Dat 子环的拍级着色**，不加第三环，不加 flit 位，不借 Snp，不用 DataID（2 b 只表示 line 内偏移，IHI 0050E.b §13.10.50）。

## 2. 机制

### 结构

只在 Dat 设备 NI 与 RBRG **入本环** 口。Req/Rsp/Snp 不改。

1. 子环下标 `k = (cs_id + beat_idx) mod 2`。`cs_id` 是本环注入 CS（已有配置），`beat_idx` 是该 txn 已成功注入的拍数（用既有 beat 计数，不进 flit）。
2. 该拍只允许写入 Dat `TNetwork[k]` 的空槽；另一子环本拍不因本卡被占用。
3. 槽满则该拍等待既有 head/share（AIC Dat share 11，`gen_config.py:138-141`），**不**改投另一子环（避免所有源涌向瞬时空环）。下一拍 `beat_idx` 不变，仍要上同一 `k`。
4. 跨环：不改 `defaultSubChannel=0` 的路由表。进入目的环时用 **目的环着陆 CS** 重算 `k=(cs_land + beat_idx) mod 2`。
5. 方向不改。无密度阈值、无停注配额、无令牌。

不在 `NetworkFlit` 上增加 `k`：子环是对象树下标，不是通道字段（`README.ch.md:169`）。

### 数据路径与状态机

每 Dat txn 一个 `beat_idx` 计数（已有 outstanding/beat 状态 +1，或 NI 侧 4-bit，8 beat 足够）。每拍：

1. `k = (cs_id + beat_idx) mod 2`。
2. 只试 `TNetwork[k]` 的 `tryLocalToWay`。
3. 成功则 `beat_idx++`。

过路各子环独立。Snp +0。

## 3. 第一性原理与逐环段密度上界

环段必须写成 `(物理环, Dat 子环 k, CS s, 方向 d)`。

**单源：** 一笔 B 拍的 txn 在子环 0 上至多 `⌈B/2⌉` 拍、子环 1 上至多 `⌊B/2⌋` 拍，且时间上交错。故该源对任一子环段的贡献满足长时间 `λ^{(k)} ≤ 1/2`（有空槽时），且 **不会在单一子环上打出 B 长列车**。512 B → B=8 → 每子环最多 4 拍，中间隔着另一子环上的拍。

**邻 CS：** `cs_id` 进入哈希，相邻 CS 在 beat 0 上偏向不同子环，减轻「所有上游第一拍同时打 Dat0」。

**下游不饿死（相对单源列车）：** 下游在子环 `k` 上看到该源的占用被每隔一拍打断；另一子环上该源此拍不在。下游可在互补子环注入（同物理环两 `TNetwork` 拓扑相同，见 §8）。这不是配额：源并不在 `ρ≥ρ*` 时停注，只是 **把已有的 2 槽/周期 Dat 容量用起来**。

**多源对齐：** 若许多源 `cs_id+beat` 同相，仍可把一个子环打满。本卡不声称多源聚合上界 <1。证伪项就是「着色后最差节点等待梯度仍在」。

**延迟：** 拍在子环间交错不增加 hop；一圈仍是 42/72–76/132/148/152。不走反向环。

不丢拍：等本 `k` 的空槽，头留既有缓冲。

## 4. 推理收益与失效条件

推理（主）：KV Dat 8-beat 列车是下游饿死的常见形态。拆到两个子环后，单子环段上的连续占用减半，下游在互补子环上得到空槽，`T_step` 尾下降。主指标不是「Dat1 利用率」。

失效：跨环流量在目的环未着色（实现漏 RBRG 口）；两子环都被过路打满；herding 被「不准改投」挡住后变成傻等——若 `T_step` 变差则失败。

训练大块（一句）：拍数大，着色把块拆到两环，块内完成时间允许变长，不作过线。

## 5. Cycle 级评估计划

### 基线

**B\***：`experiment_srcfc` + i-tag + 动态 leaf-tag。另对照只开 `--sub-rr` 或只开 L1 swap，不得并入本卡。

### 仿真器改动（新分支）

1. `TNetworkInterfaceBase.cpp` 选择子环；`TNetworkInterfaceRbrg.cpp` 入目的环同样着色。
2. **禁止** 把 `k` 写入 DataID / RSVDC / 任何 flit 位。
3. `--cc-scheme dat-color`。`infer-decode` + **按子环** 的逐环段占用。

### 必须 cycle 级建模

- `beat_idx`、`k=(cs+beat) mod 2`、双 `TNetwork` 各 1 槽。
- `L_link` 与 `C_ring`。不要密度门、不要令牌。

### 消融与证伪

- C0：B\*。
- C1：设备 NI 着色。
- C2：设备 + RBRG（HARD）。
- C3：强制永远 Dat0（负对照）。
- C4：每拍改投较空子环（herding 臂，预期差）。

C2 须 `T_step` 优于 C0。只见 Dat1 利用率而 `T_mix≈1` → 失败。Snp 超阈 → KILL。

## 6. 面积 / 功耗 / 延迟估算

每 Dat NI 4-bit `beat_idx` + 1-bit `k` 组合，`<0.2 kGE`×口数，`<3 kGE`，0 SRAM，0 新 flit 位。选择同拍。过路 +0。

## 7. 与已有功能 / 先例的区别

- **不是** `dualRingRR` / `--sub-rr` / L1 swap。
- **不是** srcfc / i-tag / leaf-tag / 多播 / Uturn。
- **不是** 令牌/信用/ECN/RPR/GSF：无停注阈值。
- **不是** 借 Snp、不是 DataID 选环。
- **不加线。**
