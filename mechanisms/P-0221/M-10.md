# M-10: 源 CS 奇偶绑定 Dat 子环

- problem: P-0221
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

Dat 每物理环 2 个 `TNetwork`（`TRing.cpp:48-54`）。上游 **多个源** 若都从默认 sub 0 注入，它们的路径在下游某段对齐，段占用是合计，不是逐源。M-8 把 **同一源的拍** 拆到两子环，管的是单源列车；本卡管的是 **不同源之间的空间对齐**：相邻 CS 的整笔 txn 绑到相反 Dat 子环，使「上游合计」在两个段副本上错开。

三项先例是逐口速率/预留，不按源 CS 给子环着色。`dualRingRR` 要求等长双路径。本卡不改方向、不加线、不用 DataID、不借 Snp。

## 2. 机制

### 结构

只在 Dat。Snp 1 环不动。

1. 源 CS 号 `s`（本环注入 CS）为偶数：该源本环所有 Dat txn 整笔绑定 `k=0`；奇数绑定 `k=1`。RBRG **入目的环** 时用着陆 CS 的奇偶再绑一次（源环与目的环各自独立）。
2. 整笔（所有 beat）保持同一 `k`，避免拍级来回。
3. 所选子环槽满：等既有 head/share，**不**改投另一子环（与 M-8 相同，防 herding）。
4. 无密度门、无令牌、无 flit 位。`k` 只是对象树下标。

可用 CSR `FLIP` 把奇偶对调，消融用。复位 `FLIP=0`。

### 数据路径与状态机

无 FSM。注入口组合：`k = (s & 1) ^ FLIP`。过路不动。

## 3. 第一性原理与逐环段密度上界

把上游可覆盖段 `s` 的源集 `U` 按 CS 奇偶分成 `U_even`、`U_odd`。

**子环 0 段 `s`：** 只有 `U_even`（再加过路、RBRG 按着陆奇偶）能注入。故

\[
ρ_s^{(0)} \le 1,\quad
λ^{(0)}_{\mathrm{new}} \le |U_{\mathrm{even}}|\text{ 的空槽竞争},
\]

但相对基线「`U_even ∪ U_odd` 全打 Dat0」，新注入源数大约减半（拓扑上奇偶 CS 交错，`gen_config.py` 设备挂在相邻 CS 的奇偶分环习惯：top AIC 偶/奇分到 ring0/ring1，这里是 **同一物理环的 Dat 子环**，不是那条 HRing 分法）。

在设备沿环交替挂载时，`|U_even|≈|U_odd|≈|U|/2`。若各源提供负载对称，则每个 Dat 子环段上的 **新注入源集合** 约为基线的一半，单子环段密度上界从「全 `U` 可叠加到 1」降为「约 `U/2` 可叠加到 1」。这仍允许 `ρ=1`，但 **对齐的上游个数减半**，连续列车期望长度按独立叠加近似减半。

**下游不饿死：** 下游在子环 `k` 上面对的上游注入源是半集。互补子环上，另一半源不出现。下游自己的绑定由 **自己的 CS 奇偶** 决定：它可以在自己的 `k` 上注入；该 `k` 上少了一半上游。空槽期望提高的条件是：过路不是已经被另一半源 + 跨环着陆打满。不保证 `ρ<1`，保证的是「可叠加上游集合减半」。

**一圈 / 反向：** 绑定是静态组合，无闭环反馈，无反向信令。一圈 42/72–76/132/148/152 只出现在「过路绕环」的对照里，不进本卡控制环。

不丢：等本 `k` 空槽。

## 4. 推理收益与失效条件

推理（主）：多 AIC 同时读 HA，源在环上相邻，基线全挤 Dat0 下游段。奇偶错开后，最慢下游 rank 在自己的子环上少一半上游列车，`T_step` 应降。若设备挂载不是奇偶交错（整段都是偶 CS 源），减半不成立，必须报失效。

训练大块（一句）：大块源少、对齐弱，预期中性。

## 5. Cycle 级评估计划

### 基线

**B\***：`experiment_srcfc` + i-tag（`:1095-1110,:1151-1158,:894-950`）+ 动态 leaf-tag。对照 `--sub-rr` / L1 swap / M-8 拍级着色（若评估树有），不得混称。

### 仿真器改动（新分支）

1. Dat NI / RBRG 入环：`k=(cs_id&1)^FLIP`。禁止写进 flit。
2. `--cc-scheme src-parity`。
3. `infer-decode` + 按子环逐环段占用 + 按源 CS 奇偶分列的注入成功/等待。

### 必须 cycle 级建模

- 静态 `k`、双 `TNetwork`、满则等。
- **不要** 令牌、密度门、flit 位、反向线。

### 消融与证伪

- P0：B\*。
- P1：设备口奇偶绑定。
- P2：设备 + RBRG 着陆（HARD）。
- P3：`FLIP=1`。
- P4：强制全 Dat0。

P2 须 `T_step` 优于 P0。源挂载奇偶极不均时 P2≈P0 → 记失效，禁写因果。`T_mix≈1` 或 `r≈1` → 失败。Snp 超阈 → KILL。

## 6. 面积 / 功耗 / 延迟估算

1-bit 组合 XOR，`<50 GE`×口，0 SRAM，0 新 flit 位。+0 拍。过路 +0。
