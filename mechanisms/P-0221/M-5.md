# M-5 路径配额再平衡（Path-Mask Quota Rebalance, PMQR）

- problem: P-0221
- id: P-0221/M-5
- author: Jim Keller
- class: 共享配额分割（Σq_i[s]=B_s 恒成立；不是单桶、不是拉动、不是纯测量）

## 1. 根因

逐节点 cap 的数学就是 `Σ_i cap_i` 可以大于 1 个环段。题面已经宣判：节点都合规，段仍满。

前面四张分别是：共享速率桶、饥饿 skip、守恒账、测量门。都还把「谁可以多吃」留给先到先得。集合尾节点需要的不是平均公平，是 **把该段的配额从闲上游挪到饿下游**。

MetaRing SAT / i-tag 给的是活性，不是 `Σq=B_s`。TDM 给的是第 k 拍属于谁——T0 已杀。本卡给 **窗口内可注入拍数** 的分割，拍位不指定。

## 2. 机制

### 2.1 环段

同一几何。Dat×2 每条子环自己的 `B_s`；Snp×1 自己的 `B_s`。不借用。

### 2.2 结构

| 结构 | 容量 / 位宽 | 出处 / 假设 |
|------|-------------|-------------|
| 窗长 W | 默认 **16 拍（假设）** | 与再平衡周期相同 |
| 段预算 `B_s` | `⌊ρ_max·W⌋`；ρ_max=3/4 ⇒ **B_s=12（假设）** | 过路注入拍/窗 |
| `q_i[s]` | 每节点每段 4b（0–15） | **不变式 `Σ_i q_i[s] = B_s`** |
| `used_i[s]` | 4b，窗内已用 | `used==q` ⇒ 本窗不能再向 s 打过路 |
| 需求 `d_i[s]` | 4b | 本窗 fail-wait 且路径含 s 的次数，饱和 15 |
| REBAL flit | 同通道对向，每 W 拍一圈 | Dat：1 拍控制 Dat，Data 放向量；Snp：见下 |
| Dat 向量宽 | `C_ring × (4+4)` = 需求+配额 ≤64×8=**512 b** | 正好等于 Table 13-9 DW=512 @ `kBeatBytes=64`。BE 全 0 |
| Snp 向量 | SNP **无 Data**（Table 13-8） | Snp 环 **不走 512 b 向量**。Snp 用「段主持有 B_s，再平衡只传 64b 饥饿位图」：有 fail 的节点置 1b，段主按位置把 B_s 分给置位者（均分余数给更下游）。位图捎带 ESL 1b/节点或对向连续控制拍的 TxnID 打包 |
| 段主再平衡器 | 组合：max-min / starved-first | 默认 **下游优先**：`d_i>0` 的节点按环序从 s 的 **紧邻下游** 往上游分完 `B_s` |
| i-tag | 库内 | 配额用尽后 i-tag 也不得注入过路 |

**下游优先** 不是最短方向路由（不改 CW/CCW）。只改 **谁还有配额往这段打过路**。闲上游 `d=0` 分到 0，正好堵住「合计填满」。

**不是 TDM**：节点在窗内任意空拍注入，只要 `used_i[s] < q_i[s]`。没有「第 3 拍属于节点 7」。
**不是** 逐节点 cap：cap 是常数且 Σ 可爆；`q_i` 每窗变、Σ 锁死为 `B_s`。
**禁止** 借 Snp 运 Dat；Dat 的 REBAL 走 Dat 对向，Snp 的位图走 Snp 对向。

### 2.3 同拍规则

1. 窗边界（本地计数 `t mod W==0`）：段主根据上一窗 `d_i` 重算 `q_i[s]`，写入对向 REBAL / 位图。`Σ q = B_s` 由构造保证；探针 `sum_q_fail` 必须 ≡0。
2. 注入过路（路径含 s 且 hops≥2）：若对所有这种 s 有 `used_i[s] < q_i[s]` 且槽空 ⇒ 注入，`used++`。否则 fail-wait，`d_i[s]++`。
3. hop-1：不消耗 `q_i[s]`（不是过路）。
4. 过路仍赢。不丢在途。窗末 `used` 清零；未用完的 q **不结转**（结转会让 Σ 在下一窗爆炸）。
5. REBAL 丢失：看门狗沿用上一窗 q；连续丢 2 窗则退回均匀分割 `q_i = ⌊B_s/N⌋`（均匀分割 **不是** 逐节点独立 cap——Σ 仍 = B_s）。
6. 软件/harness **禁止** 按未来到达写 `d_i`。`d_i` 只来自本地 fail 计数。

### 2.4 环段密度上界

任意窗 W：

```
Σ_i used_i[s] ≤ Σ_i q_i[s] = B_s
ρ_transit(s, W) ≤ B_s / W ≤ ρ_max
```

**执行论证**：

1. 每次过路注入恰好使某个 i 的 `used_i[s]++`，并在随后恰好一拍占用 s（无缓冲，不丢）。
2. `used_i` 被门卡在 `q_i`。故合计过路注入 ≤ `B_s`。
3. 窗内过路占用拍数 ≤ 过路注入数（已在途的上一窗尾巴：窗对齐时最多 1 个在途 flit 仍在来的路上——`C_ring` 可能 >W）。

**尾巴修正（必须写）**：上一窗已注入、本窗才越过 s 的 flit ≤ `I_pipe`。`I_pipe ≤ min(B_s, C_ring)`。因此严格式是

```
ρ_transit(s, W) ≤ (B_s + I_pipe) / W
```

取 **W ≥ C_ring** 时 `I_pipe/W ≤ B_s/C_ring`。默认 W=16、top C=21，W<C，尾巴不可忽略。

**闭合选择（实现钉死，不是扫出来再讲）**：

- **主列**：`W = C_ring`（top 21，bottom 按该环 CS_NUM）。则 `B_s = ⌊ρ_max·C_ring⌋`，`I_pipe ≤ B_s`，`ρ ≤ 2ρ_max` 太松。
- **收紧**：越过时才记占用，注入时记 `used`。窗按 **越过时钟** 计 ρ，注入窗与越过窗错开最多 `C_ring`。主列改报 **越过窗** `ρ_pass(s, W=C_ring) ≤ B_s / C_ring ≤ ρ_max`——因为每窗最多 `B_s` 次注入，每次越过一次，任意一圈越过次数 ≤ `B_s`。

主列上界用 **越过 / 圆周**：

```
ρ_pass(s, C_ring) ≤ B_s / C_ring = ρ_max
```

`B_s = ⌊ρ_max·C_ring⌋`。W_rebalance 仍可 16 拍更新 q（配额更新快于圆周），但密度证辞锁在圆周越过。两套窗必须在表里分列：`W_q`（配额）与 `W_ρ=C_ring`（密度）。禁止合成一个数。

逐节点 cap 做不到这条：它没有 `Σ q = B_s`。

## 3. 为什么尾会动

饿下游的 `d_k[s_k]` 高。再平衡把 `B_{s_k}` 尽量分给 k（自身注入）和少分给上游过路。上游 `q` 被砍 ⇒ 空槽被让到 k ⇒ k 的 `used_k` 有额度可吃空槽。集合 last-completion 跟着 k 走。

这是唯一一张 **显式把段预算划给被饿节点** 的卡。M-1 共享桶仍是先到先得；M-2 要等 fail 再 skip；M-3 大家抢 I_max；M-4 一刀切停上游。PMQR 停的是闲上游，留的是饿下游。

相对基线（假设）：逐节点 cap 的 Σ 爆段；PMQR 的 Σ 锁死。i-tag 不分割 B_s。无 CC / 源端 FC 无段预算。

`pmqr-off` 必须让最差节点完成变差。只报基尼系数 / 配额更匀、尾不动 = 淘汰。

## 4. 失败模式

- REBAL 512 b Dat 税：每 `W_q` 一圈 1 槽。`W_q=16`、C=21 ⇒ 约 1/16 对向。双向 KV 单列。
- 下游优先饿死合法上游短流：扫「下游优先 vs max-min」。max-min 若尾不降，不得改口。
- `W_q` 与 `W_ρ` 混报：审计直接杀。
- 未用 q 结转：Σ 爆，退化成无上界。
- Snp 上偷用 Dat 宽向量：关闭路线，禁止。
- 神谕写 `d_i`：卡死。

## 6. 评估

推理 makespan / 最差节点。基线：无 CC、**逐节点 cap（点名对打）**、源端 FC、i-tag。消融 `pmqr-off`；再加 `uniform-q`（均匀分割、Σ 仍 =B_s）——若 uniform-q 已赢 cap 且下游优先无增量，新颖性降，须老实报。Snp 15:1 分列。

预期（UNSIGNED）：相对逐节点 cap **0.70–0.93×** 最差节点；相对无 CC **0.68–0.92×**；`uniform-q` 对照 **0.85–1.05×**（假设下游优先才吃到尾）。不是 claim。

## 7. 可证伪

1. **H-SUM**：所有段所有窗 `Σ q = B_s` 且 `quota_exceeded≡0`。
2. **H-RHO**：`ρ_pass(s, C_ring) ≤ B_s/C_ring`。
3. **H-CAP-GAP**：逐节点 cap 列存在段满；PMQR 列段不满且最差节点更快。
4. **H-TAIL**：off 尾 > on。
5. **H-NO-DROP / H-NO-ORACLE**：不丢包；`d_i` 仅本地 fail。
