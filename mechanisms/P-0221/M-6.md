# M-6: 注入成功让孔

- problem: P-0221
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

冻结信封：DV200，≤12 top + 2 bottom；CHI 四通道各自成环；环间经 RBRG。无缓冲双向环，每方向每拍 1 个 highway 槽（`m_sendFlit[dir]`，`src/TCsHighWay.cpp:83-84,182`）。过路优先；织物无 flit 队列（`README.ch.md:127`）。环段 = 每 CS 每方向输出槽 + 邻接 `m_highWayBuf`（`include/TCsHighWay.h:113,136`）。

一圈时间是 **链路延迟之和**，不是站数 21：top 21 CS × 链路 2 = **42** 拍（`docs/noc_simulator_faq.html:109`；`tests/soc_sim/gen_config.py:345`）；bottom HRing 24/25 CS × 链路 3 = **72 / 75**（凑偶可达 ~76）；bottom VRing 33/37/38 CS × 链路 4 = **132 / 148 / 152**（CS：`gen_config.py:17-19`；H=3/V=4：`gen_config.py:429-451`）。空槽走到下游 k 跳要 `k·L_link` 拍，不是 k 拍。

空间不公平的供给侧：上游看到空槽就注，把流向下游环段的空槽吃光。逐节点 outstanding（读 512 / 写 256）与库内三项先例——环内流控 `experiment_srcfc`、i-tag 预留槽、动态 leaf-tag——都 **不** 在注入成功之后强制留孔。i-tag 是饥饿侧预约（饿 `2·thr=128` 拍才打标，占位再走最多一圈 42/72–152 拍才回来，`TCsHighWay.cpp:1095-1110,1151-1158,894-950`）。本卡作用点相反：在 **注入成功** 这一拍给下游留一个孔，不打标、不加 flit 位、不走反向环。

## 2. 机制

### 结构

每个设备 NI 所在 CS、每个 `(channel, subchannel)`、每个方向一份 **本地 1-bit** `OWE`。Dat 2 子环各算各的；Snp 硬关（`ISHS_EN_SNP=0`）。不改 flit 格式。

1. `tryLocalToWay` 成功把本地头写入空的 `m_sendFlit[dir]` 后：`OWE[dir] ← 1`。
2. 此后本方向再看到空槽（`m_sendFlit==nullptr` 或 `valid==false` 且未被 i-tag / leaf-tag 预留）时：若 `OWE=1`，**本拍不注入**，空槽按基线 `xfer` 交给下游延迟线；`OWE ← 0`。
3. 过路 valid 仍绝对优先，不碰 `OWE`。
4. 与 i-tag / 动态 leaf-tag 的关系：若该空槽已被 `sender_tagged` 指向本 CS 或 `is_dyn_leaf_tagged` 留给本设备，**先履约预留、再清 OWE**（不偷别人的预留槽，也不用本卡破坏两项先例）。`OWE` 只挡住「无预留的普通空槽」。
5. 不经 `NetworkFlowCtrl`、不加令牌/窗口/ECN。不在 flit 上加 1 bit。反向环零占用。

### 数据路径与状态机

两状态（`OWE∈{0,1}`），无多拍流水。每拍每方向，嵌在既有 `arbitration()` 的 `tryLocalToWay` 之前（`TCsHighWay.cpp:217-264`）：

1. 过路填槽：结束。
2. 槽空且 `OWE=1` 且槽 **无** i-tag/leaf-tag 预留：跳过注入，`OWE=0`，`xfer` 送空。
3. 槽空且可注入：注入成功则 `OWE=1`。
4. 预留槽履约：按库内 `tryItagProcess`（`:894-950`）/ leaf-tag（`:745-805`）执行，然后 `OWE=0`。

时序：1-bit 寄存，同拍。1 槽/方向/周期不变。让出的孔到达下一 CS 的时间 = 该段 `inLatency`（top 2 / bottom H 3 / V 4），不是 1 拍。

## 3. 第一性原理与逐环段密度上界

记环段 `s` = CS `s` 方向 `d` 的 `m_sendFlit`。`O_s(t)∈{0,1}`。到达空槽率 `h_s`，过路占用率 `ρ_tr`，本地注入率 `λ`，则 `h_s = 1-ρ_tr`（空才轮到本地）。

**约束：** 每次本地注入消耗 1 个无预留空槽，并强制转发随后 1 个无预留空槽。故

\[
\lambda_s \le \tfrac12 h_s = \tfrac12(1-\rho_{\mathrm{tr},s}).
\]

**本段密度：** `ρ_s = ρ_tr + λ_s ≤ ρ_tr + (1-ρ_tr)/2 = (1+ρ_tr)/2 ≤ 1`。`ρ_tr=0` 时本段因本地注入 `ρ_s≤1/2`；`ρ_tr→1` 时本来就不能注，上界退化为 1（本卡不声称能拆过路列车）。

**下游环段 `s+1`：** 本卡转发的孔在 `L_link` 拍后出现在 `s+1`（top `L_link=2`，bottom H=3，V=4）。转发孔率 `≥ λ_s`（1:1 税）。若 `s` 是紧邻上游主注入源，则 `s+1` 的空槽到达率下界 `≥ (1-ρ_tr,s)/2`，注入不被饿死到 0。

**一跳之外：** 中间 CS 若也有就绪流量，会吃掉部分孔（指数衰减）。本卡 **不** 用反向信令、不加孔保护位（加位 = 加线）。因此 **保证的是紧邻下游环段**；更远下游的密度上界弱化为「每经过一个也在注入的 CS，残差孔率至多减半」。这不是回程扣减：本向空槽前送，反向环容量为 0 占用。

**与一圈时间：** 孔不绕回才生效；不把「一圈 21 站」写成延迟。若评估方要看绕回孔，绕回下界是 `C_ring∈{42,72–76,132,148,152}`，本卡不依赖绕回。

不丢 flit：被跳过的头留在既有 `inputHead`（深度 1）。

## 4. 推理收益与失效条件

推理（主）：decode 步 `T_step=max_i C_i`。下游 KV / P2P / 集合 rank 的注入等待进尾。紧邻上游每注一拍就放一孔，孔 `L_link` 拍后到下游，等待从「列车无限」变成「至多隔一拍有孔」。主指标是分流量类 makespan 与最差节点，不是注入率。

失效：饥饿点在注入集群 **下游多跳** 且中间站也抢孔（残差孔指数掉）；或环上长期无空槽（`ρ_tr=1`，无孔可让）；或全是 Snp（本卡关闭）。

训练大块集合（一句）：源自己连续就绪，让孔会拉长块传输，允许中性或变差，不作过线。

## 5. Cycle 级评估计划

### 基线（三项先例必须全开）

记 **B\***：

1. 环内流控 `--fc-profile experiment_srcfc`（rate 112 / credit 2 / window 16 / timeout 64 / spread 3；`--flow-control off` 时也会开实验 Req FC，`gen_config.py:225-233,486-487`）。
2. i-tag 预留槽：默认 policy 0、`itagThreshold=64`；打标 `:1095-1110`，预留判定 `:1151-1158`，空槽替换 `:894-950`。
3. 动态 leaf-tag：top Dat `dyn_leaf_tag_en true`，窗口 100，阈值 80/90/95，标签 1/2/3（`gen_config.py:359-362`；`TCsHighWay.cpp:745-805`）。

本卡开/关叠在 B\* 上。另报 B0=三项全关，**不得用 B0 冒充基线**。禁止把 i-tag 阈值 / srcfc rate / leaf-tag 阈值调参写成卡收益。

### 仿真器改动（独立分支，不改 RTL）

1. `src/TCsHighWay.cpp` / `include/TCsHighWay.h`：每方向 1-bit `OWE`，插入 `tryLocalToWay` 前。不改 `NetworkFlit`。
2. `--cc-scheme ishs`。不要塞进 `CongestionCtrl.h`（那是令牌/赤字，本卡禁止走配额类）。
3. 推理负载生成器 `infer-decode`（平台无现成推理负载，事实 5.16）：12+2；每步每 AIC 8 笔 KV 读 + 1 笔 128 B P2P + 1 次集合（扫 gather/reduce/allreduce/allgather/alltoall/broadcast，每 rank 512 B）；配比写死。
4. 新增逐环段占用时间序列（每 CS 每方向 `m_sendFlit`，按 `L_link` 对齐），以及沿环位置的注入等待 P50/P99/max。

### 必须 cycle 级建模

- 1-bit `OWE`、与 i-tag/leaf-tag 预留的优先级。
- `L_link` 延迟线（2/3/4），不要建成 1 拍/跳。
- **不要** 令牌桶、信用窗口、ECN、flit 侧带、反向脉冲。

### 扫参、消融、证伪

扫：Snp 保持关；`ISHS_EN` 按通道 Dat/Req。消融：

- H0：B\*，本卡 off。
- H1：B\* + Dat 让孔（HARD）。
- H2：B\* + Dat+Req。
- H3：让孔但抢 i-tag 预留（负对照，应禁止）。

H1 须诚实 cycle 下推理 `T_step` 优于 H0。H0 满占用且与 H1 不可分则禁写因果。证伪：`T_mix=T_step(H1)/T_step(H0)≈1` 或只抬注入率 `r≈1` → 失败。沿环等待梯度在 1 跳内无改善 → 失败。Snp 超阈 → KILL。不把 `1/2` 解析贴成测量。

## 6. 面积 / 功耗 / 延迟估算

每 CS 每 Dat 子环每方向 1 flop，合计 `<0.5 kGE`，0 SRAM，0 新 flit 位。功耗可忽略。决策 +0 拍；孔到下游 `L_link` 拍。过路 +0。

## 7. 与已有功能 / 先例的区别

- **不是** `experiment_srcfc` 令牌桶：不看 inject-fail，不反向传播，无 rate/credit/window。
- **不是** i-tag：触发是注入成功不是饥饿；不打 `sender_tagged`；延迟是下一空槽 + `L_link`，不是 128+`C_ring`。
- **不是** 动态 leaf-tag：不在指定 CS 停 invalid，不按 COC/SLLC 设备类。
- **不是** Dat 多播 / 发射顺序 / UturnConnect / e-tag。
- **不是** TDM / 最短路 / Age+Class / 偷气泡（空槽在 OWE=1 时 **不准** 注）。
- **不是** 令牌/信用/ECN/RPR/GSF 配额：无目标速率、无窗口积分。
- **不加线**：0 新 flit 位；不复用 RSVDC；不占用反向环。

## 9. 逐条自检

1. **不加线、不改 RTL**：0 新 flit 位；只加本地 1-bit；新分支改 `TCsHighWay`。结论：写入。
2. **逐环段上界**：`ρ_s≤(1+ρ_tr)/2`；紧邻下游孔率 `≥(1-ρ_tr)/2`，延迟 `L_link`。不是逐节点配额。结论：写入。
3. **不丢数据**：头留既有 head。结论：写入。
4. **推理 makespan/尾**：`T_mix≈1` 或 `r≈1` 失败。结论：写入。
5. **非功能等价**：§7；不借 Snp 运 Dat。结论：写入。
6. **CHI 位宽**：§8。结论：写入。
7. **消融 / 信封**：H1 须 cycle 优于 B\*；满占用不可分禁写因果。结论：写入。
8. **存储不是队列**：1-bit 标志。结论：写入。
9. **无完美预测**：不读下游未来。结论：写入。
10. **不把解析贴 cycle**：`1/2` 是上界。结论：写入。
11. **三项先例是基线**：B\* = srcfc + i-tag + 动态 leaf-tag；不是配额类新卡。结论：写入。
12. **加线**：无新 flit 位；未复用字段。结论：写入。
13. **一圈按链路和**：42 / 72–76 / 132/148/152；孔传播用 `L_link` 不是站数。结论：写入。
14. **反向环**：本卡不走反向信令，反向容量占用 = 0；不谈回程扣减。结论：写入。
