# M-2 下游空槽索取（Downstream Vacancy Claim, DVC）

- problem: P-0221
- id: P-0221/M-2
- author: Jim Keller
- class: 需求拉动（starved NIC 向上游索空槽，不是速率桶、不是快照门）

## 1. 根因

空槽顺时针走，上游先吃。下游 NIC 的 i-tag 只能在 **空槽已经到达本口** 之后抢仲裁；空槽到不了，tag 是 Recv 端的宗教。逐节点 cap 同样不向上游喊停。

P-0198/M-12 HSSL 推迟近源——近源就是被饿的下游，方向再错一次。CSR 用 GRANT 公民税换扇入，T3 `r≈1`。本卡不发 GRANT、不造日历、不回收在途数据。

根因：**下游饥饿是可观测事件，必须变成对「将占用本出边的上游注入」的显式跳空命令。** 没有索取，段密度没有执行者。

## 2. 机制

### 2.1 环段

与 M-1 同一几何：`(channel, sub-ring, direction, CS_i→CS_{i+1})`。Dat **2** 子环、Snp **1** 环（`TMultiRing.cpp:223-231`）。过路 = valid ∧ `dst ≠ next`。密度上界钉在 **被索取的那条出边** `s_claim = 索取者的出边`。

### 2.2 结构

| 结构 | 容量 / 位宽 | 出处 / 假设 |
|------|-------------|-------------|
| 失败计数 | 每 NIC 每向 8b | 本口连续 inject-fail；默认阈值 **K_fail=8（假设）**，对照 i-tag 默认 128 |
| CLAIM flit | 同通道 **对向** 1 槽 | opcode 自定义；**不是** 新导线 |
| 载荷 | `claimant` NodeID 7–11b + `seg` 6b（CS_NUM≤64）+ `Q` 4b + `wave` 4b | NodeID：CHI Issue E.b Table 13-8 注释 7–11b；段索引 6b 因 `CS_NUM≤64` |
| `Q` | 默认 **4（假设）** | 本窗口上游必须跳过的空槽数 |
| 每段 claim latch | 1 活 claim：`owner` + 剩余 `q_left` | **每段至多 1 个活索取**（避免多下游互抢命令） |
| skip 门 | 1b / NIC | 待注入路径含 `s_claim` ⇒ 下一空槽必须让过 |
| CLAIM_REL | 对向 1 槽 | `q_left=0` 或超时 `T_claim=2·C_ring` 后释放 |
| i-tag | 库内原样 | 索取让空槽到达后，i-tag 可在 **索取者** 口上抢；上游对 `s_claim` **禁止** 用 i-tag 违抗 skip |

CLAIM 走同通道对向：CW 数据的索取沿 CCW 传给上游。Dat 索取走 Dat 对向子环；Snp 索取走 Snp 对向。不跨通道。不借 Snp 运 Dat。

SNP flit 无 Data（Issue G §B13.9.3 / Table 13-8）。CLAIM 对 Snp 是 **本征 Snp 控制 flit**：只用 SrcID/TxnID/Opcode/FwdNID 编码 `claimant+seg+Q`（7–11+6+4 ≤ 12+5+11 量级，放得进 Table 13-8 字段，不需要 Data）。Dat 的 CLAIM 用 Dat 控制拍，Data 可空，BE=0（Table 13-9）。

### 2.3 同拍规则

1. 节点 k 在本向连续 fail ≥ `K_fail` 且本出边 `s_k` 无活 claim：对向注入 1 条 CLAIM（对向槽忙则等空，不抢过路）。
2. CLAIM 沿对向每到一个 CS：若该 CS 的 **正向** 待注入路径包含 `s_k`，置 `skip[s_k]=1`，`q_left` 以段上为准（段主 CS_k 持有权威 `q_left`）。
3. 上游节点见空槽且 `skip[s_k]∧路径含 s_k`：**不许注入**，空槽前进。这不是把 payload 改 empty——槽本来就是 empty。
4. 空槽到达 k 且 k 注入成功：段主 `q_left--`。到 0 发 CLAIM_REL，沿对向清 skip。
5. 超时 `T_claim`：强制 REL，回退无 CC。超时必须计数，禁止静默当「已索取」。
6. 过路 flit 仍赢。禁止为了给下游让路而丢/改在途 Dat。
7. 多下游同时饿：每段 1 活 claim。后来者排队（本地 1b `claim_pending`）。**不**在环上堆 claim 列车。

### 2.4 环段密度上界

活 claim 窗口内，段 `s_k` 上至少有 `Q` 个空槽被规定为「上游过路注入不可见」：

```
ρ_transit(s_k, W_claim) ≤ 1 − Q / W_claim
```

`W_claim` = claim 存活拍数（有界 ≤ `T_claim`）。默认假设 `Q=4`，若 `W_claim=16` ⇒ `ρ ≤ 0.75`。

**执行论证**：

1. skip 门在所有路径含 `s_k` 的上游注入口；过路已在途的 flit 继续走（已占用的拍不算「新过路注入」）。
2. 窗口内新过路注入次数 ≤ 总空槽到达上游次数 − Q（Q 个空槽被强制让到 k）。
3. 无缓冲下段占用 = 过路转发 ∨ 本地注入。被让过的空槽到达 k 后由 k 注入 ⇒ 这些拍是 **本地注入占用**，不是过路占用。故过路密度少 Q 拍。
4. 无 claim 时本卡 **不** 宣称上界——那是「未饥饿，问题没激活」。闭合靠：饥饿 ⇒ claim ⇒ 上界生效。探针 `claim_active ∧ ρ_transit > 1-Q/W` 必须 ≡0。
5. 与逐节点 cap 的差：cap 永远按节点分；DVC 只在段被饿时把 **该段** 的空槽配额临时划给索取者，上游合计被砍的是 Q，不是「每节点 1/N」。

无 claim 的稳态若仍 `ρ=1` 且无人 fail——则没有下游饿死，问题证伪（见题面待证伪），本卡应当自己报没活干，而不是编吞吐故事。

### 2.5 时序

| 事件 | 周期 |
|------|------|
| fail 计数 + 发 CLAIM | fail 达阈值的下一空对向槽 |
| CLAIM 传到最远上游 | ≤ `C_ring` |
| 跳空到达索取者 | ≤ `C_ring`（空槽顺向） |
| 最坏一次索取闭环 | ≤ `2·C_ring` + 注入 |

相对 i-tag 等 128 拍才打标：K_fail=8 是 **更早** 的上游抑制，不是同一机制的换阈值。

## 3. 为什么尾会动

集合 / 多源 KV 的 last-completion = 最慢下游的注入+到达。DVC 把「我饿了」在 ≤1 圈对向内变成上游跳空；空槽顺向 ≤1 圈到口。税是 1 条对向控制拍 + Q 个上游少注入的拍。上游少注入的是 **挡路的过路**，不是把数据丢掉——它们留在 NIC outstanding 里，等 skip 解除。

相对基线（假设）：

- 无 CC：无索取，空槽到不了。
- 逐节点 cap：上游仍合计填满；没有 Q 个保留空槽。
- 源端 FC：dest 窗口，不按段索空槽。
- i-tag：同口仲裁，不向上游发 skip。K_fail≪128 且作用点在 **别人的** 注入口。

`dvc-off` 必须让最差节点完成变差。只报 claim 次数 / 下游 `p_inj` 上升 = 淘汰。

## 4. 失败模式

- 对向也饱和（双向 KV）：CLAIM 发不出，行为=基线。必须单列。
- Q 过大：上游饿死，尾换人。扫 Q∈{1,2,4,8}。
- 多下游争同一段：1 活 claim 让第二名等。若第二名才是真正 last-completion，要靠超时轮转；探针 `claim_wait_p99`。
- 把 skip 写成「丢掉过路 flit」：非法，卡死。
- 与 i-tag 抢同一空槽且上游 i-tag 赢：违例，`skip_honored` 失败。

## 6. 评估

信封与主指标同 M-1：推理 makespan / 最差节点 / 尾。基线：无 CC、逐节点 cap、源端 FC、i-tag。强制 15:1 Snp 列（本卡不借 Snp）。消融 `dvc-off`。包络 12+2 + Dat×2。

预期（UNSIGNED）：饥饿扇入（gather/KV）相对无 CC **0.65–0.92×**；无饥饿广播接近 1；双向 all-to-all **0.95–1.20×**。不是 card-claim。

## 7. 可证伪

1. **H-CLAIM-BOUND**：`claim_active ⇒ ρ_transit(s) ≤ 1-Q/W` 且 `inject_from_skipped_empty≡0`。
2. **H-GRADIENT**：基线沿环等待梯度显著；DVC on 后最差节点等待下降且 makespan 下降。
3. **H-TAIL**：off 的推理主类完成时间 > on。
4. **H-NOT-ITAG**：仅改 i-tag 阈值到 8 **不得** 复现 DVC 曲线（作用点不同）。
5. **H-NO-DROP**：不丢 completions。
