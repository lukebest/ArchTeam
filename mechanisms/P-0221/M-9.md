# M-9: 弹出孔前送

- problem: P-0221
- author: 保守架构师
- style: conservative / implementable

## 1. 根因分析

基线 `insertAfterRemoval=true`（AIC/HA/3DIO/ChangeRing 生成值，`TNetworkInterfaceBase.cpp:40`；`gen_config.py:134,157,198`；仲裁顺序先弹出再注入，`TCsHighWay.cpp:217-264`）。一个 flit 在目的 CS 弹出后，**同一拍** 该方向输出槽被本地下一笔吃掉。完成一笔本应「退还」的环段容量，从未变成沿环前行的空槽。下游（以及绕回后的中游）看不到这笔退款。

三项先例不管这件事：srcfc 在源端扣令牌；i-tag 要先饿 128 拍再等被标 flit 走完剩余路程 + 最多一圈才拿到孔；动态 leaf-tag 在指定 CS **停** 一个 invalid。本卡把「弹出成功」改成强制前送一个空槽，不打标、不加 flit 位。

绕回延迟必须用链路和：top **42**，bottom H **72–76**，V **132/148/152**，不是 21 站。中游饥饿点若只能吃到绕回孔，等待下界是剩余弧的 `Σ L_link`，最坏 `C_ring`。

## 2. 机制

### 结构

每个 CS、每个 `(channel, subchannel)`、每个方向一份本地 1-bit `EHOLE`。Dat 2 子环独立。Snp `EHOLE_EN_SNP=0`。

1. `tryWayToLocal` 成功弹出后：`EHOLE ← 1`，本拍 **禁止** `tryLocalToWay`（覆盖 `insertAfterRemoval`）。
2. `xfer` 把 `m_sendFlit==nullptr` 交给下游延迟线——这就是前送孔，对象是「无 flit」，**不加** invalid 占位、不加 TTL 位（那会变成 leaf-tag / 加线）。
3. 下一拍 `EHOLE ← 0`（只挡住弹出当拍；若要消融「连挡一拍」，用 CSR `HOLD=0/1`，复位 0）。
4. 若该方向同时有 i-tag / leaf-tag 预留指向本 CS：预留仍优先（先例履约），`EHOLE` 让路。本卡只挡住无预留的 `insertAfterRemoval`。
5. 弹出失败：保持基线绕环（`:574-577`），不丢、不 U-turn（soc_sim 未生成 `UturnConnect`）。

### 数据路径与状态机

每拍 `arbitration()`：

1. `getFlit`；若本 CS 是 dest 且弹出成功：`EHOLE=1`，跳过本地注入。
2. `tryItagProcess` / leaf-tag 仍可走（预留履约）。
3. `tryLocalToWay` 增加 AND `!EHOLE`。
4. `xfer`。

无新 flit 字段。反向环不参与。

## 3. 第一性原理与逐环段密度上界

流守恒：稳定时全局注入率 = 弹出率。基线把弹出孔就地吃掉，退款留在 dest。本卡让每次成功弹出在环段 `j`（dest 的输出槽）产生 `H_j=1`，该孔沿方向以每跳 `L_link` 前进。

**段 `j`（dest 输出）：** 弹出当拍 `I_j=0`，`O_j=0`。该段因「完成退款」的空槽率 `≥ λ_eject`。密度上界 `ρ_j ≤ 1-λ_eject`（相对「弹出后立刻再注」的基线，本段少占 `λ_eject`）。

**段 `j+k`：** 孔在 `Σ_{i=0}^{k-1} L_{j+i}` 拍后到达。top 上 k 跳 = `2k` 拍；bottom H = `3k`；V = `4k`。途中若被无预留的下游注入吃掉，孔消失——本卡 **不加保护位**。保证的是：**从 dest 出发的第一跳环段** 一定看到该孔；更远只保证「若中间不抢」。

**中游饥饿（在 dest 上游、源下游）：** 孔要走完剩余弧再绕回，时延 ∈ `(0, C_ring]`，`C_ring∈{42,72–76,132,148,152}`。绕回后该孔与任何普通空槽一样可被注入。本卡把「完成率」耦合到「绕回空槽率」，长时间中游看到的绕回孔率 ≤ `λ_eject`，延迟一个 `C_ring` 量级。这 **不是** 反向环送孔，也不是回程扣减：孔始终在 **本向** 往前走，绕的是同一方向的 FullRing。

**与 i-tag 对比：** i-tag 孔绑定给打标者、最坏 128+`C_ring`。本卡孔不绑定、弹出当拍就产生，中游若要等绕回才是 `C_ring`，且中间可能被抢。两者叠加时预留优先。

不丢：弹出失败继续绕；注入被挡的头留在 head。

## 4. 推理收益与失效条件

推理（主）：KV 在 HA/AIC 弹出后，基线 dest 立刻再注，下游集合 rank / 下一笔 KV 看不到退款。前送孔让 dest 之后（及绕回后的中游）得到与完成率匹配的空槽，最慢 rank 的等待下降。若饥饿点全在 dest **之前** 且中间站吃光绕回孔，本卡对中游无效，必须报失效。

训练大块（一句）：dest 持续弹出又持续有下一块要注，前送会打断 dest 自己的流水，允许变差。

## 5. Cycle 级评估计划

### 基线

**B\***：`experiment_srcfc` + i-tag + 动态 leaf-tag，且 `insertAfterRemoval=true`（生成默认）。本卡叠在 B\* 上。

### 仿真器改动（新分支）

1. `TCsHighWay.cpp`：`tryWayToLocal` 成功后置 `EHOLE`，`tryLocalToWay` AND `!EHOLE`。不改 `NetworkFlit`，不生成 invalid TTL。
2. `--cc-scheme eject-hole`。
3. `infer-decode` + 逐环段占用 + dest CS 与 dest+1 的空槽率 + 绕回孔到达中游的延迟直方图（应按 `C_ring` 分 top/H/V 报，禁止用 21）。

### 必须 cycle 级建模

- `EHOLE`、`insertAfterRemoval` 覆盖、`L_link` 链、FullRing 绕回 `C_ring`。
- **不要** 令牌、flit 位、反向信令、保护 TTL。

### 消融与证伪

- E0：B\*。
- E1：B\* + 弹出当拍前送（HARD）。
- E2：`HOLD=1`（再多挡一拍）。
- E3：前送但抢 i-tag 预留（负对照）。

E1 须 `T_step` 优于 E0。中游等待无改善而只有 dest+1 空槽率上升、`T_mix≈1` → 失败。Snp 超阈 → KILL。

## 6. 面积 / 功耗 / 延迟估算

1-bit/`(CS,子环,向)`，`<0.5 kGE`，0 新 flit 位。决策 +0；孔到下一 CS = `L_link`；绕回 = `C_ring`。过路 +0。

## 7. 与已有功能 / 先例的区别

- **不是** i-tag：不打标、不绑定受益者。
- **不是** 动态 leaf-tag：不在 CS 停 invalid。
- **不是** srcfc 令牌。
- **不是** 偷气泡：dest 在弹出当拍 **不准** 注。
- **不是** TDM / 最短路 / Age+Class / 配额窗。
- **不是** UturnConnect。
- **不加线，不占反向环。** 绕回是本向 FullRing，占用的是本向空槽本身（本来就要走），不是反向容量。
