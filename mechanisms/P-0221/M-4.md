# M-4 环段占用快照门（Segment Occupancy Snapshot Gate, SOSG）

- problem: P-0221
- id: P-0221/M-4
- author: Jim Keller
- class: 测量前馈（观察密度再关门，不是记账、不是索取、不是配额分割）

## 1. 根因

桶和守恒都是 **模型**：认为「答应过的会来」。环上还有 eject 失败绕圈、RBRG 换路、U-turn——账和真占用会偏。P-0198 的 T2 代数贴不到 T3，就是模型密度 ≠ 周期占用。

本卡不记账。段主用滑动窗 **量** 过路占用，把 `over[s]` 推给上游。门看测量，不看信用。超调必须有界，否则这不是上界是装饰。

不是 CBC 日历（日历是愿望密度）。不是 i-tag（i-tag 不测量下游段）。

## 2. 机制

### 2.1 环段

同一几何。Dat×2、Snp×1。测量对象 = 本出边过路占用，**不是** 总 valid（下一跳弹出不计入过路）。

### 2.2 结构

| 结构 | 容量 / 位宽 | 出处 / 假设 |
|------|-------------|-------------|
| 滑动窗移位 | W bit，默认 **W=16（假设）** | 段主 CS，每拍移入 1b `transit` |
| `occ[s]` | `popcount`，5b | `occ/W = ρ_hat` |
| `over[s]` | 1b：`occ > ρ_max·W` | 默认 ρ_max=3/4 ⇒ 阈值 **12/16（假设）** |
| `over` 向量 | ≤64 b | CS_NUM≤64；对向捎带 |
| 注入锁存 | 每 NIC 一份 `over_latch[0:C)` | 过期 ≤ `C_ring` |
| 门 | 路径 P 上存在 `remaining_hops(s)≥2 ∧ over_latch[s]` ⇒ 禁注入 | hop-1 不看门 |
| 滞回清 | `over` 在 `occ ≤ ρ_lo·W` 时清；**ρ_lo=1/2（假设）** | 防抖，不是第二套指标 |
| i-tag | 库内 | **不得** 覆盖 over 门 |

捎带：每个对向 flit（含普通 Rsp/Dat/Snp 过路）在 ESL `NetworkFlit` 上带 1b，值为 **刚刚离开的那个正向段** 的 `over`。节点把该 bit 写入 `over_latch[src_cs]`。对向完全空闲时，段主每 W 拍发 1 条同通道对向 HEARTBEAT（1b 有效，其余 0）。

64 个 1b 不需要 DAT Data。Snp 无 Data（Table 13-8）——1b 走 ESL 元数据，与 i-tag/e-tag 同类，**不是新 CHI 字段、不是新导线**。禁止把测量向量塞进 Snp 当 payload。

### 2.3 同拍规则

1. 段主：出边转发且 `dst≠next` ⇒ 窗移入 1，否则 0。更新 `over`（置位阈值 12，清除阈值 8 @W=16）。
2. 对向 flit 路过：更新下游锁存。
3. 本地注入：槽空且路径上无 `over` 的过路段 ⇒ 按基线注入。否则 fail-wait。
4. 过路仍赢。不改、不丢在途。
5. 单套密度定义：只 `ρ_hat = occ/W` 这一套。禁止再报「有效注入密度」第二套（09-04 双指标禁令）。

### 2.4 环段密度上界（软上界 + 有界超调）

诚实：测量门 **不是** 瞬时硬帽。陈述必须带超调：

```
稳态（inhibit 传播之后）：ρ_transit(s, W) ≤ ρ_max
瞬态超调长度 ≤ T_prop + T_drain ≤ 2·C_ring
T_prop ≤ C_ring     # 对向捎带/心跳
T_drain ≤ C_ring    # 已在途过路最多再占一圈
```

**执行论证**：

1. `occ>ρ_max·W` 的下一拍 `over=1`。
2. ≤`C_ring` 后所有上游锁存看到 `over`，新过路注入停止。
3. 已在途 ≤`C_ring-1` 个正向槽，排空 ≤`C_ring`。
4. 之后新过路=0，窗内 1 被移出，`occ` 降到 ≤`ρ_lo·W` 才开门。
5. 若 `over=1` 持续 >`3·C_ring` 而 `ρ_hat` 仍 >ρ_max：**门没执行**，卡死（探针 `overshoot_fail`）。
6. 这不是逐节点 cap：门键是 **段测量**，10 个上游同时看见同一 bit。

对比 M-1/M-3：它们宣称注入前硬账。SOSG 承认绕圈/换路让账假，改信尺子。超调必须进报表，不得把 `2·C_ring` 藏进平均值。

### 2.5 时序

| 事件 | 周期 |
|------|------|
| 窗更新 / over | 同拍 |
| 捎带到最远上游 | ≤ `C_ring` |
| 开门滞回 | 窗再滑到 `occ≤8`（假设） |

## 3. 为什么尾会动

下游饿 = 进边过路窗满。`over` 让上游停手，空槽按滞回进入下游。比 DVC 早：不必等 K_fail，尺子先响。比 IPCW 真：绕圈占用算在 `transit=1` 里，账外公民也被量到。

相对基线（假设）：无 CC 没有尺子。逐节点 cap 不看窗。源端 FC 不看段。i-tag 不看下游 `occ`。

`sosg-off` 必须让尾变差。`ρ_hat` 好看但 last-completion 不动 = 淘汰（测量优势不算）。

## 4. 失败模式

- 窗太短：抖，门控振荡，双向尾变差。扫 W∈{8,16,32}。
- 窗太长：反应慢，超调吃满 `2·C_ring`，集合一步就被钉死。
- 把总 valid 当过路：hop-1 自锁。必须 `dst≠next`。
- 两套密度定义：禁止。
- 心跳在对向造第三拥塞：只在对向空闲时发，须计数。

## 6. 评估

推理 makespan / 最差节点为主。基线四条。消融 `sosg-off`。强制报超调分布与 `overshoot_fail`。Snp 15:1 分列。

预期（UNSIGNED）：扇入 **0.72–0.96×** vs 无 CC；超调敏感的短步 decode 可能 **0.90–1.10×**，必须按步数分列。不是 claim。

## 7. 可证伪

1. **H-SOFT-BOUND**：`overshoot_fail≡0`；`over=1` 后 `2·C_ring` 内 `ρ_hat≤ρ_max`。
2. **H-MEASURE**：绕圈 / U-turn 占用计入 transit（打开 `UturnConnect` 对照列）。
3. **H-TAIL**：off 尾 > on。
4. **H-ONE-RHO**：全表只用 `occ/W`。
5. **H-NO-DROP**：不丢包。
