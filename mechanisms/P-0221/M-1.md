# M-1 环段令牌桶准入（Segment Token Bucket, STB）

- problem: P-0221
- id: P-0221/M-1
- author: Jim Keller
- class: 共享速率信用（per-segment token bucket，不是逐节点 cap）

## 1. 根因

无缓冲双向环：空槽跟数据同向走。节点 j 先看见空槽，填进去的长途 Dat 会一连占掉 `s_j, s_{j+1}, …, s_{dst-1}`。节点 k（j 的下游）要注入的是 **自己的出边** `s_k`；等空槽到 k 时，上游合计已经把 `s_k` 填满。过路恒赢（`TCsHighWay.cpp:1041-1117`），k 只能 fail-wait。

逐节点注入上限为什么废：10 个上游各自守 `1/10`，`s_k` 上仍是 `10 × 1/10 = 1`。节点都合规，环段满，下游饿死。集合 makespan = 最慢参与者；饿死的就是尾。

HSSL（P-0198/M-12）把故事写成「近源抢远源的空槽」——根因方向反了，T0 已杀。CBC / AODI 抬 `p_inj`、`T_mix=1`。i-tag 只让 **本节点** 在空槽到达后赢仲裁（阈值默认 `itagThreshold×2=128` 拍，每 highway 一活标），**不阻止上游把空槽在到达前吃光**。本卡不管日历、不造洞、不借 Snp。

根因钉死：**环段 `s` 的过路占用没有共享上界**。要的是 `ρ_transit(s) ≤ ρ_max`，不是每个 NIC 各自节流。

## 2. 机制

### 2.1 环段定义

一条 **环段** = `(channel, sub-ring, direction, CS_i → CS_{i+1})` 的出边 highway 槽。

| 通道 | 子环数 | 出处 |
|------|--------|------|
| Req | 1 | `src/TMultiRing.cpp:223-231` |
| Rsp | 2 | 同上 |
| Snp | **1**（无 Data 字段） | 同上；CHI Issue G §B13.9.3 / Issue E.b **Table 13-8** |
| Dat | **2** | 同上。**禁止**再把 Dat 写成 1 条环 |

每向每 CS 1 个 `NetworkFlit*` 槽（`include/TCsHighWay.h:136`）。环周 `C_ring = CS_NUM`（top 21；bottom H 24/25；bottom V 33/37/38）；`CS_NUM≤64`。默认 SoC 12 top + 2 bottom。密度上界 **逐子环逐段** 独立执行：Dat 有两套段，Snp 一套，互不借用。

**过路占用**：该拍槽 valid 且 `dst ≠ CS_{i+1}`（下一跳不是弹出点）。本地下一跳弹出 **不** 饿 `CS_{i+1}` 的注入（`CS_{i+1}` 注入走它自己的出边）。

### 2.2 结构

每个环段一只令牌桶，**所有** 路径包含该段的注入者共享，不是 per-node。

| 结构 | 容量 / 位宽 | 出处 / 假设 |
|------|-------------|-------------|
| `bucket[s]` | 饱和计数，宽 `⌈log2(B+1)⌉`；默认 **B=2（假设）** | 本卡；非测得 |
| 补充率 | 每拍 `+ρ_max`，封顶 B；默认 **ρ_max=3/4（假设）** | 本卡；分数用 2b 小数 `{0, 1/2, 3/4, 1}` |
| 路径消耗 | 注入一拍、路径 P：`∀s∈P: bucket[s]--`（须全部 ≥1） | 组合；缺一则 fail-wait，**不丢** |
| 对向心跳 / 捎带 | 同通道对向 1 槽；载荷 = 全段 `bucket` 向量 | 不加线；见 §2.4 / §8 |
| `hot[s]` | 1b：`bucket[s]==0` | 注入门用锁存副本 |
| i-tag 门 | 1b | **i-tag 不得拿走桶禁止的空槽**；合法空槽上 i-tag 仍按库内规则 |

**不是** slotted-ring / TDM：无第 k 拍日历、无节点–时隙表。有令牌的节点任何空拍都可注入。
**不是** 源端流控：窗口不是 dest outstanding，是路径上每段的共享速率。
**不是** MetaRing 整环 SAT：SAT 管整环一个人说了算；STB 是 **每段** 一只桶。
**不是** CBC：不制造 bubble、不日历 duty。
**禁止** 借 Snp 槽运 Dat（CRRF / M-5r1 / M-5r2 / TOSE 线已关）。

### 2.3 同拍规则

每拍、每个 NIC、每个通道子环方向，待注入 flit 路径 P 由 `(src, dst, direction)` 静态决定（拓扑 ROM，非到达预测）：

1. 过路仍赢（零和不变）。
2. 槽空且 `∀s∈P: latch_bucket[s] ≥ 1` → 注入；本地对 P 内每段 `latch--`；下一次心跳与权威桶对账。
3. 任一 `latch_bucket[s]==0` → fail-wait，与基线注入失败同形。不占槽，不改 payload。
4. hop=1（下一跳即 dest）：**不**消耗下游段；只消耗本出边桶。本出边桶耗尽仍允许 hop-1——hop-1 是弹出预备，不构成下游过路。
5. 权威 `bucket[s]` 在 **段主 CS** 每拍 `min(B, bucket+ρ_max)`。心跳 flit 路过时写入向量槽 `vec[s]=bucket[s]`。
6. 对账保守：锁存过期 ≤ `C_ring` 拍。注入用 `latch-1` 与权威比，禁止超订；超订计数 `oversub` 必须 ≡0，否则机制失败。

控制面 **只走同通道对向**（Dat 的对向 Dat 子环，Snp 的对向 Snp）。不跨 Req/Rsp/Snp/Dat。无跨通道循环依赖。

### 2.4 心跳位宽（CHI，不加线）

权威向量必须能表示 ≤64 段 × `⌈log2(B+1)⌉`。B=2 → 每段 2b → **128 b**。

| 载荷 | 宽 | CHI 出处 | 能不能用 |
|------|----|----------|----------|
| DAT Data | 128/256/512 b | Issue G §B13.9.4；Issue E.b **Table 13-9** DW∈{128,256,512} | 平台 `kBeatBytes=64`（`Endpoint.h:27`）⇒ Data=**512 b**，128 b 向量放得下。心跳是 **控制 Dat**，不是把 Snp 当 Dat |
| DAT BE | DW/8 = 64 b @512 b | Table 13-9 | 心跳 BE 全 0，无部分写语义 |
| SNP flit | **无 Data/BE/DataID** | Issue G §B13.9.3；Table 13-8 | **禁止**把向量塞进 Snp 当数据面 |
| RSVDC | 4/8/12/16/24/32 b | Issue E.b / G 协议字段：REQ/DAT 可选 | 32 b 装不下 128 b；只作捎带热位，不作权威向量 |
| REQ Addr | SAW+3 ≈ 44–52 b | Table 13-8 注释 SAW∈[41,49] | 不够 128 b |

心跳默认走 **本 Dat 子环对向**，每 `W_hb` 拍一圈（默认 **W_hb=16，假设**）。Snp 环上的 STB 用 **1b `hot` 捎带 + 每段 2b 在段主 CS 本地**，对向 Snp 心跳只带 `hot` 位图（≤64 b）。Snp 位图塞不进 SNP flit 的 Data（没有 Data）：用连续两拍对向 Snp 控制 flit 的 **TxnID(12)+Opcode 自定义 + FwdNID** 不够。Snp 环 STB 的权威桶 **只活在各 CS 本地**；对向每拍捎 1b `hot[s]`（ESL `NetworkFlit` 元数据，与已有 i-tag/e-tag 同类，**不是新导线**）。Snp 注入门看 `hot`，不看完整桶——Snp 稀疏，1b 够用。

`tests/esl_wrapper/compat/chi_common.h:92-118` 四通道共用 `CHIFlitFields`、无 Data/BE/DataID。这是 **假 ABI**。本卡主列按 Table 13-8/13-9 的真宽度记账，禁止把 Snp 当成 Dat 宽。

### 2.5 环段密度上界（必须）

定义窗口 W 拍内段 s 的过路密度

```
ρ_transit(s, W) = (过路占用拍数) / W
```

**上界（假设，待 cycle 证伪）**：

```
ρ_transit(s, W) ≤ ρ_max + B/W
```

论证（执行点 = 注入准入，不是过路丢包）：

1. 物理上每拍每段至多 1 个 flit（`TCsHighWay.h:136`）。
2. 新过路只能来自路径含 s 的注入；每次这种注入消耗 1 个 `bucket[s]`。
3. 任意 W 拍，段主至多补充 `ρ_max·W` 个令牌，桶深 B，故消耗 ≤ `ρ_max·W+B`。
4. 每个被消耗的令牌对应恰好 1 次未来对 s 的过路占用（flit 过 s 一次，不丢）。
5. 因此 W 内过路占用拍数 ≤ `ρ_max·W+B` ⇒ 上式。
6. 已在途 flit 不消耗新令牌、也不被丢；它们的占用已在注入时付过账。
7. 心跳过期：对账规则禁止超订（`oversub≡0`）。若 cycle 上 `oversub>0`，本上界作废，卡死。

默认假设 `ρ_max=3/4`、`B=2`、`W=16` ⇒ `ρ ≤ 0.75+0.125=0.875`。更长窗 `B/W→0`，渐近 `ρ_max`。**这些数是假设，不是 card-claim。**

执行者：段主 CS 的桶 + 全上游注入门。不是逐节点 cap：10 个上游共享同一只桶，合计不能超过补充率。

## 3. 为什么尾会动

下游饿死 ⇒ 该节点的 decode KV / 集合贡献晚注入 ⇒ last-completion 钉在它身上。STB 把 `s_k` 的过路上界压到 `ρ_max` 以下，空槽以 ≥ `1-ρ_max` 的速率到达 k，k 的等待从「上游吃光」变成「几何等待剩余空槽」。

相对必须打败的 cycle 基线（假设，未测）：

- **无 CC**：上游自由填段，`ρ_transit→1`，下游尾主导。
- **逐节点 cap**：合计仍可填满段。STB 的桶是共享的，合计受 `ρ_max` 管。
- **源端 FC**：削 dest outstanding，不看段。扇入 dest 窗口小了，上游仍可把下游段填满。
- **已有 i-tag**：空槽不到达，tag 无对象。STB 先制造到达率，i-tag 再在合法空槽上公平。

消融 `stb-off` 必须让推理主类 last-completion / 最差节点 **严格变差**。只涨下游 `p_inj` 而 `T_mix≈1` = 与 CBC/AODI 同类，淘汰。

## 4. 失败模式

- 心跳税把对向 Dat 填满（双向 KV）：必须单列；`W_hb` 扫 {8,16,32}。
- `ρ_max` 过低：吞吐塌、makespan 更差。过关看尾，不看「更公平」。
- 锁存超订：`oversub>0` = 上界没执行。
- 把 hop-1 也闸死：dest 门口自堵。
- 用 Snp 环运 Dat 心跳载荷：关闭路线，禁止。

## 6. 评估计划

- 信封：DV200 `tests/soc_sim`，12+2，512 B，读 ost 512 / 写 256；禁完美预测 / 无限带宽。
- **主指标**：decode KV/P2P + 推理集合的 makespan / 最差节点完成 / p99 尾。训练不单独过关。
- **cycle 基线（分列，不平均）**：无 CC；逐节点 cap（扫公开档）；源端 FC；已有 i-tag（门限 8/16/32/64）。
- 强制探针：沿环注入等待梯度；逐段 `ρ_transit` 是否 ≤ 上界；`oversub`；Snp 15:1 小包（本卡不借 Snp，仍必须报，>1.4× = 该列 KILL）。
- 消融：`stb-off`。HARD：off 的推理主类 last-completion **>** on。
- 包络：满 12+2 + 四通道 + Dat×2。单环 / 只均匀读 = reduced-bbox。
- 预期（**假设 / UNSIGNED**）：下游尾相对无 CC **0.70–0.95×**；相对逐节点 cap **0.75–0.98×**；双忙 all-to-all **0.95–1.15×**（须单列）。0.85 是 bar 不是均值。

## 7. 可证伪

1. **H-SEG-BOUND**：所有 Dat 子环段、Snp 段，稳态 `ρ_transit ≤ ρ_max+B/W` 且 `oversub≡0`。违例 = 上界没执行。
2. **H-NOT-PER-NODE**：存在「每节点都低于逐节点 cap、但某段 `ρ=1`」的基线点；STB on 后该段下降且最差节点完成下降。
3. **H-TAIL**：`stb-off` 推理主类 makespan > on。等号淘汰。
4. **H-NO-DROP**：completions 不丢；无 payload→empty。
5. **H-SNP**：15:1 不得用未过线数字卖。
