# M-2: Odd-Ring Cubic MAC (ORCM) — 奇数环上的立方累加

- problem: P-0103
- author: Jim Keller
- id: P-0103/M-2

## 1. 根因分析

整数取模是线性环同态。`δ ≡ 0 (mod 3)` 时像落在 `3Z` 的陪集，DMC 因子 3 被吃掉，`n_DMC = min(384, K)/3`，`X_rel = 3`。线性奇乘数（`×0x4D` 这类）在 `Z_{2^11}` 上是双射，对 `Z_9` 无济于事：`u` 若是 3 的倍数，`u · odd` 仍是 3 的倍数。

本卡打的环：**奇数环上的非线性**。CRT 仍切 `Z_18432 ≅ Z_{2048} × Z_9`。2-adic 用奇乘双射。`Z_9` 上放立方 MAC：`r' = (r + p_wide^2 + p_wide^3) mod 9`。立方在 `Z_9` 自身不是我们要的双射。有效性来自：**冻住的 `r` 加上一个随 `p_wide` 变的多项式**。`p_wide` 不动则 `r'` 不动；`p_wide` 动则要看差分 `Δ` 是否恒 0。

下面把 `Δ` 在 `Z_9` 上逐点算完。不造表。

## 2. 机制

### 2.1 结构

1. **SPLIT**：`p = G[10:0]`，`r = G mod 9`，`p_wide = A[24:9]`（16b）。
2. **ODD_MUL**：`p' = (p · 0x4D)[10:0]`。`0x4D = 77` 为奇数，×奇数是 `Z_{2^11}` 双射（2048 个输入，2048 个像）。
3. **SQ_CUBE**：16b 平方 + 立方，组合 CSA，禁止时序乘循环。
4. **RED9**：8b 量级的 `mod 9` 归约，得到 `g = (p_wide^2 + p_wide^3) mod 9`。
5. **ODD_ADD**：`r' = (r + g) mod 9`。
6. **CRT_DEC**：同 M-1 的 CRT 公式，用 `(p', r')`。
7. **PACK_SEL**：每 DMC 一张 48b 好 bank 掩码；`k = r' || p_low` 做 select-k。禁止对 `N_good` 再取模 3。

核侧 ×120：SPLIT / ODD_MUL / SQ_CUBE / RED9 / ODD_ADD / CRT_DEC / 一份 select-k 数据路径。掩码 SRAM 共享 ×1。

### 2.2 数据路径

```
G      = A[63:9]
p      = G[10:0]
r      = G mod 9
p_wide = A[24:9]                         // 16b 整数，不是 p mod 9
p'     = (p · 77) mod 2048               // 77 = 64+8+4+1，三次移位加
```

平方拆 8b：`a = p_wide[7:0]`，`b = p_wide[15:8]`。

```
a2     = SQ8[a]                          // 256×16 ROM，或 8b 部分积阵列
b2     = SQ8[b]
axb    = a · b                           // 8×8 → 16b
p2     = a2 + (axb << 1) + (b2 << 16)   // 32b，只用低 8b 等价类进 RED9
p3     = p_wide · p2                     // 16×32 的低 8–12b CSA，截到 12b 足够模 9
g_raw  = p2[11:0] + p3[11:0]            // 12b CSA
g      = g_raw mod 9                     // 见下
r'     = (r + g) mod 9
```

多项式在整数上算再 `mod 9`，与先 `p_wide mod 9` 再代入是同一件事：`(x+9k)^2 ≡ x^2`、`(x+9k)^3 ≡ x^3 (mod 9)`。硬件 16b 平方不改变 `Z_9` 代数。

`mod 9`：对 8b 值 `x`，`x − 9·⌊x·(2^{12}/9)/2^{12}⌋`。`2^{12}/9 ≈ 455 = 0x1C7`。一次 8×9 乘 + 两次减 9。或三次比较减 9。无除法器。

CRT 与 M-1 相同：`idx = p' + 2048 · ((2 · (r' − p' mod 9)) mod 9)`，再 `/48`、`%48` 得 DMC、bank。DMC 拓扑拆分（192 DMC/die，不是 256+128）：

```
u     = DMC / 3
die   = u[6]
local = (DMC % 3) + 3 · u[5:0]
HA    = local / 2
pipe  = local % 2
```


### 2.3 容量 / 端口 / 位宽

| 结构 | 容量 | 位宽 | 端口 | 副本 |
| --- | --- | --- | --- | --- |
| ODD_MUL 移位加 | ~2×10^2 GE | 11b × 常数 8b | 组合 | ×120 |
| SQ8 | 256 项 × 16b = 4 kb，×2（lo/hi） | 8b 地址 / 16b 数据 | 1R（若 ROM）；或纯组合部分积 | ×120 用组合，不放 120 份 ROM |
| 8×8 乘 | ~3×10^2 GE | 8×8 | 组合 | ×120 |
| 16×16 截断乘（立方） | ~8×10^2 GE CSA | 入 16b+32b，出 12b | 组合 | ×120 |
| RED9 | ~50 GE | 8–12b → 4b | 组合 | ×120 |
| GOOD 掩码 | 384 × 48b | 48b | 1R 共享 | ×1 |
| select-k 前缀 | 48 输入并行前缀 popcount + 48 比较 | 48b mask，6b k | 组合，1 份 | ×1 共享数据路径 |

2 拍流水：拍 0 乘方/立方 CSA；拍 1 RED9 + ODD_ADD + CRT + select-k。SQ8 若用 ROM：256×16，1R，两份并行（lo/hi），延迟藏在拍 0。

### 2.4 Partial-good

`k_raw` 把已混合的奇数坐标和 2-adic 低位拼进 48 桶：

```
k_raw  = r' + 9 · p'[3:0]                // 0..8 + 9·(0..15) 可到 143，再
k      = k_raw mod 48                    // 48 = 16×3；用已混合的 r'，不再对 3 取模
```

`N_good = popcount(mask)`。若 `N_good == 0` 该 DMC 全死，这条发行失败（冻结信封不改 DMC 数）。

select-k：并行前缀 `pre[i] = popcount(mask[0:i])`。输出最小的 `i` 使 `pre[i] == (k mod N_good) + 1`。48 输入前缀，1 拍。

**禁止**：`N_good | 3` 时再做一次 `mod 3` 或 `+1` 找下一个好 bank。那会把刚注入的 `r'` 抹回 3-陪集。1/3 图案下 `N_good = 32` 仍被 3 整除；再取模 3 等于把奇数环线性化回去。

select-k 用的 `k` 已经含 `r'`。即使 `N_good` 被 3 整除，选取轨道仍是混合后的，不是 `G mod 3`。

### 2.5 时序与因果

- 拍 0：ODD_MUL ∥ SQ_CUBE。输入只有当前 `A`。
- 拍 1：RED9 + `r'` + CRT + 可选 select-k（mask 来自拍 1 的 1R）。
- 无 stride 状态。无 warmup。同一 `A` 同一映射（select-k 的 `k` 是 `A` 的函数，掩码是静态 fusedown）。
- 2 拍。不是 0。

## 3. 为什么有效

令 `g(x) = x^2 + x^3`。`Δ(p, u) = g(p+u) − g(p) = 3p^2 u + 3p u^2 + u^3 + 2p u + u^2`（在 `Z_9`）。

**表 A. `u ≢ 0 (mod 3)`，即 `u ∈ {1,2,4,5,7,8}`。逐点 `Δ`。无恒 0 列。**

```
p\u    1   2   4   5   7   8
 0     2   3   8   6   5   0
 1     1   7   4   7   7   7
 2     6   5   6   2   6   8
 3     8   6   5   0   2   3
 4     7   1   1   1   4   1
 5     3   8   3   5   3   2
 6     5   0   2   3   8   6
 7     4   4   7   4   1   4
 8     0   2   0   8   0   5
```

每一列都有非 0。多项式在 `u ≢ 0 (mod 3)` 上不是恒 0。`p_wide` 一旦按这类 `u` 走，`g` 必变。

`g` 在 `Z_9` 上的像（`p` 跑满一周期）恒为 `{0,2,3,5,6,8}`，`|im| = 6`，不是 9。这是立方+平方的代数像，不是仿真噪声。

**表 B. `u ≡ 0 (mod 3)`。最坏步长就在这里。** `S = 3·2^k` ⇒ `δ = 3·2^{k-9}`（`k ≥ 9`）⇒ 若 `p_wide` 被当成连续整数，则 `u ≡ 0 (mod 3)`。

`u = 3` 时 `Δ ≡ 6p (mod 9)`：`p ≡ 0 (mod 3)` 则 `Δ = 0`；否则 `Δ ∈ {3,6}`。从 `p0 ≡ 0 (mod 3)` 出发的 AP，`g` 像是单点 `{0}`。从其它 `p0`，像大小 3。

`g(x) mod 3` 对**任意** `x` 只取 `{0,2}`，永不取 1：`x^2(x+1)` 在 `F_3` 上，`x ≡ 0 ⇒ 0`，`x ≡ 1 ⇒ 2`，`x ≡ 2 ⇒ 0`。因此

```
t' = r' mod 3 = (r + g) mod 3 ∈ { r, r+2 }   // 缺 r+1
```

`r` 在 `3 | δ` 时本身冻在一个 `Z_3` 类上。立方 MAC **不能**单独盖满 3 个 DMC 剩余。这不是证明失败后的补丁，是这张卡的边界。

机制级结论（不装成 384）：

- DMC 奇数因子：从 1 类（基线塌缩，`n_DMC = 128`）扩到 **2 类，`n_DMC ≈ 256 = 128 × 2`**。`X_rel` 从 3 降到 1.5，不是 1。
- bank 奇数因子：`u ≢ 0 (mod 3)` 时 `|g-im| = 6`，`r'` 盖 6/9 的 `Z_9`。`u = 3` 且 `p0 ≡ 0 (mod 3)` 时退化为 1 点，此时本卡在奇数环上**不比取模强**。
- 2-adic：`p' = p · 77` 是 `Z_{2048}` 双射，2 幂 stride 上的均匀性保住。128 个 DMC 组全在。

Amdahl：占用从 128 拉到 256 是 ×2，不是 ×3。Little：15360 outstanding / 256 DMC ≈ 60，相对塌缩时的 120 减半，相对满 384 时的 40 仍差 1.5×。roofline 仍是带宽墙。

min/mean：在被占用的 256 个 DMC 上，若 2 个 trit 类被均匀打中，期望 ~0.9–1.0；对全部 384 个 DMC，有 128 个空，全局 min = 0。主指标是 `n_DMC`，不要用全局 min/mean 偷换。

**未证严的方程：** 把 `p_wide` 改成 bitrev(G[15:0]) 并不能绕开 `g ≡ 0 or 2 (mod 3)`——这是多项式在 `Z` 上的性质，与位排列无关。没有一个封闭公式让 `r + p^2 + p^3` 盖满 `Z_3`。若要 384 不是 256，必须加一次非 `g` 的 trit 注入（本卡按规格不加）。

## 4. 评估计划

- 基线: ModMapper %31, Mod192Mapper %192, Mod248Mapper %248, plus a power-of-two-only XOR mapper that is uniform on 2^k strides
- 指标: n_DMC, n_bank, min/mean R/W BW, X_rel, occupancy vs min(384,K)
- 负载: 8GiB shared, outstanding 128, S ∈ {512B, 1KiB, 1536B, 3KiB, 4608B, 12KiB, 1.5MiB, 2MiB} × sequential AP, plus bank partial-good 0%/6%/12% random and 1/3-patterned
- 必须 cycle 级建模的结构: ODD_MUL（11b×77）、SQ8 双平方 CSA、16b 截断立方 CSA、RED9、CRT_DEC、384×48 掩码 1R、48 输入 select-k 前缀（禁止 N_good 再 mod 3，禁止 +1）
- 预期收益与置信度: `S = 3·2^k` 上 n_DMC 从 ~128 到 **~256（不是 384）**；占用 ×2。min/mean（占用集）~0.85–1.0。置信度 **中偏低**：表 A 严；表 B 证明最坏 AP 上立方可退化成常数；partial-good 1/3 图案与缺的那个 trit 类再对齐时，256 还会往下掉。

## 5. 硬件开销估算

- 逻辑：每核 ~1×10^3–3×10^3 GE（8×8 乘 + 截断 16b 乘 + 归约）。7nm **~10^{-3} mm² / 核**。×120：**~10^{-1} mm²**。
- SQ8 用组合部分积，不实例化 120 份 4 kb ROM。若共享 ROM：2×256×16 = 8 kb，1R×2，**~10^{-3} mm²**，但 120 核争 1R，不值得。
- 掩码 SRAM 与 M-1 同量级：**~10^{-2} mm²** 共享。select-k ~3×10^2 GE，一份。
- 功耗：每核 **1–3 mW** @ 2 GHz（乘方是大头）。共享 SRAM **1–10 mW**。
- 延迟：**2 拍**（mul | reduce+CRT）。
