# M-4: Cut-Resilient Mixed-Radix Digit Reversal (CR-MRDR) — 割切鲁棒混合进位数位反转

- problem: P-0103
- id: P-0103/M-4
- author: Jim Keller
- replaces: 冻结窗 MRDR（T1 致命缺陷，Dr. Archi）

## 1. 根因分析

整数取模把 AP 送进真子群。`3|δ` 时 DMC 的因子 3 被吃掉。

T1（Dr. Archi）把上一版 MRDR 的电路拓扑算穿，不是评测噪声：

- `BITREV11` 只能重排 `p=G[10:0]`。`H0/H1` 只向 trit 注入，**不**把高位送进 128 组索引。
- `S=1.5MiB`（`δ=3072`）：`G[9:0]` 冻，`q[6:0]` 只有 LSB 活 → **2 个组**。`t0'` 即使满 `Z_3` 也只给出 `n_DMC=2×3=6`，不是 384。
- `S=2MiB`（`δ=4096`）：`p` 全冻，`q` 常数，只剩 trit → **n_DMC=3**。
- §3 把「trit 解冻」写成「占用回到 384」是结构上界谎言。改 11→N 仍是同一窗口上的位宽调参，救不了。

必须验证的假设现在改写到**新电路**上，旧电路的 H-MRDR-384 已经失败（结构上界 6）。新卡打的是同一刀：**组索引必须吃到冻结线以上的位**，不是再救一个 trit。

信封不变：384 / 18432 / ×3 不改。只改交织。

## 2. 机制

### 2.1 结构

1. **LIVE_DIGIT**：11 个二进制数位，每个是跨冻结边界的 3 抽头 XOR。数位**不是** `G[10:0]`。
2. **TRIT_SRC**：两路不相交无权重 mod-3 和（不是 `G mod 9`）。
3. **TRIT_INJ**：`t0'=(t0+H0) mod 3`，`t1'=(t1+H1) mod 3`。H 只乘在**已经满扫的组索引**上，不再假装 trit 能把 2 档变成 128 档。
4. **DIGIT_REV**：11 位数位倒序接到组索引。
5. **DIGIT_DEC**：`DMC=t0'+3·q[6:0]`，`bank_in=t1'+3·q[10:7]`。
6. **GOOD_MAP**：384×48b、1R 共享。XOR 重试只动 `bank_in`。禁止 `+1`，禁止跨 DMC。

无 ROM、无 stride FSM、无 `core_id`。1 拍组合。

### 2.2 数据路径

`G=A[63:9]`。

信封两个杀手步长：

| S | δ_blocks | 冻结 | 行走 |
| --- | --- | --- | --- |
| 1.5MiB | 3072=2^10+2^11 | `G[9:0]` | `U:=G>>10` 每步 +3 |
| 2MiB | 4096=2^12 | `G[11:0]` | `G[12+]` |

每个数位三抽头，**中抽头与高抽头在 i=0..10 上不得撞车**（上一稿用 `G[21]` 当高抽头，`i=10` 时 `G[10+11]=G[21]`，高抽头被异或消掉，2MiB 上 `d[10]` 退回冻结的 `G[10]`）：

```
// 低：小步长活。中：1.5MiB 活（落在 U[i+1]）。高：G[23]（addr[32]），
// 8GiB 窗口内 S=2MiB 走 4096 点，G+=2^12，G[23] 翻转 2 次，不是冻位。
// i+11 ∈ {11..21}，永不等于 23。
d[i] = G[i] ⊕ G[i+11] ⊕ G[23]     // i=0..10
q[j] = d[10−j]                    // j=0..10
```

组索引是 `q[6:0] = {d[10], d[9], d[8], d[7], d[6], d[5], d[4]}`。逐位在杀手步长上的活源：

**S=1.5MiB**（`G[9:0]` 冻，`G[10+]` 走，`U+=3`，`gcd(3,2^8)=1` 则 `U[7:0]` 满 256）：

| 组 bit | 数位 | 活抽头 |
| --- | --- | --- |
| q[6] | d[10]=G[10]⊕G[21]⊕G[23] | 三个都在 `G[10+]` |
| q[5] | d[9]=G[9]⊕G[20]⊕G[23] | G[20], G[23] |
| q[4] | d[8]=G[8]⊕G[19]⊕G[23] | G[19], G[23] |
| q[3] | d[7]=G[7]⊕G[18]⊕G[23] | G[18], G[23] |
| q[2] | d[6]=G[6]⊕G[17]⊕G[23] | G[17], G[23] |
| q[1] | d[5]=G[5]⊕G[16]⊕G[23] | G[16], G[23] |
| q[0] | d[4]=G[4]⊕G[15]⊕G[23] | G[15], G[23] |

中抽头 `{G[15],…,G[21]}` 覆盖 `U[5]..U[11]` 的低段。`U[7:1]` 满 128 的 2-adic 计数仍在，公共 `G[23]` 不降秩。**|{q[6:0]}|=128**，不是 2。

**S=2MiB**（`G[11:0]` 冻）：

同一张表：`G[4]..G[10]` 冻，但每一行都剩 `G[15..21]` 与 `G[23]`，全部在 `G[12+]`。**|{q[6:0]}|=128**，不是 1。旧卡这里 `p` 全冻 → n_DMC=3。

trit（只乘在满组上）：

```
t0 = (G[0]+G[3]+G[6]+G[10]+G[13]+G[16]+G[19]) mod 3
t1 = (G[1]+G[4]+G[7]+G[11]+G[14]+G[17]+G[20]) mod 3
H0_2 = { ⊕ G[19:16] , ⊕ G[15:12] }     // 1.5MiB 与 2MiB 都活
H1_2 = { ⊕ G[11:8]  , ⊕ G[7:4]  }
H0 = (H0_2==3)?0:H0_2                  // 直方图 {2,1,1}，偏置保留，不装成均匀
H1 = (H1_2==3)?0:H1_2
t0' = (t0+H0) mod 3
t1' = (t1+H1) mod 3
DMC = t0' + 3 · q[6:0]                 // 128 组 × 3 trit
bank_in = t1' + 3 · q[10:7]
die = DMC[8]
HA  = DMC[7:1]
pipe= DMC[0]
```

`S=1.5MiB`：128 组满、`H0` 吃 `G[19:12]` 满跑，`t0'` 满 `Z_3` ⇒ **n_DMC=384**。这是组索引活了之后再乘 trit，不是 trit 把 6 变成 384。

消融（评估必跑，复现 T1）：`d[i]=G[i]`，其余相同。`S=1.5MiB` 必须 n_DMC=6；`S=2MiB` 必须 n_DMC=3。回不去说明没打到 Archi 的电路。

### 2.3 容量 / 端口 / 位宽

| 结构 | 容量 | 位宽 | 端口 | 副本 |
| --- | --- | --- | --- | --- |
| LIVE_DIGIT 3-XOR | 11×2 XOR2 | 3×1→1 | 组合 | ×120 |
| TRIT_SRC | 两路 7 输入 mod-3 CSA | 7b→2b | 组合 | ×120 |
| H0/H1 折叠 | 8+8 XOR + 2b 模 3 | 8b→2b | 组合 | ×120 |
| DIGIT_REV | 0 GE，接线 | 11b | 组合 | ×120 |
| DIGIT_DEC | 7b 拼接 + trit×3 | 9b+6b | 组合 | ×120 |
| GOOD_MAP | 384×48b = 2.25KB | 48b | **1R 共享** | ×1 |
| XOR_RETRY | 6b XOR，≥48 则减 48 | 6b | 组合，掩码已在触发器 | ×120 |

GOOD_MAP 1R 对 120 核是吞吐缺口（Archi 已点）。发行路径先出组合 `(DMC,bank)`；位图只在 partial-good 使能时读，冲突进 cycle 模型，**不**复制 120 份 SRAM，**不**加请求队列冒充带宽。100% good 时跳过 SRAM。

门数量级：3-XOR + 两路 7 输入 CSA + 折叠，每核 **~4×10^2–1×10^3 GE**，不写 200 GE。

### 2.4 Partial-good

DMC 锁定。掩码一次读出 48b，三次探针都在触发器上的 mask 上做，不三次探 SRAM。

```
b0 = bank_in                              // 构造上 ∈[0,47]
b1 = (b0 ⊕ {1'b0, live5})                 // live5=G[23:19]，两个杀手步长都活
if b1 ≥ 48: b1 = b1 − 48                  // 落到 0..15，禁止 −32（−32 把 32..47 与 0..31 拆成不连通）
b2 = (b1 ⊕ {G[18:16], 2'b11})
if b2 ≥ 48: b2 = b2 − 48
bank_out = 第一个 mask[]==1 的 bi
三次全 miss：本拍 NACK，下一拍用 (b2 ⊕ G[22:17]) mod 48 再探，DMC 仍不变。不借 DMC。
```

XOR 不是 `Z_3` 运算，1/3 图案下存在两次仍停在被杀类的请求——所以有第三探和 NACK，不假装两次必离开。

### 2.5 时序与因果

1 拍组合映射。partial-good 使能时 +1 拍 SRAM（1R 冲突时 +N，模型必须计）。无状态，无 warmup，不看未来 stride。纯函数。CSA 之后有小宽度 CPA，2 GHz 一拍是目标不是 STA 证明。

## 3. 为什么有效

Archi 的反对写的是电路拓扑：组索引 = 对 `G[10:0]` 的接线置换，高位进不了 `q[6:0]`。本卡改的是数位定义，让 `q[6:0]` 的每一 bit 在两个杀手步长上都有 `G[12+]` 抽头。trit 仍只提供因子 3，**不再被写成占用从 128 回到 384 的理由**。

`S=1.5MiB`：`|{q[6:0]}|=128`（中抽头在 `U+=3` 上满扫）× `t0'` 满 3 = 384。旧上界 6 被拆掉的是「2 个组」，不是「少一个 trit」。

`S=2MiB`：旧上界 3（`p` 全冻）。新电路每行剩 `G[i+11]` 与 `G[23]`，`i≥4` 时 `i+11≥15≥12`，行走。128 组 × trit 3 = 384。

`S=1536B / 4608B`：低抽头与无权重 trit 活；整数 `G mod 9` 冻不等于 XOR 数位冻。

Amdahl：相对整数取模的 128，满 384 是 ×3；相对 T1 实测的 6，是 ×64。Little：15360/384≈40，对比 6 DMC 时 2560/DMC。1 拍被 128 outstanding 盖住。

`{2,1,1}` 直方图在 `t0` 冻、只靠 H0 时把三类打成 2:1:1，热类 1.5×，`min/mean` 可能 ~0.7。**不**并列写「满 trit ⇒ Amdahl 项回 1」。主指标是 `n_DMC`，min/mean 是次指标。

**未证严：** 11 个 3 抽头对 24b `G` 的 GF(2) 秩未算，不声称 18432 双射。公共 `G[23]` 相关，满 128 靠中抽头移位结构。H 折叠满 `Z_3` 不是同态定理。

## 4. 评估计划

- 基线: ModMapper %31, Mod192Mapper %192, Mod248Mapper %248, plus a power-of-two-only XOR mapper
- 对照（必须，复现 T1）: 冻结窗 `d[i]=G[i]`。预期 `S=1.5MiB` 上 n_DMC=6，`S=2MiB` 上 n_DMC=3。
- 指标: n_DMC, n_bank, min/mean R/W BW, X_rel
- 负载: 8GiB shared, outstanding 128, S ∈ {512B, 1KiB, 1536B, 3KiB, 4608B, 12KiB, 1.5MiB, 2MiB} × sequential AP；partial-good 0%/6%/12% random 与 1/3-patterned
- **H-MRDR-384（新电路）**：sequential AP、`S=1.5MiB`、`δ=3072`、8GiB 窗口，cycle 级闭合 `LIVE_DIGIT → TRIT_INJ → DIGIT_REV → DIGIT_DEC`（禁止关掉 TRIT_INJ）。失败判据：`n_DMC < 128`。通过目标：`n_DMC=384`。另测 `S=2MiB`，失败判据同样 `n_DMC<128`（旧上界是 3）。必须打印 `|{q[6:0]}|`（杀手步长上预期 128，对照卡预期 2 或 1）。
- 必须 cycle 级建模的结构: 11×`G[i]⊕G[i+11]⊕G[23]`、H0=`fold(G[19:12])`、DIGIT_DEC 公式、GOOD_MAP 1R（含 120 核冲突）、mask 上三次 XOR 探针（禁止三次读 SRAM，禁止 −32）
- 预期收益与置信度: 杀手步长 n_DMC 6→384 与 3→384。min/mean ~0.7–1.0（直方图偏置）。置信度 **中高**：组索引满 128 是 2-adic 计数；trit 满 `Z_3` 是折叠，不是定理。不自评通过。

## 5. 硬件开销估算

- 逻辑：每核 ~4×10^2–1×10^3 GE。7nm **~10^{-4}–10^{-3} mm² / 核**。×120：**~10^{-2}–10^{-1} mm²**。
- SRAM：共享 GOOD_MAP 2.25KB，**~10^{-3}–10^{-2} mm²`**（单口）。不是 120 读口。
- 功耗：每核 **0.1–1 mW** @ 2 GHz。共享 SRAM **1–10 mW**。
- 延迟：**1 拍** 组合 + **0/1 拍** SRAM（冲突另计）。无 warmup。
