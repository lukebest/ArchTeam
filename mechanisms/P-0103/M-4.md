# M-4: Mixed-Radix Digit Reversal (MRDR) — 混合进位数位反转

- problem: P-0103
- author: Jim Keller
- id: P-0103/M-4

## 1. 根因分析

`18432 = 2^{11} × 3 × 3`。混合进制写下来是 11 个二进制位 + 2 个 trit。整数取模把低位当 DMC/bank 的低数位。AP 的低位冻住时，被当低数位的 trit 也冻住。`t0 = (G mod 9) mod 3 = G mod 3`。`3 | δ` 时 `t0` 常数，DMC 的 ×3 直接消失。

**只做数位反转不够。** 把两个 trit 翻到 DMC 的高数位，若 trit 本身冻着，高数位照样冻着，384 = 128×3 仍少因子 3。根因不在接线顺序，在 trit 没有活源。本卡必须在反转**之前**注入：`t0' = t0 + H0(p_wide) (mod 3)`，`t1' = t1 + H1(p_wide) (mod 3)`。H0/H1 来自不相交的地址位 XOR 折叠。反转负责 2 幂 stride（bitrev 11b）。注入负责奇数因子。两件事缺一不可。

硬件是接线置换 + 两个 2b 模 3 加，1 拍。不是表，不是预测器。

## 2. 机制

### 2.1 结构

1. **RADIX_SPLIT**：`p[10:0] = G[10:0]`，`r = G mod 9`，`r = t0 + 3·t1`，`t0, t1 ∈ {0,1,2}`。
2. **H0_FOLD / H1_FOLD**：两路不相交 8b XOR 折叠 → 2b → 模 3。
3. **TRIT_INJ**：`t0' = (t0 + H0) mod 3`，`t1' = (t1 + H1) mod 3`。
4. **BITREV11**：`q[10:0] = p[0], p[1], …` 倒序，即 `q[i] = p[10−i]`。
5. **DIGIT_DEC**：用 `t0'` 当 DMC 的奇数因子，`q[6:0]` 当 128 组；`t1'` 与 `q[10:7]` 当 bank-in-DMC（48 = 16×3）。
6. **XOR_RETRY**：只打 bank-in-DMC，DMC 保持。禁止跨控制器弹跳。禁止 `+1`。

无 ROM（H 折叠的 2b→trit 是 4 项常数接线）。无 FSM。

### 2.2 数据路径

```
G   = A[63:9]
p   = G[10:0]
r   = G mod 9                              // 6b 块求和，同 M-1
t0  = r mod 3                              // r 的低 trit
t1  = r / 3                                // 0..2，高 trit
```

H0 必须吃大步长仍活的位。`δ = 3·2^{10} = 3072` 时 `G[9:0]` 冻，`G[10:]` 以 3 步进。H0 喂 DMC 的 `t0'`，所以 H0 的 8b 取高位。H1 喂 bank trit，取低位，覆盖 `δ = 3, 9, 24`。

```
h0_bits = A[26:19]                         // G[17:10]，8b。与 p 的高段重叠但 H0 是 XOR 不是算术
h1_bits = A[16:9]                          // G[7:0]，8b。与 h0_bits 不相交
H0_2    = { ⊕ h0_bits[7:4] , ⊕ h0_bits[3:0] }     // 2b，值 0..3
H1_2    = { ⊕ h1_bits[7:4] , ⊕ h1_bits[3:0] }
H0      = (H0_2 == 3) ? 0 : H0_2           // {0,1,2,0}，直方图 2,1,1
H1      = (H1_2 == 3) ? 0 : H1_2
t0'     = (t0 + H0) mod 3                  // 2b 加，≥3 则减 3
t1'     = (t1 + H1) mod 3
q[i]    = p[10−i]                          // i=0..10，纯接线
```

解码（干净，不用 CRT 模逆）：

```
DMC     = t0' + 3 · q[6:0]                 // t0'∈{0,1,2}，q[6:0]∈0..127 → 0..383
                                           // 384 = 3×128，DMC 奇数因子只用一个 trit
bank_in = t1' + 3 · q[10:7]                // t1'∈{0,1,2}，q[10:7]∈0..15 → 0..47
                                           // 48 = 3×16
die     = q[6]                                 // 64 组/die × 3 = 192。禁止 DMC[8]
local   = t0' + 3 · q[5:0]                     // 0..191
HA      = local / 2                            // 0..95
pipe    = local % 2
```

`q[6:0] = {p[10], p[9], …, p[4]}`。大步长 `δ = 3072` 时 `p[10] = G[10]` 每步翻转，它是 `q[0]`，即 128 组的 LSB，2-adic DMC 组仍走。`t0'` 靠 H0=`fold(G[17:10])` 走奇数因子。

若砍掉 TRIT_INJ、直接 `DMC = t0 + 3·q[6:0]`：`t0` 在 `3 | δ` 时冻，DMC 只走 128 组。这就是“只反转不够”。根因节已经写了，数据路径不允许走这条短路。

H0/H1 直方图 `{2,1,1}` 对 `{0,1,2}` 不均。AP 上 8b 折叠是否满 4 个 2b 值，取决于哪些位翻转。`δ = 3`：`h1_bits = G[7:0]` 以 3 步进，`gcd(3,256)=1`，满 256 点，H1 满。`h0_bits = G[17:10]` 以 3 步进每当低 10b 进位，约每 1024/3 步；8GiB 窗口里 ~1.6×10^7 / 341 ≈ 4.7×10^4 次翻转，H0 不是常数。`δ = 3072`：H1 冻，H0 以 3 步进满跑 `G[17:10]` 的 8b 场（`gcd(3,256)=1`），`t0'` 满 `Z_3`。这正是 DMC 因子 3 最需要活的场景。

### 2.3 容量 / 端口 / 位宽

| 结构 | 容量 | 位宽 | 端口 | 副本 |
| --- | --- | --- | --- | --- |
| MOD9_PRE | 组合 CSA | 55b → 4b | 组合 | ×120 |
| H0/H1 XOR-fold | 8+8 个 XOR + 2 个 2b 模 3 | 8b→2b→2b | 组合 | ×120 |
| trit 加 | 2 个 2b 加 | 2b+2b | 组合 | ×120 |
| bitrev11 | 0 GE，接线 | 11b | 组合 | ×120 |
| DIGIT_DEC | 7b 移位加 2b | 出 9b DMC + 6b bank | 组合 | ×120 |
| GOOD_MAP | 384 × 48b | 48b | 1R 共享 | ×1 |
| XOR_RETRY | 6b XOR + 比较 48 | 6b | 组合 | ×120 |

无乘法器。无 RAM 在组合映射路径。16×4 那种 ROM 也不要——那是另一张卡的代数对象。

### 2.4 Partial-good

DMC 在发行后不变。只改 `bank_in`。

```
b0 = bank_in                               // 0..47
if mask[b0] == 0:
    b1 = (b0 ⊕ live5)                      // live5 = h1_bits[4:0]（低 8b 折叠源，小 stride 活）
    if b1 ≥ 48: b1 = b1 − 32               // 6b XOR 最大 63；减 32 不是 +1 扫描，落到 0..31
if mask[b1] == 0:
    b2 = (b1 ⊕ {h0_bits[2:0], 2'b01}) 
    if b2 ≥ 48: b2 = b2 − 32
```

第二次重试用 H0 的位，避免两次 XOR 落回同一 trit 类。1/3 图案若按 `bank_in % 3` 杀 bank，第一次 XOR 6b 编码会改 `t1'` 的编码，通常离开被杀类。仍禁止 `+1`。

### 2.5 时序与因果

1 拍组合：MOD9_PRE 的 CSA 深度 ~4，XOR 深度 3，模 3 加深度 2，bitrev 深度 0。总深度 < 10 级 XOR/加，7nm 2 GHz 一拍可合。partial-good 再加 1 拍 SRAM。无状态。无 warmup。纯函数。

## 3. 为什么有效

代数对象是混合进制的数位置换，加上 `Z_3^2` 上的平移。不是 Feistel，不是多项式 MAC，不是步长 FSM，不是基 3 CSA 树。

DMC 像。`DMC = t0' + 3·q[6:0]`。`q[6:0]` 是 `p[10:4]` 的反转：2 幂 stride 下 `p` 的低位冻、高位走，反转后冻的位到高、走的位到低，128 组被扫开。奇数因子：`t0' = t0 + H0 (mod 3)`。`3 | δ` 时 `t0` 冻，但 H0 来自 `G[17:10]`。

`δ = 3`：H1 满，H0 慢变，`t1'` 满 `Z_3`，`t0'` 在长窗口满。`δ = 24 = 3·2^3`：`G[2:0]` 冻，`h1_bits = G[7:0]` 的高 5b 仍走，H1 变。`δ = 3072`：H0 满 `Z_3`，`t0'` 满，**DMC 的 3 个剩余全在**。这是占用从 128 回到 384 的机制级理由：`t0'` 不是 `G mod 3`，是 `G mod 3` 加一个与 `δ` 的 2-adic 高段同余的折叠。折叠是 XOR 不是 `mod 3` 同态，不把 `3 | δ` 传进 `H0`。

XOR 折叠不是 `Z_3` 同态：`H0(x+3) − H0(x)` 不恒 0。8b 场加 3 改变低 2b 的模式，两路 4b XOR 至少一路翻转，`H0_2` 以 1/2 量级的概率变（不是定理，是组合开关计数）。**此处不装成已证满射。** 8GiB 窗口步数足够把 2b 状态打满，是经验覆盖，不是群论双射。

Amdahl：`X_rel = 3` 对应 384→128。`t0'` 满 3 类则这项回 1。Little：15360 / 384 = 40 vs 15360 / 128 = 120。1 拍 mapper 相对 128 outstanding 可忽略。roofline：带宽墙。

min/mean：接线+注入在 AP 上若 trit 均匀，期望 0.9–1.0。H0 直方图 2,1,1 会留下 ~2:1 的 trit 偏置，min/mean 可能落到 ~0.7–0.9 而不是 1.0。这是这张卡相对 M-1 ROM 平衡直方图的代价。不把 0.85 写成已达到。

## 4. 评估计划

- 基线: ModMapper %31, Mod192Mapper %192, Mod248Mapper %248, plus a power-of-two-only XOR mapper that is uniform on 2^k strides
- 指标: n_DMC, n_bank, min/mean R/W BW, X_rel, occupancy vs min(384,K)
- 负载: 8GiB shared, outstanding 128, S ∈ {512B, 1KiB, 1536B, 3KiB, 4608B, 12KiB, 1.5MiB, 2MiB} × sequential AP, plus bank partial-good 0%/6%/12% random and 1/3-patterned
- 必须 cycle 级建模的结构: RADIX_SPLIT（含 G mod 9 → 两 trit）、H0 取 A[26:19]、H1 取 A[16:9]、2b 模 3 加、bitrev11 接线、DIGIT_DEC 公式 `t0'+3·q[6:0]` 与 `t1'+3·q[10:7]`、GOOD_MAP 1R、仅 bank_in 的 XOR 重试（DMC 锁定）。必须有一个对照实验：**关掉 TRIT_INJ 的纯数位反转**，预期 `S=3·2^k` 上 n_DMC 仍是 128，用来证伪“反转就够”。
- 预期收益与置信度: n_DMC ~128 → 384（×3）若 H0 在该 S 上盖满 `Z_3`；min/mean ~0.7–1.0（直方图偏置）。置信度 **中**：接线延迟硬；XOR-fold 满 `Z_3` 不是定理；1/3 图案对 `t1'` 再相关。纯反转对照必须失败，否则这张卡的根因是错的。

## 5. 硬件开销估算

- 逻辑：每核 ~2×10^2 GE（MOD9_PRE 是大头，H 折叠和 trit 加是小头，bitrev 是线）。7nm **~10^{-4} mm² / 核**。×120：**~10^{-2} mm²**。五张卡里最便宜。
- SRAM：仅共享 GOOD_MAP **~10^{-2} mm²**。
- 功耗：每核 **0.1 mW** 量级 @ 2 GHz。共享 SRAM **1–10 mW**。
- 延迟：**1 拍** 组合 + **0/1 拍** SRAM。
