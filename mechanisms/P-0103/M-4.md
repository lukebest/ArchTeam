# M-4: Cut-Resilient Mixed-Radix Digit Reversal (CR-MRDR) — 割切鲁棒混合进位数位反转

- problem: P-0103
- id: P-0103/M-4
- author: Jim Keller
- replaces: 冻结窗 MRDR（T1 否决：1.5MiB 上 11b 熵把 n_DMC 锁死在 6）

## 1. 根因分析

整数取模 `f(G)=G mod N` 是环同态。`δ ≡ 0 (mod 3)` 时像落在 `3Z` 的陪集，DMC 因子 3 被吃掉，`n_DMC = min(384,K)/3 = 128`，`X_rel = 3`。

上一版 MRDR 的结构是：把 `p = G[10:0]`（正好是 `N_bank` 的 2^11 因子）拆成 11 个二进制数位 + 2 个 trit，注入后再反转。T1（Dr. Archi）把它在 `S = 1.5MiB` 上算穿了：

- `S = 3·2^19 = 1.5MiB`，粒号步长 `δ = 3·2^{10} = 3072`。
- `G[9:0]` 冻结。`p = G[10:0]` 只剩 `p[10]` 一拍一跳。
- `q[i] = p[10−i]` 之后，`q[6:0] = {p[10], p[9], …, p[4]}` 只有 LSB 活，128 个 DMC 组塌成 **2** 档。
- trit 注入最多再乘 3。`n_DMC = 2 × 3 = 6`，不是 384。

这不是「11 改成 16」能救的。根因是：**数位取自命名 18432 桶的那截 2-adic 窗口，窗口宽度 ≤ 步长的 2 进位赋值时，反转只是把那一位置换一下，活熵还是 1 bit。** 加宽同一窗口仍是同一对象上的位宽调参。

本卡重做的是**数位本身**。每个二进制数位改成跨冻结边界的 3 抽头 GF(2) 线性型：低位（小步长活）+ 中位（1.5MiB 活）+ `G[21]`（≤2MiB 的行走位）。然后再反转、再注入 trit。反转仍然打 2 幂步长；3 抽头打的是「11b 窗在大 `3·2^k` 上冻死」这条 T1 致命路径。

冻结信封不变：384 DMC / 18432 bank / 因子 3 不改。只改交织数据通路。

## 2. 机制

### 2.1 结构

1. **LIVE_DIGIT**：11 个二进制数位，每个 3 抽头 XOR，不是 `G[10:0]` 的接线。
2. **TRIT_SRC**：两个不相交的无权重 mod-3 和（不是 `G mod 9`，那在 `9|δ` 时冻）。
3. **TRIT_INJ**：`t0' = (t0 + H0) mod 3`，`t1' = (t1 + H1) mod 3`。H0/H1 来自与数位抽头错开的 8b 折叠。
4. **DIGIT_REV**：11 个数位倒序接到 DMC 组 / bank 组。
5. **DIGIT_DEC**：`DMC = t0' + 3·q[6:0]`，`bank_in = t1' + 3·q[10:7]`。
6. **GOOD_MAP**：384×48b 位图 + 仅 bank_in 的 XOR 重试。禁止 `+1`，禁止改 DMC。

无 ROM。无 stride FSM。1 拍组合。

### 2.2 数据路径

`G = A[63:9]`。`G[k] = A[k+9]`。

**T1 杀手步长的位图（必须写清，评估要打印翻转计数）：**

| S | δ_blocks | 冻结 | 行走 |
| --- | --- | --- | --- |
| 1536B = 3·2^9 | 3 | 无（gcd(3,2^n)=1 对低位） | `G[1:0]` 每步被加 3 |
| 4608B = 9·2^9 | 9 | `G mod 9` 冻 | `G[0]` 与 `G[3]` |
| 1.5MiB = 3·2^19 | 3072 = 2^10+2^11 | `G[9:0]` | `U := G>>10` 每步 +3 |
| 2MiB = 2^21 | 4096 = 2^12 | `G[11:0]` | `G[12+]` |

上一版 `p=G[10:0]` 在第三行只剩 1 bit。本卡每个数位跨这三条冻结线：

```
// i = 0..10。低抽头 G[i]：小步长活。
// 中抽头 G[i+11]：1.5MiB 时落在 U[i+1] = G[11+i]，U+=3 满跑。
// 高抽头 G[21]：所有 S≤2MiB 的行走位（S=2MiB 时 G 步长 2^12，G[21] 必走）。
d[i] = G[i] ⊕ G[i+11] ⊕ G[21]
```

`S=1.5MiB` 时 `G[0..9]` 冻，但 `d[0] = 冻 ⊕ G[11] ⊕ G[21]`。`G[11]=U[1]`，`U+=3` 且 `gcd(3,256)=1`，`U[7:0]` 满 256 点。`d[6:0]` 作为 7 向量含 `U[1]..U[7]` 加公共 `G[21]`：`U[7:1] = (U>>1) mod 128`，`U` 跑满 256 时 `U>>1` 跑满 128（每个值两次）。**128 个 DMC 组全在。** 这就是对 T1「n_DMC=6」的直接否定：组索引不再等于冻住的 `p[10:4]`。

`S=2MiB` 时 `G[11:0]` 冻，`G[i]` 与 `G[i+11]` 对 `i≤0` 可能冻，但 `G[21]` 进入**每一个** `d[i]`，7 个组 bit 至少有公共行走位；再加 `i≥1` 的中抽头 `G[12]..G[21]`。组索引不能塌成 2 档。

反转：

```
q[j] = d[10−j]          // j=0..10，纯接线
t0   = (G[0]+G[3]+G[6]+G[10]+G[13]+G[16]+G[19]) mod 3
t1   = (G[1]+G[4]+G[7]+G[11]+G[14]+G[17]+G[20]) mod 3
H0_2 = { ⊕ A[28:25] , ⊕ A[24:21] }     // G[19:12]，1.5MiB 上满跑
H1_2 = { ⊕ A[18:15] , ⊕ A[14:11] }     // G[9:2]，与 H0 不相交
H0   = (H0_2 == 3) ? 0 : H0_2          // {0,1,2,0}
H1   = (H1_2 == 3) ? 0 : H1_2
t0'  = (t0 + H0) mod 3
t1'  = (t1 + H1) mod 3
DMC  = t0' + 3 · q[6:0]                // 0..383
bank_in = t1' + 3 · q[10:7]            // 0..47
die  = DMC[8]
HA   = DMC[7:1]
pipe = DMC[0]
```

`H0` 取 `G[19:12]`：`S=1.5MiB` 时这 8b 落在 `U[9:2]`，`U+=3` 满跑，`t0'` 满 `Z_3`。组 128 × trit 3 = **384**。上一版 H0 只救了 trit，救不了已经冻死的 `q[6:0]`——那是 T1 的 6。本卡 `q[6:0]` 自己就活。

消融（评估必跑）：把中抽头和高抽头剪掉，只留 `d[i]=G[i]`。`S=1.5MiB` 必须回到 `n_DMC=6`。回不去说明 T1 杀手没打到。

### 2.3 容量 / 端口 / 位宽

| 结构 | 容量 | 位宽 | 端口 | 副本 |
| --- | --- | --- | --- | --- |
| LIVE_DIGIT 3-XOR | 11 × 2 XOR2 | 3×1b → 1b | 组合 | ×120 |
| TRIT_SRC 两路 7 输入 mod-3 | CSA + 8×2 LUT | 7b→2b | 组合 | ×120 |
| H0/H1 8b 折叠 | 8+8 XOR + 2b 模 3 | 8b→2b | 组合 | ×120 |
| trit 加 | 2 × 2b 加 | 2b+2b | 组合 | ×120 |
| DIGIT_REV | 0 GE，接线 | 11b | 组合 | ×120 |
| DIGIT_DEC | 7b 拼接 + 2b | 9b DMC + 6b bank | 组合 | ×120 |
| GOOD_MAP | 384 × 48b | 48b | 1R 共享 | ×1 |
| XOR_RETRY | 6b XOR | 6b | 组合 | ×120 |

无乘法器。无每核 ROM。与被否决的那张卡相比，多的是每数位 2 个 XOR，不是更宽的 `G[n:0]` 窗口。

### 2.4 Partial-good

DMC 在发行后不变。只改 `bank_in`。

```
mask = GOOD_MAP[DMC]
b0 = bank_in
if mask[b0] == 0:
    b1 = (b0 ⊕ live5)           // live5 = G[21:17]，1.5MiB / 2MiB 都活
    if b1 ≥ 48: b1 = b1 − 32    // 不是 +1 扫描
if mask[b1] == 0:
    b2 = (b1 ⊕ {G[16:14], 2'b01})
    if b2 ≥ 48: b2 = b2 − 32
```

1/3 图案按 `bank_in % 3` 杀 bank 时，XOR 改的是 6b 编码，会离开被杀 trit 类。禁止 `+1`（沿陪集滑）。禁止跨 DMC 弹跳。

### 2.5 时序与因果

1 拍组合：3-XOR 深度 2，mod-3 CSA 深度 ~4，trit 加深度 2。总深度 < 10 级。partial-good 再加 1 拍 SRAM。无状态。无 warmup。纯函数。不看未来 stride。

## 3. 为什么有效

被否决的对象是「对 `G[10:0]` 做数位反转」。本卡的对象是「对跨冻结边界的 3 线性型做数位反转」。不是把 11 改成 24。

`S=1.5MiB`（T1 杀手）。`U = G>>10`，`U += 3`。`d[i] = 冻 ⊕ U[i+1] ⊕ G[21]`（`i=0..6` 时 `i+11 ≥ 11`）。`U[7:1]` 满 128，故 `q[6:0]` 满 128 组。`H0` 吃 `G[19:12]` 满跑，`t0'` 满 `Z_3`。`n_DMC = 128×3 = 384`。上一版 `q[6:0]` 只有 `p[10]`，`n_DMC=6`。差在数位定义，不在 ROM、不在预测器。

`S=1536B`，`δ=3`。低抽头 `G[i]` 以 3 步进，`gcd(3,2^i)` 管不了 XOR 的低位翻转；`G[1:0]` 每步被加 3，`d[0],d[1]` 变。trit 和 `H1` 活。

`S=4608B`，`δ=9`。整数 `G mod 9` 冻，无权重 trit 仍吃 `G[0]` 与 `G[3]`（9=8+1）。中抽头 `G[11+i]` 间歇进位。不是 `G mod 9` 同态。

`S=2MiB`，`δ=2^{12}`。无因子 3。每个 `d[i]` 含 `G[21]`，组索引随 AP 走，不会冻成 1 个 DMC。2 幂均匀性靠反转：小 2 幂步长冻低位，反转后冻的数位到高、走的到低，128 组被扫开。

Amdahl：`X_rel=3` 对应 384→128。T1 实测是 384→6（`X_rel=64`），更差。本卡在杀手步长上把组索引从 2 拉回 128，trit 从「乘在塌缩组上」变成「乘在满组上」。Little：15360 outstanding / 384 ≈ 40，对比 6 个 DMC 时 2560/DMC。1 拍 mapper 被 128 outstanding 盖住。roofline：带宽墙。

XOR 3 线性型不是 `Z_3` 同态，也不宣称是 18432 上的双射。`n_DMC=384` 的机制级理由是：杀手步长上 7 个组 bit 的中/高抽头张成满 `F_2^7`（`U>>1` 满 128），不是直方图猜想。

**未证严：**（1）11 个 3 抽头在 GF(2) 上对 28b 地址的秩未算，不声称对 18432 双射。（2）公共 `G[21]` 让 `d[i]` 相关；满 128 靠的是中抽头 `U[1..7]` 几乎是移位，公共 XOR 不降秩。（3）H0 直方图 `{2,1,1}` 仍偏置，min/mean 可能落到 0.7–0.9。不把 0.85 写成已达到。

## 4. 评估计划

- 基线: ModMapper %31, Mod192Mapper %192, Mod248Mapper %248, plus a power-of-two-only XOR mapper that is uniform on 2^k strides
- 对照（必须）: **冻结窗 MRDR**（`d[i]=G[i]`，其余相同）。`S=1.5MiB` 上预期 n_DMC=6，用来复现 T1。
- 指标: n_DMC, n_bank, min/mean R/W BW, X_rel, occupancy vs min(384,K)。**主指标是 `S=1.5MiB` 的 n_DMC，必须是 384 不是 6。**
- 负载: 8GiB shared, outstanding 128, S ∈ {512B, 1KiB, 1536B, 3KiB, 4608B, 12KiB, 1.5MiB, 2MiB} × sequential AP, plus bank partial-good 0%/6%/12% random and 1/3-patterned
- 必须 cycle 级建模的结构: 11 个 3 抽头 `G[i]⊕G[i+11]⊕G[21]`、两路 7 输入 mod-3、H0=`fold(G[19:12])`、H1=`fold(G[9:2])`、接线反转、`DMC=t0'+3·q[6:0]`、GOOD_MAP 1R、仅 bank_in XOR 重试。评估必须打印 `S=1.5MiB` 下 `d[0..6]` 的翻转计数和 `|{q[6:0]}|`（预期 128，对照卡预期 2）。
- 预期收益与置信度: 杀手步长上 n_DMC 6→384（相对冻结窗 ×64；相对整数取模的 128 是 ×3）。min/mean ~0.7–1.0（trit 直方图偏置）。置信度 **中高**：`U+=3` 满 128 组是 2-adic 计数；trit 满 `Z_3` 靠 H0 折叠，不是定理。1/3 图案可再相关。

## 5. 硬件开销估算

- 逻辑：每核 ~3×10^2 GE（相对旧 MRDR 多 22 个 XOR2）。7nm **~10^{-4} mm² / 核**。×120：**~10^{-2} mm²**。
- SRAM：仅共享 GOOD_MAP **~10^{-2} mm²**。
- 功耗：每核 **0.1 mW** 量级 @ 2 GHz。共享 SRAM **1–10 mW**。
- 延迟：**1 拍** 组合 + **0/1 拍** SRAM。无 warmup。
