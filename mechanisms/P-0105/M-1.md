# M-1 割切鲁棒 XOR 铺散（CRXS）

- problem: P-0105
- id: P-0105/M-1
- author: Jim Keller

## 1. 根因分析

冻结包络不变：2×Die2，每 die 60 AI 核 / 96 HA，每 HA 2 pipe，每 pipe 1 DMC，每 DMC 48 bank。整机 120 核 / 384 DMC / 18432 bank。只改交织；粒度 512 B；页 4 K；共享作业 8 GiB；每核 128 独立 outstanding；步长 1 B–2 MiB；必须覆盖 bank partial-good。

记号。`G_bit[k] := phys_addr[k]`（k≥9 才进交织；粒度 512 B = 2^9）。整数粒号 `G := phys_addr >> 9`。割切 `c ∈ {9,…,21}` 对应步长 `S = 2^c`：流中 `phys_addr[c-1:0]` 为相位/base（2^c 对齐时冻结，否则冻结但随 base 变），`phys_addr[≥c]` 随请求下标行走。S=2 MiB 时 c=21：相位是 `addr[20:0]`，行走是 `addr[≥21]`。8 GiB / 2 MiB = 4096 个点；这 4096 点是 18432 bank 的一个**滑动子集**，子集随 start address 平移。

1D 线性映射 `DMC = G mod 384` 保格子。S=2 MiB 时粒号步进 4096，`gcd(4096, 384) = 128`，只命中 `384/128 = 3` 个 DMC，且是 `a, a+128, a+256 (mod 384)`。`a` 由 base 决定——格子整体滑过 DMC/HA 分区。顺序低位交织把 DMC 钉在 `G` 低 9 bit：S=2 MiB 时低 12 个粒号 bit 冻结，`n_DMC = 1`，**哪 1 个**随相位变。仅高位交织在 S=2 MiB 看起来均匀（行走位就是高位），但 S=512 B 时高位冻结，全部流量砸进同一组 DMC。三条基线都是同一失败模式的切片：**线性同余保格子，相位一滑，控制器占用多重集就变。**

人钉症状：同样的 stride、只改 start address，R/W BW 抖动；实验室要的正是 same-base/same-phase vs wrong-phase。假设：存在固定 S，只改 start，使 min/mean BW 跨过 0.85，或占用控制器数变化 ≥2×。单轴容量 2 / 96 / 2 / 48 都 <4096；联合 18432 也不能在**一条** 1D 轴上吸收 4096 个自由度。要的不是“全空间均匀”，是**每一个割切 c 上，占用对相位平移不变**。

Little 定律：120×128 = 15360 inflight。均匀时 384 DMC × ~40 outstanding/DMC；1D 坏相位 3 DMC × 5120 outstanding——队列把有效 BW 钉死在 3/384。4096 点若均匀落 384 DMC，~10.67 hit/DMC；1D 坏相位可把全部 hit 堆到 128 乃至 1 个 DMC（占用控制器 ≥3× 摆动）。

## 2. 机制

GF(2) 线性铺散。15 bit 身份 `{die1, HA7, pipe1, bank6} = H · G_bit[36:9]`，H 是 15×28 矩阵。硬约束：对**每一个** c∈{10,…,21}（c=9 是粒度本身，粒度内 bit 不进 H，AP 就是连续粒号，天然平移不变），**每一个**输出 bit 在列 ≥c 至少 1 个非零系数（随 AP 走）**并且**在列 <c 至少 1 个非零系数（相位混入）。然后 XOR Latin：冻结相位 P、行走 W，`out = A·P XOR B·W`，B 每行非零 ⇒ W 扫过 dim≥1 的子空间时，out 扫仿射空间且**均匀、与 P 无关**。占用多重集对相位不变。

### 结构

显式 H（行 = 输出 bit i=0..14；列 = `phys_addr` bit）。每行强制含 `G[21]`、`G[9+(i mod 12)]`、`G[12+(i mod 8)]`、`G[24]`；再补两处洞：

- 所有行加 `G[9]`：否则 c=10 时只有 `i ≡ 0 (mod 12)` 的行在 <10 有抽头，其余行相位侧为空。
- 每行加 `G[22+(i mod 11)]`（落在 bit 22..32）。8 GiB 作业只走到 `phys_addr[32]`，bit 33..36 在作业内冻结，不能当唯一行走抽头；它们仍接在 H 的 28 列上供更大 PA 使用，但不承担割切鲁棒性。

| i | 字段 | 抽头 phys_addr bits |
|---|------|---------------------|
| 0 | die | 9, 12, 21, 22, 24 |
| 1 | HA[0] | 9, 10, 13, 21, 23, 24 |
| 2 | HA[1] | 9, 11, 14, 21, 24 |
| 3 | HA[2] | 9, 12, 15, 21, 24, 25 |
| 4 | HA[3] | 9, 13, 16, 21, 24, 26 |
| 5 | HA[4] | 9, 14, 17, 21, 24, 27 |
| 6 | HA[5] | 9, 15, 18, 21, 24, 28 |
| 7 | HA[6] | 9, 16, 19, 21, 24, 29 |
| 8 | pipe | 9, 12, 17, 21, 24, 30 |
| 9 | bank[0] | 9, 13, 18, 21, 24, 31 |
| 10 | bank[1] | 9, 14, 19, 21, 24, 32 |
| 11 | bank[2] | 9, 15, 20, 21, 22, 24 |
| 12 | bank[3] | 9, 16, 21, 23, 24 |
| 13 | bank[4] | 9, 10, 17, 21, 24 |
| 14 | bank[5] | 9, 11, 18, 21, 24, 25 |

此 15×28 矩阵 GF(2) 秩 = 15。S=2 MiB 行走子空间 bit 21..32 上的行秩 = 11（≤12，饱和），像空间 2^11=2048 点覆盖 384 DMC 足够。

解码（不改 96/48 计数，只折合）：

```
ha_raw  = HA[6:0]            // 0..127
ha      = (ha_raw < 96) ? ha_raw : ha_raw - 96     // 96..127 → 0..31
bank_raw= bank[5:0]          // 0..63
bank_in = (bank_raw < 48) ? bank_raw : bank_raw - 48 // 48..63 → 0..15
DMC     = ((die * 96 + ha) * 2 + pipe)             // 0..383
```

fold96 / fold48 在 7 bit→96、6 bit→48 上引入恒定 2:1 偏置（HA 0..31、bank 0..15 双倍）。这是恒定的 covering 偏置，**不随相位变**。不要用更多 DMC/bank 去抹平它。

### 数据路径

15 棵 XOR 树，每棵 4–6 输入（上表 n=5 或 6），组合逻辑，0 mapper SRAM。输入直接抽 `phys_addr[36:9]`。输出经上述比较-减法折合得到 DMC∈[0,383]、bank_in∈[0,47]。此后只查 partial-good 位图，不碰任何 load 表。

### Partial-good

384 × 48-bit SRAM = 18432 bit = 2.25 KB，每 DMC 一行，bit=1 表示该 bank 可用。命中坏 bank 时 48:6 优先编码器（PE）在同一 mapper 周期给出下一好 bank 编号，作为 1-cycle retry 的目标；不增加 DMC/HA 数量，不增加数据带宽。整 DMC 全坏则该行全 0，PE 无输出，请求在该 DMC 的 replay 路径上耗尽 outstanding——这是 partial-good 的既有语义，交织层不发明新的控制器。

### 时序

H 为纯组合 XOR + 两级 8 bit 比较减法，1 mapper cycle。位图 SRAM 1R 与 XOR 并行启动：地址先出 DMC/bank 猜测，后半拍用 PE 修正。总 mapper 延迟 1 cycle。不加 outstanding 缓冲。

## 3. 为什么有效

格子+phase。S=2^c 的请求是仿射格 `B + k·2^c`。H 把地址切成 P（<c）与 W（≥c）。每行在 W 上非零 ⇒ 输出第 i bit 作为 W 的非零线性型，W 沿格走一步至少翻一次；P 只提供仿射偏移。GF(2) 上这是 Latin：固定 P，W 扫子空间时 out 对每个陪集命中次数相等，与 P 无关。因此 **occupancy 多重集对 base 平移不变**。Wrong-phase 不再换一套控制器。

与 1D 对照。`G mod 384` 在 Z/384Z 上保格，步进 4096 ≡ 256，周期 3，占用集 `{a,a+128,a+256}` 随 a=base 滑——多重集的**标签**变，投影到 HA/pipe 的碰撞模式变。CRXS 的不变性在 GF(2) 向量空间，不保 Z-格。

Discrepancy。S=2 MiB、4096 点：代数像空间 ≥2^11，fold 后 n_DMC=384 对所有扫过的 page-offset 与 2 MiB 窗内 base 成立；maxload=16、minload=8（fold 2:1），CV≈0.354，**对 base 的相对差 = 0**。均匀目标 4096/384≈10.67；8 与 16 是折合偏置不是相位抖动。

Balls-and-bins 不是本机制的随机模型——这是确定性 Latin。Little：15360 inflight 在 384 DMC 上约 40/DMC，不再出现 5120/DMC 的 3 控制器锁死。n_HA=96、n_bank=48 在 S=2 MiB 对所有测试 base 保持满轴。

失败形态（不作过关宣称）：若某割切上有一行 B 行全零，该 bit 退化为纯相位函数，占用随 base 变，本卡作废。上表每行对 c∈[10,21] 同时含 bit 9 与 bit 21，堵住这条。

## 4. 评估计划

- 基线：`G mod 384`；顺序低位交织（DMC←G[8:0] 再 fold384）；仅高位交织（DMC←addr[32:21] mod 384）。
- 指标：对每个固定 S，扫 base，记 BW(base)、min/mean BW 的相对差 `(max-min)/mean`、`n_DMC(base)`、`n_HA(base)`、每 HA/DMC occupancy CV。成功判据（问题给定）：跨 base 的 min/mean BW 相对差 <5%；`n_DMC(base)` 变化 <10%。主指标是 **base 不变性**，不是 `n_DMC=min(384,K)`（后者 nice-to-have）。
- 负载：固定 S，base 扫一页内 `0..4K-512` 步 512 B，以及 2 MiB 对齐窗内平移；S∈{2 MiB, 1 MiB, 512 KB, 4608 B, 512 B}。4608 B=9×512，非 2 幂，专门打 `gcd(step, 384)` 这类 1D 漏洞。作业 8 GiB；每核 128 outstanding，总 inflight 15360。partial-good：随机 1/16 bank 拉黑（每 DMC 约 3 坏 / 45 好），重复上述扫。
- **必须 cycle 级建模的结构**：15×28 XOR 矩阵（组合，按上表接线，禁止用 `xor-reduce of all bits` 之类简化）；fold96/fold48 比较减法；2.25 KB 位图 SRAM 1R；48:6 PE 的 1-cycle retry。不要抽象成“随机 hash”。
- 预期收益与置信度：相对 1D，S=2 MiB 的占用从 3 DMC 升到 384，inflight 从 5120/DMC 降到 ~40/DMC；跨 base 的 n_DMC 相对差 → 0（代数不变性）。置信度高：XOR Latin 在 GF(2) 上对每个割切可证；剩余风险是 fold96/fold48 的 2:1 恒定偏置进入 min/mean 的**绝对值**（不进入跨 base 相对差），以及 PE retry 在 1/16 坏 bank 下的二次冲突。不作过关宣称。

## 5. 硬件开销估算

- XOR：15 树 × 平均 5.5 输入 ≈ 70 个 XOR2，5 nm 量级 <0.001 mm²。
- fold：两套 8 bit 比较器 + 减法器，可忽略。
- SRAM：2.25 KB 位图，单口，mapper 时钟 1R；PE ≈ 48 输入优先编码，~0.5k gate。
- mapper SRAM 除位图外为 0。不增加 384 DMC / 18432 bank / 96 HA。不增加数据带宽，不加 outstanding 缓冲。
- 延迟 1 cycle；功耗 mW 级（XOR 树 + 2.25 KB SRAM 漏电与 1R）。面积主导是 2.25 KB 位图，不是 H。
