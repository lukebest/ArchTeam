# M-5 轴均衡二维仿射（AB2A）

- problem: P-0105
- id: P-0105/M-5
- author: Jim Keller

## 1. 根因分析

冻结包络：2×Die2；每 die 60 核 / 96 HA；2 pipe/HA；1 DMC/pipe；48 bank/DMC。整机 120 核 / 384 DMC / 18432 bank。只改交织；粒度 512 B；页 4 K；8 GiB 作业；128 outstanding/核独立；步长 1 B–2 MiB；必须覆盖 bank partial-good。

`G := phys_addr >> 9`。S=2 MiB：相位 bit<21，行走 bit≥21。8 GiB/2 MiB=4096 点，滑动子集。1D `DMC = G mod 384`：**保格**。粒号步进 4096，`gcd(4096,384)=128`，只命中 3 个 DMC `a, a+128, a+256`，`a` 随 base——这就是 wrong-phase。顺序低位把相位钉在低位，n_DMC=1。仅高位小步长冻高位。根因不是“不够均匀”，是 **1D 线性图把 4096 个自由度倒进一条轴**；每条轴容量 2 / 96 / 2 / 48 都 <4096，联合 18432 也救不了单轴塌缩。相位一滑，占用多重集变，min/mean R/W BW 抖。

人钉症状 + 实验室 “same base/same phase vs wrong phase” 就是这个 bug。假设：存在固定 S 只改 start，使 min/mean BW 跨 0.85，或占用控制器数 ≥2× 变化。要的图：每个轴上的占用对**每一个**割切 c∈[9,21] 平移不变。本卡是该命题在 Z_n 上的 2D 仿射版本（对照 M-1 在 GF(2) 上的两侧支撑）。

Little：15360 inflight。1D 坏相位 3 DMC × 5120 outstanding；均匀 384 × ~40。4096/384≈10.67 hit/DMC 若联合均匀。

## 2. 机制

不要把 4096 DOF 倒进一条轴。每个轴独立仿射，两个系数都与该轴模互素，于是每个割切仍在该轴上行走：

```
x = phys_addr[20:9]     // 12b
y = phys_addr[32:21]    // 12b
HA      = (11*x + 13*y) mod 96     // gcd(11,96)=gcd(13,96)=1
bank_in = ( 5*x +  7*y) mod 48     // gcd(5,48)=gcd(7,48)=1
```

die / pipe 是 2 元轴，用两侧 XOR（GF(2) 1-bit 仿射），但行走抽头必须高于 HA 模数的 2-幂核：

96 = 2^5 · 3。S=2 MiB 时 x 冻结、`HA ≡ const(x) + 13y (mod 96)`，`gcd(13,96)=1` ⇒ y mod 96 被 HA 决定 ⇒ **y[4:0] 是 HA 的函数**。若 `die = x[0] XOR y[0]`、`pipe = x[3] XOR y[2]`（题目初值），则 die、pipe 都是 HA 的函数，联合 DMC 只剩 96 个——轴间不独立，4096 点的联合像塌成 HA 轴。这是必须补的洞：行走抽头改到 y[5]、y[6]（addr[26]、addr[27]），仍各取相位侧 1 bit + 行走侧 1 bit，跨过 cut 21，但不落在 2^5 核里。

```
die  = x[0] XOR y[5]      // addr[9] XOR addr[26]
pipe = x[3] XOR y[6]      // addr[12] XOR addr[27]
DMC  = ((die * 96 + HA) * 2 + pipe)    // 0..383 的双射
```

对偶：x 侧 48=2^4·3、96=2^5·3 同样吃 x[4:0]；die 用 x[0]（相位，cut 21 下全部 x 都是相位）、pipe 用 x[3]，小步长时 x 行走、y 近似冻，HA 决定 x[4:0]，die/pipe 的 x 抽头落在核内——小步长 AP 稠密，y 的高 bit 仍随作业窗走。S=2 MiB 是本问题的硬割切，优先保证这一侧独立。

### 结构

平移不变性（HA 轴，S=2 MiB，x 冻）：

```
HA(k) = (11x + 13 k) mod 96,   k = 0..4095
gcd(13,96)=1 ⇒ k ↦ 13k 是 Z/96Z 的置换
```

每个 HA 被命中 42 或 43 次（4096 = 42×96 + 64）。换 base 只换 `11x` 这个旋转量，**占用多重集 {42×32 个, 43×64 个} 不变**（64 来自 4096 mod 96=64）。min/mean BW vs base 的相对差 → 0（理想）。bank 同理：`gcd(7,48)=1`，占用 85 或 86（4096=85×48+16）。die、pipe 在 y[5]、y[6] 上随 k 以 32、64 为周期翻转，与 HA 独立 ⇒ 联合 n_DMC=384，DMC 占用 10 或 11（fold 式 covering：4096=10×384+256），CV≈0.044。

对照 1D `G mod 384`：步进 4096，gcd=128，只有 3 个 DMC，**哪 3 个**随 base——占用集的标签变，投影到 HA 的碰撞随相位变。本卡 HA 轴永远满 96，标签旋转但多重集不变。这是 Z_n 上“每个割切两侧都有支撑”的 2D 版本，与 M-1 的 GF(2) 矩阵、M-2 的双线性、M-3 的双哈希、M-4 的 S-box 都不同构。

### 数据路径

常数乘全是移位加，12×7 位宽：

- `11x = (x<<3) + (x<<1) + x`
- `13y = (y<<3) + (y<<2) + y`
- `5x  = (x<<2) + x`
- `7y  = (y<<3) - y`

两个模约简：

- `mod 96`：96=2^5·3。17 bit 以内的 `11x+13y`（最大 11×4095+13×4095=98280）用 Barrett：`q = (n * 683) >> 16`（683 ≈ 2^16/96），`r = n - q*96`，再 0..2 次减/加 96。禁止 1000 级减法链。
- `mod 48`：48=2^4·3。同结构，magic ≈ 2^16/48=1365，`5x+7y` 最大 12×4095=49140。

die/pipe：各 1 XOR。DMC 拼接：`die<<? ` 用 `die*192 + HA*2 + pipe`（`*192=(<<7)+(<<6)`）。

无 mapper SRAM 除位图。无负载表。

### Partial-good

384×48-bit = 2.25 KB 位图 + 48:6 PE，1-cycle retry。仿射输出是猜测；坏 bank 不反馈进仿射系数（那会引入数据相关，毁掉平移不变式）。1/16 坏 bank 下占用多重集仍由仿射决定，PE 只在 bank 轴上做局部置换，HA/DMC 轴不变。

### 时序

移位加 + Barrett 折合 + 2 XOR 组合进 1 mapper cycle。若 mapper 时钟跟核频，Barrett 的 17×10 乘法可拆成“移位加近似 1/96”（`n * 2^10 / 96 ≈ n * 10.66`，用 `n+(n>>1)+(n>>2)+(n>>4)` 再校正）仍 1 拍。位图 1R 并行。不加 outstanding 缓冲。

## 3. 为什么有效

格子+phase。S=2^c，坐标 (x,y) 一个冻一个走（c=21 冻 x 走 y；c=9 粒号连续，x 每步 +1）。冻 x 走 y 时，HA 是 `const + 13y mod 96`，互素 ⇒ 满轴均匀，相位只旋转标签。bank 同。die/pipe 两侧各 1 bit，大步长必走。占用多重集平移不变 ⇒ min/mean BW vs base 相对差理想为 0。Wrong-phase 不再换一套控制器。

Latin 在这里是 Z_n 上的单循环覆盖，不是 GF(2) Latin square。Discrepancy 就是覆盖剩余：HA 42 vs 43（相对 42.67 为 ±0.8%），bank 85 vs 86，DMC 10 vs 11（相对 10.67 为 ±3%）。这些是 covering 偏置，对所有 base 相同，不进跨 base 相对差。

Balls-and-bins 不适用。Little：15360/384≈40 outstanding/DMC；最热 11 hit ×3.75≈41。1D 的 5120 是 125×。联合空桶：填洞后 S=2 MiB n_DMC=384，空桶 0。未填洞（y[0]/y[2]）时 n_DMC=96 恒定——多重集仍不变，但 288 个联合空桶把 inflight 集中到 160/DMC，是 leftover 不是相位抖动；主指标过、次指标不过。本卡采用填洞后的抽头，主次一起对准。

证伪路径（问题给定）：若所有可逆图都对任意 base 与 S∈[1 B,2 MiB] 有 min/mean BW 相对差 <5%，则“存在坏相位”的假设不成立。本卡给出一个具体可逆图（各轴系数互素 ⇒ 每轴置换），其占用多重集对 S=2 MiB 的所有 base 代数不变；若 cycle 模型里 BW 仍随 base 抖，抖动源不在占用而在 DRAM 时序/partial-good 对齐，应记为剩余，不是映射失败。

## 4. 评估计划

- 基线：`G mod 384`（S=2 MiB 必现 n_DMC=3、maxload=1366、CV≈11.27）；顺序低位交织（n_DMC=1、maxload=4096）；仅高位交织（S=2 MiB 看似均匀，S=512 B 应塌）。
- 指标：min/mean BW vs base 相对差、n_DMC(base)、occupancy CV per HA/DMC。主指标：跨 base 相对差 <5%，n_DMC 变化 <10%。次指标 `n_DMC=min(384,K)` 在 S=3·2^k 上 nice-to-have，不是本题主指标。
- 负载：固定 S 扫页内 base `0..4K-512` 步 512 B，及 2 MiB 对齐平移；S∈{2 MiB, 1 MiB, 512 KB, 4608 B, 512 B}；partial-good 1/16 bank；inflight 15360。消融：die/pipe 改回 y[0]/y[2]，应看到 n_DMC 从 384 掉到 96 但跨 base 仍不变——用来分离“轴独立”与“相位不变”。
- **必须 cycle 级建模的结构**：两路模 MAC（`11x+13y mod 96`、`5x+7y mod 48`，含 Barrett/校正，禁止用无限整数 `%` 代替 17 bit 数据通路）；die/pipe 的 2 XOR（抽头 addr[9]/[26]、addr[12]/[27]）；拼接到 DMC 的移位加；2.25 KB 位图。不要抽象成“随机 2D hash”。
- 预期收益与置信度：S=2 MiB 相对 1D，占用 3 DMC → 384 DMC，maxload 1366 → 11，HA 满 96 且 42/43 覆盖与 base 无关，跨 base 相对差代数上为 0。置信度高：互素 ⇒ 置换 ⇒ 多重集不变，可在 Z_n 上写完。剩余风险：Barrett 校正实现若与数学 mod 不一致会引入相位相关的 off-by-96；partial-good 1/16 与旋转后的 bank 标签对齐可能造成 BW 绝对值差（多重集仍不变，但好 bank 集合不旋转）。不作过关宣称。

## 5. 硬件开销估算

- 两路 12 bit 移位加 + 两个 Barrett（17×10 量级或移位近似）：<0.005 mm²。
- 2 XOR + DMC 拼接：可忽略。
- 位图 2.25 KB + 48:6 PE。
- 不改 384 DMC / 18432 bank / 96 HA，不加带宽，不加 outstanding 缓冲。
- 1 cycle；功耗 mW 级。面积主导 2.25 KB 位图。
