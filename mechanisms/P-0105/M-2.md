# M-2 双线性平面函数破相（BPPB）

- problem: P-0105
- id: P-0105/M-2
- author: Jim Keller

## 1. 根因分析

冻结包络：2×Die2；每 die 60 AI 核 / 96 HA；2 pipe/HA；1 DMC/pipe；48 bank/DMC。整机 120 核 / 384 DMC / 18432 bank。只改交织；粒度 512 B；页 4 K；8 GiB 共享作业；每核 128 独立 outstanding；步长 1 B–2 MiB；必须覆盖 bank partial-good。

`G := phys_addr >> 9`。S=2 MiB 时 bit <21 是相位/base，bit ≥21 随请求下标走。8 GiB / 2 MiB = 4096 个点。这 4096 点是 18432 bank 里随 start address **滑动**的子集，不是全空间均匀问题。

1D 线性 `DMC = G mod 384` 保格：粒号步进 4096，`gcd(4096,384)=128`，只占 3 个 DMC，哪 3 个由 base 决定。顺序低位：相位冻结低位，`n_DMC=1` 且标签随 base 滑。仅高位：小步长时高位冻结，同样塌缩。根因就一句：**G mod N 保格子；base 一平移，格子滑过 DMC/HA 分区，占用多重集变。** 人钉症状是 start-address 差 + 不同 stride ⇒ R/W BW 抖动；实验室 “same phase vs wrong phase” 就是这个 bug。

GF(2) 线性 XOR（M-1 类）能做到每个割切两侧都有支撑，从而相位不变。但它仍是线性码：4096 点的像落在一个仿射子空间，fold 到 384 后可能沿 2-幂方向成团。本卡在整数环上加一项 `x·y`，把 1D 格打成平面函数：固定相位差 `Δx` 时，DMC 对行走坐标 y 的导数含 `C·Δx·y`，斜率随 y 变，格子无法再被某个 base 停在 DMC 的真子群里。

约束：384 / 96 / 48 计数冻结；只动交织数据通路。单轴 2/96/2/48 都 <4096，必须两维一起吃这 4096 个自由度。Little：15360 inflight；均匀 ~40 outstanding/DMC；1D 坏相位 3 DMC × 5120。

## 2. 机制

把 2 MiB 内外拆成两个 12 bit 坐标，做一次双线性再 mod 384。

```
x = phys_addr[20:9]     // 12b，2 MiB 内；S=2 MiB 时冻结（相位）
y = phys_addr[32:21]    // 12b，哪个 2 MiB；S=2 MiB 时随 k 行走
xy_lo = (x * y)[11:0]   // 12×12 乘积低 12 bit = xy mod 2^12
DMC     = (A·x + B·y + C·xy_lo) mod 384
bank_in = (D·x + E·y) mod 48
```

系数全奇数且 ≇ 0 (mod 3)，使对 384=2^7·3 与 48=2^4·3 尽可能多的 Δx 可逆：

```
A=7, B=11, C=5, D=5, E=7
```

7≡1, 11≡2, 5≡2 (mod 3)；全部为奇数。

### 结构

平面导数（忽略 12 bit 截断时的理想式）：

```
f(x+Δx, y) - f(x, y) = A·Δx + C·Δx·y     （在 Z 上，再 mod 384）
```

对固定 Δx，这是 y 的仿射函数，斜率 `C·Δx = 5·Δx`。若 `gcd(5Δx, 384)=1`，y 走 0..4095 时 DMC 走 384 的长循环，**循环长度与 base x 无关**——相位不能把格停在 DMC 子集里。`gcd=3` 时循环长 128，占用计数仍与 x 无关，只是陪集标签转。这是本卡相对纯 GF(2) 线性的增量：破坏残留的线性子空间成团。

12 bit 截断是实现，不是 Z/384 上的双线性。`(xy)[11:0] = xy - q·4096`，`4096 ≡ 256 (mod 384)`，多一项 `-C·q·256`。评估必须按截断+fold 的真实电路建模，不能用理想双线性代替。

残余（必须写进评估，不是藏）：`B+C x = 11+5x`。x=1 时斜率 =16，`gcd(16,384)=16`，`n_DMC=24`。x≡17 (mod 128) 时 `11+5x ≡ 0 (mod 128)`，`n_DMC | 3`。奇数 Δx 上 `gcd(5Δx,384)` 取 1 的有 1365/2048，取 3 的有 683/2048。这是 medium-high 而不是 high 的原因：平面论证在“足够多的 Δx 可逆”上成立，不是对所有相位。系数按题目给定，不改 A,B,C 去“调过”这几个坏剩余类——那是另一张卡。

bank 轴：`gcd(5,48)=gcd(7,48)=1`，x 或 y 任一满扫，bank_in 满 48。S=2 MiB 时 y 走 4096，bank 占用 85 或 86，CV≈0。

### 数据路径

1. 12×12 无符号乘法得 `xy`（24 bit），截 `[11:0]`。一拍。
2. 常数乘用移位加，**不**做通用乘法：
   - `7x = (x<<3) - x`
   - `11y = (y<<3) + (y<<1) + y`
   - `5·xy_lo = (xy_lo<<2) + xy_lo`
   - `5x = (x<<2) + x`，`7y = (y<<3) - y`（bank 通路）
3. 三项在 9 bit 域相加：每个 12 bit 量先 fold384 到 [0,383]（见下），再 9 bit 加法器链，和 < 3×383，再最多两次“≥384 则减 384”。
4. 12 bit → mod 384 的组合折合：384=256+128。对 12 bit n，先用 n[11:8] 做粗商（n>>8 最大 15；384×10=3840，384×11=4224>4095），ROM/比较器选 0..10，`n - q*384`，一次 CSA + 一次校正。不要 10 级串行减法。

fold384 硬件语义与 M-3 的 9 bit 版不同：这里输入 12 bit（0..4095），`4096 = 10×384 + 256`，折合后 256 个 DMC 得 11 次、128 个得 10 次——这是 covering 偏置，相位不变当且仅当 12 bit 像在 Z/4096 上均匀。坏相位（斜率 gcd 大）时像本身不是均匀的，fold 救不了。

### Partial-good

同一张 384×48-bit = 2.25 KB 位图 + 48:6 PE，1-cycle retry 到同 DMC 下一好 bank。不增加控制器，不增加带宽。双线性输出的是 (DMC, bank_in) 猜测，位图是唯一的额外状态。

### 时序

拍 1：12×12 乘法（xy_lo）与四路移位加并行（Ax, By, Dx, Ey）。拍 2：C·xy_lo、三路 9 bit 加、fold384、bank mod 48。2 mapper cycle。不增加 outstanding 缓冲；2 拍地址产生在 128 deep 队列后完全隐藏。

## 3. 为什么有效

格子+phase。S=2 MiB：x 冻结为 base，y=0..4095 行走。`f(y) = (Ax + By + C(xy mod 2^12)) mod 384` 对 y 近似仿射，斜率 `B+Cx`（截断扰动下）。斜率与 384 互素时，y 的 4096 点是 384 上的 10 或 11 次覆盖，maxload=11，CV≈0.044，**与 x 无关**。1D 的 `G mod 384` 斜率是常数 4096≡256，gcd=128，永远 3 点循环——相位只旋转那 3 个标签。平面项让斜率变成 x 的函数，多数 x 把 gcd 打到 1。

Latin 不在 GF(2)，在 Z/384Z 的长循环：对好 x，像是单条 Hamilton 循环的 4096/384 覆盖，没有空桶。坏 x 退化为短循环（24 或 3 DMC），这是本卡的可证伪点，评估必须扫到 x=1 与 x=17+128t。

Balls-and-bins：不是随机抛球；是确定性模循环。均匀时 4096 球 / 384 桶 ≈10.67。1D 坏相位 4096/3≈1365 球/桶。Little：15360 inflight 在 384 DMC ~40/DMC；塌到 24 DMC 时 640/DMC，BW 按控制器数掉一个数量级——这正是 min/mean 随 base 跨 0.85 的候选。本卡不把这说成已经修好，而是把这些 base 列为必测。

Discrepancy：好相位下 12 bit 均匀像经 fold384 的 discrepancy 就是 11 vs 10 的 covering（相对 10.67 为 ±3%），进入 BW 相对差的是 base 间差，不是这 ±3%。

## 4. 评估计划

- 基线：`G mod 384`；顺序低位交织；仅高位交织。
- 指标：min/mean BW vs base 的相对差、`n_DMC(base)`、每 HA/DMC occupancy CV。主指标 base 不变性（相对差 <5%，n_DMC 变化 <10%）。把 `n_DMC=min(384,K)` 当次指标。
- 负载：固定 S 扫 base∈一页 `0..4K-512` 步 512 B（覆盖 x=0 与 x=1），以及 2 MiB 窗内平移（覆盖 x≡17 mod 128 的 32 个 12 bit 类）。S∈{2 MiB, 1 MiB, 512 KB, 4608 B, 512 B}。partial-good 1/16 bank。inflight 15360。
- **必须 cycle 级建模的结构**：12×12 乘法器；移位加常数乘（7/11/5）；12 bit→mod 384 折合（含 4096≡256 的截断层）；9 bit 加法链与最多 2 次减 384；2.25 KB 位图。禁止用 `f= (7x+11y+5*x*y) % 384` 在无限整数上代替 `[11:0]` 截断。
- 预期收益与置信度：好相位相对 1D 从 3 DMC/maxload 1366 到 384 DMC/maxload 11，inflight 从 5120 降到 ~40。置信度中高：平面导数在 gcd(CΔx,384)=1 时可证；残余坏剩余类（x=1 → n_DMC=24；x≡17 mod 128 → n_DMC|3）会使跨 base 的 n_DMC 相对差达到 O(1)，**这是本卡可能被证伪的路径**。不作过关宣称。

## 5. 硬件开销估算

- 12×12 乘法：~144 全加器，5 nm <0.005 mm²，1 拍。
- 移位加：四路 12 bit 加减，可忽略。
- fold384：一组 12×4 粗商 + CSA，组合进第 2 拍。
- 位图 2.25 KB + 48:6 PE，与 M-1 相同。
- 不增加 384 DMC / 18432 bank / 96 HA，不加带宽，不加 outstanding 缓冲。
- 2 cycle；功耗 mW 级（乘法器动态 + SRAM 1R）。面积主导仍是 2.25 KB 位图，乘法器次之。
