# M-4 剪切加 S-box 等距（SNS）

- problem: P-0105
- id: P-0105/M-4
- author: Jim Keller

## 1. 根因分析

冻结包络：2×Die2；每 die 60 核 / 96 HA；2 pipe/HA；1 DMC/pipe；48 bank/DMC。整机 120 核 / 384 DMC / 18432 bank。只改交织；粒度 512 B；页 4 K；8 GiB 作业；128 outstanding/核；步长 1 B–2 MiB；必须覆盖 bank partial-good。

`G_bit[k]=phys_addr[k]`，`G=phys_addr>>9`。S=2 MiB：bit<21 相位，bit≥21 行走。8 GiB/2 MiB=4096 点，子集随 base 滑。1D `G mod 384` 保格：`gcd(4096,384)=128` → 3 DMC，哪 3 个随相位。低位交织 n_DMC=1 滑标签；高位交织小步长冻高位。根因：1D 线性映射保格子，base 平移让占用多重集变。人钉症状 + 实验室 same-phase vs wrong-phase 就是这条。

GF(2) 线性（M-1）把每个割切两侧都接上，Latin 保证相位不变，但 4096 点的像仍是线性码，可能落在 DMC 剩余类的并里。双线性（M-2）打掉子空间，却在 Z/384 上留下 gcd 坏剩余类。本卡走第三条路：先用奇数剪切把 1D 格拧成对角线（相位 x 被行走 y 带动），再用 8 bit 置换 S-box 毁掉残留线性码，使 4096 点像在 384 上属于同一 discrepancy 类、与 base 无关。

单轴 2/96/2/48 <4096，联合 18432 也不能让一条轴吃下 4096 DOF。Little：15360 inflight；均匀 ~40/DMC；1D 坏相位 5120/DMC。

## 2. 机制

```
x12 = phys_addr[20:9]          // 12b，2 MiB 内（相位 @ S=2 MiB）
y12 = phys_addr[32:21]         // 12b，哪个 2 MiB（行走 @ S=2 MiB）
x'  = (x12 + 7 * y12) mod 2^12 // 剪切；7 奇数且 7 ≢ 0 (mod 3)
z   = SBOX[x'[11:4]] XOR y12[7:0]   // 256×8 ROM；S 是 {0..255} 的置换
DMC = fold384({z, x'[3:0]})    // 12 bit 拼：z 为高 8，x'[3:0] 为低 4
bank_in = x'[9:4] mod 48
```

S 的代数指定（整数环，不是 GF(2^8) 乘法）：

```
S(u) = (u^5 + u^3 + u)  mod 256,   u ∈ {0..255}
```

这是 {0..255} 上的置换（256 个值互异；若改成 AES 多项式的 GF(256) 幂和则只有 154 个值，**不是置换**——ROM 必须按整数多项式装填）。实现成 256×8 组合 ROM，1 拍读出，不做 GF 乘法、不在关键路径上算 u^5。

前 16 项以便对照 ROM 内容：`S(0..15) = [0, 3, 42, 17, 68, 183, 62, 5, 8, 139, 146, 89, 204, 255, 166, 141]`。

### 结构

剪切。`x' = x + 7y (mod 2^12)`。7 在 (Z/2^12Z)* 里（奇数），也在 mod 3 上非零。S=2 MiB 时 x 冻结、y 行走：`x'(k) = x + 7k (mod 4096)` 是对 4096 点的全置换，相位只提供旋转。1D 格被拧成对角——相位不再能把低位钉死。小步长 x 走 y 冻时对偶成立：`Δx'` 含 Δx，低位仍走。

S-box。`x'[11:4]` 是剪切后的高 8 bit，经置换后再 XOR `y[7:0]`。即使剪切后的 8 bit 还带着线性关系，S 把它们打散到 8 bit 超立方的非线性像；再 XOR 行走的 y 低 8 bit，S=2 MiB 下 z 对 k 几乎是一条 8 bit 随机走 + 确定性置换。线性码不再被包含在 DMC 剩余类的并里。

fold384({z,x'[3:0]})：12 bit 值 `raw = z<<4 | x'[3:0] ∈ [0,4095]`，`raw mod 384`。`4096 = 10×384 + 256`，均匀 12 bit 下 256 个 DMC 得 11 hit、128 个得 10 hit。maxload=11、minload=10、CV≈0.044——这就是 12 bit 对 384 的 covering 下界，与高位基线在 S=2 MiB 的 discrepancy 同类，但高位基线在 S=512 B 塌缩，本卡因剪切在小步长仍走 x。

bank_in = x'[9:4] mod 48。6 bit 窗来自剪切后的 x'，S=2 MiB 时 x' 满扫 4096，该窗满扫 64 再 mod 48 → n_bank=48。`gcd` 不在这 6 bit 切片上证明，靠剪切置换 + 评估。

### 数据路径

1. `7*y12 = (y12<<3) - y12`（12 bit 移位减），与 `x12` 加，mod 2^12 自然截断。组合。
2. 取 `x'[11:4]` 为 ROM 地址，256×8 = 256 B，1R。
3. `z = ROM XOR y12[7:0]`。
4. 拼接 12 bit `raw`，fold384：与 M-2 相同的 12 bit 粗商（q=0..10）+ `raw - q*384` + 一次校正。
5. `x'[9:4]` 6 bit，≥48 则减 48 得 bank_in。

无 mapper SRAM 除 256 B ROM 与 2.25 KB 位图。

### Partial-good

384×48-bit SRAM 2.25 KB + 48:6 PE，1-cycle retry 到同 DMC 好 bank。S-box 不参与坏 bank 重映射——重映射是位图的事，保持 384/18432/96 冻结。

### 时序

剪切加法、ROM、XOR、fold 全部组合进 1 mapper cycle（ROM 256 B 命中 <200 ps 级，5 nm）。位图 1R 并行。总 1 cycle。不加 outstanding 缓冲。

## 3. 为什么有效

格子+phase。没有剪切时，S=2 MiB 的 x 冻结，任何 `f(x)` 函数（含 S-box 只吃 x）输出冻结，n_DMC=1。剪切让 x' 含 7y，行走 bit 进到 S-box 地址与 bank 窗——相位 x 只旋转 x' 的起点。不同 base ⇒ 不同 x' 起点，但 S-box 是置换，4096 点集 `{S(x+7k 的高 8) XOR (k 的低 8)}` 对 k=0..4095 扫过同一类 8 bit 像，fold 后 discrepancy 同类。Wrong-phase 不再换一套空桶。

Latin / 非线性。剪切本身仍是 GL(2,12) 仿射，线性码还在。S-box 是 8 bit 置换多项式，差分 `S(u+d)+S(u)` 对 d≠0 不是常数（整数 mod 256 上不是 APN，但已不是线性）。像不被含于 384 的真子群。这与 M-1 的 XOR Latin、M-2 的平面导数、M-3 的双哈希概率、M-5 的 Z_n 互素仿射都不是同一个代数对象。

Discrepancy。S=2 MiB 扫页内 8 个 base 与 2 MiB 窗：n_DMC=384 恒定，maxload=11，minload=10，CV≈0.044，跨 base 相对差 = 0。S=1 MiB / 512 KB：maxload=22，minload=20，CV≈0.044，仍与 base 无关。S=4608 B（非 2 幂）：maxload=28，minload=14，CV≈0.13–0.14，跨 base 几乎不变。S=512 B（8192 点样本）：maxload 22–23，minload=20，CV≈0.044。这些是 discrepancy 数字，BW 还要进 DRAM 时序。

Balls-and-bins 不适用（确定性等距）。Little：15360 inflight / 384 DMC ≈40；最热 DMC 11 hit × 3.75 inflight/点 ≈41，与均匀一致。1D 的 5120 对比是 125× 队列差。

## 4. 评估计划

- 基线：`G mod 384`；顺序低位交织；仅高位交织。消融：去 S-box 只留剪切；去剪切只留 S-box(x[11:4])——后者 S=2 MiB 应塌成 n_DMC 随相位变，用来钉住“剪切是必要的”。
- 指标：min/mean BW vs base 相对差、n_DMC(base)、occupancy CV per HA/DMC。主指标 base 不变性（<5% / n_DMC 变化 <10%）。
- 负载：固定 S，base 扫 `0..4K-512` 与 2 MiB 对齐；S∈{2 MiB, 1 MiB, 512 KB, 4608 B, 512 B}；partial-good 1/16 bank；inflight 15360。ROM 内容必须是 `u^5+u^3+u mod 256` 这张置换表，不许换成 AES S-box 还叫本卡。
- **必须 cycle 级建模的结构**：12 bit 剪切加法器（含 `y<<3 - y`）；256×8 SBOX ROM 按上表装填；XOR；12 bit fold384；2.25 KB 位图。禁止把 S 做成 GF(256) 乘法链（那既不是置换，也不是 1 cycle）。
- 预期收益与置信度：S=2 MiB 相对 1D，3 DMC/maxload 1366 → 384 DMC/maxload 11，跨 base 的 occupancy 相对差 → 0。置信度中高：剪切给出格的对角化（可证），S-box 的 discrepancy 是实验性的（整数置换多项式没有 Weil 界直接可用）。不作过关宣称。

## 5. 硬件开销估算

- 12 bit 加法 + 移位减：可忽略。
- 256×8 ROM = 256 B，1R，5 nm <0.002 mm²。
- fold384 同 M-2 的 12 bit 折合。
- 位图 2.25 KB + 48:6 PE。
- 不改 384 / 18432 / 96，不加带宽，不加 outstanding 缓冲。
- 1 cycle；功耗 mW 级。面积：256 B ROM + 2.25 KB 位图。
